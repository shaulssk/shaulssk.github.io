UDISE+ ಪೂರ್ಣ ಮಾರ್ಗದರ್ಶಿ 2026-27

Unified District Information System for Education+ · ಶಾಲಾ ಸಿಬ್ಬಂದಿಗೆ · ಕೊನೆಯ ನವೀಕರಣ: 06-09-2026

UDISE+ — ಭಾರತದ ಎಲ್ಲಾ ಮಾನ್ಯತೆ ಪಡೆದ ಶಾಲೆಗಳ ಸಮಗ್ರ ದತ್ತಾಂಶ ಸಂಗ್ರಹಣಾ ವ್ಯವಸ್ಥೆ (Ministry of Education / NIEPA). ಪ್ರತಿ ಶಾಲೆಗೆ 11-ಅಂಕಿಯ UDISE+ ಕೋಡ್ — ಶಾಲೆಯ profile, teachers, students, infrastructure, finances ಎಲ್ಲವೂ ಈ ವ್ಯವಸ್ಥೆಗೆ ಸೇರುತ್ತದೆ. PM POSHAN, Samagra Shiksha, RTE infrastructure ಅನುದಾನಗಳು UDISE+ ದತ್ತಾಂಶದಿಂದಲೇ compute ಆಗುತ್ತವೆ — ಇದಕ್ಕೆ ಶಾಲೆ certify + freeze ಮಾಡಬೇಕು.

⚠️ ಮುಖ್ಯ ಸೂಚನೆ: 2026-27 cycle ನ Reference Date — 30 ಸೆಪ್ಟೆಂಬರ್ 2026 (ರಾಷ್ಟ್ರೀಯ). ಕರ್ನಾಟಕ State Project Office ಸಹ data submission ಅನ್ನು ಆ ದಿನಾಂಕಕ್ಕೆ ನಿಗದಿ ಮಾಡಿದೆ. ದಿನಾಂಕ/ಮೆನು ಬದಲಾದರೆ ನಿಮ್ಮ BEO/DDPI ಸೂಚನೆಗಳೇ ಅಂತಿಮ.

🌐 UDISE+ Portal 📊 SDMS (Student Module) Login

1. ಯಾವ ಮಾಡ್ಯೂಲ್, ಯಾರು?

ಮಾಡ್ಯೂಲ್ಯಾರು ಬಳಸುವುದುಏನು ನಮೂದಿಸುವುದು
School Profile & Facilitiesಮುಖ್ಯಗುru (Principal/HM)ಕಟ್ಟಡ, ತರಗತಿ ಕೊಠಡಿ, ಶೌಚಾಲಯ, ನೀರು, ವಿದ್ಯುತ್, ICT, ಗ್ರಂಥಾಲಯ
SDMS (Student Module)ಡೇಟಾ ಎಂಟ್ರಿ ಆಪರೇಟರ್ವಿದ್ಯಾರ್ಥಿ ದಾಖಲಾತಿ, progression, ಪ್ರವೇಶ, APAAR ID, CWSN
Teacher Moduleಶಾಲೆ / BEOಶಿಕ್ಷಕರ ವಿವರ, ಅರ್ಹತೆ, ನೇಮಕ
UD Moduleಜಿಲ್ಲಾ/ರಾಜ್ಯ ಅಧಿಕಾರಿಗಳುಪರಿಶೀಲನೆ, validation, data lock

2. Login ಹೇಗೆ?

1

udiseplus.gov.in open → SDMS Login (ವಿದ್ಯಾರ್ಥಿ module) ಆಯ್ಕೆ.

2

State = ಕರ್ನಾಟಕ ಆಯ್ಕೆ — ತಪ್ಪಿದರೆ login error ಬರುತ್ತದೆ.

3

UDISE code (11 ಅಂಕಿ) username ಆಗಿ; password + captcha ನಮೂದಿಸಿ. Password BEO/DDPI/Block MIS coordinator ಕೊಡುತ್ತಾರೆ.

4

ಮೇಲೆ academic year 2026-27 ಕಾಣುತ್ತಿದೆಯೇ check — ಹಳೆಯ ವರ್ಷ ಕಂಡರೆ view-only mode (ನಮೂದಿಗೆ ಆಗುವುದಿಲ್ಲ).

3. ಡೇಟಾ ಎಂಟ್ರಿ ಸರಿಯಾದ ಸರಣಿ

✅ ಕ್ರಮ ಹೀಗಿದೆ: Student Progression (ಹಿಂದಿನ ವರ್ಷ) → New Admissions → APAAR ID → CWSN/ವಿವರ → Validate → Certify → Freeze. Progression finalize ಮಾಡದೆ ಹೊಸ ವರ್ಷದ entry ಆಗುವುದಿಲ್ಲ.

4. Student Progression (ಹಿಂದಿನ ವರ್ಷ 2025-26)

1

Student Management → Student Progression open.

2

ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ status: Promoted (ಮುಂದಿನ ತರಗತಿ) / Detained (ಅದೇ ತರಗತಿ) / Left with TC (TC ಸಂಖ್ಯೆ + ದಿನಾಂಕ) / Dropout (ಕಾರಣ ಸಹಿತ).

3

ಪ್ರತಿ ತರಗತಿ ಕೊನೆಯಲ್ಲಿ save + confirm — duplicate counting ತಪ್ಪುತ್ತದೆ.

5. New Admissions (2026-27)

1

Student Management → New Admission → Add New Student.

2

ಹೆಸರು (birth certificate/Aadhaar ಪ್ರಕಾರ), DOB (DD/MM/YYYY), ಲಿಂಗ, admission number, admission date, class & section, category (SC/ST/OBC/EWS/General), Aadhaar, ತಾಯಿಯ ಹೆಸರು, contact.

3

Aadhaar ಇಲ್ಲದಿದ್ದರೆ "Aadhaar Not Available" tick + ಕಾರಣ ನೀಡಿ.

4

100+ ವಿದ್ಯಾರ್ಥಿ ಇದ್ದರೆ Excel bulk upload template ಬಳಸಿ (ಸಮಯ ಉಳಿತಾಯ).

6. APAAR ID (2026-27 ನಿಂದ ಕಡ್ಡಾಯ)

  • ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ 12-ಅಂಕಿಯ APAAR ID (NEP 2020 ಅಡಿ) — SDMS ನಲ್ಲೇ ಸಿಗುತ್ತದೆ; ಹಳೆಯದಿದ್ದರೆ "Verify", ಹೊಸದಾದರೆ "Generate New".
  • ಪೋಷಕರ digital consent ಕಡ್ಡಾಯ — consent form generate → ಸಹಿ → upload.
  • Consent pending ಇದ್ದರೆ "Consent Pending" ಆಗಿ ಇಡಬಹುದು, ಆದರೆ freeze ಗಿಂತ ಮೊದಲು ಪೂರ್ಣಗೊಳಿಸಿ.
  • APAAR ಇಲ್ಲದಿದ್ದರೆ data certification block ಆಗಬಹುದು.

7. Verify → Certify → Freeze

1

Data Validation Report run — ದೋಷಗಳನ್ನು ತಿದ್ದಿ (duplicate Aadhaar, invalid DOB, missing APAAR).

2

Admission register ಜೊತೆ ಒಟ್ಟು ದಾಖಲಾತಿ ಕ್ರಾಸ್-ಚೆಕ್ ಮಾಡಿ.

3

Certify Data → ಮುಖ್ಯಶಿಕ್ಷಕರ approve → Freeze Data (30 ಸೆಪ್ಟೆಂಬರ್ 2026 ಒಳಗೆ).

4

Freeze ನಂತರ: ದೋಷ → Request for Change module ನಲ್ಲಿ,DEO formal approval ಇಲ್ಲದೆ ಯಾವುದೇ change ಆಗುವುದಿಲ್ಲ. ಮಧ್ಯದಲ್ಲಿ ಸೇರುವ ವಿದ್ಯಾರ್ಥಿ → Mid-Year Admission module (ನವೆಂಬರ್ ಮುಂದಿನ period).

8. ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು & ಪರಿಹಾರ

ಸಮಸ್ಯೆಪರಿಹಾರ
Login rejected — ತಪ್ಪು stateಕರ್ನಾಟಕ ಆಯ್ಕೆ ಮಾಡಿರಿ; UDISE code 11-ಅಂಕಿ complete ಇರಲಿ.
User locked (3 attempts)ಸ್ವಲ್ಪ ಸಮಯ ಕಾಯ್ದು ಅಥವಾ Block MIS coordinator ನಿಂದ unlock/ಘರ್ಷಣೆ.
Password resetBRC/Block coordinator — reset ಗೆ 2–3 ಕೆಲಸದ ದಿನ.
Progression complete ಮಾಡದೆ ಹೊಸ entryಪೋರ್ಟಲ್ block ಮಾಡುತ್ತದೆ — ಹಿಂದಿನ ವರ್ಷ finalize ಮೊದಲು ಮುಗಿಸಿ.
Duplicate Aadhaar / invalid DOBValidation report ನಿಂದ ಪಟ್ಟಿ → register ಪರಿಶೀಲಿಸಿ → correct ಮಾಡಿ.
APAAR ID missingGenerate/verify ಎಲ್ಲಾ ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ; ಪೋಷಕ consent ಮುಗಿಸಿ.
Freeze ಆದಮೇಲೆ changeRequest for Change + DEO approval (5–7 ಕೆಲಸದ ದಿನ).

9. ಪ್ರಮುಖ ಅಂಶಗಳು ⭐

  • Freeze missed = zero allocation: PM POSHAN, Samagra Shiksha, RTE infrastructure ಅನುದಾನಕ್ಕೆ ಶಾಲೆ certify+freeze ಮಾಡದಿದ್ದರೆ ಆ cycle ಗೆ ಏನೂ ಸಿಗುವುದಿಲ್ಲ.
  • Keep records open: ನೋಂದಣಿ register, TC register, staff details — ಡೇಟಾ ಎಂಟ್ರಿ ಮಾಡುವಾಗ physically open ಇರಲಿ; "ಆಮೇಲೆ ಸರಿಪಡಿಸುತ್ತೇನೆ" ಬೇಡ.
  • ಒಬ್ಬ ಮುಖ್ಯ: ಒಬ್ಬರು enter, ಇನ್ನೊಬ್ಬರು cross-check — 10 ನಿಮಿಷ review.
  • ಕೊನೇ ದಿನ ಬೇಡ: portal traffic spike — ವೇಳಾಪಟ್ಟಿಗಿಂತ ಒಂದು ವಾರ ಮುಂಚಿತವೇ submit.
  • Reports save: preview PDF, reports, verification screenshot — ಒಂದು folder ನಲ್ಲಿ ದಾಖಲಿಸಿ.

10. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. UDISE code ಸಿಗುತ್ತಿಲ್ಲ — ಎಲ್ಲಿಂದ ತರುವುದು?

ಹಿಂದಿನ ವರ್ಷದ UDISE report ನಲ್ಲಿ, recognition certificate ನಲ್ಲಿ, ಅಥವಾ BEO/DDPI office ನಿಂದ. 11-ಅಂಕಿಯ code ಕರ್ನಾಟಕದ್ದು "29" ಆರಂಭ.

2. ಹಳೆಯ ವರ್ಷದ ದತ್ತಾಂಶ lock ಆಗಿದೆ — ಸರಿಪಡಿಸಲು ಹೊಸ ವರ್ಷದ entry ಆಗುತ್ತದೆಯೇ?

ಹಳೆಯ ವರ್ಷ complete ಆದಾಗ ಮಾತ್ರ ಹೊಸ ವರ್ಷದ entry ಆಗುತ್ತದೆ. Lock ಆಗಿದ್ದರೆ block/district MIS ನಿಂದ unlock/change request.

3. APAAR ID ಮಾಡಲು ಒಂದು student ನ consent ಬರುವುದಿಲ್ಲ — freeze ಆಗುತ್ತದೆಯೇ?

"Consent Pending" ಆಗಿ enter ಮಾಡಬಹುದು, ಆದರೆ freeze ಮೊದಲು consent + APAAR ಪೂರ್ಣಗೊಳಿಸುವಂತೆ ಇಲಾಖೆ ನಿರೀಕ್ಷಿಸುತ್ತದೆ — ಬೇಗನೆ ಮುಗಿಸಿ.

4. November ನಲ್ಲಿ ಹೊಸ ವಿದ್ಯಾರ್ಥಿ ಸೇರಿದರೆ ಏನು?

Freeze ನಂತರ Mid-Year Admission module ಮೂಲಕ — ಮುಖ್ಯ baseline ಗೆ ಸೇರದೆ supplementary ನಲ್ಲಿ ಬರುತ್ತದೆ, ಮುಂದಿನ ವರ್ಷದ ದಾಖಲೆಗೆ.

5. Error "invalid" ಎನ್ನುತ್ತಿದೆ — ಯಾರನ್ನು ಕೇಳುವುದು?

Block MIS coordinator / BRC ಮೊದಲನೆಯ; ಆಗದಿದ್ದರೆ ಜಿಲ್ಲಾ (DDPI) MIS; ರಾಷ್ಟ್ರೀಯ helpdesk ಹಂತಕ್ಕೆ udiseplus@nic.in / 011-24305493.
