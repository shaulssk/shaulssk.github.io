Nirantara App — ತಪ್ಪು ನೋಂದಣಿಯಾದ ವಿದ್ಯಾರ್ಥಿಯನ್ನು Delete ಮಾಡುವ ವಿಧಾನ

ನಿರಂತರ Attendance App · Wrong / Duplicate Student Entry Remove · ಕೊನೆಯ ನವೀಕರಣ / Last updated: 16-09-2026
Last verified / ಕೊನೆಯ ಪರಿಶೀಲನೆ: 16 September 2026

✍️ Written by Shaul SSK · shaulssk.in · ಸ್ವತಂತ್ರ ಕನ್ನಡ ಶಾಲಾ-ದತ್ತಾಂಶ ಮಾರ್ಗದರ್ಶಿ

ℹ️ Nirantara is a government school-attendance system. This article is an independent guide and is not an official government page.
ಇದು ಸರ್ಕಾರದ ಅಧಿಕೃತ ಪುಟವಲ್ಲ — ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ.

📋 Official Source / ಅಧಿಕೃತ ಮೂಲ: ನಿರಂತರ (Nirantara) — ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ವಿದ್ಯಾರ್ಥಿ ಹಾಜರಾತಿ ವ್ಯವಸ್ಥೆ — nirantara.karnataka.gov.in · Web Portal Grievance: nirantara.karnataka.gov.in/grievance · ಮೊಬೈಲ್ ಆ್ಯಪ್ (Play Store).

✅ Last verified: 16 September 2026

ℹ️ Note: App ಆವೃತ್ತಿ/ಮೆನು ಹೆಸರುಗಳು ಬದಲಾಗಬಹುದು; ತಪ್ಪು ನೋಂದಣಿ delete ಗೆ ಕೆಲವು ಬಳಕೆದಾರರಿಗೆ App ನಲ್ಲಿ delete option ಇಲ್ಲದಿದ್ದರೆ Web Portal ನ Grievance ಮೂಲಕ ದೂರು ನೀಡಬೇಕಾಗುತ್ತದೆ — ಕೆಳಗಿನ 2 ಮಾರ್ಗಗಳನ್ನು ನೋಡಿ.

ಯಾವಾಗ ಬೇಕು: ಶಾಲೆಯಲ್ಲಿ ತಪ್ಪಾಗಿ ನೋಂದಣಿಯಾದ ವಿದ್ಯಾರ್ಥಿ (ಉದಾ. ತಪ್ಪು ಹೆಸರು/ವರ್ಗದ ಮಗು) ಅಥವಾ Duplicate registration (ಒಬ್ಬನೇ ಮಗು ಎರಡು ಬಾರಿ ನೋಂದಣಿ ಆಗಿರುವುದು) ಕಂಡುಬಂದಾಗ — ಆಗ ಆ entry ಯನ್ನು delete ಮಾಡಬೇಕಾಗುತ್ತದೆ.

1. ಮಾರ್ಗ-1 — App ನಲ್ಲಿ delete option ಇದ್ದರೆ (Step-by-Step)

1

App ಓಪನ್ ಮಾಡಿ (Open App): ನಿರಂತರ ಮೊಬೈಲ್ ಆ್ಯಪ್‌ಗೆ ನಿಮ್ಮ ರುಜುವಾತುಗಳಿಂದ (login credentials) ಲಾಗಿನ್ ಆಗಿ.

2

ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿ ತೆರೆಯಿರಿ (Student List): ತಪ್ಪುನೋಂದಣಿ ಇರುವ ವರ್ಗ/ಶಾಲೆಯ ನೋಂದಾಯಿತ ವಿದ್ಯಾರ್ಥಿಗಳ ವಿವರ (student list/profile) ತೆರೆದು ಪ್ರತಿ ಮಗುವಿನ ಹೆಸರು/ಫೋಟೋ ಪರಿಶೀಲಿಸಿ.

3

Delete ಆಯ್ಕೆ ಮಾಡಿ (Select Delete): ತಪ್ಪುನೋಂದಣಿಯಾದ ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರು/ಫೋಟೋ ಪಕ್ಕದಲ್ಲಿ ಇರುವ Delete option / icon ಕ್ಲಿಕ್ ಮಾಡಿ.

4

ಸರಿಯಾದ ಕಾರಣ ಆಯ್ಕೆ (Choose Delete Reason): App ನಲ್ಲಿ allowed ಇರುವ valid reason ಆಯ್ಕೆ ಮಾಡಿ — ಉದಾಹರಣೆಗೆ "Wrong student registered" (ತಪ್ಪು ಮಗು ನೋಂದಣಿಯಾಗಿದೆ) ಅಥವಾ "Duplicate registration" (ಇಬ್ಬಗಿಯ ನೋಂದಣಿ).

5

ಖಚಿತಪಡಿಸಿ (Confirm): Submit / Confirm ಒತ್ತಿ — ಆಗ ತಪ್ಪು ನಮೂದು ವ್ಯವಸ್ಥೆಯಿಂದ ಅಳಿಸಲಾಗುತ್ತದೆ.

2. ಮಾರ್ಗ-2 — ನಿರಂತರ Web Portal ನ Grievance ಮೂಲಕ delete (ಅಧಿಕೃತ)

ಹಲವು ಶಾಲೆಗಳಿಗೆ ತಪ್ಪು ನೋಂದಣಿಯ ವಿದ್ಯಾರ್ಥಿಯನ್ನು App ನಲ್ಲಿ ನೇರ delete ಮಾಡಲು ಆಗುವುದಿಲ್ಲ — ಆಗ ಅಧಿಕೃತ ನಿರಂತರ Web Portal ನ Grievance ವಿಭಾಗದಲ್ಲಿ ದೂರು ಸಲ್ಲಿಸಬೇಕು.

Grievance ಮೂಲಕ delete ಮಾಡುವ ಹಂತಗಳು:

  1. Portal ತೆರೆಯಿರಿ: ಬ್ರೌಸರ್‌ನಲ್ಲಿ nirantara.karnataka.gov.in/grievance — ನಿಮ್ಮ ಶಾಲೆಯ login ಅಗತ್ಯವಿರಬಹುದು.
  2. Issue Type ಆಯ್ಕೆ: ತಪ್ಪು ನೋಂದಣಿ/duplicate ಆಗಿದ್ದರೆ "Registration Issue" ಆಯ್ಕೆ ಮಾಡಿ (ದತ್ತಾಂಶ ಸಂಬಂಧವೆಂದರೆ "Data Issue").
  3. Description ಬರೆಯಿರಿ: ಉದಾ: "Student [ಹೆಸರು], STS/SATS ID [ಸಂಖ್ಯೆ] ತಪ್ಪಾಗಿ/ದುಪ್ಪಟ್ಟು ನೋಂದಣಿಯಾಗಿದೆ — ದಯವಿಟ್ಟು ಅಳಿಸಿರಿ" — ಶಾಲಾ ಹೆಸರು, ತಾಲೂಕು, ಜಿಲ್ಲೆ ಮತ್ತು ಮೊಬೈಲ್ ಸಂಖ್ಯೆ ಸೇರಿಸಿ.
  4. Screenshot/ಉದಾಹರಣೆ ಲಗತ್ತಿಸಿ: ತಪ್ಪು ನಮೂದು ಕಾಣುವ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ (+) ಬಟನ್ ಬಳಸಿ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ.
  5. Submit: ದೂರು ಸಲ್ಲಿಸಿ — Raised Grievance ಬಟನ್‌ನಲ್ಲಿ ಸ್ಥಿತಿ ಪರಿಶೀಲಿಸಿ (ಅನುಮೋದನೆಗೆ ಸಾಮಾನ್ಯವಾಗಿ ½ – 2 ದಿನ ಸಮಯ ಬೇಕಾಗಬಹುದು).

3. Delete ಮಾಡುವಾಗ ನೆನಪಿಡಿ

  • ಸರಿಯಾದ ಮಗುವನ್ನೇ ಆಯ್ಕೆ ಮಾಡಿ: Delete ಶಾಶ್ವತ (permanent) — ತಪ್ಪು ಮಗುವನ್ನು delete ಮಾಡದಂತೆ ಹೆಸರು/ಫೋಟೋ/ವರ್ಗ ಮೂರು ಬಾರಿ ಸರಿಪಡಿಸಿ.
  • Valid reason ಕಡ್ಡಾಯ: Delete ಮಾಡುವಾಗ ಸೂಕ್ತ ಕಾರಣವನ್ನು (allowed reason) ಮಾತ್ರ ಆಯ್ಕೆ ಮಾಡಿ — ಸರಿಯಾಗಿ ಕಾರಣ ನೀಡದಿದ್ದರೆ ಅದನ್ನು ನಿರಾಕರಿಸಬಹುದು / ದತ್ತಾಂಶ ತಪ್ಪಾಗಬಹುದು.
  • Duplicate ಸಂದರ್ಭ: ಒಬ್ಬನೇ ಮಗು ಎರಡು ನಮೂದಿದ್ದರೆ, ಒಂದನ್ನು ಮಾತ್ರ duplicate ಕಾರಣದೊಂದಿಗೆ delete ಮಾಡಿ — ವಿದ್ಯಾರ್ಥಿಯ ನಿಜವಾದ ನಮೂದು ಉಳಿಯುವಂತೆ ನೋಡಿ.
  • ಪರಿಶೀಲನೆ: Submit ಮೊದಲು ಹೆಸರು, UDISE/SATS ಹೆಸರು, ತರಗತಿ — ಎಲ್ಲವೂ verify ಮಾಡಿ.

4. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆ → ಪರಿಹಾರ

ಸಮಸ್ಯೆಏನು ಮಾಡಬೇಕು
Delete option ಕಾಣುತ್ತಿಲ್ಲ / disabled ಇದೆApp ಅಪ್ಡೇಟ್ ಮಾಡಿ; ಕೆಲವು ಪ್ರಕ್ರಿಯೆಗಳಲ್ಲಿ delete ಆಗುವುದು ಮುಕ್ತ ಅವಧಿಯಲ್ಲಿ ಮಾತ್ರ ಇರಬಹುದು — BEO/ಇಲಾಖಾ ಸೂಚನೆ ಪರಿಶೀಲಿಸಿ.
ಕಾರಣ ಪಟ್ಟಿಯಲ್ಲಿ ಸರಿಯಾದ option ಇಲ್ಲಹತ್ತಿರದ allowed option ಆಯ್ಕೆ ಮಾಡಿ (ಉದಾ. Wrong student registered / Duplicate registration) — ಅಥವಾ ಬ್ಲಾಕ್ (BEO) ನೋಡಲ್ ಅಧಿಕಾರಿಯನ್ನು ಸಂಪರ್ಕಿಸಿ.
Delete ಆದ್ರೂ student list ನಲ್ಲಿ ಕಾಣುತ್ತಿದ್ದಾರೆApp/app refresh; ಕೆಲವೊಮ್ಮೆ sync ಮತ್ತು ನಿರ್ವಾಹಕ ಅನುಮೋದನೆಗೆ ಸಮಯ ಹಿಡಿಯಬಹುದು — ಸ್ವಲ್ಪ ಬಿಟ್ಟು ನೋಡಿ, ಆಗದಿದ್ದರೆ DDPI/BEO ಸೂಚಿಸಿರಿ.
ತಪ್ಪಾಗಿ delete ಮಾಡಿದ್ದೇನೆಆ ಮಗುವನ್ನು ಮತ್ತೆ ಸರಿಯಾಗಿ ನೋಂದಣಿ (re-register) ಮಾಡಿ — ಅಗತ್ಯವಿದ್ದರೆ ತಪ್ಪು deletion ವರದಿ ಮಾಡಿ BEO ಗೆ ತಿಳಿಸಿ.

5. Delete ಮೊದಲು Checklist

  • ☑ 1. ಈ ಮಗು ನಿಜಕ್ಕೂ ತಪ್ಪು/duplicate ನಮೂದು ಎಂದು ಖಚಿತವಾಯಿತಾ?
  • ☑ 2. ಸರಿಯಾದ ಮಗುವಿನ ಹೆಸರು/ಫೋಟೋ/ವರ್ಗ ಆಯ್ಕೆಯಾಗಿದೆಯಾ?
  • ☑ 3. Delete ಮಾಡುವ ಮಗು ಪ್ರಸ್ತುತ ಹಾಜರಾತಿ/ವರ್ಗಾವಣೆ/TC ಯಾವುದೇ ಪ್ರಕ್ರಿಯೆಯಲ್ಲಿಲ್ಲವಾ?
  • ☑ 4. ಸೂಕ್ತ valid reason ಆಯ್ಕೆಯಾಗಿದೆಯಾ?
  • ☑ 5. Verify → Confirm → submit ನಂತರ ಪಟ್ಟಿ refresh ಮಾಡಿ ದೃಢೀಕರಿಸಿದ್ದೀರಾ?

6. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. Delete ಮಾಡಿದ ಮಗು ಮತ್ತೆ ಬರುತ್ತಾನೆಯೇ?

Delete ಮಾಡಿದ ನಮೂದು ವ್ಯವಸ್ಥೆಯಿಂದ ಅಳಿಸಲಾಗುತ್ತದೆ. ಅಗತ್ಯವಿದ್ದರೆ ಮಗುವನ್ನು ಹೊಸ ನೋಂದಣಿ (re-register) ಮಾಡಬಹುದು. Delete ಮೊದಲು ಚೆನ್ನಾಗಿ ಯೋಚಿಸಿ — ಶಾಲಾ ದಾಖಲೆ, SATS ಹೆಸರು ಮುಂತಾದವು ಬೇರೆಯೇ ಆಗಿರಬಹುದು.

2. Delete option ಯಾವಾಗ ಮಾತ್ರ ಇರುತ್ತದೆ?

ಸಾಮಾನ್ಯವಾಗಿ ನೋಂದಣಿ/ದತ್ತಾಂಶ ನಮೂದಿಸುವ ಅವಧಿಯಲ್ಲಿ (ಆ್ಯಪ್‌ನ ಸಕ್ರಿಯ window) delete/ಮಾರ್ಪಾಡು ಲಭ್ಯ ಇರಬಹುದು; ಮುಂದೆ freeze/monitor ಆದ ಮೇಲೆ ಇಲ್ಲವಾಗಬಹುದು — ಇಲಾಖಾ ಸೂಚನೆ ಮತ್ತು App ಆವೃತ್ತಿ ಪರಿಶೀಲಿಸಿ. Delete option ಇಲ್ಲದಿದ್ದರೆ ಮಾರ್ಗ-2 (Portal Grievance) ಬಳಸಿ.

3. Delete ಆಗದಿದ್ದರೆ ಏನು?

App ಉತ್ತಮಗೊಳಿಸಿ, internet ಪರಿಶೀಲಿಸಿ; ಆಗಲೂ ಆಗದಿದ್ದರೆ ಸಮಸ್ಯೆಯ ಉದಾಹರಣೆಯೊಂದಿಗೆ (screenshot) ನಿಮ್ಮ BEO ಬ್ಲಾಕ್ ನೋಡಲ್ / ಜಿಲ್ಲಾ ನೋಡಲ್ ಅಧಿಕಾರಿಗೆ ತಿಳಿಸಿ.

4. Delete ಮಾಡಿದರೆ attendance/ದತ್ತಾಂಶ ಏನಾಗುತ್ತದೆ?

ತಪ್ಪು ನಮೂದು remove ಆಗುತ್ತದೆ — ಆ ಮಗುವಿನ ತಪ್ಪು ದಾಖಲೆಗಳೂ delete ಆಗಬಹುದು. ಸರಿಯಾದ ವಿದ್ಯಾರ್ಥಿಯ ದಾಖಲೆ ಮುಟ್ಟದಂತೆ ಎಚ್ಚರ ವಹಿಸಿ.
