SATS FLN Assessment — SATS ಪೋರ್ಟಲ್ ಒಳಗಿನ Foundational Literacy & Numeracy (FLN) module. ಇದರಲ್ಲಿ ಮುಖ್ಯ ಶಿಕ್ಷಕರು/ಶಿಕ್ಷಕರು ವಿದ್ಯಾರ್ಥಿಗಳ ಮೂಲ ಕಲಿಕಾ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಕನ್ನಡ, ಇಂಗ್ಲಿಷ್ ಮತ್ತು ಗಣಿತ ಎಂಬ ಮೂರು ವಿಷಯಗಳಲ್ಲಿ ದಾಖಲಿಸುತ್ತಾರೆ. ಪ್ರತಿ ವಿಷಯದಲ್ಲಿ ನಾಲ್ಕು ಕಲಿಕಾ ಫಲಿತಾಂಶಗಳನ್ನು (LO1–LO4) ಮೌಲ್ಯಮಾಪನ ಮಾಡಿ level (ಉದಾ. A, B) ನಮೂದಿಸಲಾಗುತ್ತದೆ.

🗓️ FLN 2026-27 — ಇಲಾಖಾ ಸುತ್ತೋಲೆ (DSERT / DIET): ಪ್ರಾಥಮಿಕ ಮತ್ತು ಪ್ರೌಢಶಾಲೆಗಳ ಎಲ್ಲಾ ವಿದ್ಯಾರ್ಥಿಗಳು 2026-27 ಶೈಕ್ಷಣಿಕ ಸಾಲಿನೊಳಗೆ FLN ಪ್ರಾವೀಣ್ಯತೆ ಪಡೆಯುವ ಗುರಿ ಇದೆ. ಈ ನಿಟ್ಟಿನಲ್ಲಿ ಶಾಲಾ ಹಂತದಿಂದ ಜಿಲ್ಲಾ ಹಂತದವರೆಗೆ FLN ಪರಿಣಾಮಕಾರಿ ಅನುಷ್ಠಾನಕ್ಕಾಗಿ ಅಧಿಕಾರಿಗಳಿಗೆ ಶಾಲೆಗಳನ್ನು ದತ್ತು (adoption) ನೀಡಲಾಗಿದೆ. ಉಲ್ಲೇಖ ಪತ್ರಗಳು: E-110911/DSERT/NEP/ECCE/15/2025-TECD (07-08-2026) ಮತ್ತು E-110911/DSERT/NEP/ECCE/15/2026-TECD (21-09-2026).

📌 ಪ್ರಮುಖ ಅಂಶಗಳು:

  • ಕಲಿಕಾ ಫಲಗಳು: 4–10ನೇ ತರಗತಿಯ ಪ್ರಥಮ ಭಾಷೆ, ದ್ವಿತೀಯ ಭಾಷೆ ಮತ್ತು ಗಣಿತಗಳಿಗೆ ಏಕರೂಪದ FLN ಕಲಿಕಾ ಫಲಗಳ ಪಟ್ಟಿ (ಪ್ರತಿ ವಿಷಯದ ಪ್ರಾರಂಭದ 04 ಕಲಿಕಾ ಫಲ = FLN ಕಲಿಕಾ ಫಲ) — ಕೆಳಗೆ section 5 ರ ಪಟ್ಟಿಗಳನ್ನು ನೋಡಿ.
  • ಸೇತುಬಂಧ: ಜೂನ್ನಲ್ಲಿ 4–10ನೇ ತರಗತಿಗೆ 15 ದಿನ ಸೇತುಬಂಧ ಕಾರ್ಯಕ್ರಮ — ಮೊದಲ 4 LO ಗಳಲ್ಲಿ FLN (ಶೇ.40) + ಪೂರ್ವ-ಅಪೇಕ್ಷಿತ ಕಲಿಕಾ ಫಲ (ಶೇ.60) ಆಧಾರಿತ ಪ್ರಶ್ನೆಪತ್ರಿಕೆ → ನಿದಾನಿಕ ಪರೀಕ್ಷೆ → ಪರಿಹಾರ ಬೋಧನೆ → ಸಾಫಲ್ಯ ಪರೀಕ್ಷೆ.
  • ಗುರುತಿಸುವಿಕೆ: ಸಾಫಲ್ಯ ಪರೀಕ್ಷೆಯಲ್ಲಿ FLN ಕಲಿಕಾ ಫಲ ಆಧಾರಿತ ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರಿಸದ ವಿದ್ಯಾರ್ಥಿಗಳನ್ನು "FLN ಸಾಧಿಸದ" ವಿದ್ಯಾರ್ಥಿಗಳೆಂದು ಗುರುತಿಸಲಾಗುವುದು.
  • ಅನುಷ್ಠಾನ: ಪ್ರತಿ ತಿಂಗಳ 2ನೇ ಶನಿವಾರ ಮುಖ್ಯ ಶಿಕ್ಷಕರ ಸಭೆ; ಕ್ಲಸ್ಟರ್/ಹೋಬಳಿ ಹಂತದಲ್ಲಿ DRG/BRG; SATS ನಲ್ಲಿ FLN ಪ್ರಗತಿ ನಿಖರವಾಗಿ ದಾಖಲಿಸುವುದು ಕಡ್ಡಾಯ.
  • ವರದಿ: ತಾಲ್ಲೂಕು ಹಂತದಲ್ಲಿ FLN ಫಲಿತಾಂಶ ವಿಶ್ಲೇಷಣೆ (BEO, BRC, ECO, BRP); ಶೇ.100 FLN ಸಾಧಿಸಿದ ಶಾಲೆಗಳಿಗೆ ಜಿಲ್ಲಾ ಹಂತದಲ್ಲಿ ಪ್ರಮಾಣಪತ್ರ.
  • ಗುರಿ: ಫೆಬ್ರವರಿ ಅಂತ್ಯದಲ್ಲಿ ತರಗತಿಗೆ ಅನುಗುಣವಾದ ಎಲ್ಲಾ FLN ಕಲಿಕಾ ಫಲಗಳನ್ನು ವಿದ್ಯಾರ್ಥಿಗಳು ಸಾಧಿಸಿರುವುದನ್ನು ಖಾತ್ರಿಪಡಿಸುವುದು.

1. ಹಂತ 1 — LBA ಪೋರ್ಟಲ್ ಲಾಗಿನ್

1

2

  • Government & Aided School Teachers: Teacher option → ನಿಮ್ಮ KGID / Employee ID ನಮೂದಿಸಿ.
  • Unaided Teachers, HMs, BEOs & CRPs: SATS User option → SATS User ID (Unaided Teacher → Teacher ID; HM → SATS User ID; BEO/CRP → SATS User ID).
3

ಸೂಕ್ತ ರೋಲ್ ಆಯ್ಕೆ ಮಾಡಿದ ನಂತರ Username ಕ್ಷೇತ್ರದಲ್ಲಿ ಮೇಲಿನಂತೆ ನಿಮ್ಮ ID ನಮೂದಿಸಿ → Send OTP / Login ಒತ್ತಿ.

4

Portal ಕಳುಹಿಸಿದ OTP ನಮೂದಿಸಿ (ಉದಾಹರಣೆ: "OTP sent to ******1141" — ನೋಂದಾಯಿತ ಮೊಬೈಲ್‌ನಲ್ಲಿ ಬರುತ್ತದೆ) → login ಪೂರ್ಣಗೊಳಿಸಿ. OTP ಹಂಚಿಕೊಳ್ಳಬೇಡಿ.

⚠️ Security: HM username ಮತ್ತು OTP ನಿಮ್ಮ ವೈಯಕ್ತಿಕ/login ಮಾಹಿತಿ — ಯಾರೊಂದಿಗೂ share ಮಾಡಬೇಡಿ. ಮೊಬೈಲ್ ಬದಲಾಗಿದ್ದರೆ OTP ಸಿಗದೇ ಇರಬಹುದು — BEO/ಬ್ಲಾಕ್ ಕಚೇರಿ ಮೂಲಕ login ಸಹಾಯ ಪಡೆಯಿರಿ.

⚠️ Login ಪಾತ್ರ / AI Answer confusion: LBA ಪೋರ್ಟಲ್‌ನಲ್ಲಿ Login as ಯಲ್ಲಿ TEACHER, SATS USER ಇತ್ಯಾದಿ ಪಾತ್ರಗಳಿವೆ. Government & Aided Teachers → TEACHER + KGID / Employee ID; Unaided Teachers / HMs / BEOs / CRPs → SATS USER + SATS User ID. ನಿಮ್ಮ ಪಾತ್ರಕ್ಕೆ ಸೂಕ್ತವಾದದ್ದನ್ನು select ಮಾಡಿ. ಜೊತೆಗೆ, ಕೆಲವು AI ಉತ್ತರಗಳಲ್ಲಿ Kannada/English/Maths LOs ಗೆ "alphabet recognition, sight words, CVC" ಎಂಬ ಬೇರೆ ಪಟ್ಟಿ ಕಾಣಿಸಬಹುದು — ಅದು ಈ portal ನದ್ದು ಅಲ್ಲ. ಇಲ್ಲಿ ನಮೂದಿಸಬೇಕಾದದ್ದು ಕೆಳಗಿನ section 5 ರಲ್ಲಿ ಕೊಟ್ಟಿರುವ 4–10ನೇ ತರಗತಿಯ ಅಧಿಕೃತ LO1–LO4 ಗಳೇ (ಓದು–ಅರ್ಥ–ಉತ್ತರ–ಬರಹ–ಮಾತು; ಗಣಿತದಲ್ಲಿ 3/4-ಅಂಕಿಯ ಕಾರ್ಯಾಚರಣೆ). ಯಾವುದೇ answer ನ್ನು ಪೋರ್ಟಲ್ / BEO ಸೂಚನೆಯೊಂದಿಗೆ cross-check ಮಾಡಿ.

5. ಕಲಿಕಾ ಫಲಿತಾಂಶಗಳು (Learning Outcomes — LOs)

View All LOs ಬಟನ್ (ಅಥವಾ ಪ್ರತಿ ವಿಷಯದ ಮೇಲಿನ ಬಟನ್) ಒತ್ತಿದರೆ ಮೌಲ್ಯಮಾಪನದ reference pop-up ತೆರೆಯುತ್ತದೆ — ಏನು ಪರಿಶೀಲಿಸಬೇಕು ಎಂದು ತೋರಿಸುತ್ತದೆ.

ಕನ್ನಡ — LOಪರಿಶೀಲಿಸಬೇಕಾದ ಸಾಮರ್ಥ್ಯ
LO1ವಾಕ್ಯ/ಪ್ಯಾರಾವನ್ನು ಸರಾಗವಾಗಿ ಅರ್ಥಸಹಿತ ಓದಿ, ಅರ್ಥವನ್ನು ಹೇಳುವರು.
LO2ಓದಿದ ವಿಷಯವನ್ನು ಅರ್ಥೈಸಿಕೊಂಡು, ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರಿಸುವರು (ಯಾರು, ಏನು, ಎಲ್ಲಿಗೆ, ಏಕೆ).
LO3ಸರಳ ವಾಕ್ಯಗಳನ್ನು ಸ್ವತಃ ಬರೆಯುವರು (3–5 ವಾಕ್ಯಗಳು).
LO4ದಿನನಿತ್ಯ ಜೀವನದಲ್ಲಿ ಕನ್ನಡ ಭಾಷೆಯನ್ನು ಮಾತನಾಡುವರು ಹಾಗೂ ಬಳಸುವರು.
English — LOSkill to check
LO1Reads simple sentences and a short paragraph with understanding.
LO2Answer simple questions based on the text (who, what, where, why).
LO3Write simple sentences independently (3–5 sentences).
LO4Use English for everyday communication (introductions, needs, basic expressions).
ಗಣಿತ — LOಪರಿಶೀಲಿಸಬೇಕಾದ ಸಾಮರ್ಥ್ಯ
LO14 / 5 ನೇ ತರಗತಿ: 3-ಅಂಕಿಯವರೆಗೆ; 6–10 ನೇ ತರಗತಿ: 4-ಅಂಕಿಯವರೆಗೆ ಸಂಖ್ಯೆಗಳನ್ನು ಓದುವ, ಬರೆಯುವ ಮತ್ತು ಅರ್ಥೈಸಿಕೊಳ್ಳುವ.
LO24 / 5 ನೇ ತರಗತಿ: 3-ಅಂಕಿಯ; 6–10 ನೇ ತರಗತಿ: 4-ಅಂಕಿಯ ಮಟ್ಟದ ಸರಳ context ನಲ್ಲಿ ಸಂಕಲನ, ವ್ಯವಕಲನ, ಗುಣಾಕಾರ, ಭಾಗಾಕಾರ ಮಾಡುವ.
LO3ಮೂಲಭೂತ ಕಾರ್ಯಾಚರಣೆಗಳನ್ನು ಬಳಸಿ ವಾಕ್ಯರೂಪ/ಪದ ಸಮಸ್ಯೆಗಳನ್ನು ಬಿಡಿಸುವ.
LO4ದಿನನಿತ್ಯ ಜೀವನದಲ್ಲಿ ಗಣಿತ ಅನ್ವಯಿಸುವ (ಸಮಯ, ಹಣ, ಉದ್ದ, ಮೂಲಭೂತ ದತ್ತಾಂಶ).

6. ಹಂತ 5 — ವಿದ್ಯಾರ್ಥಿ FLN ದತ್ತಾಂಶ ನಮೂದನೆ

  1. ವಿದ್ಯಾರ್ಥಿ ಹುಡುಕಿ: ಪಟ್ಟಿಯಲ್ಲಿ Sr No, Student Name, SATS ID ಕಾಣುತ್ತದೆ. ದೊಡ್ಡ ತರಗತಿಯಲ್ಲಿ ಬೇಗ ಹುಡುಕಲು ಮೇಲ್ಭಾಗದ ಬಲ ಮೂಲೆಯ Search box ಬಳಸಿ.
  2. Performance level ನಮೂದಿಸಿ: ಪ್ರತಿ ಕಲಿಕಾ ಫಲಿತಾಂಶ ಕಾಲಂನಲ್ಲಿ ಸೂಕ್ತ level (ಉದಾ. A, B) ಆಯ್ಕೆ ಮಾಡಿ:
    • ಕನ್ನಡ: LO1, LO2, LO3, LO4
    • ಇಂಗ್ಲಿಷ್: LO1, LO2, LO3, LO4
    • ಗಣಿತ: LO1, LO2, LO3, LO4

    ಒಟ್ಟು 12 ಕಾಲಂಗಳು (3 ವಿಷಯ × 4 LO). ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೂ ಎಲ್ಲಾ ಕಾಲಂ ಭರ್ತಿಯಾಗುವಂತೆ ನೋಡಿ.

  3. Export (ಐಚ್ಛಿಕ): ಪಟ್ಟಿಯ ಮೇಲ್ಭಾಗದ ಎಡಭಾಗದ PDF / Excel ಐಕಾನ್ ಬಳಸಿ pile/down ಬ್ಯಾಕಪ್ copy ಇಟ್ಟುಕೊಳ್ಳಿ.
  4. Save: ಕೆಳಕ್ಕೆ ಸ್ಕ್ರಾಲ್ ಮಾಡಿ Save ಬಟನ್ ಒತ್ತಿ — ಎಲ್ಲಾ ನಮೂದಿದ level ಗಳು ದಾಖಲಾಗುತ್ತವೆ.
  5. Pagination: ತರಗತಿಯಲ್ಲಿ 10ಕ್ಕಿಂತ ಹೆಚ್ಚು ವಿದ್ಯಾರ್ಥಿಗಳಿದ್ದರೆ, ಕೆಳಗಿನ ಬಲ ಮೂಲೆಯ page numbers ಒತ್ತಿ ಎಲ್ಲಾ pages ನಲ್ಲಿ ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ level ನಮೂದಿಸಿ.

✏️ ಉದಾಹರಣೆ: 9ನೇ ತರಗತಿ, ಕನ್ನಡ ಮಾಧ್ಯಮ. Medium = Kannada, Class = 9, Date = ಇಂದಿನ ದಿನಾಂಕ → Search. ಪಟ್ಟಿಯಲ್ಲಿ 35 ವಿದ್ಯಾರ್ಥಿಗಳು (pages ನಲ್ಲಿ). ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ ಕನ್ನಡ/ಇಂಗ್ಲಿಷ್/ಗಣಿತದ 4+4+4 LO ಕಾಲಂಗಳಿಗೆ ಓದಿ/ಮೌಲ್ಯಮಾಪನ ಮಾಡಿ level ನಮೂದಿಸಿ → ಪ್ರತಿ page ಮುಗಿಸಿ → ಕೊನೆಗೆ Save. ಮಧ್ಯೆ save ಮರೆತರೆ ಮಾಹಿತಿ ಕಳೆದುಕೊಳ್ಳಬಹುದು — ಮುಗಿಸುವ ಮೊದಲು Save ಒತ್ತಿ ಖಚಿತಪಡಿಸಿ.

7. Save ಮಾಡುವ ಮೊದಲು — Teacher Checklist

✅ Save ಬಟನ್ ಒತ್ತುವ ಮೊದಲು/ಮಾಡಿದ ನಂತರ ಈ 10 ಅಂಶಗಳನ್ನು ಪರಿಶೀಲಿಸಿ:

  • 1. ಮೇಲಿನ card ನಲ್ಲಿ ನಿಮ್ಮ ಶಾಲೆ ಹೆಸರು + DISE code ಸರಿಯಿದೆಯೇ?
  • 2. Medium — ಸರಿಯಾದ ಮಾಧ್ಯಮ ಆಯ್ಕೆಯಾಗಿದೆಯೇ?
  • 3. Class — ಪ್ರಸ್ತುತ ತರಗತಿ ಆಯ್ಕೆಯಾಗಿದೆಯೇ?
  • 4. Date — ಮೌಲ್ಯಮಾಪನದ ದಿನಾಂಕ ಸರಿಯಿದೆಯೇ?
  • 5. ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಯ 12 LO ಕಾಲಂಗೂ level ನಮೂದಾಗಿದೆಯೇ?
  • 6. 10ಕ್ಕಿಂತ ಹೆಚ್ಚು ವಿದ್ಯಾರ್ಥಿಗಳಿದ್ದರೆ ಎಲ್ಲಾ pages ನಲ್ಲಿ ನಮೂದಿಸಿದ್ದೀರಾ?
  • 7. ಯಾರನ್ನೂ ಬಿಟ್ಟು ಹೋಗಿಲ್ಲವೇ (Search ಮೂಲಕ ಪರಿಶೀಲಿಸಿದ್ದೀರಾ)?
  • 8. Save ಸಂದೇಶ/status ಕಾಣಿಸಿತೇ?
  • 9. ಅಗತ್ಯವಿದ್ದರೆ PDF/Excel export ತೆಗೆದಿದ್ದೀರಾ?
  • 10. ಬೇರೆ ತರಗತಿ ಮಾಧ್ಯಮ ಇದ್ದರೆ ಅದರ ದತ್ತಾಂಶ ಉಳಿದಿದೆಯೇ?

8. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು & ಪರಿಹಾರ

ಸಮಸ್ಯೆಏನು ಪರಿಶೀಲಿಸುವುದುಪರಿಹಾರ
LBA login ಆಗುತ್ತಿಲ್ಲUsername = SATS HM user name; ಇಂಟರ್ನೆಟ್; ಸರಿಯಾದ URL (sts.karnataka.gov.in/LBA/)OTP ಮತ್ತೆ ಪಡೆಯಲು ಪ್ರಯತ್ನಿಸಿ; ಬಂದಿಲ್ಲದಿದ್ದರೆ mobile ನಂಬರ್/login ನಲ್ಲಿರುವುದನ್ನು ಪರಿಶೀಲಿಸಿ; BEO ಮೂಲಕ ಸಹಾಯ.
ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿ ಖಾಲಿ ಇದೆMedium / Class / Date ಫಿಲ್ಟರ್ಎಲ್ಲಾ 3 ಫಿಲ್ಟರ್ ಆಯ್ಕೆ → Search ಒತ್ತಿ; ಸರಿಯಾದ ದಿನಾಂಕ/ತರಗತಿ ಆಯ್ಕೆಯಾಗಿದೆಯೇ ನೋಡಿ.
LO levels ನಮೂದಿಸಲು ಆಗುತ್ತಿಲ್ಲDropdown/ಆಯ್ಕಾ ಕ್ಷೇತ್ರ ತೆರೆದಿದೆಯೇ; ಯಾವ ಪುಟದಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತಿದ್ದೀರಿಪುಟ refresh → ಫಿಲ್ಟರ್ ಮತ್ತೆ ಆಯ್ಕೆ → ಆಯಾ ವಿದ್ಯಾರ್ಥಿ ಸಾಲಿನಲ್ಲಿ level ಆಯ್ಕೆ ಮಾಡಿ.
Save ಆಗುತ್ತಿಲ್ಲ / ದತ್ತಾಂಶ ಉಳಿಯುತ್ತಿಲ್ಲಪ್ರತಿ page ನಲ್ಲಿ ನಮೂದಿಸಿ; ಕಡೆಯ Save ಬಟನ್ಮಧ್ಯೆ ಮಧ್ಯೆ Save ಒತ್ತುತ್ತಿರಿ; ಎಲ್ಲಾ pages ಮುಗಿಸಿ ಕೊನೆಯ Save ಸಂದೇಶ ನೋಡಿ.
Export/PDF ಕೆಲಸ ಆಗುತ್ತಿಲ್ಲBrowser download ಅನುಮತಿChrome/Edge ನಲ್ಲಿ download ಅನುಮತಿ ನೀಡಿ; pop-up blocker ತೆಗೆದು ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ.
ತರಗತಿ ದೊಡ್ಡದಾಗಿದೆ — ಸಮಯ ಸಾಕುತ್ತಿಲ್ಲPagination pagesಪ್ರತಿ page ಮುಗಿದ ಕೂಡಲೇ Save; Slide/Search ಮೂಲಕ ಉಳಿದ ವಿದ್ಯಾರ್ಥಿ ಇದೆಯೇ ನೋಡಿ.

9. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. FLN Assessment ಎಂದರೇನು?

Foundational Literacy & Numeracy (FLN) — ವಿದ್ಯಾರ್ಥಿಗಳ ಮೂಲ ಓದು/ಬರಹ/ಅಂಕಗಣಿತ ಸಾಮರ್ಥ್ಯವನ್ನು ಕನ್ನಡ, ಇಂಗ್ಲಿಷ್, ಗಣಿತ ವಿಷಯಗಳಲ್ಲಿ ಪ್ರತಿ ತರಗತಿಗೆ ನಿಗದಿತ ಕಲಿಕಾ ಫಲಿತಾಂಶಗಳ (LO1–LO4) ಆಧಾರದಲ್ಲಿ ದಾಖಲಿಸುವ SATS ನ ಮಾಡ್ಯೂಲ್. ಶಿಕ್ಷಕರು/ಮುಖ್ಯ ಶಿಕ್ಷಕರು ಒಬ್ಬೊಬ್ಬ ವಿದ್ಯಾರ್ಥಿಗೆ ಮೌಲ್ಯಮಾಪನ ಮಾಡಿ level ನಮೂದಿಸುತ್ತಾರೆ.

2. ಯಾರು login ಮಾಡಬೇಕು?

LBA ಪೋರ್ಟಲ್ (sts.karnataka.gov.in/LBA/) ನಲ್ಲಿ Login as ಆಯ್ಕೆ ಮಾಡಿ: Government & Aided Teacher → Teacher option + KGID / Employee ID; Unaided Teacher / HM / BEO / CRP → SATS User option + SATS User ID. ನಂತರ OTP ನಮೂದಿಸಿ. ರುಜುವಾತು ಇಲ್ಲದಿದ್ದರೆ/ಮರೆತರೆ BEO/ಬ್ಲಾಕ್ ಕಚೇರಿಯಿಂದ ಸಹಾಯ ಪಡೆಯಿರಿ.

3. Performance level (A, B) ಅಂದರೆ ಏನು?

ಪ್ರತಿ LO ಯಲ್ಲಿ ವಿದ್ಯಾರ್ಥಿಯ ಪ್ರದರ್ಶನಕ್ಕೆ portal ನೀಡುವ level ಗಳಲ್ಲಿ (ಉದಾ. A, B) ಆಯ್ಕೆ — LO reference (View All LOs) ನಲ್ಲಿ ಏನು ಪರಿಶೀಲಿಸಬೇಕು ಎಂಬ ವಿವರ ಕೊಟ್ಟಿರುತ್ತದೆ. ಸಾಧ್ಯವಾದಷ್ಟು ಸರಿಯಾದ ಮೌಲ್ಯಮಾಪನಕ್ಕಾಗಿ LO ವಿವರ ಓದಿ.

4. ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣುತ್ತಿಲ್ಲ

Medium, Class, Date ಫಿಲ್ಟರ್ ಸರಿಯಿದೆಯೇ ಮತ್ತು Search ಒತ್ತಿದ್ದೀರಾ ಎಂದು ನೋಡಿ. ಸರಿಯಾದ filter ನಲ್ಲೂ ಕಾಣದಿದ್ದರೆ ಆ ತರಗತಿಯ SATS ದಾಖಲೆ/ವರ್ಗಾವಣೆ ಸರಿಯಾಗಿದೆಯೇ ಪರಿಶೀಲಿಸಿ, BEO ಮಾರ್ಗದರ್ಶನ ಪಡೆಯಿರಿ.

5. 10ಕ್ಕಿಂತ ಹೆಚ್ಚು ವಿದ್ಯಾರ್ಥಿ — ಹೇಗೆ?

ಕೆಳಗಿನ ಬಲ ಮೂಲೆಯ page numbers ಒತ್ತಿ ಎಲ್ಲಾ pages ನಲ್ಲಿ ನಮೂದಿಸಿ. ಪ್ರತಿ page ಮುಗಿಸಿ Save ಮಾಡುತ್ತಿದ್ದರೆ ದತ್ತಾಂಶ ಉಳಿಯುತ್ತದೆ.

6. ದಾಖಲಿಸಿದ ನಂತರ level ತಪ್ಪಾದರೆ?

ಮೊದಲು ಅದೇ FLN ಪುಟದಲ್ಲಿ ಆ ವಿದ್ಯಾರ್ಥಿಯ ಸಾಲಿನ ಮೌಲ್ಯ ಸರಿಪಡಿಸಬಹುದಾದರೆ ಮಾಡಿ. portal edit ನಿಯಮ ಏನು ಎಂದು ಖಚಿತಪಡಿಸಿ; edit ಸಾಧ್ಯವಿಲ್ಲದಿದ್ದರೆ BEO/ಬ್ಲಾಕ್ ಮಟ್ಟದ ಸಹಾಯ ಪಡೆಯಿರಿ. Save ಮೊದಲು ಡಬಲ್ ಚೆಕ್ ಮಾಡುವುದೇ ಉತ್ತಮ.

7. PDF/Excel ಏನಕ್ಕೆ?

ದತ್ತಾಂಶ ದಾಖಲೆಯ backup/reference ಆಗಿ ಅಥವಾ ಶಾಲಾ ದಾಖಲಾತಿಯಲ್ಲಿ school copy ಇಟ್ಟುಕೊಳ್ಳಲು ಬಳಸಬಹುದು. ದತ್ತಾಂಶದ ವಿವರ ಮೊದಲು user rights/data-use ಪ್ರಕಾರ ಮಾತ್ರ school record ಗಳಂತೆ ಸುರಕ್ಷಿತವಾಗಿ ಇರಿಸಿ.

8. Google/AI ಯಲ್ಲಿ ಬೇರೆ login/LO list ಕಂಡರೆ?

ಕೆಲವು AI ಸರ್ಚ್ ಫಲಿತಾಂಶಗಳು login ಅಥವಾ LOs ಬಗ್ಗೆ ಬೇರೆ ಮಾಹಿತಿ ತೋರಿಸಬಹುದು. ನೆನಪಿಡಿ — ಅಧಿಕೃತ ನಿಯಮ: Government & Aided Teachers → Teacher option + KGID / Employee ID; Unaided Teachers / HMs / BEOs / CRPs → SATS User option + SATS User ID; OTP ಆಧಾರಿತ. LOs section 5 ರ ಪಟ್ಟಿಯಂತೆ (4–10ನೇ ತರಗತಿಯ ಅಧಿಕೃತ LO1–LO4) ಮಾತ್ರ. ಯಾವುದೇ answer ನ್ನು portal ಅಥವಾ BEO ಸೂಚನೆಯೊಂದಿಗೆ ಹೋಲಿಸಿ.

9. ಯಾವ ದಿನಾಂಕ ಆಯ್ಕೆ ಮಾಡಬೇಕು?

ನೀವು ಮೌಲ್ಯಮಾಪನ ಮಾಡಿದ/ನಮೂದಿಸುವ ದಿನಾಂಕವೇ (dd-mm-yyyy) ಆಯ್ಕೆ. ತಪ್ಪು ದಿನಾಂಕದಲ್ಲಿ ನಮೂದಿಸಿದರೆ ಆ ದಿನದ ದಾಖಲೆಗೆ ಸೇರಬಹುದು — ದಿನಾಂಕ ಸರಿಯಿದೆಯೇ ಪರಿಶೀಲಿಸಿ.
