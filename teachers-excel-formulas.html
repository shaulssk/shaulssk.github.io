ಶಿಕ್ಷಕರಿಗೆ ಉಪಯುಕ್ತ Excel ಫಾರ್ಮುಲಾಗಳು

ಅಂಕಪಟ್ಟಿ · ಹಾಜರಾತಿ · ಶೇಕಡಾ · ಗ್ರೇಡ್ · VLOOKUP · ಕೊನೆಯ ನವೀಕರಣ: 06-09-2026

Excel ಶಾಲಾ ಶಿಕ್ಷಕರ ಪ್ರತಿದಿನದ ಸಾಧನ — ಅಂಕಪಟ್ಟಿ, ಹಾಜರಾತಿ, ಶೇಕಡಾ, ಪ್ರಶಸ್ತಿ ಲೆಕ್ಕ, ವರದಿ. ಚಿಕ್ಕದಾದ ಕೆಲವೇ ಫಾರ್ಮುಲಾಗಳನ್ನು ತಿಳಿದರೆ ನೀವು ಗಂಟೆಗಟ್ಟಲೆ ಖರ್ಚು ಮಾಡುವ ಕೈ-ಲೆಕ್ಕ ಹತ್ತಾರು ಸೆಕೆಂಡ್‌ನಲ್ಲಿ ಆಗುತ್ತದೆ. ಈ ಮಾರ್ಗದರ್ಶಿ ಕನ್ನಡದಲ್ಲಿ, ಹಂತ-ಹಂತದಲ್ಲಿ ನಿಮ್ಮ daily ಕೆಲಸಕ್ಕೆ ನೇರ ಬಳಕೆ ಆಗುವಂತೆ ಸಿದ್ಧಪಡಿಸಿದ್ದೇವೆ.

📌 ಹೇಗೆ ಬಳಸುವುದು: ಸೂತ್ರವನ್ನು = ನಿಂದ ಪ್ರಾರಂಭಿಸಿ. ಸೆಲ್ address (ಉದಾ. A1) ಅಥವಾ ಶ್ರೇಣಿ (range, ಉದಾ. B2:B30) ಬಳಕೆಯಾಗುತ್ತದೆ. ನಿಮ್ಮ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಲಂ ಯಾವ ಅಕ್ಷರದಲ್ಲಿದೆ ಎಂದು ನೋಡಿ ಅದಕ್ಕೆ ತಕ್ಕಂತೆ ಹೊಂದಿಸಿ.

1. ಅಂಕ ಒಟ್ಟು (SUM)

1

ಒಬ್ಬ ವಿದ್ಯಾರ್ಥಿಯ ಎಲ್ಲಾ ವಿಷಯದ ಅಂಕ ಸೇರಿಸಲು: =SUM(B2:F2) — ಎಂದರೆ B2 ರಿಂದ F2 ವರೆಗಿನ ಅಂಕ ಸೇರುತ್ತದೆ.

2

ಫಾರ್ಮುಲಾ ಸೆಲ್‌ನ ಕೆಳಗಿನ ಮೂಲೆ (fill handle) ತುಂಬಿದರೆ, ಕೆಳಗಿರುವ ಎಲ್ಲಾ ವಿದ್ಯಾರ್ಥಿಗಳಿಗೂ ಅದೇ ಸೂತ್ರ ಅನ್ವಯ ಆಗುತ್ತದೆ.

3

ಒಟ್ಟು ಮೊತ್ತ ಸಹ =SUM(B2:B40) — ಕಾಲಂನ ಒಟ್ಟಿಗೆ.

2. ಶೇಕಡಾ ಲೆಕ್ಕ (Percentage)

1

ಶೇಕಡಾ: =(B2/600)*100 — ಒಟ್ಟು 600 ಅಂಕ ಇದ್ದರೆ. ಇಲ್ಲಿ B2 ಒಬ್ಬರ ಒಟ್ಟು ಅಂಕ.

2

ಅಥವಾ =B2/600 ಮಾಡಿ ಸೆಲ್‌ನ format ಅನ್ನು Percentage ಆಗಿ ಬದಲಿಸಿ — ಹೆಚ್ಚು ಸುಲಭ.

3

ದಶಮಾಂಶ ಒಂದು/ಎರಡು ಅಂಕಿಗೆ ಸುತ್ತಲು: =ROUND((B2/600)*100,1) — ಕೊನೆಯ 1 ಎಂದರೆ ಒಂದು ದಶಮಾಂಶ ಸ್ಥಾನ.

3. ಗ್ರೇಡ್ ಆಟೋಮ್ಯಾಟಿಕ್ (IF)

1

ಶೇಕಡಾ ಪಟ್ಟಿ (C ಕಾಲಂ) ಆಧಾರದ ಗ್ರೇಡ್: =IF(C2>=85,"A",IF(C2>=70,"B",IF(C2>=60,"C",IF(C2>=35,"D","F"))))

2

ಇದು C2ನ ಶೇಕಡಾ ನೋಡಿ: 85+ = A, 70+ = B, 60+ = C, 35+ = D, ಇಲ್ಲದಿದ್ದರೆ F — ಆಗಿ ತೋರಿಸುತ್ತದೆ.

3

ನಿಮ್ಮ ಶಾಲೆ/ಬೋರ್ಡ್ ನಿಯಮಕ್ಕೆ ತಕ್ಕಂತೆ ಮಿತಿಗಳನ್ನು (85, 70...) ಬದಲಿಸಿ.

4. ಹಾಜರಾತಿ ಲೆಕ್ಕ (COUNTIF)

1

ಒಂದು ವಿದ್ಯಾರ್ಥಿ ಎಷ್ಟು ದಿನ ಹಾಜರ್ ಇದ್ದರು: =COUNTIF(B2:AE2,"P") — P ಇದ್ದ ಸೆಲ್ಗಳ ಸಂಖ್ಯೆ.

2

ಗೈರು: =COUNTIF(B2:AE2,"A") — A (absent) ಸೆಲ್ ಸಂಖ್ಯೆ.

3

ಶೇಕಡಾ ಹಾಜರಾತಿ: =ROUND((COUNTIF(B2:AE2,"P")/30)*100,1)

5. ಹೆಸರಿಗಾಗಿ VLOOKUP

1

ಎರಡು ಪಟ್ಟಿ ಇದ್ದಾಗ (ಒಂದರಲ್ಲಿ ಅಂಕ, ಇನ್ನೊಂದರಲ್ಲಿ ಹೆಸರು) ಹೊಂದಿಸಲು: =VLOOKUP(A2,Sheet2!A:B,2,FALSE)

2

ಇದು ಶೀಟ್2ರ A ಕಾಲಂನಲ್ಲಿ A2ನ ಹೆಸರನ್ನು ಹುಡುಕಿ, ಹತ್ತಿರದ B ಕಾಲಂನ (2ನೇ ಕಾಲಂ) ಮಾಹಿತಿ ತರುತ್ತದೆ.

3

ಕೊನೆಯ FALSE — ನಿಖರ ಹೊಂದಾಣಿಕೆಗೆ. TRUE ಬಳಕೆ ಎಂದರೆ ಸರಿಸುಮಾರು — ದತ್ತಾಂಶ ಏರಿಕೆ ಇದ್ದರೆ ಮಾತ್ರ.

6. ಹಾಜರಾತಿ/ಅಂಕ ತುಂಬದ ಸೆಲ್‍ಗಳ ಸಂಖ್ಯೆ (COUNTA / COUNTBLANK)

  • =COUNTA(A2:A40) — ಅಂಕ ಇರುವ ವಿದ್ಯಾರ್ಥಿಗಳ ಸಂಖ್ಯೆ (ಖಾಲಿ ಇಲ್ಲದವು).
  • =COUNTBLANK(A2:A40) — ಖಾಲಿ ಸೆಲ್ ಸಂಖ್ಯೆ (ಅಂಕ ನಮೂದಾಗದವರ ಲೆಕ್ಕ).
  • =COUNTIF(B2:B40,">=35") — 35+ ಅಂಕ ಪಡೆದವರ ಸಂಖ್ಯೆ (ಉತ್ತೀರ್ಣ).

7. ಹೆಸರನ್ನು ಒಟ್ಟುಗೂಡಿಸುವುದು (CONCATENATE / &)

1

ಮೊದಲ + ಕೊನೆಯ ಹೆಸರು ಒಟ್ಟಿಗೆ: =A2&" "&B2

2

ದೊಡ್ಡ ಅಕ್ಷರ: =UPPER(B2), ಚಿಕ್ಕಕ್ಕೆ =LOWER(B2).

3

ಹೆಸರಿನಲ್ಲಿ ಅಕಸ್ಮಾತ್ ಜಾಗ ಇದ್ದರೆ ಸರಿಪಡಿಸಲು: =TRIM(C2).

8. ದಿನಾಂಕ ಲೆಕ್ಕ (DATEDIF)

1

ಮಗುವಿನ ವಯಸ್ಸು (ವರ್ಷದಲ್ಲಿ): =DATEDIF(B2,TODAY(),"Y") — B2 ಜನ್ಮ ದಿನಾಂಕ.

2

ವರ್ಷ+ತಿಂಗಳು+ದಿನ: =DATEDIF(B2,TODAY(),"Y")&" ವರ್ಷ "

3

ಎರಡು ದಿನಾಂಕಗಳ ವ್ಯತ್ಯಾಸ (ದಿನಗಳಲ್ಲಿ): =C2-B2 — ಸಾಮಾನ್ಯ ವ್ಯವಕಲನ.

9. ಶ್ರೇಣಿ/ರ್ಯಾಂಕ್ (RANK)

1

ಅಂಕದ ಆಧಾರದ ಶ್ರೇಣಿ: =RANK(B2,$B$2:$B$40)

2

ಶ್ರೇಣಿಯನ್ನು ಲಾಕ್ ಮಾಡಲು $ ಗುರುತು ಬಳಸಿ — ಇಲ್ಲದಿದ್ದರೆ fill ಮಾಡುವಾಗ ಶ್ರೇಣಿ ಜಾರುತ್ತದೆ.

3

ಅತಿ ಹೆಚ್ಚು/ಕಡಿಮೆ: =MAX(B2:B40), =MIN(B2:B40) — ಸರಾಸರಿ =AVERAGE(B2:B40).

10. ತಪ್ಪು ಸೂತ್ರಗಳಿಂದ ಹೇಗೆ ರಕ್ಷಿಸಿಕೊಳ್ಳುವುದು

ದೋಷ (error)ಅರ್ಥಪರಿಹಾರ
#N/AVLOOKUP ನಲ್ಲಿ ಹೆಸರು ಸಿಗಲಿಲ್ಲಕಾಗುಣಿತ/ಜಾಗ check ಮಾಡಿ; Sheet ಹೆಸರು ಸರಿಯೇ?
#VALUE!ಸೆಲ್‌ನಲ್ಲಿ ಅಕ್ಷರ/ಸಂಖ್ಯೆಯಲ್ಲಿದೆಎಲ್ಲಾ ಅಂಕ ಸಂಖ್ಯೆ format ನಲ್ಲಿದೆಯೇ ನೋಡಿ
#DIV/0!ಶೂನ್ಯದಿಂದ ಭಾಗಿಸಲು ಹೋದೆಛೇದ (denominator) 0 ಆಗಿರುವ ಸಾಧ್ಯತೆ — IFERROR ತೊಡಿಸಿ
1

ಸುತ್ತಮುತ್ತ error ತೋರಿಸದೆ ಇಡಲು: =IFERROR(ನಿಮ್ಮ ಸೂತ್ರ,»,"—")

2

ಸೂತ್ರದ ಬದಲು ಬರೆದಿದ್ದೇನೋ ನೋಡಲು: ಕೀಬೋರ್ಡ್‌ನ Ctrl+` (backtick) — ಸೂತ್ರ/ಮೌಲ್ಯ toggle.

11. ದತ್ತಾಂಶ ಬ್ಯಾಕಪ್ & ಶೇರ್

  • ಅಂಕ/ಹಾಜರಾತಿ ಫೈಲಿಗೆ ದಿನಾಂಕ ಹೆಸರು ಇಡಿ: "Class7-Marks-06Sep2026.xlsx".
  • ಫೈಲ್ → Save As → PDF — ಶಾಲಾ ದಾಖಲೆಗೆ ರೀಡ್-ಕಾಪಿ PDF.
  • ಪ್ರಮುಖ ಫೈಲುಗಳ ಬ್ಯಾಕಪ್ — ಎರಡು ಸ್ಥಳ (ಉದಾ. pen drive + cloud).
  • ಶೇರ್ ಮಾಡುವ ಮೊದಲು confidential ವಿವರ (ಸಂಪೂರ್ಣ ಆಧಾರ) ಇಲ್ಲ ಎಂದು ಖಚಿತಪಡಿಸಿ — ಗೋಪ್ಯತೆ.

12. ಪ್ರಮುಖ ಅಂಶಗಳು ⭐

  • ಎಲ್ಲಾ ಸೂತ್ರ = ಯಿಂದ — ಸೆಲ್‌ನಲ್ಲಿ ನೇರವಾಗಿ.
  • SUM, AVERAGE, IF, COUNTIF, VLOOKUP — ಇವೇ daily most used.
  • ಶೇಕಡಾ: =(part/total)*100 ಅಥವಾ Percentage format.
  • ಗ್ರೇಡ್: nested IF — ಮೊದಲು ಅತಿ ಧನ, ಆಮೇಲೆ ಇಳಿಯುತ್ತ.
  • ಬ್ಯಾಕಪ್ + PDF — ದಾಖಲೆಗೆ ಕಡ್ಡಾಯ.

13. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. ಸೂತ್ರ ಹಾಕಿದರೆ "formula" ಬರವಣಿಗೆಯೇ ತೋರಿಸುತ್ತದೆ — ಏಕೆ?

ಹೆಚ್ಚಾಗಿ ಸೆಲ್ format "Text" ಆಗಿರಬಹುದು. ಸೆಲ್ ಹೈಲೈಟ್ ಮಾಡಿ Home → Number → General ಆಗಿ ಬದಲಿಸಿ, ಅನಂತರ ಸೂತ್ರ ಪುನಃ ಬರೆಯಿರಿ. ಫಾರ್ಮುಲಾ = ನಿಂದ ಪ್ರಾರಂಭ ಆಗಬೇಕು.

2. VLOOKUP ಕೆಲಸ ಮಾಡುತ್ತಿಲ್ಲ — ಏನು check?

Lookup column (ಹುಡುಕುವ ಕಾಲಂ) ಶ್ರೇಣಿಯ ಮೊದಲ ಕಾಲಂ ಆಗಿರಬೇಕು. ಕಾಗುಣಿತ/ರಿಟರ್ನ್ ತಪ್ಪು. ಕೊನೆಯ FALSE ಇರಲಿ. Sheet ಹೆಸರು ಬದಲಾದರೆ refrence ಜಾರುತ್ತದೆ.

3. ಇಡೀ class ಗೆ ಒಂದೇ ಸೂತ್ರ ಹೇಗೆ ಅನ್ವಯಿಸುವುದು?

ಫಾರ್ಮುಲಾ ಸೆಲ್‌ನ ಕೆಳಗಿನ ಬಲ ಮೂಲೆಯ fill handle (+ ಚಿಹ್ನೆ) ಕಾಣುವವರೆಗೆ ಬಂದು, ಕೆಳಗೆ ಎಳೆಯಿರಿ. ಶ್ರೇಣಿ ಕುಗ್ಗದಂತೆ $ ಬಳಸಿ.

4. ಪ್ರಯೋಗ ಮಾಡುವಾಗ ಫೈಲ್ ಹಾಳಾಗಿದರೆ?

ಆಗಾಗ Ctrl+S ಉಳಿಸಿ, ಮತ್ತು Copy (ಉದಾ. "backup") ಇಡಿ. Undo (Ctrl+Z) ಸಹ ಸಹಾಯ.

5. ಹಾಜರಾತಿ ದಿನಗಳು ಬೇರೆ ಬೇರೆ ಇದ್ದರೆ ಶೇಕಡಾ ಹೇಗೆ?

ದಿನಗಳ ಸಂಖ್ಯೆಯನ್ನು ಒಂದು ಸೆಲ್‌ನಲ್ಲಿ (ಉದಾ. H1) ಹಾಕಿ: =(COUNTIF(B2:AE2,"P")/$H$1)*100 — ಹೀಗೆ ದಿನಗಳು ಬದಲಾದರೆ ಒಂದೇ ಸೆಲ್ ಬದಲಿಸಿದರೆ ಸಾಕು.
