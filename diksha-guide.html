1. DIKSHA ಎಂದರೇನು?

DIKSHA = Digital Infrastructure for Knowledge Sharing. ಇದು ಭಾರತ ಸರ್ಕಾರದ ಶಿಕ್ಷಣ ಸಚಿವಾಲಯದ ಅಡಿ (NCERT ನೊಂದಿಗೆ) ರಾಷ್ಟ್ರೀಯ ಡಿಜಿಟಲ್ ಶಿಕ್ಷಣ ವೇದಿಕೆ. ಶಿಕ್ಷಕರು, ವಿದ್ಯಾರ್ಥಿಗಳು ಮತ್ತು ಸಾರ್ವಜನಿಕರಿಗೆ ಉಚಿತವಾಗಿ ಲಭ್ಯ.

  • 📖 ಪಠ್ಯಪುಸ್ತಕಗಳ ಡಿಜಿಟಲ್ ವಿಷಯ, ಪಾಠಗಳು, ಕೋರ್ಸ್‌ಗಳು
  • 🎓 ಶಿಕ್ಷಕರ ವೃತ್ತಿಪರ ಅಭಿವೃದ್ಧಿ — NISHTHA, NCERT CPD, Virtual Labs ಮೊದಲಾದ ಕೋರ್ಸ್‌ಗಳು
  • 🗂️ Content repository — 12 ಭಾರತೀಯ ಭಾಷೆಗಳಲ್ಲಿ (English, Hindi, Kannada, Marathi, Bengali, Tamil, Telugu, Urdu, Assamese, Odia, Gujarati, Punjabi)
  • 🔠 QR code ಆಧಾರಿತ ಪ್ರವೇಶ — ಪಠ್ಯಪುಸ್ತಕ/ಕೋರ್ಸ್‌ QR scan ಮಾಡಿ ನೇರವಾಗಿ ತೆರೆಯುವುದು

📌 ಗಮನಿಸಿ: DIKSHA App ಹೊರಗಿನ ದೇಶಗಳಲ್ಲಿ ಲಭ್ಯವಿಲ್ಲದಿರಬಹುದು (ಭಾರತದಲ್ಲಿ release). ಹೊರಗಿನಿಂದ DIKSHA ವೆಬ್‌ಸೈಟ್ (diksha.gov.in) ಮೂಲಕ ಎಲ್ಲಾ ಸಂಪನ್ಮೂಲ ಪ್ರವೇಶಿಸಬಹುದು.

2. ಯಾರಿಗಾಗಿ? (Audience)

DIKSHA ಯಲ್ಲಿ ಪ್ರಕಟವಾಗುವ ಪ್ರತಿ content ಗೂ ಒಂದು ಕಲಿಕಾ ಉದ್ದೇಶವಿರುತ್ತದೆ. ಬಳಕೆದಾರರು ಮುಖ್ಯವಾಗಿ ಎರಡು:

  • Learners (ಕಲಿಯುವವರು) — ವಿದ್ಯಾರ್ಥಿಗಳು ಮತ್ತು ಸಂಪನ್ಮೂಲ ಬಳಸುವವರು.
  • Instructors (ಬೋಧಕರು) — ಶಿಕ್ಷಕರು, ಕಲಿಕೆಗೆ ಮಾರ್ಗದರ್ಶನ ಮಾಡುವವರು.

ಸಂಸ್ಥೆ-ನಿರ್ದಿಷ್ಟ content ಮಾಡಲೂ ಆಗುತ್ತದೆ: ರಾಜ್ಯ/ಸಂಸ್ಥೆ ತನ್ನ app/website ನಲ್ಲಿ login ಆದ ಬಳಕೆದಾರರಿಗೆ ನಿರ್ದಿಷ್ಟ content ತೋರಿಸಬಹುದು. ಇದು ಒಟ್ಟು searchability ಯನ್ನು ಕಡಿಮೆ ಮಾಡುವುದಿಲ್ಲ.

📄 Content License (ಪರವಾನಗಿ): DIKSHA ನಲ್ಲಿ ಈ ಪರವಾನಗಿಗಳನ್ನು ಅನುಮತಿಸಲಾಗಿದೆ — CC BY 4.0 · CC BY-SA 4.0 · CC BY-NC 4.0 · CC BY-NC-SA 4.0 · CC BY-ND 4.0 · CC BY-NC-ND 4.0 · YouTube License. NC (ವಾಣಿಜ್ಯೇತರ) ಪರವಾನಗಿ ಇರುವ content ವನ್ನು ವಾಣಿಜ್ಯ ಉದ್ದೇಶಕ್ಕೆ ಬಳಸಬಾರದು. ಲೇಖಕರಿಗೆ metadata ದಲ್ಲಿ ಹೆಸರು ನಮೂದಿಸಿ ಕ್ರೆಡಿಟ್ ನೀಡಲಾಗುತ್ತದೆ.

3. ಖಾತೆ ನೋಂದಣಿ & Login (Sign In)

DIKSHA ಖಾತೆ ನೋಂದಣಿಗೆ 3 ಮಾರ್ಗಗಳಿವೆ:

  1. Self Sign-up: ನಿಮ್ಮ ಮೊಬೈಲ್ ಸಂಖ್ಯೆ ಅಥವಾ ಇಮೇಲ್ ಮೂಲಕ ನೋಂದಣಿ.
  2. Google Sign-in: ನಿಮ್ಮ Google ಖಾತೆ ಮೂಲಕ login.
  3. State Login: ರಾಜ್ಯ/ಸಂಸ್ಥೆ ಅನುಮತಿಸಿದಲ್ಲಿ ರಾಜ್ಯ ಖಾತೆಯ ಮೂಲಕ. ಕರ್ನಾಟಕ ಶಿಕ್ಷಕರು: ನಿಮ್ಮ ಇಲಾಖೆ ಸೂಚಿಸಿದ login ವಿಧಾನವನ್ನು ಅನುಸರಿಸಿ.

ರಾಜ್ಯ ಖಾತೆ ಸೃಷ್ಟಿಯಾದರೆ ಗೊತ್ತಾಗೋದು ಹೇಗೆ? ನೋಂದಾಯಿತ ಮೊಬೈಲ್/ಇಮೇಲ್‌ಗೆ welcome message + Set Password ಲಿಂಕ್ ಬರುತ್ತದೆ. ಆ ಲಿಂಕ್ ತೆರೆದು ಪಾಸ್‌ವರ್ಡ್ ಹೊಂದಿಸಿ.

ಪಾಸ್‌ವರ್ಡ್ ಮರೆತರೆ (Forgot Password)

  1. Sign In ಪುಟ ತೆರೆಯಿರಿ
  2. Forgot password ಲಿಂಕ್ ಕ್ಲಿಕ್ ಮಾಡಿ
  3. ನೋಂದಾಯಿತ ಮೊಬೈಲ್ ಸಂಖ್ಯೆ ಅಥವಾ ಇಮೇಲ್ ನಮೂದಿಸಿ
  4. Reset ಒತ್ತಿ — OTP ಬರುತ್ತದೆ
  5. OTP ನಮೂದಿಸಿ
  6. Submit ಒತ್ತಿ
  7. ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿ
  8. Reset ಒತ್ತಿ — ಯಶಸ್ವಿಯಾದರೆ DIKSHA Library ಪುಟಕ್ಕೆ ನಿರ್ದೇಶನ

4. Features — content creators / providers

Content creation ಹಕ್ಕು (rights) ಇರುವ ಬಳಕೆದಾರರು DIKSHA ಯಲ್ಲಿ ಇವನ್ನು ಮಾಡಬಹುದು:

  • Courses, Books, Lessons, Collections — content ಸೃಷ್ಟಿ
  • Content Authoring Tool ಬಳಕೆ
  • ಬೆಂಬಲಿತ file format ನಲ್ಲಿ content upload
  • Repository ನಿಂದ content download
  • Content edit
  • ಇತರ users/groups ಜೊತೆ collaborate
  • ಟಿಪ್ಪಣಿಗಳು (notes)
  • ಇತರರಿಗೆ content recommend / share

💡 ಸಾಮಾನ್ಯ ಬಳಕೆದಾರರಿಗೆ ಈ ಎಲ್ಲಾ ಆಯ್ಕೆಗಳು ಕಾಣಿಸದೇ ಇರಬಹುದು — ನಿಮ್ಮ Role ಗೆ ಅನುಸಾರವೇ menu ಇರುತ್ತದೆ.

5. User Roles & Profile

ನನ್ನ Role ಏನು ಅಂತ ಗೊತ್ತಾಗೋದು ಹೇಗೆ? DIKSHA ವೆಬ್‌ಸೈಟ್‌ನಲ್ಲಿ login ಮಾಡಿ → Profile ಪುಟ ತೆರೆಯಿರಿ. ಅಲ್ಲಿ ನಿಮಗೆ ನೀಡಿರುವ Roles ಕಾಣುವವು. ಹೆಚ್ಚಿನ ವಿವರ: User Types (ಅಧಿಕೃತ).

Role ಬದಲಾಯಿಸೋದು ಹೇಗೆ? ಬಳಕೆದಾರರ Role ಅನ್ನು ರಾಜ್ಯದ Organisation Administrator ಮಾತ್ರ ಬದಲಾಯಿಸಬಹುದು:

  1. Administrator ಖಾತೆ login
  2. Profile ಪುಟ ತೆರೆಯಿರಿ
  3. Search box ನಲ್ಲಿ ಬಳಕೆದಾರರ ಹೆಸರು ನಮೂದಿಸಿ
  4. Submit — ಸಂಬಂಧಿತ ಫಲಿತಾಂಶ ಕಾಣುತ್ತದೆ
  5. ಹೆಸರಿನ ಎದುರಿನ Edit ಐಕಾನ್ ಒತ್ತಿ
  6. Role / ವಿವರ edit ಮಾಡಿ
  7. Save ಒತ್ತಿ

Workspace ಕಾಣಿಸುತ್ತಿಲ್ಲವೇ? Workspace content creation / content review ಗಾಗಿ ಬರುತ್ತದೆ. ಸರಿಯಾದ ಖಾತೆಯಲ್ಲಿ login ಆಗಿದ್ದೀರಾ ಎಂದು ಖಚಿತಪಡಿಸಿ; ಇನ್ನೂ ಕಾಣದಿದ್ದರೆ ನೋಡಲ್ ಅಧಿಕಾರಿ/org Administrator ಸಂಪರ್ಕಿಸಿ.

6. Courses — ಹುಡುಕುವುದು, join & progress

  1. Courses tab → My Courses ವಿಭಾಗದಲ್ಲಿ enrolled ಕೋರ್ಸ್‌ಗಳು; ಅಥವಾ filter ಬಳಸಿ search ಮಾಡಿ.
  2. Course detail page ನಲ್ಲಿ Join Course ಬಟನ್ ಒತ್ತಿ batch join.
  3. Course progress — course detail page ನ ಮೇಲ್ಭಾಗದ ಬಲಭಾಗದಲ್ಲಿ (%) ಕಾಣುತ್ತದೆ.
  4. ಕೋರ್ಸ್ ಪೂರ್ಣಗೊಂಡಾಗ Your progress 100% ಕಾಣುತ್ತದೆ.
  5. ಪೂರ್ಣಗೊಂಡ ಕೋರ್ಸ್‌ಗಳ ಪಟ್ಟಿ: Profile → Course(s) Attended (portal ಹಾಗೂ App ಎರಡರಲ್ಲೂ).

✅ QR code ಮೂಲಕ ಕೋರ್ಸ್: DIKSHA Portal ನಲ್ಲಿ Enter QR code textbox ನಲ್ಲಿ 6-ಅಂಕಿ QR code ನಮೂದಿಸಿ Submit — course detail page ನೇರವಾಗಿ ತೆರೆಯುತ್ತದೆ. App ನಲ್ಲಿ QR scan ಮಾಡಲು DIKSHA App ನೇ scan ಬಳಸಿ (ಇತರ scanning app ಗಳನ್ನು recommend ಮಾಡಲಾಗುವುದಿಲ್ಲ).

💡 ಕೋರ್ಸ್ ಮುಂದುವರಿಯಲು ಮತ್ತೆ login ಕೇಳಿದ್ರೆ — ನಿಮ್ಮಲ್ಲಿ ಬಹು ಖಾತೆಗಳಿವೆಯೇ ಆಗಿರಬಹುದು; ಮೊದಲು ಬಳಸಿದ್ದ ಅದೇ ಖಾತೆ ನಲ್ಲಿ login ಆಗಿರಲು ಖಚಿತಪಡಿಸಿ. Print/download — ಪ್ರಸ್ತುತ PDF content ಗಳಿಗೆ ಮಾತ್ರ ಲಭ್ಯ (Download → PDF → Print).

7. Mobile App — ಪಠ್ಯಪುಸ್ತಕ, QR, ಸಮಸ್ಯೆಗಳು

ಪಠ್ಯಪುಸ್ತಕ ತೆರೆಯುವುದು:

  • ವಿಧಾನ 1 — Library tap ಮಾಡಿ → ನಿಮ್ಮ Board, Medium, Class ಆಯ್ಕೆ (App profile ನಲ್ಲಿ default set ಮಾಡಬಹುದು).
  • ವಿಧಾನ 2 — Scan tap ಮಾಡಿ → ಭೌತಿಕ ಪಠ್ಯಪುಸ್ತಕದ QR code scan ಮಾಡಿ.

⚠️ App ನಲ್ಲಿ content upload ಸಾಧ್ಯವಿಲ್ಲ: DIKSHA Mobile App ಕೇವಲ consumption (ಬಳಕೆ) ಗಾಗಿ. ಹೊಸ content ಸೃಷ್ಟಿ/upload ಗೆ Content Creator role ಇದ್ದರೆ portal (diksha.gov.in) ಗೆ login ಆಗಿ ಮಾಡಬೇಕು.

Profile settings / QR scan ಬಟನ್ ಕಾಣಿಸುತ್ತಿಲ್ಲವೇ? ಇದಕ್ಕೆ ಸಾಮಾನ್ಯ ಕಾರಣ — ಫೋನ್‌ನ Android System WebView ಹಳೆಯ ಆವೃತ್ತಿ. ಇದನ್ನು update ಮಾಡಿ:

  1. Google Play Store ತೆರೆಯಿರಿ
  2. Android System WebView ಹುಡುಕಿ (ಅಥವಾ ನೇರ ಲಿಂಕ್)
  3. Update ಮಾಡಿ, DIKSHA App ಮತ್ತೆ ತೆರೆಯಿರಿ
