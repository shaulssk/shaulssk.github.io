ℹ️ Note: Portal ನಲ್ಲಿ menu/field ಹೆಸರುಗಳು ಮತ್ತು ನೋಂದಣಿ ಕ್ಷೇತ್ರಗಳು ಇಲಾಖಾ ಪರಿಚಲನೆಯಂತೆ ಬದಲಾಗಬಹುದು — ದತ್ತಾಂಶ ನಮೂದಿಸುವ ಮೊದಲು ಅಧಿಕೃತ User Manual / BEO ಸೂಚನೆ ಪರಿಶೀಲಿಸಿ.

SATS (Student Achievement Tracking System) — ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆಯ ಅಧಿಕೃತ ವಿದ್ಯಾರ್ಥಿ ದತ್ತಾಂಶ ವ್ಯವಸ್ಥೆ. ಪ್ರತಿ ಮಗುವಿಗೆ ಒಂದು SATS ID ಇರುತ್ತದೆ; ಪ್ರವೇಶ, ತರಗತಿ ಏರಿಕೆ (promotion), ಶಾಲೆ ಬದಲಾವಣೆ, TC, ಹಾಜರಾತಿ ಮತ್ತು ಪ್ರಮಾಣಪತ್ರ — ಎಲ್ಲವೂ ಈ ID ಯ ಆಧಾರದಲ್ಲಿ ನಿರ್ವಹಣೆಯಾಗುತ್ತದೆ. ಕೆಲವು school/student services ಮತ್ತು reporting processesಗಳಲ್ಲಿ SATS data ಬಳಸಲಾಗಬಹುದು; ಸಂಬಂಧಿತ ಇಲಾಖೆಯ ಪ್ರಸ್ತುತ ಸೂಚನೆಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.

⚠️ ಮುಖ್ಯ ಸೂಚನೆ: ನೋಂದಣಿ ಕ್ಷೇತ್ರಗಳು, ಫೋಟೋ ಗಾತ್ರ, ID ರೂಪ ಮತ್ತು ಮೆನು ಹೆಸರುಗಳು ಅಧಿಕೃತ portal ಉತ್ತಮಗೊಳ್ಳುತ್ತಿದ್ದಂತೆ ಭಿನ್ನವಾಗಿರಬಹುದು. ನೋಂದಣಿ/ದತ್ತಾಂಶ ನಮೂದಿಸುವ ಮೊದಲು ಅಧಿಕೃತ ಪೋರ್ಟಲ್ ಮತ್ತು User Manual ಪರಿಶೀಲಿಸಿ — ನಿಮ್ಮ BEO/ಜಿಲ್ಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ಸೂಚನೆಗಳೇ ಅಂತಿಮ.

1. SATS ನಲ್ಲಿ ಏನೇನು ಮಾಡಬಹುದು?

ಕೆಲಸಏನು?ಯಾರು
ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿಹೊಸ ಮಗುವಿಗೆ SATS ID ಸೃಷ್ಟಿ — ಹೆಸರು, DOB, ಜಾತಿ, ವಿಳಾಸ, ಫೋಟೋಶಾಲಾ admin / ಡೇಟಾ ಆಪರೇಟರ್
ದೈನಂದಿನ ಹಾಜರಾತಿಪ್ರತಿ ಕೆಲಸದ ದಿನದ Present/Absent ದಾಖಲೆತರಗತಿ ಶಿಕ್ಷಕ
Promotion / Class changeಶೈಕ್ಷಣಿಕ ವರ್ಷ ಆರಂಭದಲ್ಲಿ ತರಗತಿ ಏರಿಕೆಶಾಲೆ (ಇಲಾಖಾ ಸೂಚನಾನುಸಾರ)
TC / ವರ್ಗಾವಣೆಮಗು ಶಾಲೆ ಬದಲಿಸಿದಾಗ TC ಮತ್ತು ನಿರ್ಗಮನ ದಾಖಲೆಶಾಲೆ / BEO
ವರದಿ ಕಾರ್ಡ್School Report Card — ದತ್ತಾಂಶ ನೋಡುವುದು/ಪ್ರಿಂಟ್ಮುಖ್ಯ ಶಿಕ್ಷಕ / BEO

2. ದತ್ತಾಂಶ ಮೊದಲು — ಏನು ಸಿದ್ಧವಿರಬೇಕು?

✅ Check-list (ನೋಂದಣಿ/ದತ್ತಾಂಶ ಕೆಲಸ ಮೊದಲು):

  • Login ರುಜುವಾತು: User ID + password — DDPI/BEO office ನೀಡುತ್ತದೆ; Portal ಸೂಚಿಸಿದರೆ ಮೊದಲ loginನಲ್ಲಿ password ಬದಲಿಸಿ.
  • ಮಗುವಿನ ದಾಖಲೆ: ಜನ್ಮ ಪ್ರಮಾಣಪತ್ರ/ಸ್ಕೂಲ್ ದಾಖಲೆಯ ಪ್ರಕಾರ ಹೆಸರು + DOB; ಜಾತಿ ಪ್ರಮಾಣಪತ್ರ.
  • ಇತ್ತೀಚಿನ ಫೋಟೋ: JPG, ಸಣ್ಣ ಗಾತ್ರ (ಉದಾ. ~100 KB — portal ನ ನಿಗದಿ ಪರಿಶೀಲಿಸಿ).
  • ಹಳೆಯ ದಾಖಲೆ (ವರ್ಗಾವಣೆ ಮಗು): ಹಿಂದಿನ ಶಾಲೆಯ TC/ವಿವರ.
  • ಕಂಪ್ಯೂಟರ್/ಇಂಟರ್ನೆಟ್: ಒಳ್ಳೆಯ ಬ್ರೌಸರ್ (Chrome/Edge) ಮತ್ತು ಸ್ಥಿರ internet ಸಂಪರ್ಕ.

1

sts.karnataka.gov.in/SATS ತೆರೆದು LOGIN ಆಯ್ಕೆ ಮಾಡಿ.

2

User ID ಮತ್ತು Password ನಮೂದಿಸಿ (DDPI/BEO office ನೀಡಿದ ರುಜುವಾತು).

3

ಮೊದಲ ಬಾರಿ login ಆಗುತ್ತಿದ್ದರೆ Portal ಸೂಚಿಸಿದರೆ password ಬದಲಿಸಿ — ಬಲವಾದ password ಇಡಿ ಮತ್ತು ಎಲ್ಲೂ ಹಂಚಿಕೊಳ್ಳಬೇಡಿ.

4

Login ನಲ್ಲಿ ಸಮಸ್ಯೆಯಾದರೆ → User ID/ಪಾಸ್‌ವರ್ಡ್ Reset ಗಾಗಿ BEO/ಬ್ಲಾಕ್ ಕಚೇರಿ ಸಂಪರ್ಕಿಸಿ (ಕಡಿಮೆ ಸಮಯ — ಜಿಲ್ಲಾ/ರಾಜ್ಯ helpdesk ಕೊನೆಯ ಆಯ್ಕೆ).

✅ Portal ಮೆನುಗಳಿಗೆ ಅನುಗುಣವಾಗಿ ಈ ಹಂತಗಳನ್ನು ನವೀಕರಿಸಲಾಗಿದೆ (09-09-2026).

4. ಹೊಸ ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ (Student Registration)

  1. ಮೊದಲು duplicate check: ಹೊಸ ID ಸೃಷ್ಟಿಸುವ ಮೊದಲು ಶಾಲಾ ಪಟ್ಟಿಯಲ್ಲಿ (ಮತ್ತು ಸಾಧ್ಯವಾದಷ್ಟು ಹುಡುಕಾಟದಲ್ಲಿ) ಹೆಸರಿನಿಂದ/mobile ನಿಂದ ಪರಿಶೀಲಿಸಿ — ಮಗುವಿಗೆ ಈಗಾಗಲೇ SATS ID ಇದ್ದರೆ ಹೊಸದು ಬೇಡ.
  2. Login ಆಗಿ Registration → Add New Student ಆಯ್ಕೆ ಮಾಡಿ.
  3. ವಿವರ ಭರ್ತಿ: ಹೆಸರು (ಜನ್ಮ/ಶಾಲಾ ದಾಖಲೆಯಂತೆ), ಜನ್ಮದಿನ (DD/MM/YYYY), ಲಿಂಗ, ಜಾತಿ, ಧರ್ಮ, ವಿಳಾಸ, ತಾಯಿ/ತಂದೆ ಹೆಸರು, ಏನಾದರೂ ಹಿಂದಿನ ಶಾಲೆ ಇದ್ದರೆ ಅದರ ವಿವರ.
  4. ಫೋಟೋ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ (ನಿಗದಿತ ಗಾತ್ರ/ಫಾರ್ಮ್ಯಾಟ್).
  5. Save/Submit ಒತ್ತಿ — SATS ID generate ಆಗುತ್ತದೆ (ಉದಾ. KA-… — ರೂಪ ಇಲಾಖಾ ಸೂಚನೆಯಂತೆ ಬದಲಾಗಬಹುದು).
  6. ನೋಂದಣಿಯಾದ ವಿದ್ಯಾರ್ಥಿ ಶಾಲಾ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿ ಕಾಣಿಸುತ್ತಿದೆಯೇ ಪರಿಶೀಲಿಸಿ — ಕಾಣಿಸದಿದ್ದರೆ Save/Submit status, student search, class selection ಮತ್ತು portal notificationಗಳನ್ನು ಮೊದಲು ಪರಿಶೀಲಿಸಿ.

✏️ ಉದಾಹರಣೆ: 1ನೇ ತರಗತಿಗೆ ಹೊಸದಾಗಿ ಪ್ರವೇಶ ಪಡೆದ ಮಗು. ಶಾಲೆಯಲ್ಲಿ ಈ ಮಗುವಿಗೆ SATS ID ಇಲ್ಲ ಎಂದು ಖಚಿತಪಡಿಸಿ → Registration form ನಲ್ಲಿ ಹೆಸರು (ಜನ್ಮ ಪ್ರಮಾಣಪತ್ರದಂತೆ), DOB, ಜಾತಿ ಭರ್ತಿ → ಫೋಟೋ ಅಪ್‌ಲೋಡ್ → Save. ಹೊಸ SATS ID ಬಂದಾಗ ಶಾಲಾ ದಾಖಲೆಯಲ್ಲಿ (register) ಬರೆದಿಡಿ — ಭವಿಷ್ಯದ ವರದಿಕಾರ್ಡ್/TC ಯಲ್ಲಿ ಅದೇ ID ಬಳಕೆಯಾಗುತ್ತದೆ.

5. ದೈನಂದಿನ ಹಾಜರಾತಿ

  1. Attendance → Daily Attendance ಆಯ್ಕೆ ಮಾಡಿ.
  2. ದಿನಾಂಕ (ಇಂದಿನ) ಆಯ್ಕೆ ಮಾಡಿ — ತರಗತಿಯ ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿ ಬರುತ್ತದೆ.
  3. ಸುಲಭ ಕ್ರಮ: ಮೊದಲು ಎಲ್ಲರನ್ನೂ Present ಆಗಿ ಗುರುತಿಸಿ, ನಂತರ absent ಆದ ಮಕ್ಕಳನ್ನು ಬದಲಿಸಿ — ಸಮಯ ಉಳಿಯುತ್ತದೆ.
  4. Absent ಮಗುವಿಗೆ ಕಾರಣ (ಇದ್ದರೆ) ನಮೂದಿಸಿ.
  5. Save ಒತ್ತಿ — ದಿನ ಕೊನೆಯಲ್ಲಿ ನಮೂದಿದ್ದು ಖಚಿತಪಡಿಸಿ; ಅರ್ಧ ಬಿಟ್ಟ ದಿನ ಮುಂದಿನ ಬೆಳಿಗ್ಗೆ ತಿದ್ದಲು ಸಾಧ್ಯವಾಗುವುದಿಲ್ಲ (ಪೋರ್ಟಲ್ ನಿಯಮದಂತೆ).

💡 ಒಂದು ದಿನದ ಹರಿವು (quick routine): Login → Daily Attendance (ಸ್ಕೂಲ್ ಮುಗಿಯುವ ಮೊದಲೇ) → ಹೊಸ ಮಗು ಸೇರಿದ್ದರೆ Registration → ಯಾವುದೇ ವರದಿ ಬೇಕಿದ್ದರೆ Report Card → Logout. ಪ್ರತಿದಿನ ಈ ಕ್ರಮವನ್ನು ಅಭ್ಯಾಸ ಮಾಡಿದಷ್ಟು ಸಮಯ ಉಳಿಯುತ್ತದೆ.

✏️ Practical example — ದಿನದ ಹಾಜರಾತಿ: 4ನೇ ತರಗತಿಯಲ್ಲಿ 32 ಮಕ್ಕಳಿದ್ದಾರೆ. ಬೆಳಿಗ್ಗೆ 9:30ಕ್ಕೆ Attendance → Daily Attendance → ದಿನಾಂಕ (ಇಂದಿನದು) → ಎಲ್ಲರನ್ನೂ Present ಗುರುತಿಸಿ → 2 ಮಕ್ಕಳನ್ನು Absent ಎಂದು ಬದಲಿಸಿ (ಕಾರಣ: ಗ್ರಾಮೀಣ ಜಾತ್ರೆ/ಅನಾರೋಗ್ಯ) → Save. ಪಟ್ಟಿಯಲ್ಲಿ ಒಟ್ಟು 32 — Present 30, Absent 2 ಎಂದು ಕಾಣುತ್ತದೆಯೇ ನೋಡಿದರೆ ದಿನದ ಕೆಲಸ ಮುಗಿದಂತೆ. ವಿದ್ಯಾರ್ಥಿ ಶಾಲೆಗೆ ಬೇರೆ ಸ್ಕೂಲ್‌ಗೆ ಹೋದ ಮಗು ಇದ್ದರೆ — ಪ್ರವೇಶವಲ್ಲದಿರುವ ಮಗು ಕಾಣಿಸುತ್ತಿದ್ದರೆ TC/ನಿರ್ಗಮನ ಮೆನುವಿನಲ್ಲಿ ದಾಖಲಿಸಿ ಆ ದಿನದ ಪಟ್ಟಿ ಸರಿಪಡಿಸಿ.

6. Promotion (ತರಗತಿ ಏರಿಕೆ) — ಶೈಕ್ಷಣಿಕ ವರ್ಷ ಆರಂಭದಲ್ಲಿ

  1. ವರ್ಷ ಆರಂಭದಲ್ಲಿ (ಸಾಮಾನ್ಯವಾಗಿ ಏಪ್ರಿಲ್–ಮೇ) ಇಲಾಖಾ ಸೂಚನೆ ಬಂದಾಗ Promotion/Class Change ಆಯ್ಕೆ ಮಾಡಿ.
  2. ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ ಮುಂದಿನ ತರಗತಿ ಆಯ್ಕೆ; ಅದೇ ತರಗತಿಯಲ್ಲಿ ಉಳಿಸಬೇಕಾದವರಿಗೆ status ಗುರುತಿಸಿ.
  3. Save → ಶಾಲಾ ದಾಖಲೆ (class-wise list) ಜೊತೆ ಹೋಲಿಸಿ.
  4. ಹೊಸ ವಿದ್ಯಾರ್ಥಿ ಪ್ರವೇಶದವರು ಇಲಾಖಾ ಸೂಚನಾ ಪ್ರಕಾರ admission/registration ಮೂಲಕ ಸೇರಿಸುತ್ತಾರೆ.

7. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು & ಪರಿಹಾರ

ಸಮಸ್ಯೆಏನು ಪರಿಶೀಲಿಸುವುದುಪರಿಹಾರ
Login ಆಗುತ್ತಿಲ್ಲUser ID ಸರಿಯಿದೆಯೇ; caps lock; ಇಂಟರ್ನೆಟ್ ಸಂಪರ್ಕಪಾಸ್‌ವರ್ಡ್ reset ಗೆ BEO office ಸಂಪರ್ಕಿಸಿ (Forgot/Reset link ಇದ್ದರೆ ಬಳಸಿ).
"Error Occurred" ಪುಟಸರ್ವರ್‌ನ ತಾತ್ಕಾಲಿಕ ದೋಷChrome/Edge ಬಳಸಿ, cache clear, sts.karnataka.gov.in/SATS/ ಮತ್ತೆ ತೆರೆದು 2–3 ನಿಮಿಷ ಬಿಟ್ಟು retry.
ಹೊಸ ನೋಂದಣಿ enabled ಇಲ್ಲಪರಿಚಲನೆ ಪ್ರಕಾರ ನೋಂದಣಿ ಅವಧಿ/ಅನುಮತಿಬ್ಲಾಕ್/ಜಿಲ್ಲಾ ಮಟ್ಟದ ಅನುಮತಿ ಪಡೆಯಿರಿ; ಅವಧಿ ಮುಗಿದಿದ್ದರೆ ಇಲಾಖಾ ಸೂಚನೆ ಪ್ರಕಾರ ಅನುಮತಿಸಿದ ಅವಧಿಯಲ್ಲಿ ಮಾಡಿ.
ಫೋಟೋ ಅಪ್‌ಲೋಡ್ ಆಗುತ್ತಿಲ್ಲಗಾತ್ರ/ಫಾರ್ಮ್ಯಾಟ್JPG, ನಿಗದಿತ KB ಒಳಗೆ ಇರುವಂತೆ ಚಿಕ್ಕದಾಗಿಸಿ; ಮತ್ತೆ ಅಪ್‌ಲೋಡ್.
ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣುತ್ತಿಲ್ಲSave ಆಗಿಲ್ಲ / ತಪ್ಪು ತರಗತಿ ಆಯ್ಕೆRegistration ಮತ್ತೆ ಬಿಟ್ಟು Save; ತರಗತಿ/ವಿಭಾಗ ಸರಿಯಿದೆಯೇ ನೋಡಿ.
Duplicate ID / ಮಗು ಎರಡೂ ಕಡೆ ನೋಂದಣಿಹಳೆಯ ಶಾಲೆ ದಾಖಲೆಮಗುವಿಗೆ ಒಂದೇ ID ಇರಲಿ — ಎರಡೆಡೆ ಇದ್ದರೆ ಹೊಸ ಶಾಲೆಗೆ TC/ನಿರ್ಗಮನ ಸರಿಪಡಿಸಿ, BEO ಮಾರ್ಗದರ್ಶನ ಪಡೆಯಿರಿ.
DOB/ಜಾತಿ ತಪ್ಪಾಗಿ ನಮೂದಾಗಿದೆಜನ್ಮ/ಜಾತಿ ದಾಖಲೆಅಧಿಕಾರಿ edit ಅನುಮತಿಯಿಂದ correction; ಸ್ಕ್ರೀನ್‌ಶಾಟ್ + ದಿನಾಂಕ ದಾಖಲಿಸಿ.

8. ಪ್ರಮುಖ ಅಂಶಗಳು ⭐

  • ಒಂದು ಮಗು = ಒಂದೇ SATS ID: ತರಗತಿ/ಶಾಲೆ ಬದಲಾದರೂ ID ಬದಲಾಗಬಾರದು — duplicate ID ಮಾಡದಿರಿ.
  • ಪ್ರಮಾಣ ದಾಖಲೆಗೆ ಭಿನ್ನ ಹೆಸರು ಬೇಡ: ಜನ್ಮ ಪ್ರಮಾಣಪತ್ರ/Aadhaar/ಹಿಂದಿನ ಶಾಲಾ ದಾಖಲೆ ಜೊತೆ ಹೊಂದಾಣಿಕೆ — ತಪ್ಪಿದರೆ ವರ್ಗಾವಣೆ/ವಿದ್ಯಾರ್ಥಿವೇತನದಲ್ಲಿ ತೊಡಕು.
  • MDM / ಉಚಿತ ಪುಸ್ತಕ / ವಿದ್ಯಾರ್ಥಿವೇತನ: ಈ ರೀತಿಯ services ಕೆಲವೊಮ್ಮೆ student records ಆಧರಿಸಿ ಇರುತ್ತವೆ — ನಿಮ್ಮ ಶಾಲೆಯ ದಾಖಲೆ ನಿಖರವಾಗಿರಲಿ; ಸಂಬಂಧಿಸಿದ ಇಲಾಖೆಯ ಪ್ರಸ್ತುತ ಸೂಚನೆ ಪರಿಶೀಲಿಸಿ.
  • ತಿಂಗಳ ಬ್ಯಾಕಪ್: Portalನಲ್ಲಿ export/download option ಲಭ್ಯವಿದ್ದರೆ, ಅಗತ್ಯವಾದ school reports ಅಥವಾ recordsಗಳನ್ನು ಇಲಾಖೆಯ data-retention procedureಗೆ ಅನುಗುಣವಾಗಿ ಸುರಕ್ಷಿತವಾಗಿ ಸಂಗ್ರಹಿಸಿ.
  • TC ಮಾಹಿತಿ: ಹೊಸ ಮಗುವಿಗೆ TC ವಿವರ ಸೂಕ್ತ ಕ್ಷೇತ್ರದಲ್ಲಿ ನಮೂದಿಸಿ.

9. SATS ಕೆಲಸ ಮುಗಿಸುವ ಮೊದಲು — Teacher Checklist

✅ Save ಬಟನ್ ಒತ್ತುವ ಮೊದಲು/ಮಾಡಿದ ನಂತರ ಈ 10 ಅಂಶಗಳನ್ನು ಪರಿಶೀಲಿಸಿ:

  • 1. Student ಹೆಸರು ಶಾಲಾ ದಾಖಲೆ (school record/register) ಜೊತೆ ಹೊಂದಿದೆಯೇ?
  • 2. DOB ಸರಿಯಾಗಿದೆಯೇ (ಜನ್ಮ ಪ್ರಮಾಣಪತ್ರದಂತೆ)?
  • 3. Class/section ಸರಿಯಾಗಿದೆಯೇ?
  • 4. Existing SATS ID duplicate ಆಗಿಲ್ಲವೇ (ಹೊಸ ID ಸೃಷ್ಟಿಸುವ ಮೊದಲು)?
  • 5. Attendance date (ದಿನಾಂಕ) ಸರಿಯಾಗಿದೆಯೇ?
  • 6. Absent students ಪಟ್ಟಿ ಪರಿಶೀಲಿಸಿದ್ದೀರಾ?
  • 7. Registration/Correction Save ಆಗಿದೆಯೇ (ಸಂದೇಶ/status)?
  • 8. Report/List ನಲ್ಲಿ updated data ಕಾಣಿಸುತ್ತಿದೆಯೇ?
  • 9. Transfer student ಗೆ ಹಿಂದಿನ record ಪರಿಶೀಲಿಸಿದ್ದೀರಾ?
  • 10. ಅಗತ್ಯವಿದ್ದರೆ report/download copy ಸುರಕ್ಷಿತವಾಗಿ ಇಟ್ಟಿದ್ದೀರಾ?

10. SATS ದತ್ತಾಂಶ ನಮೂದನೆಯಲ್ಲಿ ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

⚠️ ಈ ತಪ್ಪುಗಳಿಂದ ನಂತರ ತೊಡಕು ಬರುತ್ತದೆ — ಗಮನಿಸಿ:

  • ತಪ್ಪು 1 — ಹೊಸ SATS ID ಅನ್ನು ಬೇಗ ಸೃಷ್ಟಿಸುವುದು: ಹೊಸ ID ಕೊಡುವ ಮೊದಲು ಯಾವಾಗಲೂ existing student record ಹುಡುಕಿ — duplicate ID ವರ್ಗಾವಣೆ/ವಿದ್ಯಾರ್ಥಿವೇತನ/ವರದಿಗಳಲ್ಲಿ ಗೊಂದಲ ಸೃಷ್ಟಿಸುತ್ತದೆ.
  • ತಪ್ಪು 2 — ದಾಖಲೆ ನೋಡದೆ ಹೆಸರು/DOB ನಮೂದಿಸುವುದು: ಹೆಸರು ಮತ್ತು DOB ಯನ್ನು school record / ಜನ್ಮ ಪ್ರಮಾಣಪತ್ರ ಜೊತೆ cross-check ಮಾಡದೆ ನಮೂದಿಸಬೇಡಿ — ನಂತರ correction ಪ್ರಕ್ರಿಯೆ ಸಮಯ ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ.
  • ತಪ್ಪು 3 — Save ಮಾಡಿದ ನಂತರ verification ಮಾಡದೇ ಬಿಡುವುದು: Save ಮಾಡಿದೆ ಎಂದುಕೊಂಡು ಬಿಡದೆ — student search/ಪಟ್ಟಿಯಲ್ಲಿ data ಕಾಣಿಸುತ್ತಿದೆಯೇ ಎಂದು ಖಚಿತಪಡಿಸಿ.
  • ತಪ್ಪು 4 — Portal error ಅನ್ನು data error ಎಂದು ಭಾವಿಸುವುದು: ಏನಾದರೂ error ಬಂದರೆ ಮೊದಲು browser, internet, session ಮತ್ತು portal status ಪರಿಶೀಲಿಸಿ — ತಕ್ಷಣವೇ data ತಪ್ಪಿದೆ ಎಂದು ಭಾವಿಸಬೇಡಿ. ಪುಟ refresh/ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ.
  • ತಪ್ಪು 5 — ಹಳೆಯ instructions ಅನ್ನು ಈಗಿನ portalನಲ್ಲಿ ಬಳಸುವುದು: Portal menu/fields ವರ್ಷದಿಂದ ವರ್ಷಕ್ಕೆ ಬದಲಾಗುತ್ತದೆ — ಹಳೆಯ printed/handout ಸೂಚನೆ ಇದ್ದರೂ ಈಗಿನ portal ನಲ್ಲಿ ಪ್ರಸ್ತುತ option ಏನು ಎಂದು ಪರಿಶೀಲಿಸಿ.

11. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. SATS ID ಏನು — ಎಲ್ಲಿಂದ ಸಿಗುತ್ತದೆ?

SATS ID ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ ಶಾಶ್ವತ ದತ್ತಾಂಶ ಸಂಖ್ಯೆ. ನೋಂದಣಿ ಆದಾಗ portal ಸ್ವಯಂ generate ಮಾಡುತ್ತದೆ; ಈಗಾಗಲೇ ಇರುವ ಮಗುವಿಗೆ School Report Card/Registration ಮೆನು ಅಥವಾ BEO office ದತ್ತಾಂಶದಲ್ಲಿ ಸಿಗುತ್ತದೆ. ನಿಮ್ಮ ಶಾಲೆಯ ಹಿಂದಿನ ಶೈಕ್ಷಣಿಕ ವರ್ಷದ ಪಟ್ಟಿ/ರಿಪೋರ್ಟ್ ಕಾರ್ಡ್‌ನಲ್ಲೂ ID ಕಾಣಬಹುದು.

2. ಮಗು ಶಾಲೆ ಬದಲಿಸಿದರೆ ಹೊಸ SATS ID ಬೇಕೆ?

ಬೇಡ — ID ಶಾಶ್ವತ. ಹೊಸ ಶಾಲೆಯಲ್ಲಿ ಹಳೆಯ ID ವಿವರದೊಂದಿಗೆ Transfer/ನಿರ್ಗಮನ ಪ್ರಕ್ರಿಯೆ ಮಾಡಬೇಕು. ಬೇರೆ ರಾಜ್ಯದಿಂದ ಬಂದ ಮಗುವಿಗೆ fresh registration ಜೊತೆ ಹಿಂದಿನ ವಿವರ ಸೇರಿಸಿ. ಹೊಸ ID ಸೃಷ್ಟಿಸುವ ಮೊದಲು ಹಿಂದಿನ SATS record/ID ಪರಿಶೀಲಿಸಿ — Transfer ಅಥವಾ admission process ಕುರಿತು ಪ್ರಸ್ತುತ portal instructions ಮತ್ತು BEO/department guidance ಅನುಸರಿಸಿ.

3. Login ಪಾಸ್‌ವರ್ಡ್ ಮರೆತಿದ್ದಾರೆ — ಹೇಗೆ?

Portal ನಲ್ಲಿ Forgot/Reset ಲಿಂಕ್ ಇದ್ದರೆ ಬಳಸಿ; ಇಲ್ಲದಿದ್ದರೆ BEO office ನಲ್ಲಿ User ID reset/ಪಾಸ್‌ವರ್ಡ್ ಮರುನೀಡಿಕೆ ಮಾಡಿಸಿ — ಹಂಚದೆ ಸುರಕ್ಷಿತವಾಗಿ ಇರಿಸಿ. ಬೇರೆಯವರಿಗೆ ಹೇಳದೆ ಖಚಿತವಾದ ಜಾಗದಲ್ಲಿ/password manager ನಲ್ಲಿ ಇಡಿ.

4. ಒಂದು ದಿನ ಹಾಜರಾತಿ ಮರೆತು ಬಿಟ್ಟರೆ?

ದಿನ ಆಯ್ಕೆಮಾಡಿ Attendance ಮೆನುವಿನಲ್ಲಿ ಹಿಂದಿನ ದಿನವನ್ನು (portal ಅನುಮತಿಸಿದರೆ) ತೆರೆದು ಸರಿಪಡಿಸಬಹುದು — ಅವಕಾಶವಿಲ್ಲದಿದ್ದರೆ BEO/ಬ್ಲಾಕ್ ಮಟ್ಟದ ಸಹಾಯ ಪಡೆಯಿರಿ. ದಿನ ಕೊನೆಯಲ್ಲಿ Save ಮಾಡಿ ಖಚಿತಪಡಿಸುವ ಅಭ್ಯಾಸ ಇಟ್ಟುಕೊಳ್ಳಿ — ಇದರಿಂದ ಇಂಥ ಸಮಸ್ಯೆ ಕಡಿಮೆ ಆಗುತ್ತದೆ.

5. ಹೆಸರು/ಜಾತಿ ತಪ್ಪಾಗಿದ್ದರೆ correction ಹೇಗೆ?

ಅಧಿಕಾರಿಗಳ edit ಅನುಮತಿಯಿಂದ correction; ಪ್ರಮಾಣ ದಾಖಲೆಯ ಪ್ರಕಾರ ಹೆಸರು ಇಡಿ. ತಿದ್ದುಪಡಿ ದಾಖಲಾಗುವಂತೆ screenshot/ದಿನಾಂಕ ಇಟ್ಟುಕೊಳ್ಳಿ. correction ಶಾಲಾ ದಾಖಲೆ (register) ಯಲ್ಲಿ ಹೊಂದಾಣಿಕೆಯಾಗುವಂತೆ ನೋಡಿ — ಬೇರೆ ಬೇರೆ ದಾಖಲೆಗಳಲ್ಲಿ ಭಿನ್ನ ಹೆಸರು ಕಾಣಿಸಬಾರದು.

6. ನಿರಂತರ ಆ್ಯಪ್ ಜೊತೆ ಸಂಬಂಧವೇನು?

ನಿರಂತರ ಆ್ಯಪ್ ಮುಖ ಸೆರೆಹಿಡಿಯುವ AI ಹಾಜರಾತಿ ವ್ಯವಸ್ಥೆ; ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ/base ದತ್ತಾಂಶದಲ್ಲಿ SATS ID ಲಿಂಕ್ ಆಗುತ್ತದೆ (ಇಲಾಖಾ ಸೂಚನಾ ಪ್ರಕಾರ). ವ್ಯತ್ಯಾಸ ತಿಳಿಯಲು SATS vs ನಿರಂತರ ನೋಡಿ.

7. ಒಂದೇ ಮಗುವಿಗೆ ಎರಡು SATS ID ಆಗಿದ್ದರೆ?

Duplicate ID ಇದ್ದರೆ ಯಾವುದನ್ನು ಮುಂದುವರಿಸಬೇಕು ಎಂದು BEO/ಬ್ಲಾಕ್ ಮಟ್ಟದ ಮಾರ್ಗದರ್ಶನ ಪಡೆಯಿರಿ. ಹೊಸ ಶಾಲೆಗೆ TC/ನಿರ್ಗಮನ ಪ್ರಕ್ರಿಯೆ ಸರಿಯಾಗಿ ದಾಖಲಾಗದಿದ್ದರೆ duplicate ಆಗುವ ಸಾಧ್ಯತೆ ಹೆಚ್ಚು — ಹಿಂದಿನ ಶಾಲೆಯ ದಾಖಲೆ ಮೊದಲು ಪರಿಶೀಲಿಸಿ.

8. ಫೋಟೋ ಅಪ್‌ಲೋಡ್ ಆಗುತ್ತಿಲ್ಲ — ಏನು ಮಾಡಬೇಕು?

ನಿಗದಿತ ಫಾರ್ಮ್ಯಾಟ್/ಗಾತ್ರಕ್ಕೆ (ಸಾಮಾನ್ಯವಾಗಿ JPG, ಸಣ್ಣ ಗಾತ್ರ) ಹೊಂದಿಸಿ ಮತ್ತೆ ಪರಿಶೀಲಿಸಿ. ಹೆಸರು ಸರಳ ಅಕ್ಷರಗಳಲ್ಲೇ ಇರಲಿ (ಕನ್ನಡ/English ಇಲಾಖಾ ಸೂಚನೆಯಂತೆ), ಫೈಲ್ ಹೆಸರಿನಲ್ಲಿ ಅನಗತ್ಯ ಚಿನ್ಹೆ/space ಇದ್ದರೆ ತೆಗೆಯಿರಿ. ಇನ್‌ಟರ್‌ನೆಟ್ ಸ್ಥಿರವಾಗಿದೆಯೇ ನೋಡಿ, ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ.

9. ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣುತ್ತಿಲ್ಲ — save ಆಗಿದೆಯೇ?

ಸಾಮಾನ್ಯ ಕಾರಣ: class/section ತಪ್ಪು ಆಯ್ಕೆ, save ಸಂದೇಶ ಕಾಣದಿರುವುದು, ಅಥವಾ ನೋಂದಣಿ ಅವಧಿ/ಅನುಮತಿ ವಿಷಯ. ಮೊದಲು Save/Submit status, student search, class selection ಮತ್ತು portal notificationಗಳನ್ನು ಪರಿಶೀಲಿಸಿ; ಸರಿಪಡಿಸಿದ ಮೇಲೆಯೇ save ಮಾಡಿ.

10. promotion/taragaTI erika ತಪ್ಪಾಗಿದ್ದರೆ ಹೇಗೆ ಸರಿಪಡಿಸುವುದು?

ಪ್ರಚಾರ/ವರ್ಗ ಬದಲಾವಣೆ ಮಾಡುವ ಮೊದಲು ಶಾಲಾ ದಾಖಲೆ (class-wise list) ಜೊತೆ ಹೋಲಿಸಿ. ತಪ್ಪಾಗಿದ್ದರೆ relevant menu/ಅಧಿಕಾರಿ ಸೂಚನೆಯಂತೆ edit/status ಬದಲಾವಣೆ ಮಾಡಿ. ವರ್ಷದಲ್ಲಿ ಒಮ್ಮೆ ಮಾತ್ರ ಇದನ್ನು ಮಾಡಬೇಕಾಗುತ್ತದೆ ಎಂದು ಭಾವಿಸಿ ಜಾಗರೂಕರಾಗಿರಿ — ವರ್ಷ ಆರಂಭದ ಇಲಾಖಾ ಸೂಚನೆಗೆ ಅನುಗುಣವಾಗಿ ಪ್ರಚಾರ ಮಾಡಿ.

11. SMS/ಪ್ರಮಾಣಪತ್ರದಲ್ಲಿ ಹೆಸರು ಭಿನ್ನ ಕಾಣುತ್ತಿದೆ — ಹೇಗೆ?

ಹೆಸರು ಯಾವ ದಾಖಲೆಯ ಪ್ರಕಾರ ನಮೂದಾದೆಯೋ ಅದಕ್ಕೆ ಹೊಂದಿಕೆಯಾಗದಿದ್ದರೆ correction ಮಾಡಿಸಿ (ಪ್ರಮಾಣ ದಾಖಲೆಯಂತೆ). API/ದತ್ತಾಂಶ ವರ್ಗಾವಣೆ ಸಂದರ್ಭದಲ್ಲಿ ಹೆಸರು transliteration ವ್ಯತ್ಯಾಸ ಆಗಬಹುದು — ಶಾಲಾ ದಾಖಲೆಯಲ್ಲಿನ ಮೂಲ ಹೆಸರೇ portal ನಲ್ಲಿರಬೇಕು.

12. SATS ದತ್ತಾಂಶವನ್ನು ಇನ್ನಾವ ಕೆಲಸಗಳಿಗೆ ಬಳಸಬಹುದು?

ಪ್ರವೇಶ, ಹಾಜರಾತಿ, ತರಗತಿ ಏರಿಕೆ, TC, ವರದಿ ಕಾರ್ಡ್ — ಇವು SATS ಬಳಕೆಯ ಪ್ರಮುಖ ಕೆಲಸಗಳು. ಸರ್ಕಾರಿ service/reporting ಸಂದರ್ಭದಲ್ಲಿ student records ಬಳಸಬಹುದು; ಅದರ ಪ್ರಸ್ತುತ ವಿಧಾನ, ಅಧಿಕೃತ portal/ಸೂಚನೆಯ ಪ್ರಕಾರ ಮಾತ್ರ. ಯಾವುದೇ data-usage claim ಗಾಗಿ ಸಂಬಂಧಿತ department notification ಪರಿಶೀಲಿಸಿ.

13. session timeout ಆಗುತ್ತಿದೆ — ಡೇಟಾ ಉಳಿಯುತ್ತದೆಯೇ?

ಸೆಷನ್ ಮುಗಿದರೆ ನೀವು ಟೈಪ್ ಮಾಡಿದದು save ಆಗಿಲ್ಲ ಎಂದು ಭಾವಿಸಬೇಡಿ — ಆಗಲೇ save ಆಗಿದ್ದರೆ ಉಳಿಯುತ್ತದೆ. save ಮಾಡದೆ ದೀರ್ಘ ಸಮಯ ಸಮಯ ಇದ್ದರೆ ಸೆಷನ್ ಕಳೆದು ಸಮಸ್ಯೆ ಬರಬಹುದು — ಮುಖ್ಯ data ಅನ್ನು ಮೊದಲು save ಮಾಡಿ ವಿರಾಮ ಮಾಡಿ. ದೊಡ್ಡ ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿಯಲ್ಲಿ ಕೆಲಸ ಮಾಡುವಾಗ ಮಧ್ಯೆ ಮಧ್ಯೆ save ಮಾಡುತ್ತ ಮಾಡಿ.

14. ಬೆರೆ ರಾಜ್ಯದ ಮಗು ಬಂದರೆ registration ಹೇಗೆ?

ಹೊಸ ನೋಂದಣಿ ಮಾಡಿ, ಹಿಂದಿನ ಶಾಲೆ/ರಾಜ್ಯದ TC ವಿವರ ಸೇರಿಸಿ; ID/ವಿದ್ಯಾರ್ಥಿ ವಿವರ ವಿಭಿನ್ನ ರೀತಿಯಲ್ಲಿ ಇದ್ದರೆ ಇಲಾಖಾ ಮಾರ್ಗದರ್ಶನ ಪಡೆಯಿರಿ. "ವಿದ್ಯಾರ್ಥಿ ಈಗಾಗಲೇ ನೋಂದಾಯಿತ" ಎಂದು ಬಂದರೆ — duplicate ಸೃಷ್ಟಿಸದೆ BEO/ಜಿಲ್ಲಾ ದತ್ತಾಂಶ ಸಹಾಯ ಪಡೆಯಿರಿ.

15. SATS ಕುರಿತು ನಮ್ಮ ಶಾಲೆಗೆ ಅಧಿಕೃತ ಸಹಾಯ ಹೇಗೆ ಪಡೆಯುವುದು?

ಮೊದಲು ಬೇಕಾದುದು ನಿಮ್ಮ BEO/ಬ್ಲಾಕ್ ಕಚೇರಿ ಮತ್ತು district DDPI office — ಇವು ರುಜುವಾತು, ಪಾಸ್‌ವರ್ಡ್ reset, correction ಅನುಮತಿ ಇತ್ಯಾದಿ ನೀಡುತ್ತವೆ. ಸರಕಾರಿ portal ನಲ್ಲೇ helpdesk/contact ಇದ್ದರೆ ಬಳಸಿ. ಈ website ನ ಸ್ವತಂತ್ರ guide ಮಾಹಿತಿ ಸಹಾಯಕವಾಗಬಹುದು ಆದರೆ ನಿಮ್ಮ ಶಾಲೆಯ data ವಿಷಯದಲ್ಲಿ ಇಲಾಖಾ ಮಾಹಿತಿಯೇ ಅಂತಿಮ.
