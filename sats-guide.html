SATS — ವಿದ್ಯಾರ್ಥಿ ದತ್ತಾಂಶ ವ್ಯವಸ್ಥೆ

✅ Last verified: 09 September 2026

ℹ️ Note: Portal ನಲ್ಲಿ menu/field ಹೆಸರುಗಳು ಮತ್ತು ನೋಂದಣಿ ಕ್ಷೇತ್ರಗಳು ಇಲಾಖಾ ಪರಿಚಲನೆಯಂತೆ ಬದಲಾಗಬಹುದು — ದತ್ತಾಂಶ ನಮೂದಿಸುವ ಮೊದಲು ಅಧಿಕೃತ User Manual / BEO ಸೂಚನೆ ಪರಿಶೀಲಿಸಿ.

SATS (Student Achievement Tracking System) — ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆಯ ಅಧಿಕೃತ ವಿದ್ಯಾರ್ಥಿ ದತ್ತಾಂಶ ವ್ಯವಸ್ಥೆ. ಪ್ರತಿ ಮಗುವಿಗೆ ಒಂದು SATS ID ಇರುತ್ತದೆ; ಪ್ರವೇಶ, ತರಗತಿ ಏರಿಕೆ (promotion), ಶಾಲೆ ಬದಲಾವಣೆ, TC, ಹಾಜರಾತಿ ಮತ್ತು ಪ್ರಮಾಣಪತ್ರ — ಎಲ್ಲವೂ ಈ ID ಯ ಆಧಾರದಲ್ಲಿ ನಿರ್ವಹಣೆಯಾಗುತ್ತದೆ. ವಿದ್ಯಾರ್ಥಿವೇತನ, ಮಿಡ್-ಡೇ ಮೀಲ್ ಮತ್ತು UDISE+ ದತ್ತಾಂಶ ಸಹ SATS ದತ್ತಾಂಶದಿಂದಲೇ ಸಂಬಂಧಿಸುತ್ತವೆ.

⚠️ ಮುಖ್ಯ ಸೂಚನೆ: ನೋಂದಣಿ ಕ್ಷೇತ್ರಗಳು, ಫೋಟೋ ಗಾತ್ರ, ID ರೂಪ ಮತ್ತು ಮೆನು ಹೆಸರುಗಳು ಅಧಿಕೃತ portal ಉತ್ತಮಗೊಳ್ಳುತ್ತಿದ್ದಂತೆ ಭಿನ್ನವಾಗಿರಬಹುದು. ನೋಂದಣಿ/ದತ್ತಾಂಶ ನಮೂದಿಸುವ ಮೊದಲು ಅಧಿಕೃತ ಪೋರ್ಟಲ್ ಮತ್ತು User Manual ಪರಿಶೀಲಿಸಿ — ನಿಮ್ಮ BEO/ಜಿಲ್ಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ಸೂಚನೆಗಳೇ ಅಂತಿಮ.

1. SATS ನಲ್ಲಿ ಏನೇನು ಮಾಡಬಹುದು?

ಕೆಲಸಏನು?ಯಾರು
ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿಹೊಸ ಮಗುವಿಗೆ SATS ID ಸೃಷ್ಟಿ — ಹೆಸರು, DOB, ಜಾತಿ, ವಿಳಾಸ, ಫೋಟೋಶಾಲಾ admin / ಡೇಟಾ ಆಪರೇಟರ್
ದೈನಂದಿನ ಹಾಜರಾತಿಪ್ರತಿ ಕೆಲಸದ ದಿನದ Present/Absent ದಾಖಲೆತರಗತಿ ಶಿಕ್ಷಕ
Promotion / Class changeಶೈಕ್ಷಣಿಕ ವರ್ಷ ಆರಂಭದಲ್ಲಿ ತರಗತಿ ಏರಿಕೆಶಾಲೆ (ಇಲಾಖಾ ಸೂಚನಾನುಸಾರ)
TC / ವರ್ಗಾವಣೆಮಗು ಶಾಲೆ ಬದಲಿಸಿದಾಗ TC ಮತ್ತು ನಿರ್ಗಮನ ದಾಖಲೆಶಾಲೆ / BEO
ವರದಿ ಕಾರ್ಡ್School Report Card — ದತ್ತಾಂಶ ನೋಡುವುದು/ಪ್ರಿಂಟ್ಮುಖ್ಯ ಶಿಕ್ಷಕ / BEO

2. ದತ್ತಾಂಶ ಮೊದಲು — ಏನು ಸಿದ್ಧವಿರಬೇಕು?

✅ Check-list (ನೋಂದಣಿ/ದತ್ತಾಂಶ ಕೆಲಸ ಮೊದಲು):

  • Login ರುಜುವಾತು: User ID + password — DDPI/BEO office ನೀಡುತ್ತದೆ; ಮೊದಲ login ನಲ್ಲಿ password ಬದಲಿಸಬೇಕಾಗುತ್ತದೆ.
  • ಮಗುವಿನ ದಾಖಲೆ: ಜನ್ಮ ಪ್ರಮಾಣಪತ್ರ/ಸ್ಕೂಲ್ ದಾಖಲೆಯ ಪ್ರಕಾರ ಹೆಸರು + DOB; ಜಾತಿ ಪ್ರಮಾಣಪತ್ರ.
  • ಇತ್ತೀಚಿನ ಫೋಟೋ: JPG, ಸಣ್ಣ ಗಾತ್ರ (ಉದಾ. ~100 KB — portal ನ ನಿಗದಿ ಪರಿಶೀಲಿಸಿ).
  • ಹಳೆಯ ದಾಖಲೆ (ವರ್ಗಾವಣೆ ಮಗು): ಹಿಂದಿನ ಶಾಲೆಯ TC/ವಿವರ.
  • ಕಂಪ್ಯೂಟರ್/ಇಂಟರ್ನೆಟ್: ಒಳ್ಳೆಯ ಬ್ರೌಸರ್ (Chrome/Edge) ಮತ್ತು ಸ್ಥಿರ internet ಸಂಪರ್ಕ.

3. Login ಹೇಗೆ?

1

sts.karnataka.gov.in/SATS ತೆರೆದು LOGIN ಆಯ್ಕೆ ಮಾಡಿ.

2

User ID ಮತ್ತು Password ನಮೂದಿಸಿ (DDPI/BEO office ನೀಡಿದ ರುಜುವಾತು).

3

ಮೊದಲ ಬಾರಿ login ಆಗುತ್ತಿದ್ದರೆ ಪಾಸ್‌ವರ್ಡ್ ಬದಲಿಸಲು ಸೂಚನೆ ಬರುತ್ತದೆ — ಬಲವಾದ ಪಾಸ್‌ವರ್ಡ್ ಇಡಿ ಮತ್ತು ಎಲ್ಲೂ ಹಂಚಿಕೊಳ್ಳಬೇಡಿ.

4

Login ನಲ್ಲಿ ಸಮಸ್ಯೆಯಾದರೆ → User ID/ಪಾಸ್‌ವರ್ಡ್ Reset ಗಾಗಿ BEO/ಬ್ಲಾಕ್ ಕಚೇರಿ ಸಂಪರ್ಕಿಸಿ (ಕಡಿಮೆ ಸಮಯ — ಜಿಲ್ಲಾ/ರಾಜ್ಯ helpdesk ಕೊನೆಯ ಆಯ್ಕೆ).

✅ Portal ಮೆನುಗಳಿಗೆ ಅನುಗುಣವಾಗಿ ಈ ಹಂತಗಳನ್ನು ನವೀಕರಿಸಲಾಗಿದೆ (09-09-2026).

4. ಹೊಸ ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ (Student Registration)

  1. ಮೊದಲು duplicate check: ಹೊಸ ID ಸೃಷ್ಟಿಸುವ ಮೊದಲು ಶಾಲಾ ಪಟ್ಟಿಯಲ್ಲಿ (ಮತ್ತು ಸಾಧ್ಯವಾದಷ್ಟು ಹುಡುಕಾಟದಲ್ಲಿ) ಹೆಸರಿನಿಂದ/mobile ನಿಂದ ಪರಿಶೀಲಿಸಿ — ಮಗುವಿಗೆ ಈಗಾಗಲೇ SATS ID ಇದ್ದರೆ ಹೊಸದು ಬೇಡ.
  2. Login ಆಗಿ Registration → Add New Student ಆಯ್ಕೆ ಮಾಡಿ.
  3. ವಿವರ ಭರ್ತಿ: ಹೆಸರು (ಜನ್ಮ/ಶಾಲಾ ದಾಖಲೆಯಂತೆ), ಜನ್ಮದಿನ (DD/MM/YYYY), ಲಿಂಗ, ಜಾತಿ, ಧರ್ಮ, ವಿಳಾಸ, ತಾಯಿ/ತಂದೆ ಹೆಸರು, ಏನಾದರೂ ಹಿಂದಿನ ಶಾಲೆ ಇದ್ದರೆ ಅದರ ವಿವರ.
  4. ಫೋಟೋ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ (ನಿಗದಿತ ಗಾತ್ರ/ಫಾರ್ಮ್ಯಾಟ್).
  5. Save/Submit ಒತ್ತಿ — SATS ID generate ಆಗುತ್ತದೆ (ಉದಾ. KA-… — ರೂಪ ಇಲಾಖಾ ಸೂಚನೆಯಂತೆ ಬದಲಾಗಬಹುದು).
  6. ನೋಂದಣಿಯಾದ ವಿದ್ಯಾರ್ಥಿ ಶಾಲಾ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿ ಕಾಣಿಸುತ್ತಿದೆಯೇ ಪರಿಶೀಲಿಸಿ — ಕಾಣಿಸದಿದ್ದರೆ Save ಆಗಿಲ್ಲ ಎಂದರ್ಥ.

✏️ ಉದಾಹರಣೆ: 1ನೇ ತರಗತಿಗೆ ಹೊಸದಾಗಿ ಪ್ರವೇಶ ಪಡೆದ ಮಗು. ಶಾಲೆಯಲ್ಲಿ ಈ ಮಗುವಿಗೆ SATS ID ಇಲ್ಲ ಎಂದು ಖಚಿತಪಡಿಸಿ → Registration form ನಲ್ಲಿ ಹೆಸರು (ಜನ್ಮ ಪ್ರಮಾಣಪತ್ರದಂತೆ), DOB, ಜಾತಿ ಭರ್ತಿ → ಫೋಟೋ ಅಪ್‌ಲೋಡ್ → Save. ಹೊಸ SATS ID ಬಂದಾಗ ಶಾಲಾ ದಾಖಲೆಯಲ್ಲಿ (register) ಬರೆದಿಡಿ — ಭವಿಷ್ಯದ ವರದಿಕಾರ್ಡ್/TC ಯಲ್ಲಿ ಅದೇ ID ಬಳಕೆಯಾಗುತ್ತದೆ.

5. ದೈನಂದಿನ ಹಾಜರಾತಿ

  1. Attendance → Daily Attendance ಆಯ್ಕೆ ಮಾಡಿ.
  2. ದಿನಾಂಕ (ಇಂದಿನ) ಆಯ್ಕೆ ಮಾಡಿ — ತರಗತಿಯ ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿ ಬರುತ್ತದೆ.
  3. ಸುಲಭ ಕ್ರಮ: ಮೊದಲು ಎಲ್ಲರನ್ನೂ Present ಆಗಿ ಗುರುತಿಸಿ, ನಂತರ absent ಆದ ಮಕ್ಕಳನ್ನು ಬದಲಿಸಿ — ಸಮಯ ಉಳಿಯುತ್ತದೆ.
  4. Absent ಮಗುವಿಗೆ ಕಾರಣ (ಇದ್ದರೆ) ನಮೂದಿಸಿ.
  5. Save ಒತ್ತಿ — ದಿನ ಕೊನೆಯಲ್ಲಿ ನಮೂದಿದ್ದು ಖಚಿತಪಡಿಸಿ; ಅರ್ಧ ಬಿಟ್ಟ ದಿನ ಮುಂದಿನ ಬೆಳಿಗ್ಗೆ ತಿದ್ದಲು ಸಾಧ್ಯವಾಗುವುದಿಲ್ಲ (ಪೋರ್ಟಲ್ ನಿಯಮದಂತೆ).

💡 ಒಂದು ದಿನದ ಹರಿವು (quick routine): Login → Daily Attendance (ಸ್ಕೂಲ್ ಮುಗಿಯುವ ಮೊದಲೇ) → ಹೊಸ ಮಗು ಸೇರಿದ್ದರೆ Registration → ಯಾವುದೇ ವರದಿ ಬೇಕಿದ್ದರೆ Report Card → Logout. ಪ್ರತಿದಿನ ಇರುವ ಕ್ರಮ ಇದನ್ನು 10–15 ನಿಮಿಷದಲ್ಲಿ ಮುಗಿಸಬಹುದು.

6. Promotion (ತರಗತಿ ಏರಿಕೆ) — ಶೈಕ್ಷಣಿಕ ವರ್ಷ ಆರಂಭದಲ್ಲಿ

  1. ವರ್ಷ ಆರಂಭದಲ್ಲಿ (ಸಾಮಾನ್ಯವಾಗಿ ಏಪ್ರಿಲ್–ಮೇ) ಇಲಾಖಾ ಸೂಚನೆ ಬಂದಾಗ Promotion/Class Change ಆಯ್ಕೆ ಮಾಡಿ.
  2. ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ ಮುಂದಿನ ತರಗತಿ ಆಯ್ಕೆ; ಅದೇ ತರಗತಿಯಲ್ಲಿ ಉಳಿಸಬೇಕಾದವರಿಗೆ status ಗುರುತಿಸಿ.
  3. Save → ಶಾಲಾ ದಾಖಲೆ (class-wise list) ಜೊತೆ ಹೋಲಿಸಿ.
  4. ಹೊಸ ವಿದ್ಯಾರ್ಥಿ ಪ್ರವೇಶದವರು ಇಲಾಖಾ ಸೂಚನಾ ಪ್ರಕಾರ admission/registration ಮೂಲಕ ಸೇರಿಸುತ್ತಾರೆ.

7. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು & ಪರಿಹಾರ

ಸಮಸ್ಯೆಏನು ಪರಿಶೀಲಿಸುವುದುಪರಿಹಾರ
Login ಆಗುತ್ತಿಲ್ಲUser ID ಸರಿಯಿದೆಯೇ; caps lock; ಇಂಟರ್ನೆಟ್ ಸಂಪರ್ಕಪಾಸ್‌ವರ್ಡ್ reset ಗೆ BEO office ಸಂಪರ್ಕಿಸಿ (Forgot/Reset link ಇದ್ದರೆ ಬಳಸಿ).
"Error Occurred" ಪುಟಸರ್ವರ್‌ನ ತಾತ್ಕಾಲಿಕ ದೋಷChrome/Edge ಬಳಸಿ, cache clear, sts.karnataka.gov.in/SATS/ ಮತ್ತೆ ತೆರೆದು 2–3 ನಿಮಿಷ ಬಿಟ್ಟು retry.
ಹೊಸ ನೋಂದಣಿ enabled ಇಲ್ಲಪರಿಚಲನೆ ಪ್ರಕಾರ ನೋಂದಣಿ ಅವಧಿ/ಅನುಮತಿಬ್ಲಾಕ್/ಜಿಲ್ಲಾ ಮಟ್ಟದ ಅನುಮತಿ ಪಡೆಯಿರಿ; ಅವಧಿ ಮುಗಿದಿದ್ದರೆ ಇಲಾಖಾ ಸೂಚನೆ ಪ್ರಕಾರ ಅನುಮತಿಸಿದ ಅವಧಿಯಲ್ಲಿ ಮಾಡಿ.
ಫೋಟೋ ಅಪ್‌ಲೋಡ್ ಆಗುತ್ತಿಲ್ಲಗಾತ್ರ/ಫಾರ್ಮ್ಯಾಟ್JPG, ನಿಗದಿತ KB ಒಳಗೆ ಇರುವಂತೆ ಚಿಕ್ಕದಾಗಿಸಿ; ಮತ್ತೆ ಅಪ್‌ಲೋಡ್.
ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣುತ್ತಿಲ್ಲSave ಆಗಿಲ್ಲ / ತಪ್ಪು ತರಗತಿ ಆಯ್ಕೆRegistration ಮತ್ತೆ ಬಿಟ್ಟು Save; ತರಗತಿ/ವಿಭಾಗ ಸರಿಯಿದೆಯೇ ನೋಡಿ.
Duplicate ID / ಮಗು ಎರಡೂ ಕಡೆ ನೋಂದಣಿಹಳೆಯ ಶಾಲೆ ದಾಖಲೆಮಗುವಿಗೆ ಒಂದೇ ID ಇರಲಿ — ಎರಡೆಡೆ ಇದ್ದರೆ ಹೊಸ ಶಾಲೆಗೆ TC/ನಿರ್ಗಮನ ಸರಿಪಡಿಸಿ, BEO ಮಾರ್ಗದರ್ಶನ ಪಡೆಯಿರಿ.
DOB/ಜಾತಿ ತಪ್ಪಾಗಿ ನಮೂದಾಗಿದೆಜನ್ಮ/ಜಾತಿ ದಾಖಲೆಅಧಿಕಾರಿ edit ಅನುಮತಿಯಿಂದ correction; ಸ್ಕ್ರೀನ್‌ಶಾಟ್ + ದಿನಾಂಕ ದಾಖಲಿಸಿ.

8. ಪ್ರಮುಖ ಅಂಶಗಳು ⭐

  • ಒಂದು ಮಗು = ಒಂದೇ SATS ID: ತರಗತಿ/ಶಾಲೆ ಬದಲಾದರೂ ID ಬದಲಾಗಬಾರದು — duplicate ID ಮಾಡದಿರಿ.
  • ಪ್ರಮಾಣ ದಾಖಲೆಗೆ ಭಿನ್ನ ಹೆಸರು ಬೇಡ: ಜನ್ಮ ಪ್ರಮಾಣಪತ್ರ/Aadhaar/ಹಿಂದಿನ ಶಾಲಾ ದಾಖಲೆ ಜೊತೆ ಹೊಂದಾಣಿಕೆ — ತಪ್ಪಿದರೆ ವರ್ಗಾವಣೆ/ವಿದ್ಯಾರ್ಥಿವೇತನದಲ್ಲಿ ತೊಡಕು.
  • MDM / ಉಚಿತ ಪುಸ್ತಕ / ವಿದ್ಯಾರ್ಥಿವೇತನ: ಇವುಗಳ ದಾಖಲೆ SATS ದತ್ತಾಂಶ ಆಧಾರದಲ್ಲಿ — ನಿಖರವಾಗಿರಲಿ.
  • ತಿಂಗಳ ಬ್ಯಾಕಪ್: ತಿಂಗಳ ಕೊನೆಯಲ್ಲಿ Report/dict data export ಇಳಿಸಿ ದಾಖಲಿಸಿ.
  • TC ಮಾಹಿತಿ: ಹೊಸ ಮಗುವಿಗೆ TC ವಿವರ ಸೂಕ್ತ ಕ್ಷೇತ್ರದಲ್ಲಿ ನಮೂದಿಸಿ.

9. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. SATS ID ಏನು — ಎಲ್ಲಿಂದ ಸಿಗುತ್ತದೆ?

SATS ID ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ ಶಾಶ್ವತ ದತ್ತಾಂಶ ಸಂಖ್ಯೆ. ನೋಂದಣಿ ಆದಾಗ portal ಸ್ವಯಂ generate ಮಾಡುತ್ತದೆ; ಈಗಾಗಲೇ ಇರುವ ಮಗುವಿಗೆ School Report Card/Registration ಮೆನು ಅಥವಾ BEO office ದತ್ತಾಂಶದಲ್ಲಿ ಸಿಗುತ್ತದೆ.

2. ಮಗು ಶಾಲೆ ಬದಲಿಸಿದರೆ ಹೊಸ SATS ID ಬೇಕೆ?

ಬೇಡ — ID ಶಾಶ್ವತ. ಹೊಸ ಶಾಲೆಯಲ್ಲಿ ಹಳೆಯ ID ವಿವರದೊಂದಿಗೆ Transfer/ನಿರ್ಗಮನ ಪ್ರಕ್ರಿಯೆ ಮಾಡಬೇಕು. ಬೇರೆ ರಾಜ್ಯದಿಂದ ಬಂದ ಮಗುವಿಗೆ fresh registration ಜೊತೆ ಹಿಂದಿನ ವಿವರ ಸೇರಿಸಿ.

3. Login ಪಾಸ್‌ವರ್ಡ್ ಮರೆತಿದ್ದಾರೆ — ಹೇಗೆ?

ಪೋರ್ಟಲ್ ನಲ್ಲಿ Forgot/Reset ಲಿಂಕ್ ಇದ್ದರೆ ಬಳಸಿ; ಇಲ್ಲದಿದ್ದರೆ BEO office ನಲ್ಲಿ User ID reset/ಪಾಸ್‌ವರ್ಡ್ ಮರುನೀಡಿಕೆ ಮಾಡಿಸಿ — ಹಂಚದೆ ಸುರಕ್ಷಿತವಾಗಿ ಇರಿಸಿ.

4. ಒಂದು ದಿನ ಹಾಜರಾತಿ ಮರೆತು ಬಿಟ್ಟರೆ?

ದಿನ ಆಯ್ಕೆಮಾಡಿ Attendance ಮೆನುವಿನಲ್ಲಿ ಹಿಂದಿನ ದಿನವನ್ನು (portal ಅನುಮತಿಸಿದರೆ) ತೆರೆದು ಸರಿಪಡಿಸಬಹುದು — ಅವಕಾಶವಿಲ್ಲದಿದ್ದರೆ BEO/ಬ್ಲಾಕ್ ಮಟ್ಟದ ಸಹಾಯ ಪಡೆಯಿರಿ.

5. ಹೆಸರು/ಜಾತಿ ತಪ್ಪಾಗಿದ್ದರೆ correction ಹೇಗೆ?

ಅಧಿಕಾರಿಗಳ edit ಅನುಮತಿಯಿಂದ correction; ಪ್ರಮಾಣ ದಾಖಲೆಯ ಪ್ರಕಾರ ಹೆಸರು ಇಡಿ. ತಿದ್ದುಪಡಿ ದಾಖಲಾಗುವಂತೆ screenshot/ದಿನಾಂಕ ಇಟ್ಟುಕೊಳ್ಳಿ.

6. ನಿರಂತರ ಆ್ಯಪ್ ಜೊತೆ ಸಂಬಂಧವೇನು?

ನಿರಂತರ ಆ್ಯಪ್ ಮುಖ ಸೆರೆಹಿಡಿಯುವ AI ಹಾಜರಾತಿ ವ್ಯವಸ್ಥೆ; ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ/base ದತ್ತಾಂಶದಲ್ಲಿ SATS ID ಲಿಂಕ್ ಆಗುತ್ತದೆ (ಇಲಾಖಾ ಸೂಚನಾ ಪ್ರಕಾರ). ವ್ಯತ್ಯಾಸ ತಿಳಿಯಲು SATS vs ನಿರಂತರ ನೋಡಿ.
