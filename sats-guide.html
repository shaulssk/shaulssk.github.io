SATS — ವಿದ್ಯಾರ್ಥಿ ದತ್ತಾಂಶ ವ್ಯವಸ್ಥೆ

Student Tracking System · ಕರ್ನಾಟಕ ಸರ್ಕಾರ · ಕೊನೆಯ ನವೀಕರಣ: 05-09-2026

SATS (Student Tracking System) — ಕರ್ನಾಟಕ ಸರ್ಕಾರದ ವಿದ್ಯಾರ್ಥಿ ದತ್ತಾಂಶ ನಮೂದಿಸುವ ಅಧಿಕೃತ ಪೋರ್ಟಲ್. ಪ್ರತಿ ಮಗುವಿಗೆ ಒಂದು SATS ID — ಪ್ರವೇಶ, ತರಗತಿ, ಶಾಲೆ ಬದಲಾವಣೆ, ಪ್ರಮಾಣಪತ್ರ ಎಲ್ಲದಕ್ಕೂ ಇದೇ ಆಧಾರ.

⚠️ ಮುಖ್ಯ ಸೂಚನೆ: ಈ ಮಾರ್ಗದರ್ಶಿಯಲ್ಲಿನ ವಿವರಗಳು (ನೋಂದಣಿ ಕ್ಷೇತ್ರಗಳು, ಫೋಟೋ ಗಾತ್ರ, ID ರೂಪ, ಮೆನು ಹೆಸರುಗಳು ಇತ್ಯಾದಿ) ಅಧಿಕೃತ portal/process ಬದಲಾವಣೆಯಿಂದ ಭಿನ್ನವಾಗಿರಬಹುದು. ನೋಂದಣಿ ಅಥವಾ ದತ್ತಾಂಶ ನಮೂದಿಸುವ ಮೊದಲು ಅಧಿಕೃತ ಪೋರ್ಟಲ್ ಮತ್ತು User Manual ಪರಿಶೀಲಿಸಿ — ನಿಮ್ಮ BEO/ಜಿಲ್ಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ಸೂಚನೆಗಳೇ ಅಂತಿಮ.

2. SATS ಯಾಕೆ ಮುಖ್ಯ?

  • ವಿದ್ಯಾರ್ಥಿ ID — ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ ಶಾಶ್ವತ SATS ID
  • ದಾಖಲಾತಿ — ಹೊಸ ಪ್ರವೇಶ, ತರಗತಿ ಚಕ್ರ, ಶಾಲಾ ಬದಲಾವಣೆ
  • ಹಾಜರಾತಿ — ದೈನಂದಿನ ಹಾಜರಾತಿ ದಾಖಲೆ
  • ಪ್ರಮಾಣಪತ್ರ — TC, ದೃಢೀಕರಣ ಎಲ್ಲಾ SATS ಆಧಾರ
  • ಸರ್ಕಾರಿ ಯೋಜನೆ — ಸ್ಕಾಲರ್ಶಿಪ್, ಮಿಡ್-ಡೇ ಮೀಲ್, ದತ್ತಾಂಶ ಲಿಂಕ್

1

sts.karnataka.gov.in open madi — login click madi.

2

ನಿಮ್ಮ User ID & Password ಮೂಲಕ login madi (DDPI/BEO office ಕಡೆಯಿಂದ ಕೊಡುತ್ತಾರೆ).

3

ಮೊದಲ login ge password change kudutte — strong password set madi.

4

Login aagilla andre → ಸಹಾಯ: BEO office / ಬ್ಲಾಕ್ ನೋಡಲorer ಹತ್ತಿರ user id reset madisi.

4. ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ (Student Registration)

⚠️ ಗಮನಿಸಿ: ಕೆಳಗಿನ ಹಂತಗಳು ಸಾಮಾನ್ಯ ಅನುಭವದ ಆಧಾರದಲ್ಲಿವೆ. ಅಧಿಕೃತ portalನಲ್ಲಿ ಕ್ಷೇತ್ರಗಳು / ಫೋಟೋ ಗಾತ್ರ / ID ಫಾರ್ಮ್ಯಾಟ್ ಬದಲಾಗಿರಬಹುದು — ನೋಂದಣಿ ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು ಪೋರ್ಟಲ್‌ನ User Manual ಮತ್ತು ಇದೇ ಪುಟದಲ್ಲಿನ ಅಧಿಕೃತ ಲಿಂಕ್ ಪರಿಶೀಲಿಸಿ.

1

Login aagi Student Registration menu select madi.

2

Add New Student click madi — ಹೆಸರು, ದಿನಾಂಕ, ಲಿಂಗ, ಜಾತಿ, ವಿಳಾಸ, SATS ID fill madi.

3

ಫೋಟೋ ಅಪ್‌ಲೋಡ್ madi (ಇತ್ತೀಚಿನ ಶಾಲಾ ಫೋಟೋ ಇರಬೇಕು).

4

Save click — SATS ID generate agutte (ಉದಾ. KA-XXXX-XXXX).

5

ID salivi — ಶಾಲಾ ದಾಖಲೆ, ಹಾಜರಾತಿ, ನಿರಂತರದಲ್ಲಿಯೂ ಅದೇ ID use agutte.

5. ಹಾಜರಾತಿ ನಮೂದಿಸುವುದು
