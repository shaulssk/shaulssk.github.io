👨‍🎓 UDISE+ Student Module — GP + EP + FP Update 2026-27

UDISE+ · Student Module / SDMS · GP (General Profile) · EP (Enrollment Profile) · FP (Facilities Profile)

✅ Last verified: 25 Sep 2026 · 📌 Official Portal: udiseplus.gov.in

⚠️ ಪ್ರಮುಖ: ಈ ಪುಟ ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ — UDISE+ / NIEPA / ಸರ್ಕಾರದ ಅಧಿಕೃತ ಪುಟ ಅಲ್ಲ. UDISE+ ಇಂಟರ್ಫೇಸ್, fields ಮತ್ತು Academic Year ಆಯ್ಕೆ ಬದಲಾಗಬಹುದು — ಅಧಿಕೃತ udiseplus.gov.in Portal (Login for All Modules) ಪರಿಶೀಲಿಸಿ.

1. ಈ ಕೆಲಸ ಏನು? (GP + EP + FP)

2026-27ನೇ ಸಾಲಿನಲ್ಲಿ UDISE+ Student Moduleನಲ್ಲಿ ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಯ ಮೂರು ವಿಭಾಗಗಳ ಮಾಹಿತಿಯನ್ನು ನವೀಕರಿಸುವುದು:

🟢 GP / General Profile: ವಿದ್ಯಾರ್ಥಿಯ ವೈಯಕ್ತಿಕ ಮಾಹಿತಿ — ಹೆಸರು, DOB, ಲಿಂಗ, Aadhaar ಸಂಬಂಧಿತ ವಿವರ, Social Category, Mother Tongue, Disability/CWSN ವಿವರ, Address ಮತ್ತು ಇತರೆ Profile fields.

🟢 EP / Enrollment Profile: ಶಾಲಾ ದಾಖಲಾತಿ (admission) ವಿವರ — Class, Section, Admission Number, Admission/Enrollment details, Current class details, Promotion/Progression ಸಂಬಂಧಿತ ಮಾಹಿತಿ ಮತ್ತು ಪೋರ್ಟಲ್‌ನಲ್ಲಿರುವ ಇತರೆ Enrollment fields.

🟢 FP / Facilities Profile: ವಿದ್ಯಾರ್ಥಿಗೆ ಸಿಗುವ ಸೌಲಭ್ಯಗಳು — 🍚 Meal/Nutrition, 📚 Textbook, 👕 Uniform, 🎒 ಇತರೆ student facilities, 🎓 Scholarship/benefit fields, ♿ CWSN facility (ಲಭ್ಯವಿದ್ದಲ್ಲಿ).

🎯 ಗುರಿ: ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ GP = Completed · EP = Completed · FP = Completed — Class-wise Student List ನಲ್ಲಿ status ಪೂರ್ಣವಾಗಿ ಕಾಣಿಸುವಂತೆ.

2. STEP 1 — Login

  1. 🌐 UDISE+ Portal: udiseplus.gov.in ತೆರೆಯಿರಿ.
  2. Login for All Modules ಕ್ಲಿಕ್ ಮಾಡಿ.
  3. ನಿಮ್ಮ State ಆಯ್ಕೆಮಾಡಿ.
  4. Student Module / SDMS ಆಯ್ಕೆಮಾಡಿ.
  5. School UDISE ID + Password ನಮೂದಿಸಿ.
  6. Academic Year = 2026-27 ಆಯ್ಕೆಮಾಡಿ.

💡 ನೆನಪಿಡಿ: UDISE ID 11 ಅಂಕಿಯ ಶಾಲಾ ಕೋಡ್; ಸರಿಯಾದ Academic Year ಇಲ್ಲದಿದ್ದರೆ 2026-27 ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿ ಕಾಣದೇ ಹೋಗಬಹುದು.

3. STEP 2 — Student Module

  1. Student Module ತೆರೆಯಿರಿ.
  2. Student List / Student Details ಆಯ್ಕೆಮಾಡಿ.
  3. Class & Section ಆಯ್ಕೆಮಾಡಿ.
  4. ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರನ್ನು ಆಯ್ಕೆಮಾಡಿ.
  5. ಮೊದಲು ಆ ವಿದ್ಯಾರ್ಥಿಯ GP, EP, FP Status ಪರಿಶೀಲಿಸಿ.

4. STEP 3 — GP Update (General Profile)

  • ವೈಯಕ್ತಿಕ ಮಾಹಿತಿ ಪರಿಶೀಲಿಸಿ: Student Name · Date of Birth · Gender · Aadhaar ಸಂಬಂಧಿತ ವಿವರ · Social Category · Mother Tongue · Disability/CWSN · Address.
  • 💥 ಮುಖ್ಯ: ದಾಖಲೆಗಳಲ್ಲಿರುವ ಮಾಹಿತಿಯೊಂದಿಗೆ ಹೊಂದಾಣಿಕೆ ಮಾಡಿ ಮಾತ್ರ update — ಊಹೆ ಅಥವಾ ನಕಲು ಅಲ್ಲ.
  • ಎಲ್ಲಾ ವಿವರ ಪರಿಶೀಲಿಸಿ → Save / Update → Status = Completed ಆಗಿದೆಯೇ ನೋಡಿ.

5. STEP 4 — EP Update (Enrollment Profile)

  • ದಾಖಲಾತಿ/Enrollment ವಿವರ ಪರಿಶೀಲಿಸಿ: Class · Section · Admission Number · Admission/Enrollment details · Current class details · Promotion/Progression ಮಾಹಿತಿ.
  • School records (Admission Register) ಜೊತೆ ಹೋಲಿಸಿ → ಸರಿಯಾದ ವಿವರ ನಮೂದಿಸಿ.
  • Save / Update → EP Status ಪರಿಶೀಲಿಸಿ.

6. STEP 5 — FP Update (Facilities Profile)

  • ವಿದ್ಯಾರ್ಥಿಗೆ ಸಿಗುವ ಸೌಲಭ್ಯಗಳನ್ನು ನಮೂದಿಸಿ: Meal/Nutrition · Textbook · Uniform · ಇತರೆ Student Facilities · Scholarship/benefit fields · CWSN facility (ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಇದ್ದರೆ ಮಾತ್ರ).
  • ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಕಾಣಿಸುವ current fields/options ಗಳಿಗೆ ಅನುಗುಣವಾಗಿ ಮಾತ್ರ ಸರಿಯಾದ option ಆಯ್ಕೆಮಾಡಿ.
  • Save / Update → FP Status ಪರಿಶೀಲಿಸಿ.

⚠️ ಗಮನ: FP fields ರಾಜ್ಯ/ಪೋರ್ಟಲ್ ಆವೃತ್ತಿಯಲ್ಲಿ ಬದಲಾಗಬಹುದು — ಅಲ್ಲಿ ಕಂಡ options ಪ್ರಕಾರ ಮಾತ್ರ ಭರ್ತಿ ಮಾಡಿ. ಇಲ್ಲದ option ಗಳನ್ನು ಸೇರಿಸಬೇಡಿ.

7. STEP 6 — ಅಂತಿಮ ಪರಿಶೀಲನೆ (Final Verification)

  1. ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೆ GP = Completed ✓ · EP = Completed ✓ · FP = Completed ✓ ಇರುವುದು ಖಚಿತಪಡಿಸಿ.
  2. ನಂತರ Class-wise Student List ಪರಿಶೀಲಿಸಿ.
  3. ಯಾವುದೇ ವಿದ್ಯಾರ್ಥಿ pending ಇದ್ದರೆ — ಆ ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರು/Class ಗುರುತಿಸಿ Update ಮುಗಿಸಿ.

9. FAQ

GP full form ಏನು?

GP = General Profile — ವಿದ್ಯಾರ್ಥಿಯ ವೈಯಕ್ತಿಕ ಮಾಹಿತಿ (ಹೆಸರು, DOB, ಲಿಂಗ, Aadhaar, category ಇತ್ಯಾದಿ).

EP full form ಏನು?

EP = Enrollment Profile — ಶಾಲಾ ದಾಖಲಾತಿ/Admission ವಿವರ (Class, Section, Admission Number, promotion ಇತ್ಯಾದಿ).

FP full form ಏನು?

FP = Facilities Profile — ವಿದ್ಯಾರ್ಥಿಗೆ ಸಿಗುವ ಸೌಲಭ್ಯಗಳು (Meal, Textbook, Uniform, Scholarship, CWSN ಇತ್ಯಾದಿ).

ಈ ಕೆಲಸಕ್ಕೆ ನೇರ URL ಯಾವುದು?

ಅಧಿಕೃತ Portal: udiseplus.gov.in → Login for All Modules → State → Student Module/SDMS → UDISE ID + Password.

Aadhaar/DOB ತಪ್ಪಾಗಿದ್ದರೆ ಹೇಗೆ ತಿದ್ದುವುದು?

ದಾಖಲೆಗಳೊಂದಿಗೆ ಹೊಂದಾಣಿಕೆಯಲ್ಲಿ ತಿದ್ದಿ; ಗಂಭೀರ ವ್ಯತ್ಯಾಸವಿದ್ದರೆ ಜಿಲ್ಲಾ/ರಾಜ್ಯ UDISE+ ನೋಡಲ್ ಅಧಿಕಾರಿಗೆ ತಿಳಿಸಿ — ಬದಲಾವಣೆ ಬ್ಲಾಕ್ ಆಗಿರಬಹುದು.
