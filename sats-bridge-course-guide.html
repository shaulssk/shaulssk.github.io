🎓 SATS — ಸೇತುಬಂಧ (Bridge Course) Pre-Test & Post-Test Grade Entry

Student Achievement Tracking System, Karnataka · Lesson Plan & Assessment's · SATS LBA (Learning Baseline Assessment)

✅ Last verified: 25 Sep 2026 · 📌 LBA Portal (ಪ್ರತ್ಯೇಕ login): sts.karnataka.gov.in/LBA

⚠️ ಪ್ರಮುಖ: ಈ ಪುಟ ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ — SATS / ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆಯ ಅಧಿಕೃತ ಪುಟ ಅಲ್ಲ. SATS ಇಂಟರ್ಫೇಸ್, menu ಮತ್ತು buttons ಬದಲಾಗಬಹುದು — ಅಧಿಕೃತ sts.karnataka.gov.in Portal ಪರಿಶೀಲಿಸಿ.

1. ಈ ಕೆಲಸ ಏನು?

ಕರ್ನಾಟಕದ ಶಾಲಾ ಶಿಕ್ಷಣ ಮತ್ತು ಸಾಕ್ಷರತಾ ಇಲಾಖೆಯ SATS (Student Tracking System) ತಂತ್ರಾಂಶದಲ್ಲಿ ಸೇತುಬಂಧ (Bridge Course) ಪೂರ್ವ ಪರೀಕ್ಷೆ (Pre-Test) ಮತ್ತು ಸಾಫಲ್ಯ ಪರೀಕ್ಷೆ (Post-Test) ಗಳ ಗ್ರೇಡ್/ಅಂಕ ನಮೂದಿಸುವುದು. SATS LBA (Learning Baseline Assessment) ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಬ್ರಿಡ್ಜ್ ಕೋರ್ಸ್ ವಿವರಗಳನ್ನು entry ಮಾಡಬೇಕಾಗುತ್ತದೆ.

💡 ನೆನಪಿಡಿ: ಪ್ರಕ್ರಿಯೆ ಸರಳ — Login → LBA/Bridge Course menu → ವಿವರ ಆಯ್ಕೆ → Search → ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿಯಲ್ಲಿ ಗ್ರೇಡ್/ಅಂಕ → Save/Submit.

2. SATS ನಲ್ಲಿ ಬ್ರಿಡ್ಜ್ ಕೋರ್ಸ್ ಗ್ರೇಡ್ ಎಂಟ್ರಿ — ಹಂತಗಳು

1

Login ಆಗಿ (LBA ಪ್ರತ್ಯೇಕ login): ಕುಡಾ LBA ಪೋರ್ಟಲ್ — sts.karnataka.gov.in/LBA — SATS ಮುಖ್ಯ ಪೋರ್ಟಲ್‌ಗಿಂತ ಬೇರೆ/ಪ್ರತ್ಯೇಕ ಲಾಗಿನ್ ಇದೆ.

  • SATS ಮುಖ್ಯ ಪೋರ್ಟಲ್: sts.karnataka.gov.in/SATS — ವಿದ್ಯಾರ್ಥಿ ದತ್ತಾಂಶ/ಹಾಜರಾತಿ (ಪ್ರತ್ಯೇಕ login).
  • LBA ಪೋರ್ಟಲ್: sts.karnataka.gov.in/LBA — ಸೇತುಬಂಧ/FLN/Assessment entry (ಇದಕ್ಕೆ ಬೇರೆ login credentials — OTP ಆಧಾರಿತ).
  • Login as / ಪಾತ್ರ: Government & Aided Teacher → Teacher option + KGID / Employee ID; Unaided Teacher / HM / BEO / CRP → SATS User option + SATS User ID.
  • ನಿಮ್ಮ ಶಾಲೆಯ LBA ರುಜುವಾತು (LBA user name/OTP) ಇಲ್ಲದಿದ್ದರೆ — BEO/ಬ್ಲಾಕ್ ಕಚೇರಿ ಮೂಲಕ ಪಡೆಯಿರಿ.
2

Menu ಆಯ್ಕೆ ಮಾಡಿ: ಮುಖಪುಟದ ಎಡಭಾಗದಲ್ಲಿರುವ menu ನಲ್ಲಿ LBA → Bridge Course option ಮೇಲೆ click ಮಾಡಿ. (ಮೊಬೈಲ್ ಬಳಸುತ್ತಿದ್ದರೆ ಮೇಲಿನ ಮೂರು ಗೆರೆಗಳ ☰ menu button ಒತ್ತಿ).

  • SATS menu ನಲ್ಲಿ ಕಾಣುವ items: Teacher Profile · Lesson Plan · Assessment · LBA · Foundational Literacy Numeracy · Assessment Entry Report · Bridge Course.
  • Bridge Course entry ಗಾಗಿ: ಲಾಗಿನ್ ಆದ ಮೇಲೆ LBA ವಿಭಾಗದಲ್ಲಿ Bridge Course ಆಯ್ಕೆಮಾಡಿ.
3

ತರಗತಿ ವಿವರಗಳ ಆಯ್ಕೆ: ಹೊಸ ಪುಟ ತೆರೆದಾಗ ಈ ಕೆಳಗಿನ ವಿವರಗಳನ್ನು ಸರಿಯಾಗಿ ಆಯ್ಕೆ ಮಾಡಿಕೊಳ್ಳಿ:

  • ಮಾಧ್ಯಮ (Medium)
  • ತರಗತಿ (Class)
  • ಗ್ರೂಪ್ (Group)
  • ವಿಷಯ (Subject)
  • ಅಧ್ಯಾಯ (Chapter Name)
  • ಪರೀಕ್ಷೆ ನಡೆಸಿದ ದಿನಾಂಕ (Unit Test Date — dd-mm-yyyy)

💡 Section ಬಗ್ಗೆ: ಶಾಲೆಯಲ್ಲಿ ಒಂದೇ section ಇದ್ದರೆ — Section ಆಯ್ಕೆ ಮಾಡುವ ಅಗತ್ಯ ಇಲ್ಲ. ಅನೇಕ sections ಇದ್ದರೆ: ಮೊದಲು SATS portal ನಲ್ಲಿ Section and Language Updation menu ಮೂಲಕ ವಿದ್ಯಾರ್ಥಿಗಳ Section ವಿವರ update ಮಾಡಿ, ನಂತರ LBA ನಲ್ಲಿ Search ಮಾಡಿ.

💡 Is Chapter Present (ಅಧ್ಯಾಯ ಇದೆಯೇ): ಆಯ್ದ ವಿಷಯಕ್ಕೆ Chapter ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣಿಸದಿದ್ದರೆ — Is Chapter Present option ನಲ್ಲಿ 'N' ಆಯ್ಕೆಮಾಡಿ, ನಂತರ ಕಾಣಿಸುವ ಎರಡು fields ಗಳಲ್ಲಿ ಅಧ್ಯಾಯ ಸಂಖ್ಯೆ ಮತ್ತು ಅಧ್ಯಾಯದ ಹೆಸರು ಹಸ್ತಚಾಲಿತವಾಗಿ (manually) ನಮೂದಿಸಿ.

5

Search → ಗ್ರೇಡ್ / ಅಂಕ: "Search" button ಕ್ಲಿಕ್ ಮಾಡಿದ ನಂತರ ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿ ತೆರೆಯುತ್ತದೆ. ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರಿನ ಮುಂದೆ ಇರುವ box ನಲ್ಲಿ ಅವರ ಪರೀಕ್ಷಾ ಸಾಧನೆಗೆ ಅನುಗುಣವಾಗಿ ಗ್ರೇಡ್ (A, B, C ಇತ್ಯಾದಿ) ಅಥವಾ ಅಂಕಗಳನ್ನು ನಮೂದಿಸಿ.

6

Save/Submit ಮಾಡಿ: ಎಲ್ಲಾ ವಿದ್ಯಾರ್ಥಿಗಳ ವಿವರ ದಾಖಲಿಸಿದ ನಂತರ ಕೊನೆಯಲ್ಲಿರುವ "Submit" ಅಥವಾ "Save" button ಕ್ಲಿಕ್ ಮಾಡಿ — ಪ್ರಕ್ರಿಯೆ ಪೂರ್ಣಗೊಳಿಸಿ.

3. Pre-Test vs Post-Test

ಪರೀಕ್ಷೆಯಾವಾಗಏನು entry
ಪೂರ್ವ ಪರೀಕ್ಷೆ (Pre-Test)ಬ್ರಿಡ್ಜ್ ಕೋರ್ಸ್ ಪ್ರಾರಂಭಕ್ಕೆ ಮುನ್ನಆರಂಭಿಕ ಗ್ರೇಡ್/ಅಂಕ — ಮಕ್ಕಳ ಶೈಕ್ಷಣಿಕ ಸ್ಥಿತಿ ಅಳೆಯಲು
ಸಾಫಲ್ಯ ಪರೀಕ್ಷೆ (Post-Test)ಬ್ರಿಡ್ಜ್ ಕೋರ್ಸ್ ಮುಗಿದ ನಂತರಅಂತಿಮ ಗ್ರೇಡ್/ಅಂಕ — ಕಲಿಕಾ ಫಲಿತಾಂಶ ನೋಡಲು

💡 Target: Pre-Test & Post-Test ಎರಡೂ entry ಆಗಬೇಕು — ಆಗ ಮಾತ್ರ ಸಾಫಲ್ಯ (ಸುಧಾರಣೆ) ಅಳೆಯಲು ಸಾಧ್ಯ.

4. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು ಮತ್ತು ಪರಿಹಾರಗಳು

1. ವಿದ್ಯಾರ್ಥಿಗಳ ಹೆಸರು ಕಾಣಿಸದೇ ಇರುವುದು (Student list not showing)

ಸಮಸ್ಯೆ: ತರಗತಿ ಮತ್ತು ವಿಷಯ ಆಯ್ಕೆ ಮಾಡಿ 'Search' ನೀಡಿದಾಗ ವಿದ್ಯಾರ್ಥಿಗಳ ಪಟ್ಟಿ ಬರದಿರುವುದು.

ಪರಿಹಾರ: ಆ ತರಗತಿಯ ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ "Language Group Mapping" ಮತ್ತು "Subject Mapping" ಪೂರ್ಣಗೊಂಡಿದೆಯೇ ಪರಿಶೀಲಿಸಿ. ಅವು ಆಗದಿದ್ದರೆ ಪಟ್ಟಿ ಬರುವುದಿಲ್ಲ. ಹಲವು sections ಇದ್ದರೆ Section and Language Updation menu ಮೂಲಕ section update ಮಾಡಿ.

2. ಪರೀಕ್ಷಾ ದಿನಾಂಕ ನಮೂದಿಸುವಾಗ ದೋಷ (Test Date Error)

ಸಮಸ್ಯೆ: ಕ್ಯಾಲೆಂಡರ್‌ನಲ್ಲಿ ದಿನಾಂಕ ಆಯ್ಕೆ ಸಾಧ್ಯವಾಗದಿರುವುದು / ನಿಗದಿತ ಅವಧಿಯ ಹೊರಗೆ ದಿನಾಂಕ ತೋರಿಸುವುದು.

ಪರಿಹಾರ: ಇಲಾಖೆಯು ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ನಿಗದಿಪಡಿಸಿರುವ ಅಧಿಕೃತ ಸೇತುಬಂಧ ಪರೀಕ್ಷೆಯ ದಿನಾಂಕವನ್ನೇ (ಉದಾ: ಜೂನ್/ಜುಲೈ ತಿಂಗಳ ನಿರ್ದಿಷ್ಟ ದಿನಾಂಕ) ಆಯ್ಕೆ ಮಾಡಬೇಕು.

3. ಸಬ್ಮಿಟ್ ಆಗದಿರುವುದು (Submit / Save Error)

ಸಮಸ್ಯೆ: ಎಲ್ಲಾ ವಿದ್ಯಾರ್ಥಿಗಳ ಗ್ರೇಡ್‌ಗಳನ್ನು ನಮೂದಿಸಿದ ನಂತರ 'Submit' ಕೊಟ್ಟಾಗ 'Error' ಬರುವುದು.

ಪರಿಹಾರ: ಯಾವುದೇ ವಿದ್ಯಾರ್ಥಿಯ ಗ್ರೇಡ್ ಕಾಲಂ ಖಾಲಿ ಉಳಿದಿಲ್ಲ ಎಂಬುದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ. ಗೈರಾದ (absent) ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ ಇಲಾಖೆ ನಿಯಮಾವಳಿಗಳ ಪ್ರಕಾರ (ಉದಾ: 'Ab' ಅಥವಾ 'C' ಗ್ರೇಡ್) ನಮೂದಿಸಬೇಕಾಗಬಹುದು.

💡 ಈ FAQ ಉಪಯುಕ್ತ? ಸರಿ ಇಲ್ಲ — ನಿಮ್ಮ ಶಾಲೆಯ ಲಾಗಿನ್‌ನಲ್ಲಿ ಯಾವ ನಿರ್ದಿಷ್ಟ ಸಮಸ್ಯೆ ಎದುರಾಗುತ್ತಿದೆ ಎಂದು ತಿಳಿದರೆ (ಪೇಜ್ ಓಪನ್ ಆಗುತ್ತಿಲ್ಲ / ಪಟ್ಟಿ ಬರುತ್ತಿಲ್ಲ / ಡೇಟಾ Save ಆಗುತ್ತಿಲ್ಲ / ವೆಬ್‌ಸೈಟ್ ನಿಧಾನ) — ಜಿಲ್ಲಾ/ಬ್ಲಾಕ್ SATS ನೋಡಲ್ ಅಧಿಕಾರಿಗೆ ನಿಖರವಾಗಿ ತಿಳಿಸಿ.

6. FAQ

ಸೇತುಬಂಧ (Bridge Course) ಎಂದರೇನು?

ಶಾಲಾ ವರ್ಷ ಆರಂಭದಲ್ಲಿ ಕಲಿಕಾ ಅಂತರ ತುಂಬಲು ನಡೆಸುವ ಸೇತುವೆ ಕೋರ್ಸ್ — Pre-Test (ಆರಂಭ) ಮತ್ತು Post-Test (ಕೊನೆ) ಮೂಲಕ ಮಕ್ಕಳ ಪ್ರಗತಿ ಅಳೆಯುತ್ತಾರೆ.

ವಿದ್ಯಾರ್ಥಿಗಳ ಪಟ್ಟಿ ಕಾಣಿಸುತ್ತಿಲ್ಲವೇ?

Language Group Mapping ಮತ್ತು Subject Mapping ಆಗಿದೆಯೇ ಪರಿಶೀಲಿಸಿ; ಅನೇಕ sections ಇದ್ದರೆ Section and Language Updation menu ನಲ್ಲಿ section update ಮಾಡಿ.

ಅಧ್ಯಾಯ (Chapter) ಪಟ್ಟಿಯಲ್ಲಿ ಇಲ್ಲವೇ?

Is Chapter Present option ನಲ್ಲಿ 'N' ಆಯ್ಕೆಮಾಡಿ — ನಂತರ ತೆರೆಯುವ ಎರಡು fields ನಲ್ಲಿ chapter ಸಂಖ್ಯೆ ಮತ್ತು chapter ಹೆಸರನ್ನು manually ನಮೂದಿಸಿ.

ಒಂದೇ section ಶಾಲೆಯಲ್ಲಿ section ಆಯ್ಕೆ ಬೇಕೇ?

ಇಲ್ಲ — ಒಂದೇ section ಇದ್ದರೆ section ಆಯ್ಕೆ ಮಾಡುವ ಅಗತ್ಯವಿಲ್ಲ. ಅನೇಕ sections ಇದ್ದರೆ ಮೊದಲು section update ಅಗತ್ಯ.

LBA ಲಾಗಿನ್ ಮತ್ತು SATS ಲಾಗಿನ್ ಒಂದೇನಾ?

ಇಲ್ಲ — ಬೇರೆ ಬೇರೆ. SATS (sts.karnataka.gov.in/SATS) — ವಿದ್ಯಾರ್ಥಿ ದತ್ತಾಂಶ; LBA (sts.karnataka.gov.in/LBA) — Assessment/ಸೇತುಬಂಧ/FLN entry. ಎರಡಕ್ಕೂ ಪ್ರತ್ಯೇಕ login.

SATS LBA URL ಯಾವುದು?

sts.karnataka.gov.in/LBA/ — Learning Baseline Assessment (LBA) ಪೋರ್ಟಲ್ — ಪ್ರತ್ಯೇಕ login.

ಮೊಬೈಲ್‌ನಲ್ಲಿ menu ಸಿಗುತ್ತಿಲ್ಲವೇ?

ಮೇಲಿನ ಬಲ ಅಥವಾ ಎಡ ಮೂಲೆಯ ☰ (ಮೂರು ಗೆರೆ) button ಒತ್ತಿ — menu ತೆರೆಯುತ್ತದೆ.

ಈ ಪುಟ ಅಧಿಕೃತವೇ?

ಇಲ್ಲ — ಇದು ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ. ಅಧಿಕೃತ: sts.karnataka.gov.in.
