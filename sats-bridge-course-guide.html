🎓 SATS — ಸೇತುಬಂಧ (Bridge Course) Pre-Test & Post-Test Grade Entry

Student Achievement Tracking System, Karnataka · Lesson Plan & Assessment's · SATS LBA (Learning Baseline Assessment)

✅ Last verified: 25 Sep 2026 · 📌 Official Portal: sts.karnataka.gov.in · LBA: sts.karnataka.gov.in/LBA/

⚠️ ಪ್ರಮುಖ: ಈ ಪುಟ ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ — SATS / ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆಯ ಅಧಿಕೃತ ಪುಟ ಅಲ್ಲ. SATS ಇಂಟರ್ಫೇಸ್, menu ಮತ್ತು buttons ಬದಲಾಗಬಹುದು — ಅಧಿಕೃತ sts.karnataka.gov.in Portal ಪರಿಶೀಲಿಸಿ.

1. ಈ ಕೆಲಸ ಏನು?

ಕರ್ನಾಟಕದ ಶಾಲಾ ಶಿಕ್ಷಣ ಮತ್ತು ಸಾಕ್ಷರತಾ ಇಲಾಖೆಯ SATS (Student Tracking System) ತಂತ್ರಾಂಶದಲ್ಲಿ ಸೇತುಬಂಧ (Bridge Course) ಪೂರ್ವ ಪರೀಕ್ಷೆ (Pre-Test) ಮತ್ತು ಸಾಫಲ್ಯ ಪರೀಕ್ಷೆ (Post-Test) ಗಳ ಗ್ರೇಡ್/ಅಂಕ ನಮೂದಿಸುವುದು. SATS LBA (Learning Baseline Assessment) ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಬ್ರಿಡ್ಜ್ ಕೋರ್ಸ್ ವಿವರಗಳನ್ನು entry ಮಾಡಬೇಕಾಗುತ್ತದೆ.

💡 ನೆನಪಿಡಿ: ಪ್ರಕ್ರಿಯೆ ಸರಳ — Login → LBA/Bridge Course menu → ವಿವರ ಆಯ್ಕೆ → Search → ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿಯಲ್ಲಿ ಗ್ರೇಡ್/ಅಂಕ → Save/Submit.

2. SATS ನಲ್ಲಿ ಬ್ರಿಡ್ಜ್ ಕೋರ್ಸ್ ಗ್ರೇಡ್ ಎಂಟ್ರಿ — ಹಂತಗಳು

1

Login ಆಗಿ: SATS ಅಧಿಕೃತ ವೆಬ್‌ಸೈಟ್ ಗೆ ಭೇಟಿ ನೀಡಿ, ನಿಮ್ಮ ಶಾಲೆಯ User ID ಮತ್ತು Password ಬಳಸಿ login ಆಗಿ.

2

Menu ಆಯ್ಕೆ ಮಾಡಿ: ಮುಖಪುಟದ ಎಡಭಾಗದಲ್ಲಿರುವ menu ನಲ್ಲಿ ಬ್ರಿಡ್ಜ್ ಕೋರ್ಸ್ (Bridge Course) ಅಥವಾ LBA option ಮೇಲೆ click ಮಾಡಿ. (ಮೊಬೈಲ್ ಬಳಸುತ್ತಿದ್ದರೆ ಮೇಲಿನ ಮೂರು ಗೆರೆಗಳ ☰ menu button ಒತ್ತಿ).

3

ತರಗತಿ ವಿವರಗಳ ಆಯ್ಕೆ: ಹೊಸ ಪುಟ ತೆರೆದಾಗ ಈ ಕೆಳಗಿನ ವಿವರಗಳನ್ನು ಸರಿಯಾಗಿ ಆಯ್ಕೆ ಮಾಡಿಕೊಳ್ಳಿ:

  • ಮಾಧ್ಯಮ (Medium)
  • ತರಗತಿ (Class)
  • ಲ್ಯಾಂಗ್ವೇಜ್ ಗ್ರೂಪ್ (Language group)
  • ವಿಷಯ (Subject)
  • ಪರೀಕ್ಷೆ ನಡೆಸಿದ ದಿನಾಂಕ (Test Date)
4

Search ಮಾಡಿ: ಎಲ್ಲಾ ವಿವರ ಭರ್ತಿ ಮಾಡಿದ ನಂತರ "Search" button ಕ್ಲಿಕ್ ಮಾಡಿ. ಆ ತರಗತಿಯ ವಿದ್ಯಾರ್ಥಿಗಳ ಪಟ್ಟಿ ಪರದೆಯ ಮೇಲೆ ಕಾಣಿಸುತ್ತದೆ.

5

ಗ್ರೇಡ್ / ಅಂಕಗಳ ದಾಖಲಾತಿ: ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರಿನ ಮುಂದೆ ಇರುವ box ನಲ್ಲಿ ಅವರ ಪರೀಕ್ಷಾ ಸಾಧನೆಗೆ ಅನುಗುಣವಾಗಿ ಗ್ರೇಡ್ (A, B, C ಇತ್ಯಾದಿ) ಅಥವಾ ಅಂಕಗಳನ್ನು ನಮೂದಿಸಿ.

6

Save ಮಾಡಿ: ಎಲ್ಲಾ ವಿದ್ಯಾರ್ಥಿಗಳ ವಿವರ ದಾಖಲಿಸಿದ ನಂತರ ಕೊನೆಯಲ್ಲಿರುವ "Submit" ಅಥವಾ "Save" button ಕ್ಲಿಕ್ ಮಾಡಿ — ಪ್ರಕ್ರಿಯೆ ಪೂರ್ಣಗೊಳಿಸಿ.

3. Pre-Test vs Post-Test

ಪರೀಕ್ಷೆಯಾವಾಗಏನು entry
ಪೂರ್ವ ಪರೀಕ್ಷೆ (Pre-Test)ಬ್ರಿಡ್ಜ್ ಕೋರ್ಸ್ ಪ್ರಾರಂಭಕ್ಕೆ ಮುನ್ನಆರಂಭಿಕ ಗ್ರೇಡ್/ಅಂಕ — ಮಕ್ಕಳ ಶೈಕ್ಷಣಿಕ ಸ್ಥಿತಿ ಅಳೆಯಲು
ಸಾಫಲ್ಯ ಪರೀಕ್ಷೆ (Post-Test)ಬ್ರಿಡ್ಜ್ ಕೋರ್ಸ್ ಮುಗಿದ ನಂತರಅಂತಿಮ ಗ್ರೇಡ್/ಅಂಕ — ಕಲಿಕಾ ಫಲಿತಾಂಶ ನೋಡಲು

💡 Target: Pre-Test & Post-Test ಎರಡೂ entry ಆಗಬೇಕು — ಆಗ ಮಾತ್ರ ಸಾಫಲ್ಯ (ಸುಧಾರಣೆ) ಅಳೆಯಲು ಸಾಧ್ಯ.

4. ಹೆಚ್ಚಿನ ಸಹಾಯ

  • ಪ್ರಾಯೋಗಿಕ ಪ್ರಾತ್ಯಕ್ಷಿಕೆಗೆ: ಶಿಕ್ಷಣ ಇಲಾಖೆಯ ಅಧಿಕೃತ ವೆಬ್‌ಸೈಟ್ ಅಥವಾ YouTube ನಲ್ಲಿ ಲಭ್ಯವಿರುವ SATS Solutions ಮಾರ್ಗದರ್ಶಿ ವಿಡಿಯೋಗಳನ್ನು ವೀಕ್ಷಿಸಿ.
  • Pre-Test ಗ್ರೇಡ್ entry ಸಮಸ್ಯೆ / Post-Test ಅಂಕ ನಮೂದಿಸಬೇಕೇ / ಯಾವುದೇ Error ಸಂದೇಶ — ಜಿಲ್ಲಾ/ಬ್ಲಾಕ್ SATS ನೋಡಲ್ ಅಧಿಕಾರಿ ಹತ್ತಿರ ಪರಿಶೀಲಿಸಿ.

5. FAQ

ಸೇತುಬಂಧ (Bridge Course) ಎಂದರೇನು?

ಶಾಲಾ ವರ್ಷ ಆರಂಭದಲ್ಲಿ ಕಲಿಕಾ ಅಂತರ ತುಂಬಲು ನಡೆಸುವ ಸೇತುವೆ ಕೋರ್ಸ್ — Pre-Test (ಆರಂಭ) ಮತ್ತು Post-Test (ಕೊನೆ) ಮೂಲಕ ಮಕ್ಕಳ ಪ್ರಗತಿ ಅಳೆಯುತ್ತಾರೆ.

SATS LBA URL ಯಾವುದು?

sts.karnataka.gov.in/LBA/ — Learning Baseline Assessment ಪೋರ್ಟಲ್.

ಮೊಬೈಲ್‌ನಲ್ಲಿ menu ಸಿಗುತ್ತಿಲ್ಲವೇ?

ಮೇಲಿನ ಬಲ ಅಥವಾ ಎಡ ಮೂಲೆಯ ☰ (ಮೂರು ಗೆರೆ) button ಒತ್ತಿ — menu ತೆರೆಯುತ್ತದೆ.

ಈ ಪುಟ ಅಧಿಕೃತವೇ?

ಇಲ್ಲ — ಇದು ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ. ಅಧಿಕೃತ: sts.karnataka.gov.in.
