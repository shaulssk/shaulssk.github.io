ನಿರಂತರ ಆ್ಯಪ್ ಬಳಸುವ ವಿಧಾನ — ಸಂಪೂರ್ಣ ಮಾರ್ಗದರ್ಶಿ

ಕರ್ನಾಟಕ ಸರ್ಕಾರ · ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ · 1–10ನೇ ತರಗತಿ ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ

ನಿರಂತರ ಆ್ಯಪ್ ಎಂಬುದು ಕರ್ನಾಟಕ ಸರ್ಕಾರದ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆಯ ದೈನಂದಿನ ಹಾಜರಾತಿ ಮತ್ತು ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ ವ್ಯವಸ್ಥೆ. ಪ್ರತಿ ಶಾಲೆಯ ಮುಖ್ಯ ಶಿಕ್ಷಕರು/ನೋಂದಣಿ ಶಿಕ್ಷಕರು ಪ್ರತಿದಿನ ಹಾಜರಾತಿ ದಾಖಲಿಸಬೇಕು, ಹೊಸ ಪ್ರವೇಶ ಪಡೆದ ಮಕ್ಕಳನ್ನು ನೋಂದಾಯಿಸಬೇಕು.

1. ಆ್ಯಪ್‌ನಲ್ಲಿ ಲಾಗಿನ್ ಮಾಡುವ ವಿಧಾನ

  1. Google Play Store ನಲ್ಲಿ ನಿರಂತರ (Nirantara) ಆ್ಯಪ್ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ.
  2. ಶಾಲೆಗೆ ಸಿಕ್ಕಿರುವ SDID ಮತ್ತು ಗುಪ್ತಪದ (password) ಬಳಸಿ ಲಾಗಿನ್ ಮಾಡಿ.
  3. ಮೊದಲ ಬಾರಿ ಲಾಗಿನ್ ಮಾಡಿದ ನಂತರ ಗುಪ್ತಪದ ಬದಲಾಯಿಸಿ ಸುರಕ್ಷಿತವಾಗಿರಿಸಿ.
  4. ಲಾಗಿನ್ ವಿವರ ಮರೆತಿದ್ದರೆ ಬ್ಲಾಕ್ ಮಟ್ಟದ ಅಧಿಕಾರಿಗಳ ಸಂಪರ್ಕ ಕೇಂದ್ರವನ್ನು ಸಂಪರ್ಕಿಸಿ.

2. ಪ್ರತಿದಿನದ ಹಾಜರಾತಿ ನೋಂದಣಿ

  1. ಆ್ಯಪ್ ತೆರೆದು ಹಾಜರಾತಿ (Attendance) ವಿಭಾಗ ಆಯ್ಕೆ ಮಾಡಿ.
  2. ತರಗತಿ (1–10) ಮತ್ತು ವಿಭಾಗ ಆಯ್ಕೆ ಮಾಡಿ.
  3. ಹಾಜರಿರುವ ಮಕ್ಕಳಿಗೆ Present, ಬಾರದಿರುವವರಿಗೆ Absent ಎಂದು ಗುರುತಿಸಿ.
  4. ಎಲ್ಲವನ್ನೂ ಖಚಿತಪಡಿಸಿ Submit/Save ಒತ್ತಿ — ಪ್ರತಿದಿನ ಕಡ್ಡಾಯ!
  5. ರಜೆ ಇರುವ ದಿನಗಳಲ್ಲಿ ಹಾಜರಾತಿ ನಮೂದಿಸಬೇಡಿ.

3. ಹೊಸ ವಿದ್ಯಾರ್ಥಿಯ ನೋಂದಣಿ (Registration)

  1. Student Registration ಆಯ್ಕೆ ಮಾಡಿ.
  2. ಮಗುವಿನ ಹೆಸರು, ಜನ್ಮ ದಿನಾಂಕ, ಲಿಂಗ, ತರಗತಿ, ಶಾಶ್ವತ ಶಿಕ್ಷಣ ಸಂಖ್ಯೆ (SATS ID) ಇರುವುದಾದರೆ ಅದನ್ನು ನಮೂದಿಸಿ.
  3. ಮಗುವಿನ ಫೋಟೋ, ಜನನ ಪ್ರಮಾಣಪತ್ರ / ಆಧಾರ್ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ.
  4. ಮಾಹಿತಿ ಪರಿಶೀಲಿಸಿ Submit ಒತ್ತಿ — ನೋಂದಣಿ ಸಂಖ್ಯೆ ಉಳಿಸಿಕೊಳ್ಳಿ.

4. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು ಮತ್ತು ಪರಿಹಾರ

ಸಮಸ್ಯೆಪರಿಹಾರ
Network issue / ಆ್ಯಪ್ ಲೋಡ್ ಆಗುತ್ತಿಲ್ಲಸಿಗ್ನಲ್ ಇರುವ ಸ್ಥಳದಲ್ಲಿ ಪ್ರಯತ್ನಿಸಿ; Wi-Fi ಇದ್ದರೆ ಅದನ್ನು ಬಳಸಿ; ಬೆಳಿಗ್ಗೆ ಸಮಯ ಬದಲಾಯಿಸಿ ಪ್ರಯತ್ನಿಸಿ.
"Registration is not enabled for this institution" ದೋಷಹೊಸ ಪ್ರವೇಶಗಳಿಗೆ ಶಾಲಾ ಮಟ್ಟದಲ್ಲಿ ಅನುಮತಿ ಆನ್ ಆಗಿಲ್ಲ — BRC/CRC ಮೂಲಕ ಬ್ಲಾಕ್ ಮಟ್ಟದಲ್ಲಿ ದೂರು ನೀಡಿ.
ಫೋಟೋ ಮಿಸ್‌ಮ್ಯಾಚ್ (Photo Mismatch)SATS ದಾಖಲೆಯ ಫೋಟೋ ಮತ್ತು ಅಪ್‌ಲೋಡ್ ಫೋಟೋ ಹೊಂದಾಣಿಕೆಯಾಗಬೇಕು — ಸ್ಪಷ್ಟ, ಇತ್ತೀಚಿನ ಫೋಟೋ ಬಳಸಿ; ಸಮಸ್ಯೆ ಮುಂದುವರಿದರೆ SATS ನಲ್ಲಿ ಫೋಟೋ ಸರಿಪಡಿಸಿ.
OTP / ಲಾಗಿನ್ ಬರುತ್ತಿಲ್ಲನೋಂದಾಯಿತ ಮೊಬೈಲ್ ಸಂಖ್ಯೆ ಸರಿಯೆ? ನೆಟ್‌ವರ್ಕ್ ಪರಿಶೀಲಿಸಿ; ಕೆಲ ನಿಮಿಷ ನಂತರ ಪ್ರಯತ್ನಿಸಿ.
App crash / hang ಆಗುತ್ತಿದೆಆ್ಯಪ್ ಅನ್ನು Play Store ನಲ್ಲಿ ಅಪ್‌ಡೇಟ್ ಮಾಡಿ; ಫೋನ್ ರೀಸ್ಟಾರ್ಟ್ ಮಾಡಿ.

⚠️ ಗಮನಿಸಿ: ಈ ಮಾರ್ಗದರ್ಶಿ ಅನುಭವ ಆಧರಿಸಿದ ಸಾಮಾನ್ಯ ಮಾಹಿತಿ. ಆ್ಯಪ್‌ನ ಅಧಿಕೃತ ನಿಯಮಗಳಿಗೆ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆಯ ಸೂಚನೆಗಳೇ ಅಂತಿಮ. ಹೊಸ ಅಪ್‌ಡೇಟ್‌ಗಳ ಬಗ್ಗೆ ಇಲಾಖೆ ಪರಿಚಲನೆ ನೋಡಿ.

5. ಉಪಯುಕ್ತ ಸಲಹೆಗಳು

  • ಪ್ರತಿದಿನ ಒಂದೇ ಸಮಯದಲ್ಲಿ ಹಾಜರಾತಿ ನಮೂದಿಸುವ ಅಭ್ಯಾಸ ಮಾಡಿ.
  • ನೋಂದಣಿ ಸಂಖ್ಯೆಗಳ ಡೇಟಾ ಬ್ಯಾಕಪ್ ಇಟ್ಟುಕೊಳ್ಳಿ.
  • ತಿಂಗಳ ಅಂತ್ಯದಲ್ಲಿ SATS ಸಂಖ್ಯೆ ಮತ್ತು ನಿರಂತರ ನೋಂದಣಿ ಸಂಖ್ಯೆಯನ್ನು ಹೋಲಿಸಿ — ವ್ಯತ್ಯಾಸ ಕಂಡರೆ ಕಾರಣ ದಾಖಲಿಸಿ. ಇದಕ್ಕೆ ನಮ್ಮ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಉಪಯುಕ್ತ!
  • ಸಮಸ್ಯೆಗಳ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಇಟ್ಟುಕೊಳ್ಳಿ — ದೂರು ನೀಡಲು ಸುಲಭ.
