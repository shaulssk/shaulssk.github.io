ℹ️ Note: Portal/app process may change according to departmental instructions. ಇಲ್ಲಿನ ಮಾಹಿತಿ ಸಾಮಾನ್ಯ ಮಾರ್ಗದರ್ಶಿ ಮಾತ್ರ — ಪ್ರಸ್ತುತ ಅಧಿಕೃತ ನಿಯಮಗಳಿಗೆ ಇಲಾಖಾ ಪರಿಚಲನೆ ಮತ್ತು ಅಧಿಕೃತ ಸೈಟ್‌ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ. ಅಧಿಕೃತ circular/portal instructions ಬದಲಾದರೆ ಅವುಗಳೇ ಅಂತಿಮ.

ನಿರಂತರ (Nirantara) ಎಂಬುದು ಕರ್ನಾಟಕ ಸರ್ಕಾರದ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆಯ AI ಆಧಾರಿತ ಮುಖ ಗುರುತಿಸುವಿಕೆ (Face Recognition) ಹಾಜರಾತಿ ವ್ಯವಸ್ಥೆಯಾಗಿ 2026-27ನೇ ಶೈಕ್ಷಣಿಕ ವರ್ಷದಿಂದ ಸರ್ಕಾರಿ/ಅನುದಾನಿತ ಶಾಲೆಗಳಲ್ಲಿ ಬಳಕೆಯಲ್ಲಿದೆ ಎಂದು ಇಲಾಖಾ ಸೂಚನೆಗಳು ತಿಳಿಸುತ್ತವೆ. ಶಿಕ್ಷಕರು KGID + OTP ಮೂಲಕ ಲಾಗಿನ್ ಆಗಿ ಪ್ರತಿದಿನ ಹಾಜರಾತಿ ದಾಖಲಿಸುತ್ತಾರೆ; ಹೊಸ ಪ್ರವೇಶ ಪಡೆದ ಮಕ್ಕಳನ್ನು ಮುಖದ ಫೋಟೋಗಳೊಂದಿಗೆ (ಸೂಚನೆಯಂತೆ ಸಾಮಾನ್ಯವಾಗಿ ಮೂರು — ಮುಂಭಾಗ, ಎಡ, ಬಲ) ನೋಂದಾಯಿಸುತ್ತಾರೆ.

📱 ನಿರಂತರ ಬಳಸುವಾಗ 5 ತಪ್ಪುಗಳು
  1. KGID ತಪ್ಪು ಹಾಕುವುದು: ಬೇರೆಯವರ KGID ನಮೂದಿಸಿದರೆ ಲಾಗಿನ್ ಆಗುವುದಿಲ್ಲ — ನಿಮ್ಮ ಸ್ವಂತ KGID ಪರಿಶೀಲಿಸಿ.
  2. OTP ಗಾಗಿ ತಪ್ಪು mobile: HRMS ನಲ್ಲಿ registered mobile number ಮಾತ್ರ OTP ಪಡೆಯುತ್ತದೆ — number ಹಳೆಯದಾಗಿದ್ದರೆ before update.
  3. ಫೋಟೋ ಸ್ಪಷ್ಟವಿಲ್ಲದಿರುವುದು: ಮುಖ ಸ್ಪಷ್ಟವಾಗಿ, ಬೆಳಕಿನಲ್ಲಿ ಫೋಟೋ ತೆಗೆಯಿರಿ — ಮಸುಕು ಫೋಟೋ face mismatch ಆಗುತ್ತದೆ.
  4. Attendance save ಮಾಡದೆ ಮುಚ್ಚುವುದು: ಲಾಗಿನ್ ಆಗಿ attendance ಮಾರ್ಕ್ ಮಾಡಿ submit ಮಾಡದೆ ಆ್ಯಪ್ close — data ಉಳಿಯುವುದಿಲ್ಲ.
  5. Duplicate registration: ಈಗಾಗಲೇ ನೋಂದಾಯಿತ student ಗೆ ಮತ್ತೆ register ಮಾಡದಿರಿ — duplicate delete ಮಾಡಬೇಕಾಗುತ್ತದೆ.

1. ಆ್ಯಪ್‌ನಲ್ಲಿ ಲಾಗಿನ್ ಮಾಡುವ ವಿಧಾನ

  1. Google Play Store ನಲ್ಲಿ Nirantara (ನಿರಂತರ) ಆ್ಯಪ್ ಹುಡುಕಿ — ಅಧಿಕೃತ ಡೆವಲಪರ್/ಲೋಗೋ ಪರಿಶೀಲಿಸಿ ಸುರಕ್ಷಿತವಾಗಿ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ. (ಕೇವಲ ಇಂಡೆಕ್ಸ್: Play Store ನಲ್ಲಿ ಹುಡುಕಿ)
  2. ಮೊದಲ ಬಾರಿ ತೆರೆದಾಗ ಕೇಳುವ ಎಲ್ಲಾ ಅಗತ್ಯ permissions (camera/OTP) ಅನ್ನು Allow ಮಾಡಿ.
  3. ಪ್ರಸ್ತುತ ವಿಧಾನದಲ್ಲಿ ಶಿಕ್ಷಕರ KGID ಸಂಖ್ಯೆ ನಮೂದಿಸಿ — ನೋಂದಾಯಿತ ಮೊಬೈಲ್‌ಗೆ ಬರುವ OTP ನಮೂದಿಸಿ ಲಾಗಿನ್ ಆಗಿ. (ವಿಧಾನ ಇಲಾಖಾ ಸೂಚನೆಯಂತೆ ಬದಲಾಯಿಸಬಹುದು.)
  4. ಲಾಗಿನ್ ಆಗದಿದ್ದರೆ ದಯವಿಟ್ಟು ಬ್ಲಾಕ್/ಜಿಲ್ಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ಅಥವಾ ಆ್ಯಪ್‌ನಲ್ಲಿನ Grievance ಆಯ್ಕೆ ಮೂಲಕ ದೂರು ನೀಡಿ.

📌 ಅಧಿಕೃತ ಮೂಲ: ಆ್ಯಪ್ login/ನೋಂದಣಿ ವಿಧಾನವನ್ನು ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ತನ್ನ 2026-27 ಸೂಚನೆಗಳಲ್ಲಿ ನಿಗದಿಪಡಿಸುತ್ತದೆ — ನಿಮ್ಮ ಜಿಲ್ಲಾ/BEO ಪರಿಚಲನೆ ಮತ್ತು ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ಅಧಿಕೃತ ಸೈಟ್ ಪರಿಶೀಲಿಸಿ.

2. ಪ್ರತಿದಿನದ ಹಾಜರಾತಿ ದಾಖಲೆ (AI Face Attendance)

  1. ಆ್ಯಪ್ ತೆರೆದು Attendance ವಿಭಾಗ ಆಯ್ಕೆ ಮಾಡಿ.
  2. ತರಗತಿ (1–10) ಮತ್ತು ವಿಭಾಗ ಆಯ್ಕೆ ಮಾಡಿ.
  3. AI ಮುಖ ಗುರುತಿಸುವಿಕೆ (Face Recognition) ಮೂಲಕ ಹಾಜರಾತಿ ದಾಖಲಾಗುತ್ತದೆ — ಬೆಳಕು ಸರಿಯಾಗಿರುವ ಸ್ಥಳದಲ್ಲಿ ಮುಖ ಸ್ಪಷ್ಟವಾಗಿ ಕಾಣುವಂತೆ ಫೋನ್ ಹಿಡಿದುಕೊಳ್ಳಿ.
  4. ಹಾಜರಾತಿ ಕೈಮೇಲ್‌ನಲ್ಲಿ ದಾಖಲಿಸಬೇಕಾದರೆ Present/Absent ಆಯ್ಕೆ ಮಾಡಿ; ದಿನದ ಕೊನೆಯಲ್ಲಿ Submit/Save ಒತ್ತಿ — ಇಲಾಖಾ ಸೂಚನೆಯಂತೆ ಪ್ರತಿದಿನ ದಾಖಲಿಸಬೇಕಾಗುತ್ತದೆ.
  5. ರಜೆ ಇರುವ ದಿನಗಳಲ್ಲಿ ಹಾಜರಾತಿ ನಮೂದಿಸಬೇಡಿ.

📌 ಅಧಿಕೃತ ಮೂಲ: ಈ ಹಾಜರಾತಿ ವ್ಯವಸ್ಥೆಯ ಬಗ್ಗೆ — ಯಾವ ಇಲಾಖೆ ಜಾರಿಗೊಳಿಸಿದೆ, ಯಾವ ಸಾಲಿನಿಂದ ಅನ್ವಯ — ಎಂಬುದನ್ನು ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ಮತ್ತು ಅಧಿಕೃತ ಸೈಟ್ನಲ್ಲಿ ನೀಡಿದ ಪ್ರಕಟಣೆ/ಪರಿಚಲನೆಯಲ್ಲಿ ಪರಿಶೀಲಿಸಿ. ಇಲ್ಲಿ ನೀಡಿರುವುದು ಸಾಮಾನ್ಯ ಬಳಕೆ-ಮಾರ್ಗ ಮಾತ್ರ.

2A. ಪರದೆಯ ಮೇಲೆ ಏನು ಕಾಣುತ್ತದೆ — On-screen reference

ಆ್ಯಪ್‌ನ ಪ್ರತಿ ಹಂತದಲ್ಲಿ ಯಾವ ಪರದೆ (screen) ಬರುತ್ತದೆ, ಅದರಲ್ಲಿ ಏನು ಟೈಪ್/ಕ್ಲಿಕ್ ಮಾಡಬೇಕು ಎಂಬುದನ್ನು ಮೊದಲೇ ತಿಳಿದಿದ್ದರೆ ತಪ್ಪುಗಳು ಕಡಿಮೆಯಾಗುತ್ತವೆ. ಸಾಮಾನ್ಯವಾಗಿ ಕಾಣುವ ಪರದೆಗಳು:

ನೀವು ಮಾಡುವ ಕ್ರಿಯೆಪರದೆಯ ಮೇಲೆ ಕಾಣುವಂಥದ್ದುಏನು ಒತ್ತಬೇಕು
ಆ್ಯಪ್ ತೆರೆಯುವುದುNirantara ಲೋಗೋ, "Enter KGID" ಪೆಟ್ಟಿಗೆ, OTP field, Login ಬಟನ್KGID ಟೈಪ್ ಮಾಡಿ → OTP ಬಂದಾಗ ನಮೂದಿಸಿ → Login
ಹಾಜರಾತಿ ಪರದೆClass / Section dropdown, ದಿನಾಂಕ, "Mark Attendance" ಬಟನ್ತರಗತಿ ಆಯ್ಕೆ → ಹಾಜರಾತಿ ಫಾರಂ → Submit
Face capture ಪರದೆಮುಖವನ್ನು frame ಒಳಗೆ ತರುವ camera view + Capture/Retakeಮಗುವಿನ ಮುಖ frame ಗೆ ಸರಿಸಿ → Capture → Confirm
ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿRegistered/Not Registered ಸ್ಥಿತಿ ಇರುವ student list, "+ Register" ಬಟನ್Not Registered ಮಗುವಿನ ಮುಂದಿನ Register → ಫೋಟೋ 3 → Submit
Grievance ಪರದೆCategory dropdown (Registration/Data/OTP/Other), ವಿವರ box, screenshot uploadCategory → ವಿವರ → ಸ್ಕ್ರೀನ್‌ಶಾಟ್ → Submit → ID ಉಳಿಸಿ

📷 ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಪದ್ಧತಿ: ಯಾವುದೇ ಹಂತದಲ್ಲಿ ಪರದೆ ಬದಲಾದರೆ/ದೋಷ ಬಂದರೆ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ತೆಗೆದು ಇಟ್ಟುಕೊಳ್ಳಿ (ಫೋನ್‌ನ power+volume-down ಅಥವಾ model ವಾರು gesture). ಇದು Grievance ದೂರಿನಲ್ಲಿ ನಿರ್ಣಾಯಕ ಸಾಕ್ಷ್ಯ — ನಿಖರ ಪರಿಹಾರ ವೇಗವಾಗಿ ಸಿಗುತ್ತದೆ.

3. ಹೊಸ ವಿದ್ಯಾರ್ಥಿಯ ನೋಂದಣಿ (Registration)

  1. Register Student ಆಯ್ಕೆ ಮಾಡಿ.
  2. ತರಗತಿ ಮತ್ತು ವಿಭಾಗ ಆಯ್ಕೆ ಮಾಡಿದರೆ SATS ಲಿಂಕ್ ಆದ ವಿದ್ಯಾರ್ಥಿಗಳ ಪಟ್ಟಿ ಬರುತ್ತದೆ — ಮಗುವಿನ ಹೆಸರಿನ ಮುಂದಿನ Not Registered ಆಯ್ಕೆ ಕ್ಲಿಕ್ ಮಾಡಿ.
  3. ಮಗುವಿನ ಮುಖಕ್ಕೆ ಬೆಳಕು ಸರಿಯಾಗಿ ಬೀಳುವಂತೆ ನಿಲ್ಲಿಸಿ — ಮುಂಭಾಗ, ಎಡ, ಬಲ ಮೂರು ಮುಖದ ಫೋಟೋಗಳನ್ನು (Face Photos) ತೆಗೆದುಕೊಳ್ಳಿ (ಪ್ರಸ್ತುತ ಇಲಾಖಾ ಸೂಚನೆಗಳ ಪ್ರಕಾರ — ಬದಲಾವಣೆಗೆ ಪೋರ್ಟಲ್/ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ).
  4. ಮಾಹಿತಿ ಪರಿಶೀಲಿಸಿ Submit ಒತ್ತಿ — ನೋಂದಣಿ ಸಂಖ್ಯೆ ಉಳಿಸಿಕೊಳ್ಳಿ.

📌 ಗಮನಿಸಿ: ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ SATS ದಾಖಲೆಯೊಂದಿಗೆ ಲಿಂಕ್ ಆಗಿರುತ್ತದೆ — ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರು/ಫೋಟೋ SATS ನಲ್ಲಿ ಸರಿಯಾಗಿದೆ ಎಂದು ನೋಡಿಕೊಳ್ಳಿ. ಪ್ರತ್ಯೇಕ ಲೇಖನ: ನಿರಂತರ ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ 2026 — ಸಂಪೂರ್ಣ ಮಾರ್ಗದರ್ಶಿ →

4. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು ಮತ್ತು ಪರಿಹಾರ

ಸಮಸ್ಯೆಪರಿಹಾರ
Network issue / ಆ್ಯಪ್ ಲೋಡ್ ಆಗುತ್ತಿಲ್ಲಸಿಗ್ನಲ್ ಇರುವ ಸ್ಥಳದಲ್ಲಿ ಪ್ರಯತ್ನಿಸಿ; Wi-Fi ಇದ್ದರೆ ಅದನ್ನು ಬಳಸಿ; ಆ್ಯಪ್ ಅಪ್‌ಡೇಟ್ ಮಾಡಿ.
"Registration is not enabled / class-section ಕಾಣುತ್ತಿಲ್ಲಆ್ಯಪ್‌ನ Grievance ಬಟನ್ → Registration Issue ಆಯ್ಕೆ → ವಿವರ ಬರೆದು ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಸೇರಿಸಿ Submit ಮಾಡಿ; ಪ್ರಗತಿ Raised Grievance ನಲ್ಲಿ ನೋಡಿ.
ಹಳೆಯ ವರ್ಷದ ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿ ಬರುತ್ತಿದೆGrievance → Data Issue ಆಯ್ಕೆ → "ಪ್ರಸ್ತುತ 2026-27 ಪಟ್ಟಿ ತೋರಿಸಿ" ಎಂದು ವಿವರಿಸಿ, ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ.
ಫೋಟೋ ಅಪ್‌ಲೋಡ್ ಆಗಿರುವುದು ಬೇರೆ ಮಗುವಿನದ್ದುGrievance → Registration Issue → ವಿದ್ಯಾರ್ಥಿ ಹೆಸರು + STS ID ಜೊತೆಗೆ ವಿವರಿಸಿ ಸರಿಪಡಿಸಿ.
OTP / ಲಾಗಿನ್ ಬರುತ್ತಿಲ್ಲನೋಂದಾಯಿತ KGID ಸಂಖ್ಯೆ ಸರಿಯೆ? ನೆಟ್‌ವರ್ಕ್ ಪರಿಶೀಲಿಸಿ; ಕೆಲ ನಿಮಿಷ ನಂತರ ಪ್ರಯತ್ನಿಸಿ. ಮುಂದುವರಿದರೆ ಇಲಾಖೆ ಸಂಪರ್ಕಿಸಿ.
App crash / hang ಆಗುತ್ತಿದೆPlay Store ನಲ್ಲಿ ಆ್ಯಪ್ ಅಪ್‌ಡೇಟ್ ಮಾಡಿ; ಫೋನ್ ರೀಸ್ಟಾರ್ಟ್ ಮಾಡಿ.

📌 ಅಧಿಕೃತ ಮೂಲ: ತಾಂತ್ರಿಕ ಸಮಸ್ಯೆಗಳಿಗೆ ಅಧಿಕೃತವಾಗಿ ಆ್ಯಪ್‌ನಲ್ಲಿಯೇ ಇರುವ Grievance ವಿಭಾಗವನ್ನೇ ಬಳಸಿ — ಇದು ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ನೀಡಿದ ಮಾರ್ಗ.

⚠️ ಗಮನಿಸಿ: ಈ ಮಾರ್ಗದರ್ಶಿ ಸಾಮಾನ್ಯ ಮಾಹಿತಿ. ಆ್ಯಪ್‌ನ ಅಧಿಕೃತ ನಿಯಮಗಳಿಗೆ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ಸೂಚನೆಗಳೇ ಅಂತಿಮ. ಹೊಸ ಅಪ್‌ಡೇಟ್‌ಗಳ ಬಗ್ಗೆ ಇಲಾಖೆ ಪರಿಚಲನೆ ನೋಡಿ.

4A. ವಿದ್ಯಾರ್ಥಿ ವಿವರ Delete — 5 ಕಾರಣಗಳ ಅರ್ಥ (App v1.4.2)

ಆ್ಯಪ್‌ನಲ್ಲಿ ವಿದ್ಯಾರ್ಥಿಯ ವಿವರಗಳನ್ನು delete ಮಾಡುವಾಗ ಕಾಣಿಸುವ Delete Reason ಆಯ್ಕೆಗಳ ಅರ್ಥ ಸ್ಪಷ್ಟವಾಗಿ ತಿಳಿದುಕೊಳ್ಳಿ — ಸರಿಯಾದ ಕಾರಣ ಆರಿಸಿದರೇ ತಪ್ಪಾದ ದಾಖಲೆ ಸರಿಯಾಗಿ ತೆಗೆದುಹಾಕಲ್ಪಡುತ್ತದೆ. v1.4.2 ಅಪ್‌ಡೇಟ್‌ನಿಂದ ಈ 5 ಕಾರಣಗಳಿಗೆ ಮಾತ್ರ ವಿದ್ಯಾರ್ಥಿಗಳನ್ನು Delete ಮಾಡಲು ಸಾಧ್ಯ. (ಮುಂದಿನ ಅಪ್‌ಡೇಟ್‌ನಲ್ಲಿ ಆಯ್ಕೆಗಳು ಬದಲಾಗಬಹುದು.)

Delete Reasonಯಾವಾಗ ಆರಿಸಬೇಕು?
1. Wrong student registered
(ತಪ್ಪಾದ ವಿದ್ಯಾರ್ಥಿಯ ನೋಂದಣಿ)		ಸರಿಯಾದ ವಿದ್ಯಾರ್ಥಿಯ ಬದಲಿಗೆ ಬೇರೆ ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರು/ಬೇರೆ ತರಗತಿಯ ವಿದ್ಯಾರ್ಥಿಯನ್ನು ಆಕಸ್ಮಿಕವಾಗಿ ನೋಂದಾಯಿಸಿದ್ದಾಗ.
2. Duplicate registration
(ಪುನರಾವರ್ತಿತ ನೋಂದಣಿ)		ಒಂದೇ ವಿದ್ಯಾರ್ಥಿಯನ್ನು ಒಂದಕ್ಕಿಂತ ಹೆಚ್ಚು ಬಾರಿ ನೋಂದಾಯಿಸಿದ್ದಾಗ — ಹೆಚ್ಚುವರಿ ದಾಖಲೆ ತೆಗೆದುಹಾಕಲು.
3. Incorrect face registration
(ತಪ್ಪಾದ ಮುಖ/ಫೋಟೋ ನೋಂದಣಿ)		ಒಬ್ಬ ವಿದ್ಯಾರ್ಥಿಯ ಪ್ರೊಫೈಲ್‌ಗೆ ಮತ್ತೊಬ್ಬ ವಿದ್ಯಾರ್ಥಿಯ ಮುಖದ ಫೋಟೋ (Face capture) ನೋಂದಣಿಯಾಗಿದ್ದಾಗ / ಫೋಟೋ ತಪ್ಪಾಗಿ ಹೊಂದಾಣಿಕೆಯಾದಾಗ.
4. Ghost Registration
(ಅಸ್ತಿತ್ವದಲ್ಲಿಲ್ಲದ/ನಕಲಿ ನೋಂದಣಿ)		ಶಾಲೆಯಲ್ಲಿ ಪ್ರಸ್ತುತ ವ್ಯಾಸಂಗ ಮಾಡದಿರುವ, ಶಾಲೆ ತೊರೆದಿರುವ ಅಥವಾ ವಾಸ್ತವವಾಗಿ ಇಲ್ಲದಿರುವ (ನಕಲಿ) ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರು ವ್ಯವಸ್ಥೆಯಲ್ಲಿದ್ದರೆ.
5. TC Issued
(TC ನೀಡಿರುವ ವಿದ್ಯಾರ್ಥಿ)		ವಿದ್ಯಾರ್ಥಿಗೆ ವರ್ಗಾವಣೆ ಪ್ರಮಾಣಪತ್ರ (Transfer Certificate) ನೀಡಿದ್ದರೆ — ಶಾಲೆ ತೊರೆದ/ಬದಲಾಯಿಸಿದ ವಿದ್ಯಾರ್ಥಿ.

📌 ಗಮನಿಸಿ: Delete ದಾಖಲೆ ನಿರ್ಣಾಯಕ ಬದಲಾವಣೆ — ಮಾಡುವ ಮುನ್ನ ವಿದ್ಯಾರ್ಥಿ ಹೆಸರು/SATS ID/SATS ದಾಖಲೆ ಪರಿಶೀಲಿಸಿ, ಸಾಧ್ಯವಾದರೆ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಇಟ್ಟುಕೊಳ್ಳಿ. ಅನುಮಾನ ಇದ್ದರೆ ಮೊದಲು ಇಲಾಖಾ ನೋಡಲ್ ಅಧಿಕಾರಿ/ಶಾಲಾ ಮೇಲಧಿಕಾರಿ ಸಲಹೆ ಪಡೆಯಿರಿ.

5. ಉಪಯುಕ್ತ ಸಲಹೆಗಳು

  • ಪ್ರತಿದಿನ ಒಂದೇ ಸಮಯದಲ್ಲಿ ಹಾಜರಾತಿ ದಾಖಲಿಸುವ ಅಭ್ಯಾಸ ಮಾಡಿ.
  • ನೋಂದಣಿ ಸಂಖ್ಯೆಗಳ ಡೇಟಾ ಬ್ಯಾಕಪ್ ಇಟ್ಟುಕೊಳ್ಳಿ.
  • ತಿಂಗಳ ಅಂತ್ಯದಲ್ಲಿ SATS ಸಂಖ್ಯೆ ಮತ್ತು ನಿರಂತರ ನೋಂದಣಿ ಸಂಖ್ಯೆಯನ್ನು ಹೋಲಿಸಿ — ವ್ಯತ್ಯಾಸ ಕಂಡರೆ ಕಾರಣ ದಾಖಲಿಸಿ.
  • ಸಮಸ್ಯೆಗಳ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಇಟ್ಟುಕೊಳ್ಳಿ — Grievance ದೂರಿಗೆ ಸುಲಭ.

5A. ಗಮನಿಸಬೇಕಾದ ಪ್ರಮುಖ ಅಂಶಗಳು ⭐

  • CG ಬದಲಾಯಿಸಬೇಡಿ: ಹಾಜರಾತಿ ದಾಖಲಿಸಿದ ನಂತರ ತರಗತಿಯನ್ನು (class/section) ಬದಲಾಯಿಸಿದರೆ ದಾಖಲೆ ತಪ್ಪಾಗಬಹುದು — ಬದಲಾವಣೆಗೆ ಮುನ್ನ ಇಲಾಖಾ ಮಾರ್ಗದರ್ಶನ ಪಡೆಯಿರಿ.
  • Face Photo ಸ್ಪಷ್ಟ ಇರಲಿ: AI ಹಾಜರಾತಿಗೆ ಮಗುವಿನ ಮುಖ ಸ್ಪಷ್ಟವಾಗಿ ಕಾಣಬೇಕು — ಟೋಪಿ, ಮಾಸ್ಕ್, ಕನ್ನಡಕದ ಪ್ರತಿಫಲನ ಸಮಸ್ಯೆ ಮಾಡಬಹುದು.
  • ಒಂದೇ ಮೊಬೈಲ್: ಶಾಲೆಯ ಅಧಿಕೃತ ನೋಂದಾಯಿತ ಮೊಬೈಲ್ ಸಂಖ್ಯೆಯಿಂದಲೇ OTP/login ಮಾಡಿ — ಬೇರೆಯವರ ಫೋನ್ ಬಳಸಿದರೆ ಲಾಗಿನ್ ಅನುಮತಿ ಇರುವುದಿಲ್ಲ.
  • ಪ್ರತಿದಿನ: ಒಂದೇ ದಿನ ಬಿಟ್ಟು ಹಾಜರಾತಿ ನಮೂದಿಸದಿದ್ದರೆ ದಾಖಲೆಯಲ್ಲಿ gap ಆಗುತ್ತದೆ.
  • Rajas/RBT: ಶಾಲಾ ರಜೆ, ಕಲಾ ಶಾಲಾ ಇತ್ಯಾದಿ ವಿಶೇಷ ದಿನಗಳಲ್ಲಿ ಯಾವ ಆಯ್ಕೆ ಬಳಸಬೇಕು ಎಂಬುದನ್ನು ಇಲಾಖಾ ಪರಿಚಲನೆಯಲ್ಲಿ ನೋಡಿ.
  • Data privacy: ವಿದ್ಯಾರ್ಥಿಗಳ ಫೋಟೋ/ಮಾಹಿತಿಯನ್ನು ಇತರರಿಗೆ ಹಂಚಿಕೊಳ್ಳಬೇಡಿ.

5B. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. ಆ್ಯಪ್ ಯಾವ ಹೆಸರಲ್ಲಿ Play Store ನಲ್ಲಿ ಸಿಗುತ್ತದೆ?

Play Store/App Store ನಲ್ಲಿ Nirantara / Niranthara Attendance ಎಂದು ಹುಡುಕಿ. ಡೆವಲಪರ್ ಹೆಸರು ಮತ್ತು ಲೋಗೋ ಪರಿಶೀಲಿಸಿ — ಅಧಿಕೃತವಾದ್ದರಲ್ಲಿ ಮಾತ್ರ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ. ಅಧಿಕೃತ ಲಿಂಕ್ ಶಾಲಾ ಪರಿಚಲನೆಯಲ್ಲಿ ಕೊಡಲಾಗುತ್ತದೆ.

2. ಶಾಲಾ HM ಇಲ್ಲದೆ ಶಿಕ್ಷಕರೇ ಲಾಗಿನ್ ಆಗಬಹುದೇ?

ಪ್ರಸ್ತುತ ವಿಧಾನದಲ್ಲಿ ಶಿಕ್ಷಕರ KGID ಸಂಖ್ಯೆ + OTP ಮೂಲಕ ಮುಖ್ಯ ಶಿಕ್ಷಕರು/ನೋಂದಣಿ ಶಿಕ್ಷಕರು ಲಾಗಿನ್ ಆಗುತ್ತಾರೆ. ಪ್ರತಿ ಶಾಲಾ ಮಟ್ಟದ ಅನುಮತಿ ಇಲಾಖೆ ನೀಡುವ ವಿಧಾನವನ್ನು ಅನುಸರಿಸಿ.

3. ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿ (student list) ಕಾಣಿಸುತ್ತಿಲ್ಲ — ಏನು ಮಾಡಬೇಕು?

ಇದು SATS ದತ್ತಾಂಶ ಲಿಂಕ್ ಆಗಿರುವ ಸಮಸ್ಯೆ — ಹೆಚ್ಚಾಗಿ OCR/ವರ್ಷ ಬದಲಾವಣೆ ಕಾರಣ. ಆ್ಯಪ್‌ನ Grievance → Registration Issue/Data Issue ಮೂಲಕ ಶಾಲಾ ವಿವರ + ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಜೊತೆ ದೂರು ಸಲ್ಲಿಸಿ.

4. ಫೋಟೋ ಬೇರೆ ಮಗುವಿನದ್ದು ಅಪ್‌ಲೋಡ್ ಆಗಿದೆ — ಸರಿಪಡಿಸುವುದು ಹೇಗೆ?

Grievance → Registration Issue → ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರು + STS ID ಜೊತೆ ಸರಿಯಾದ ಫೋಟೋ ಪುನಃ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ. ತಾತ್ಕಾಲಿಕ ಪರಿಹಾರವಾಗಿ ಆ ಮಗುವನ್ನು ಪುನಃ register ಮಾಡಿ.

5. ಹಾಜರಾತಿ ದಾಖಲಿಸಿದ ನಂತರ ತಪ್ಪಾಗಿದ್ದರೆ ಸರಿಪಡಿಸಬಹುದೇ?

ಇಲಾಖಾ ನಿಯಮದಂತೆ ಸೀಮಿತ ಸಮಯದಲ್ಲಿ correction ಆಯ್ಕೆ ಇರುತ್ತದೆ. ಕೂಡಲೇ ಇಲಾಖಾ ನೋಡಲ್ ಅಧಿಕಾರಿ / ಸ್ಕೂಲ್‌ನ ಮೇಲಧಿಕಾರಿ ಸಂಪರ್ಕಿಸಿ — ದಾಖಲಿಸಿದ ನಂತರ ಹೆಚ್ಚೆಂದರೆ ಬೆರಳೆಣಿಕೆಯಷ್ಟು ದಿನಗಳಲ್ಲಿ ಪರಿಹಾರ ಆಗಬೇಕು.

6. Login ಆಗಲು ಹೊಸ ಸಾಧನ (phone) ಬದಲಾಯಿಸಿದರೆ?

ಆ್ಯಪ್ ಹಳೆಯ ಫೋನ್‌ನಿಂದ logout ಮಾಡಿ ಹೊಸ ಫೋನ್‌ನಲ್ಲಿ fresh OTP login ಮಾಡಿ. ಹಳೆಯ ಫೋನ್‌ನಲ್ಲಿ session ಉಳಿದಿದ್ದರೆ ಅದನ್ನು ಬಿಡುವ ಮುನ್ನ ಹೊಸ device activate ಮಾಡಿಕೊಳ್ಳಿ.

7. ಈ ಮಾರ್ಗದರ್ಶಿಯಲ್ಲಿ ತಪ್ಪಾಗಿ ಹೇಳಿದರೆ?

ಇದು ಸಾಮಾನ್ಯ ಮಾರ್ಗದರ್ಶಿ. ಹೊಸ ಅಪ್‌ಡೇಟ್‌ನಲ್ಲಿ procedure ಬದಲಾಗಬಹುದು — ಯಾವಾಗಲೂ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ಪರಿಚಲನೆ ಮತ್ತು ಆ್ಯಪ್‌ನ ಅಧಿಕೃತ ಸೂಚನೆಗಳೇ ಅಂತಿಮ.
