UDISE+ GIS Capture — ಶಾಲಾ ಜಿಯೋ-ಟ್ಯಾಗಿಂಗ್ ಮಾರ್ಗದರ್ಶಿ

ಭಾರತ ಸರ್ಕಾರ · ಶಾಲಾ ಶಿಕ್ಷಣ ಮತ್ತು ಸಾಕ್ಷರತಾ ಇಲಾಖೆ · UDISE+ ನಲ್ಲಿ ನೋಂದಾಯಿತ ಎಲ್ಲಾ ಶಾಲೆಗಳಿಗೆ

UDISE+ GIS Capture ಆ್ಯಪ್ ಎಂದರೆ ಶಾಲೆಯ ನಿಖರ GPS ಸ್ಥಳ (ಸ್ಥಾನಾಂಶ) ಮತ್ತು ವಿಶ್ವಾಸಾರ್ಹ ಫೋಟೋ ಪುರಾವೆಗಳನ್ನು UDISE+ ಡೇಟಾಬೇಸ್‌ಗೆ ದಾಖಲಿಸುವ ಮೊಬೈಲ್ ಅನ್ವಯಿಕೆ. ಆ್ಯಪ್‌ನಲ್ಲಿ ಶಾಲೆಯ ಮುಖ್ಯ ದ್ವಾರ, ಕಟ್ಟಡ, ಒಳಾಂಗಣ ಫೋಟೋ + GPS ನಿರ್ದೇಶಾಂಕ ಸೆರೆಹಿಡಿಯಲಾಗುತ್ತದೆ; ಇದನ್ನು ಜಿಲ್ಲಾ ಮಟ್ಟದ ಬಳಕೆದಾರರು ಪರಿಶೀಲಿಸಿ ಅನುಮೋದಿಸಿದ ನಂತರ ಅಧಿಕೃತವಾಗಿ ದಾಖಲಾಗುತ್ತದೆ.

⚠️ ಮುಖ್ಯ ಸೂಚನೆ: ಇಲ್ಲಿನ ಮಾಹಿತಿ ಸಾಮಾನ್ಯ ಮಾರ್ಗದರ್ಶಿ ಮಾತ್ರ. ಪ್ರಸ್ತುತ ಅಧಿಕೃತ ನಿಯಮಗಳು ಮತ್ತು ಸೂಚನೆಗಳಿಗಾಗಿ ಸಂಬಂಧಿತ ಸರ್ಕಾರಿ ಇಲಾಖೆಯ ಅಧಿಕೃತ ಮಾಹಿತಿಯನ್ನು ಪರಿಶೀಲಿಸಿ.

1. ಆ್ಯಪ್ ಡೌನ್‌ಲೋಡ್ ಮಾಡುವ ವಿಧಾನ

  1. Google Play Store ತೆರೆದು "UDISE Plus - GIS Capture" ಹುಡುಕಿ (App ID: in.gov.udiseplus.gis)
  2. ಅಥವಾ ನೇರ ಲಿಂಕ್: play.google.com — UDISE+ GIS Capture
  3. Install ಒತ್ತಿ. ಫೋನ್‌ನಲ್ಲಿ Camera ಮತ್ತು Location (GPS) ಅನುಮತಿ ನೀಡಿ.
  4. iOS ಬಳಕೆದಾರರಿಗೂ UDISE+ GIS Capture ಆ್ಯಪ್ ಲಭ್ಯವಿದೆ.

2. ಲಾಗಿನ್ ಮಾಡುವ ವಿಧಾನ

📌 ಪ್ರಮುಖ: GIS Capture ಆ್ಯಪ್‌ಗೆ ಪ್ರತ್ಯೇಕ ನೋಂದಣಿ ಇಲ್ಲ — UDISE+ SDMS ಪೋರ್ಟಲ್‌ನ ಅದೇ ಯೂಸರ್‌ನೇಮ್ ಮತ್ತು ಪಾಸ್‌ವರ್ಡ್ ಬಳಸಿ ಲಾಗಿನ್ ಆಗುತ್ತದೆ.

  1. ಆ್ಯಪ್ ತೆರೆದು UDISE+ ಯೂಸರ್‌ನೇಮ್ ಮತ್ತು ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿ.
  2. ಲಾಗಿನ್ ಆಗದಿದ್ದರೆ — ಮೊದಲು udiseplus.gov.in ಮೂಲಕ ಪಾಸ್‌ವರ್ಡ್ ರೀಸೆಟ್ ಮಾಡಿ, ನಂತರ ಆ್ಯಪ್‌ನಲ್ಲಿ ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ.
  3. ಲೋಕೇಶನ್ ಅನುಮತಿ Always allow (ಯಾವಾಗಲೂ) ಎಂದು ಹೊಂದಿಸಿ — GPS ಸರಿಯಾಗಿ ದಾಖಲಾಗಲು ಇದು ಅಗತ್ಯ.

3. GPS ಸ್ಥಳ ಸೆರೆಹಿಡಿಯುವ ವಿಧಾನ

  1. ಶಾಲಾ ಆವರಣದಲ್ಲಿಯೇ ನಿಂತು ಆ್ಯಪ್ ತೆರೆಯಿರಿ — GPS ಓದುವಿಕೆ ಆಗಬೇಕು.
  2. ಮುಖ್ಯ ದ್ವಾರದ ಬಳಿ ನಿಂತು Location Capture ಆಯ್ಕೆ ಮಾಡಿ.
  3. GPS ನಿರ್ದೇಶಾಂಕ (Latitude/Longitude) ಲಾಕ್ ಆಗುವವರೆಗೆ ಕಾಯಿರಿ.
  4. ⚠️ ಶಾಲೆಯ ಹೊರಗಿನಿಂದ / ಮನೆಯಿಂದ capture ಮಾಡಬೇಡಿ — ತಪ್ಪು ನಿರ್ದೇಶಾಂಕ ದಾಖಲಾದರೆ ಜಿಲ್ಲಾ ಪರಿಶೀಲನೆಯಲ್ಲಿ reject ಆಗುತ್ತದೆ.

4. 4 ಕಡ್ಡಾಯ ಫೋಟೋಗಳು

#ಫೋಟೋಉದ್ದೇಶ
1ಮುಖ್ಯ ದ್ವಾರ (School Name ಕಾಣುವಂತೆ)ಶಾಲೆಯ ಗುರುತು UDISE+ ದಾಖಲೆಗೆ ಹೊಂದಾಣಿಕೆಯಾಗುವುದನ್ನು ಖಚಿತಪಡಿಸುತ್ತದೆ — ಇದರಲ್ಲಿ ಶಾಲೆಯ ಹೆಸರಿನ ಫಲಕ ಸ್ಪಷ್ಟವಾಗಿ ಕಾಣಬೇಕು.
2ಮುಖ್ಯ ಕಟ್ಟಡದ ಮುಂಭಾಗಶಾಲೆಯ ಭೌತಿಕ ಅಸ್ತಿತ್ವವನ್ನು ನಿರ್ದೇಶಾಂಕಗಳಲ್ಲಿ ದೃಢೀಕರಿಸುತ್ತದೆ.
3ಹೆಚ್ಚುವರಿ ಕಟ್ಟಡ/ಕೋನ ಅಥವಾ ಮುಖ್ಯ ಶಿಕ್ಷಕರ ಕೊಠಡಿಪರಿಶೀಲನೆಗೆ ದ್ವಿತೀಯ ಉಲ್ಲೇಖ ಬಿಂದು.
4ಒಳಾಂಗಣ ಸೌಲಭ್ಯ (ವರ್ಗ ಕೊಠಡಿ / ಆಟದ ಮೈದಾನ)ಶಾಲೆ ಕ್ರಿಯಾಶೀಲವಾಗಿದೆ ಎಂಬುದನ್ನು ದೃಢೀಕರಿಸುತ್ತದೆ.

💡 ಸಲಹೆ: ಎಲ್ಲಾ ಫೋಟೋ ಸ್ಪಷ್ಟವಾಗಿರಲಿ; ಮುಖ್ಯ ದ್ವಾರದ ಫೋಟೋದಲ್ಲಿ ಶಾಲೆಯ ಹೆಸರು ಓದುವಂತೆ ತೋರಿಸಿ — ಅನುಮೋದನೆಗೆ ಇದು ಮುಖ್ಯ ಪರಿಶೀಲನೆ.

5. Submit — ಅನುಮೋದನೆ ಪ್ರಕ್ರಿಯೆ

  1. ಫೋಟೋ ಮತ್ತು GPS ಸರಿಯಾಗಿದೆಯೆ ಪರಿಶೀಲಿಸಿ Submit ಒತ್ತಿ.
  2. Submit ಆದ ನಿರ್ದೇಶಾಂಕ + ಫೋಟೋಗಳು ಜಿಲ್ಲಾ ಮಟ್ಟದ ಬಳಕೆದಾರರ ಪರಿಶೀಲನೆಗೆ ಹೋಗುತ್ತವೆ.
  3. ಅನುಮೋದನೆಯಾದ ನಂತರ ದತ್ತಾಂಶ ರಾಜ್ಯ/ರಾಷ್ಟ್ರ ಮಟ್ಟದಲ್ಲಿ ಪ್ರಕಟವಾಗಿ ಇತರ ಉಪಯುಕ್ತ ವ್ಯವಸ್ಥೆಗಳಿಗೆ (ಸಂಚರಣೆ, ಶಾಲಾ ಹುಡುಕಾಟ) ಬಳಕೆಯಾಗುತ್ತದೆ.
  4. ಜಿಲ್ಲಾ ಪರಿಶೀಲನೆ ಕೆಲವು ದಿನಗಳನ್ನು ತೆಗೆದುಕೊಳ್ಳಬಹುದು — status ಅನ್ನು ನಿಯಮಿತವಾಗಿ ನೋಡಿ.

6. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು ಮತ್ತು ಪರಿಹಾರ

ಸಮಸ್ಯೆಕಾರಣಪರಿಹಾರ
District reviewer reject ಮಾಡಿದ್ದಾರೆದ್ವಾರದ ಫೋಟೋದಲ್ಲಿ ಶಾಲೆಯ ಹೆಸರು ಸ್ಪಷ್ಟವಿಲ್ಲ / GPS ತಪ್ಪಾಗಿದೆಹೆಸರು ಫಲಕ ಓದುವಂತೆ close-up ಮತ್ತೆ ತೆಗೆಯಿರಿ; ಶಾಲೆಯಲ್ಲಿಯೇ ನಿಂತು ಸ್ಥಳ ಮರು-ಸೆರೆಹಿಡಿಯಿರಿ.
ಆ್ಯಪ್‌ನಲ್ಲಿ ಲಾಗಿನ್ ಆಗುತ್ತಿಲ್ಲಹಳೆಯ SDMS ರುಜುವಾತು / ಪಾಸ್‌ವರ್ಡ್ ರೀಸೆಟ್ ಆಗಿಲ್ಲಮೊದಲು udiseplus.gov.in ನಲ್ಲಿ ಪಾಸ್‌ವರ್ಡ್ ರೀಸೆಟ್, ನಂತರ ಆ್ಯಪ್‌ನಲ್ಲಿ ಪ್ರಯತ್ನಿಸಿ.
GPS ನಿರ್ದೇಶಾಂಕ ದೂರ ಇದೆಕಟ್ಟಡದ ಒಳಗೆ / ಕಳಪೆ ಸಿಗ್ನಲ್ ನಲ್ಲಿ captureಮುಖ್ಯ ದ್ವಾರದ ಹೊರಗೆ ನಿಂತು ಸ್ಪಷ್ಟ ಆಕಾಶ ನೋಡುತ್ತ capture ಮಾಡಿ.
ಹಲವು ವಾರ pending ಇದೆಜಿಲ್ಲಾ ಪರಿಶೀಲನೆ ಹಿನ್ನಡೆ — ದೋಷ ಅಲ್ಲಸ್ಥಿತಿ ತಿಳಿಯಲು BRC/ಬ್ಲಾಕ್ ಅಧಿಕಾರಿಗಳನ್ನು ಸಂಪರ್ಕಿಸಿ.

⚠️ ಗಮನಿಸಿ: ಈ ಮಾರ್ಗದರ್ಶಿ ಸಾಮಾನ್ಯ ಮಾಹಿತಿ. GIS Capture ಪ್ರಕ್ರಿಯೆ ಮತ್ತು ಕಡ್ಡಾಯ ಶಾಲೆಗಳ ಬಗ್ಗೆ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ / UDISE+ ಅಧಿಕೃತ ಪರಿಚಲನೆಗಳೇ ಅಂತಿಮ.
