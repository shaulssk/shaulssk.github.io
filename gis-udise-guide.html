UDISE+ GIS Capture — ಶಾಲಾ ಜಿಯೋ-ಟ್ಯಾಗಿಂಗ್ ಮಾರ್ಗದರ್ಶಿ

UDISE+ GIS Capture ಆ್ಯಪ್ ಎಂದರೆ ಶಾಲೆಯ ನಿಖರ GPS ಸ್ಥಳ (ಸ್ಥಾನಾಂಶ) ಮತ್ತು ವಿಶ್ವಾಸಾರ್ಹ ಫೋಟೋ ಪುರಾವೆಗಳನ್ನು UDISE+ ಡೇಟಾಬೇಸ್‌ಗೆ ದಾಖಲಿಸುವ ಮೊಬೈಲ್ ಅನ್ವಯಿಕೆ. ಆ್ಯಪ್‌ನಲ್ಲಿ ಶಾಲೆಯ ಮುಖ್ಯ ದ್ವಾರ, ಕಟ್ಟಡ, ಒಳಾಂಗಣ ಫೋಟೋ + GPS ನಿರ್ದೇಶಾಂಕ ಸೆರೆಹಿಡಿಯಲಾಗುತ್ತದೆ; ಇದನ್ನು ಜಿಲ್ಲಾ ಮಟ್ಟದ ಬಳಕೆದಾರರು ಪರಿಶೀಲಿಸಿ ಅನುಮೋದಿಸಿದ ನಂತರ ಅಧಿಕೃತವಾಗಿ ದಾಖಲಾಗುತ್ತದೆ.

📍 GIS Capture ಮೊದಲು 5 check
  1. App version: Play Store ನಲ್ಲಿ UDISE+ GIS Capture app latest version — ಹಳೆಯ app ನಲ್ಲಿ error ಬರುತ್ತದೆ.
  2. GPS location on: School premises ನಲ್ಲೇ ನಿಂತು location on ಮಾಡಿ — indoor GPS accuracy ಕಡಿಮೆ.
  3. Permissions: Camera + Location allow ಇದೆಯೇ — allow ಮಾಡದೆ photos/coords save ಆಗುವುದಿಲ್ಲ.
  4. 4 ಫೋಟೋಗಳು: ಮುಂಭಾಗ, ಬಲ, ಎಡ, ಮುಖ್ಯ ದ್ವಾರ — ಸ್ಪಷ್ಟ ಮತ್ತು full building visible ಇರಲಿ.
  5. School code correct: Capturing ಮಾಡುವ ಮೊದಲು school name + UDISE+ code ಹೊಂದಾಣಿಕೆ ಪರಿಶೀಲಿಸಿ.

1. ಆ್ಯಪ್ ಡೌನ್‌ಲೋಡ್ ಮಾಡುವ ವಿಧಾನ

  1. Google Play Store ತೆರೆದು "UDISE Plus - GIS Capture" ಹುಡುಕಿ (App ID: in.gov.udiseplus.gis)
  2. ಅಥವಾ ನೇರ ಲಿಂಕ್: play.google.com — UDISE+ GIS Capture
  3. Install ಒತ್ತಿ. ಫೋನ್‌ನಲ್ಲಿ Camera ಮತ್ತು Location (GPS) ಅನುಮತಿ ನೀಡಿ (ಅನುಮತಿ ವಿವರ ಆ್ಯಪ್/version ಪ್ರಕಾರ ಭಿನ್ನವಾಗಬಹುದು).
  4. iOS ಬಳಕೆದಾರರಿಗೂ ಆ್ಯಪ್ ಲಭ್ಯವಿದೆ — ಅಧಿಕೃತ GIS ಪೋರ್ಟಲ್ (gis.udiseplus.gov.in) ನಲ್ಲಿ ಸೂಚಿಸಿರುವ QR code ಮೂಲಕ ಮಾತ್ರ download ಮಾಡಿ; ಮಾರುಕಟ್ಟೆಯ ಲಭ್ಯತೆ/ಲಿಂಕ್ ಬದಲಾಗಬಹುದು.

✅ Verified against available official information on 09-09-2026 — ಮೂಲ: gis.udiseplus.gov.in · Play Store.

2. ಲಾಗಿನ್ ಮಾಡುವ ವಿಧಾನ

📌 ಪ್ರಮುಖ: ಆ್ಯಪ್‌ನ ಅಧಿಕೃತ ವಿವರಣೆಯ ಪ್ರಕಾರ GIS Capture ಆ್ಯಪ್‌ಗೆ ಪ್ರತ್ಯೇಕ ನೋಂದಣಿ ಇಲ್ಲ — UDISE+ ಪೋರ್ಟಲ್‌ನ ಅದೇ ಯೂಸರ್‌ನೇಮ್ ಮತ್ತು ಪಾಸ್‌ವರ್ಡ್ ಬಳಸಿ ಲಾಗಿನ್ ಆಗುತ್ತದೆ (Verified 09-09-2026).

  1. ಆ್ಯಪ್ ತೆರೆದು UDISE+ ಯೂಸರ್‌ನೇಮ್ ಮತ್ತು ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿ (ಲಾಗಿನ್ ವಿಧಾನ ಆ್ಯಪ್/ಸರ್ಕಾರಿ ಸೂಚನೆ ಪ್ರಕಾರ ಬದಲಾಗಬಹುದು).
  2. ಲಾಗಿನ್ ಆಗದಿದ್ದರೆ — ಮೊದಲು udiseplus.gov.in ಮೂಲಕ ಪಾಸ್‌ವರ್ಡ್ ರೀಸೆಟ್ ಮಾಡಿ, ನಂತರ ಆ್ಯಪ್‌ನಲ್ಲಿ ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ.
  3. ಲೋಕೇಶನ್ ಅನುಮತಿ ಸೂಕ್ತವಾಗಿ ಹೊಂದಿಸಿ (ಸಾಮಾನ್ಯವಾಗಿ Always allow — ಆ್ಯಪ್/version ಪ್ರಕಾರ ವಿವರ ಬದಲಾಗಬಹುದು); GPS ಸರಿಯಾಗಿ ದಾಖಲಾಗಲು ಇದು ಸಹಾಯಕ.

✅ Verified against available official information on 09-09-2026 — ಮೂಲ: udiseplus.gov.in · GIS ಪೋರ್ಟಲ್.

3. GPS ಸ್ಥಳ ಸೆರೆಹಿಡಿಯುವ ವಿಧಾನ

  1. ಶಾಲಾ ಆವರಣದಲ್ಲಿಯೇ ನಿಂತು ಆ್ಯಪ್ ತೆರೆಯಿರಿ — GPS ಓದುವಿಕೆ ಆಗಬೇಕು.
  2. ಮುಖ್ಯ ದ್ವಾರದ ಬಳಿ ನಿಂತು Location Capture ಆಯ್ಕೆ ಮಾಡಿ.
  3. GPS ನಿರ್ದೇಶಾಂಕ (Latitude/Longitude) ಲಾಕ್ ಆಗುವವರೆಗೆ ಕಾಯಿರಿ.
  4. ⚠️ ಶಾಲೆಯ ಹೊರಗಿನಿಂದ / ಮನೆಯಿಂದ capture ಮಾಡಬೇಡಿ — ತಪ್ಪು ನಿರ್ದೇಶಾಂಕ ದಾಖಲಾದರೆ ಜಿಲ್ಲಾ ಪರಿಶೀಲನೆಯಲ್ಲಿ reject ಆಗುತ್ತದೆ.

3A. GPS ನಿಖರತೆ — ಹೇಗೆ ಪರಿಶೀಲಿಸುವುದು?

  1. ಫೋನ್‌ನ Location (GPS) ಆನ್ ಆಗಿದೆ ಮತ್ತು mode High accuracy ಇದೆಯೇ ನೋಡಿ (Setಅಟ್‌ಗಳು → Location → High accuracy — menu ಹೆಸರು ಫೋನ್/model ಪ್ರಕಾರ ಬದಲಾಗಬಹುದು).
  2. ಶಾಲೆಯ ಮುಖ್ಯ ದ್ವಾರದ ಹೊರಗೆ ನಿಂತು, ಆ್ಯಪ್‌ನಲ್ಲಿ ನಿರ್ದೇಶಾಂಕ ಲಾಕ್ ಆಗುವವರೆಗೆ 10–30 ಸೆಕೆಂಡ್ ಕಾಯಿರಿ.
  3. ದಾಖಲಾದ Latitude/Longitude ನಿಮ್ಮ ಶಾಲೆಯ ನೈಜ ಸ್ಥಳಕ್ಕೆ ಹೊಂದಿಕೊಳ್ಳುತ್ತಿದೆಯೇ ಸಮೀಪದ ನಕ್ಷೆ/Google Maps ನಲ್ಲಿ ಶಾಲೆಯ ಹೆಸರು ಹುಡುಕಿ ಹೋಲಿಸಿ ನೋಡಿ.
  4. ನಿರ್ದೇಶಾಂಕ ನೂರಾರು ಮೀಟರ್ ದೂರ ಅಂದರೆ indoor capture/CPS error ಸಾಧ್ಯತೆ — ಮರು-ಸೆರೆಹಿಡಿಯಿರಿ.
  5. ಒಂದೇ ಸ್ಥಳದಲ್ಲಿ 2–3 ಬಾರಿ capture ಮಾಡಿ ಒಂದೇ ಮೌಲ್ಯ ಬರುತ್ತದೆಯೇ ಪರಿಶೀಲಿಸಿ (ಸ್ಥಿರತೆ = ಒಳ್ಳೆಯ ಸಂಕೇತ).

📍 "Location capture ಆಗುತ್ತಿಲ್ಲ / GPS ಮುಂದಕ್ಕೆ ಹೋಗುತ್ತಿಲ್ಲ" — 10 ತಪಾಸಣೆ: ಇವು ಸಾಮಾನ್ಯ Android/GPS troubleshooting — ಫೋನ್ ಮತ್ತು ಆ್ಯಪ್/model ಪ್ರಕಾರ ವಿವರ ಭಿನ್ನವಾಗಬಹುದು.

  1. Location ಸ್ಥಗಿತವಾಗಿದೆಯೇ — ಆನ್ ಮಾಡಿ.
  2. Location mode High accuracy ಆಗಿದೆಯೇ.
  3. ಆ್ಯಪ್‌ಗೆ Location ಅನುಮತಿ ನೀಡಿದ್ದೀರಾ (Settings → Apps → GIS Capture → Permissions).
  4. ಕಟ್ಟಡದ ಒಳಗೆ ಇದ್ದೀರಾ — ಹೊರಗೆ ಬನ್ನಿ, ಆಕಾಶ ಸ್ಪಷ್ಟವಾಗಿರಲಿ.
  5. GPS ಲಾಕ್ ಆಗಲು 10–30 ಸೆಕೆಂಡ್ ಕಾಯಿರಿ; ಬೇಗ ಒತ್ತಬೇಡಿ.
  6. Airplane mode ಒಮ್ಮೆ on/off ಮಾಡಿ — ಉಪಗ್ರಹ ಸಂಪರ್ಕ ಮರುಪಡೆಯಲು ಸಹಾಯಕ.
  7. ಆ್ಯಪ್ ಮುಚ್ಚಿ ಮತ್ತೆ ತೆರೆಯಿರಿ.
  8. ಆ್ಯಪ್‌ನ ಹೊಸ version ಇದೆಯೇ — Play Store update ಪರಿಶೀಲಿಸಿ.
  9. ಹಾಗಿದ್ದರೂ ಆಗದಿದ್ದರೆ — ಮತ್ತೊಂದು ಸ್ಥಳ (ಆಟದ ಮೈದಾನ/ಮುಕ್ತ ಪ್ರದೇಶ) ಪ್ರಯತ್ನಿಸಿ.
  10. ಕೊನೆಯ ಆಯ್ಕೆ: ಆ್ಯಪ್ uninstall → ಮರು install (ನಂತರ ಲಾಗಿನ್ ಮತ್ತೆ ಮಾಡಿ).

⚠️ ಇವು ಸಾಮಾನ್ಯ ತಂತ್ರಜ್ಞಾನ ಸಲಹೆಗಳು — ಯಾವುದೇ ನಿರ್ದಿಷ್ಟ ಫೋನ್/ಆ್ಯಪ್ ಬಗ್ಗೆ ಅಧಿಕಾರಿ ಮಾತಲ್ಲ; ದೀರ್ಘ ಸಮಸ್ಯೆಗೆ ಅಧಿಕೃತ UDISE+ helpdesk ಸಂಪರ್ಕಿಸಿ.

4. ಕಡ್ಡಾಯ ಫೋಟೋಗಳು

ಇಲಾಖಾ ಸೂಚನೆಗಳಿಗನುಸಾರ (ಆ್ಯಪ್/version ಪ್ರಕಾರ) ಸಾಮಾನ್ಯವಾಗಿ ಈ ಕೆಳಗಿನ 4 ಫೋಟೋಗಳನ್ನು ನಿರೀಕ್ಷಿಸಲಾಗುತ್ತದೆ — ನಿಖರವಾದ ಸಂಖ್ಯೆ/ವಿವರಕ್ಕೆ ಪ್ರಸ್ತುತ ಇಲಾಖಾ ಪರಿಚಲನೆ ಮತ್ತು ಆ್ಯಪ್‌ನ್ನೇ ಅನುಸರಿಸಿ.

#ಫೋಟೋಉದ್ದೇಶ
1ಮುಖ್ಯ ದ್ವಾರ (School Name ಕಾಣುವಂತೆ)ಶಾಲೆಯ ಗುರುತು UDISE+ ದಾಖಲೆಗೆ ಹೊಂದಾಣಿಕೆಯಾಗುವುದನ್ನು ಖಚಿತಪಡಿಸುತ್ತದೆ — ಇದರಲ್ಲಿ ಶಾಲೆಯ ಹೆಸರಿನ ಫಲಕ ಸ್ಪಷ್ಟವಾಗಿ ಕಾಣಬೇಕು.
2ಮುಖ್ಯ ಕಟ್ಟಡದ ಮುಂಭಾಗಶಾಲೆಯ ಭೌತಿಕ ಅಸ್ತಿತ್ವವನ್ನು ನಿರ್ದೇಶಾಂಕಗಳಲ್ಲಿ ದೃಢೀಕರಿಸುತ್ತದೆ.
3ಹೆಚ್ಚುವರಿ ಕಟ್ಟಡ/ಕೋನ ಅಥವಾ ಮುಖ್ಯ ಶಿಕ್ಷಕರ ಕೊಠಡಿಪರಿಶೀಲನೆಗೆ ದ್ವಿತೀಯ ಉಲ್ಲೇಖ ಬಿಂದು.
4ಒಳಾಂಗಣ ಸೌಲಭ್ಯ (ವರ್ಗ ಕೊಠಡಿ / ಆಟದ ಮೈದಾನ)ಶಾಲೆ ಕ್ರಿಯಾಶೀಲವಾಗಿದೆ ಎಂಬುದನ್ನು ದೃಢೀಕರಿಸುತ್ತದೆ.

💡 ಸಲಹೆ: ಎಲ್ಲಾ ಫೋಟೋ ಸ್ಪಷ್ಟವಾಗಿರಲಿ; ಮುಖ್ಯ ದ್ವಾರದ ಫೋಟೋದಲ್ಲಿ ಶಾಲೆಯ ಹೆಸರು ಓದುವಂತೆ ತೋರಿಸಿ — ಅನುಮೋದನೆಗೆ ಇದು ಮುಖ್ಯ ಪರಿಶೀಲನೆ.

✅ Verified against available official information on 09-09-2026 — ಫೋಟೋಗಳ ನಿಖರ ಪಟ್ಟಿ ಇಲಾಖಾ ಸೂಚನೆಯಂತೆ ಬದಲಾಗಬಹುದು.

4A. ಒಳ್ಳೆಯ vs ಕೆಟ್ಟ ಫೋಟೋ — ಹೇಗೆ ಗುರುತಿಸುವುದು?

ಒಳ್ಳೆಯ ಫೋಟೋ ✅ಕೆಟ್ಟ/ನಿರಾಕರಣೆಗೆ ಅವಕಾಶ ❌
ಹಗಲು ಬೆಳಕಿನಲ್ಲಿ, ಸ್ಪಷ್ಟ, ಸ್ಥಿರ (ಕೈ ಅಲ್ಲಾಡಿಸದೆ)ಮಸುಕು / ಕತ್ತಲೆ / ಮಬ್ಬು (motion blur, low light)
ಶಾಲಾ ಹೆಸರಿನ ಫಲಕ ಓದುವಂತೆ ಸ್ಪಷ್ಟಫಲಕ ಇಲ್ಲ ಅಥವಾ ಓದಲಾಗದಷ್ಟು ದೂರ/ಮಸುಕು
ಪೂರ್ಣ ಕಟ್ಟಡ/ದ್ವಾರ ಚೌಕಟ್ಟಿನಲ್ಲಿ ಗೋಚರಅರ್ಧ ಕಟ್ಟಡ, ತಪ್ಪು ಕೋನ, ಬೇರೆ ಕಟ್ಟಡ ಮೇಲುಗೈ
GPS ಆ್ಯಪ್‌ನೊಳಗೆ ನಡೆಸಿದ captureಬೇರೆ ಆ್ಯಪ್/ಕ್ಯಾಮೆರಾದಿಂದ ತೆಗೆದ ಫೋಟೋ — ಸರಿ ಅಲ್ಲ
UDISE+ ದಾಖಲೆಯ ಹೆಸರಿಗೆ ಹೊಂದುವ ಶಾಲೆಬೇರೆ ಶಾಲೆ/ಸ್ಥಳದ ಫೋಟೋ — reject ಹೆಚ್ಚು

✅ Submit ಮೊದಲು — final checklist:

  • ಎಲ್ಲಾ ಅಗತ್ಯ ಫೋಟೋ (ಸಾಮಾನ್ಯವಾಗಿ 4) capture ಆಗಿವೆಯೇ.
  • GPS ನಿರ್ದೇಶಾಂಕ ಶಾಲೆಯ ನೈಜ ಸ್ಥಳದೊಂದಿಗೆ ಹೊಂದಿಕೊಳ್ಳುತ್ತಿದೆಯೇ.
  • ಮುಖ್ಯ ದ್ವಾರದ ಫೋಟೋದಲ್ಲಿ ಶಾಲೆಯ ಹೆಸರು ಓದುವಂತಿದೆಯೇ.
  • ಸರಿಯಾದ UDISE+ code/ಶಾಲೆ ಆಯ್ಕೆಯಾಗಿದೆಯೇ.
  • Upload ವೇಳೆಗೆ follow-up ಮಾಡಲು submit ದಿನಾಂಕ + ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಸಾಕ್ಷ್ಯ ಇಟ್ಟುಕೊಳ್ಳಿ.

5. Submit — ಅನುಮೋದನೆ ಪ್ರಕ್ರಿಯೆ

  1. ಫೋಟೋ ಮತ್ತು GPS ಸರಿಯಾಗಿದೆಯೆ ಪರಿಶೀಲಿಸಿ Submit ಒತ್ತಿ.
  2. Submit ಆದ ನಿರ್ದೇಶಾಂಕ + ಫೋಟೋಗಳು ಜಿಲ್ಲಾ ಮಟ್ಟದ ಬಳಕೆದಾರರ ಪರಿಶೀಲನೆಗೆ ಹೋಗುತ್ತವೆ.
  3. ಅನುಮೋದನೆಯಾದ ನಂತರ ದತ್ತಾಂಶ ರಾಜ್ಯ/ರಾಷ್ಟ್ರ ಮಟ್ಟದಲ್ಲಿ ಪ್ರಕಟವಾಗಿ ಇತರ ಉಪಯುಕ್ತ ವ್ಯವಸ್ಥೆಗಳಿಗೆ (ಸಂಚರಣೆ, ಶಾಲಾ ಹುಡುಕಾಟ) ಬಳಕೆಯಾಗುತ್ತದೆ.
  4. ಜಿಲ್ಲಾ ಪರಿಶೀಲನೆ ಕೆಲವು ದಿನಗಳನ್ನು ತೆಗೆದುಕೊಳ್ಳಬಹುದು — status ಅನ್ನು ನಿಯಮಿತವಾಗಿ ನೋಡಿ.

6. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು ಮತ್ತು ಪರಿಹಾರ

ಸಮಸ್ಯೆಕಾರಣಪರಿಹಾರ
District reviewer reject ಮಾಡಿದ್ದಾರೆದ್ವಾರದ ಫೋಟೋದಲ್ಲಿ ಶಾಲೆಯ ಹೆಸರು ಸ್ಪಷ್ಟವಿಲ್ಲ / GPS ತಪ್ಪಾಗಿದೆಹೆಸರು ಫಲಕ ಓದುವಂತೆ close-up ಮತ್ತೆ ತೆಗೆಯಿರಿ; ಶಾಲೆಯಲ್ಲಿಯೇ ನಿಂತು ಸ್ಥಳ ಮರು-ಸೆರೆಹಿಡಿಯಿರಿ.
ಆ್ಯಪ್‌ನಲ್ಲಿ ಲಾಗಿನ್ ಆಗುತ್ತಿಲ್ಲಹಳೆಯ SDMS ರುಜುವಾತು / ಪಾಸ್‌ವರ್ಡ್ ರೀಸೆಟ್ ಆಗಿಲ್ಲಮೊದಲು udiseplus.gov.in ನಲ್ಲಿ ಪಾಸ್‌ವರ್ಡ್ ರೀಸೆಟ್, ನಂತರ ಆ್ಯಪ್‌ನಲ್ಲಿ ಪ್ರಯತ್ನಿಸಿ.
GPS ನಿರ್ದೇಶಾಂಕ ದೂರ ಇದೆಕಟ್ಟಡದ ಒಳಗೆ / ಕಳಪೆ ಸಿಗ್ನಲ್ ನಲ್ಲಿ captureಮುಖ್ಯ ದ್ವಾರದ ಹೊರಗೆ ನಿಂತು ಸ್ಪಷ್ಟ ಆಕಾಶ ನೋಡುತ್ತ capture ಮಾಡಿ.
ಫೋಟೋ ಅಸ್ಪಷ್ಟ / ಮಸುಕುಕತ್ತಲೆ, ಕೈ ಅಲುಗಾಡಿಕೆ, ಮಳೆಹಗಲು ಬೆಳಕಿನಲ್ಲಿ ಸ್ಥಿರವಾಗಿ ಮತ್ತೆ ತೆಗೆಯಿರಿ — ಶಾಲಾ ಹೆಸರು ಫಲಕ ಓದುವಂತಿರಲಿ.
ಬೇರೆ ಶಾಲೆಯ/ತಪ್ಪು ನಿರ್ದೇಶಾಂಕ submitತಪ್ಪು UDISE+ code ಅಥವಾ ತಪ್ಪು ಸ್ಥಳ ಆಯ್ಕೆಶಾಲೆ/ಕೋಡ್ ಮತ್ತೆ ಪರಿಶೀಲಿಸಿ, ಸರಿಯಾದ ಶಾಲೆಯಲ್ಲೇ capture ಮಾಡಿ.
ಆ್ಯಪ್ ನಲ್ಲಿ error/version ಸಮಸ್ಯೆಹಳೆಯ version / ಡೇಟಾ ಸಂಗ್ರಹ ದೋಷPlay Store ನಲ್ಲಿ update; ಅಗತ್ಯವಿದ್ದರೆ uninstall → ಮರು install (ಲಾಗಿನ್ ಮತ್ತೆ ಮಾಡಿ).
ಹಲವು ವಾರ pending ಇದೆಜಿಲ್ಲಾ ಪರಿಶೀಲನೆ ಹಿನ್ನಡೆ — ದೋಷ ಅಲ್ಲಸ್ಥಿತಿ ತಿಳಿಯಲು BRC/ಬ್ಲಾಕ್ ಅಧಿಕಾರಿಗಳನ್ನು ಸಂಪರ್ಕಿಸಿ.

⚠️ ಗಮನಿಸಿ: ಈ ಮಾರ್ಗದರ್ಶಿ ಸಾಮಾನ್ಯ ಮಾಹಿತಿ. GIS Capture ಪ್ರಕ್ರಿಯೆ ಮತ್ತು ಕಡ್ಡಾಯ ಶಾಲೆಗಳ ಬಗ್ಗೆ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ / UDISE+ ಅಧಿಕೃತ ಪರಿಚಲನೆಗಳೇ ಅಂತಿಮ.

6A. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. GIS Capture ಆ್ಯಪ್‌ನಲ್ಲಿ ಹೊಸ ನೋಂದಣಿ ಬೇಕೇ?

ಬೇಡ — ಆ್ಯಪ್‌ಗೆ ಪ್ರತ್ಯೇಕ ನೋಂದಣಿ ಇಲ್ಲ. UDISE+ SDMS ಪೋರ್ಟಲ್‌ನ ಅದೇ username ಮತ್ತು password ಬಳಸಿ login ಆಗುತ್ತದೆ.

2. GPS ಸ್ಥಳ ದೂರ/ತಪ್ಪಾಗಿ ದಾಖಲಾಗುತ್ತಿದೆ — ಏನು ಮಾಡಬೇಕು?

ಶಾಲೆಯ ಹೊರಗೆ, ಮುಖ್ಯ ದ್ವಾರದ ಬಳಿ ಸ್ಪಷ್ಟ ಆಕಾಶ ಕಾಣುವೆಡೆ ನಿಂತು capture ಮಾಡಿ; phone setting ನಲ್ಲಿ Location ಅನ್ನು High accuracy ಆಗಿ ಹೊಂದಿಸಿ; ಒಳಾಂಗಣ/ಮನೆಯಿಂದ capture ಬೇಡ.

3. ಫೋಟೋಗಳ ಸಂಖ್ಯೆ & ವಿವರ ಏನು?

ಸಾಮಾನ್ಯವಾಗಿ 4: (1) ಮುಖ್ಯ ದ್ವಾರ — ಶಾಲಾ ಹೆಸರು ಫಲಕ ಸ್ಪಷ್ಟ, (2) ಮುಖ್ಯ ಕಟ್ಟಡದ ಮುಂಭಾಗ, (3) ಹೆಚ್ಚುವರಿ ಕಟ್ಟಡ/ಮುಖ್ಯ ಶಿಕ್ಷಕರ ಕೊಠಡಿ, (4) ಒಳಾಂಗಣ ಸೌಲಭ್ಯ (ವರ್ಗ ಕೊಠಡಿ/ಮೈದಾನ). ಇದು ಸಾಮಾನ್ಯ ಮಾರ್ಗದರ್ಶನ — ನಿಖರ ಪಟ್ಟಿಗೆ ಇಲಾಖಾ ಸೂಚನೆ ಪರಿಶೀಲಿಸಿ.

4. Submit ಮಾಡಿದ ನಂತರ ಯಾವಾಗ final ಆಗುತ್ತದೆ?

ಜಿಲ್ಲಾ ಮಟ್ಟದ ಬಳಕೆದಾರ ಪರಿಶೀಲಿಸಿ approve ಮಾಡಬೇಕು — ಸಾಮಾನ್ಯವಾಗಿ ಕೆಲವು ದಿನ ತಗಲಬಹುದು. Status ದೀರ್ಘಕಾಲ pending ಇದ್ದರೆ BRC/ಬ್ಲಾಕ್ ಅಧಿಕಾರಿಗೆ ವಿಚಾರಿಸಿ.

5. ಆ್ಯಪ್ login ಆಗುತ್ತಿಲ್ಲ — ಮಾರ್ಗ?

ಮೊದಲು udiseplus.gov.in ನಲ್ಲಿ password reset ಮಾಡಿ; ಆ್ಯಪ್‌ನ ಇತ್ತೀಚಿನ version install ಆಗಿರಲಿ. ಇದರಿಂದ ಪರಿಹಾರ ಆಗದಿದ್ದರೆ ಅಧಿಕೃತ UDISE+ helpdesk ಸಂಪರ್ಕ ಮಾಹಿತಿಗಾಗಿ udiseplus.gov.in ಪರಿಶೀಲಿಸಿ (ಸಂಪರ್ಕ ವಿವರ ಬದಲಾಗಬಹುದು).
