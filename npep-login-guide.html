🔑 NPEP Login & School Registration 2026-27 (npepncert.in)

NPEP (National Population Education Project) · NCERT · School Nodal Officer · Role Play & Folk Dance

✅ Last verified: 26 Sep 2026 · 📌 Official: npepncert.in/competition

⚠️ ಪ್ರಮುಖ: ಈ ಪುಟವು ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ (independent guide) — NCERT / NPEP / ಸರ್ಕಾರದ ಅಧಿಕೃತ ಪುಟ ಅಲ್ಲ. ನೋಂದಣಿ ದಿನಾಂಕ, login ನಿಯಮ, form fields ಬದಲಾಗಬಹುದು — ಅಧಿಕೃತ npepncert.in ಪೋರ್ಟಲ್ ಅನ್ನು ಯಾವಾಗಲೂ ಪರಿಶೀಲಿಸಿ.

1. NPEP Login — ನೇರ ಲಿಂಕ್

NPEP = National Population Education Project (NCERT). ಸ್ಪರ್ಧಾ ನೋಂದಣಿ/ನಿರ್ವಹಣೆಗೆ ಶಾಲೆಗಳು ಈ ಪೋರ್ಟಲ್‌ನಲ್ಲಿ login ಆಗುತ್ತವೆ:

🌐 Login ಪುಟ: npepncert.in/competition → ಮೇಲಿನ ಬಲ ಮೂಲೆಯ Login ಗುಂಡಿ.
📝 ಹೊಸ ಶಾಲೆ: ಅದೇ ಪುಟದಲ್ಲಿ Register / School Registration → Go to Registration Page.

Login ಮೋಡ್‌ಗಳು (User Type): School Nodal Officer · Jury · District Officer · State Officer · Final Admin — ಶಾಲೆಗಳಿಗೆ ಮುಖ್ಯವಾಗಿ "School Nodal Officer".

2. NPEP — ಏನು, ಯಾರಿಗೆ?

  • 🎭 Role Play — 9ನೇ ತರಗತಿ, 4–5 ವಿದ್ಯಾರ್ಥಿಗಳು, 5–6 ನಿಮಿಷ.
  • 💃 Folk Dance — 8–9ನೇ ತರಗತಿ, 4–6 ವಿದ್ಯಾರ್ಥಿಗಳು, 5–6 ನಿಮಿಷ.
  • 🎯 ಉದ್ದೇಶ: Life skills (ಸಮಸ್ಯೆ ಪರಿಹಾರ, ಸಂವಹನ, ತಂಡ ಕಾರ್ಯ) ಅಭಿವೃದ್ಧಿ — Adolescent Education, Mental Health, Population Education.

3. ಹಂತ-ಹಂತ: School Registration → Login

  1. ಪೋರ್ಟಲ್ ತೆರೆಯಿರಿ: npepncert.in/competition. (ಇಂಟರ್ನೆಟ್ ಸ್ಥಿರವಾಗಿ — mobile/desktop ಎರಡರಲ್ಲೂ work ಆಗುತ್ತದೆ.)
  2. Register / School Registration: "School Nodal Officer Registration is Open Now" → Register Now / menu ನಲ್ಲಿ Register, ಅಥವಾ School Registration Form → Go to Registration Page ಎಂದು ಕ್ಲಿಕ್ ಮಾಡಿ.
  3. UDISE Code ನಮೂದಿಸಿ: ಶಾಲೆಯ 11 ಅಂಕಿಯ UDISE+ ಕೋಡ್ ಹಾಕಿ → Search ಒತ್ತಿ — ಶಾಲೆಯ ಹೆಸರು ಮತ್ತು ವಿಳಾಸ ತಾನಾಗಿಯೇ ಕಾಣುತ್ತದೆ. ಸರಿಯಾಗಿ ಬಂದಿದೆಯೇ ಹೋಲಿಸಿ.
  4. Nodal Officer ವಿವರ: ಸಂಯೋಜಕರ ಹೆಸರು, ಹುದ್ದೆ (Designation), ಮೊಬೈಲ್ ಸಂಖ್ಯೆ ಮತ್ತು ಇಮೇಲ್ ವಿಳಾಸ ನಿಖರವಾಗಿ ನಮೂದಿಸಿ.
  5. ಪಾಸ್‌ವರ್ಡ್ ರಚಿಸಿ: login ಗೆ ಬಳಸುವ ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಸೆಟ್ ಮಾಡಿ.
  6. OTP ಪರಿಶೀಲನೆ: ನೋಂದಾಯಿತ ಮೊಬೈಲ್/ಇಮೇಲ್‌ಗೆ ಬರುವ OTP ನಮೂದಿಸಿ → Submit — ಶಾಲೆಯ Nodal Officer ಖಾತೆ ಸಿದ್ಧವಾಗುತ್ತದೆ.
  7. Submit → Credentials: ನೋಂದಣಿ ಮುಗಿದ ನಂತರ ಸಿಗುವ User ID/Password (ಯಾ QR/email/portal) ಉಳಿಸಿಕೊಳ್ಳಿ.
  8. Login: Portal → Login → User Type = School Nodal Officer → User ID (ನೋಂದಾಯಿತ ಇಮೇಲ್ ಅಥವಾ UDISE ಕೋಡ್) + Password → ಇದ್ದರೆ Captcha ದಾಖಲಿಸಿ → Login.
  9. ವಿದ್ಯಾರ್ಥಿ/ತಂಡ entry: login ಆದ ನಂತರ Role Play / Folk Dance ತಂಡದ ವಿದ್ಯಾರ್ಥಿ ವಿವರ + ದಾಖಲೆ (entry) ಭರ್ತಿ ಹಾಗೂ submit.

⚠️ Important: ಶಾಲಾ ನೋಂದಣಿ (School Registration) ಮೊದಲು ಆಗುವುದು ಕಡ್ಡಾಯ — ಹಿಂದೆ ಶಾಲೆ ನೋಂದಾಯಿಸದ ಹೊರತು ವಿದ್ಯಾರ್ಥಿ entry ಸಾಧ್ಯವಿಲ್ಲ. ಮೊದಲ ಹಂತವನ್ನೇ ಮುಗಿಸಿ.

3a. ವಿದ್ಯಾರ್ಥಿ/ತಂಡ Entry ಫಾರಂ (Competition Entry Form)

  1. ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿ Apply Now / Submit Entry ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿ.
  2. ವಿದ್ಯಾರ್ಥಿ ವಿವರ: ಪ್ರತಿ ಭಾಗವಹಿಸುವ ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರು, ತರಗತಿ (Class), ಲಿಂಗ (Gender) ಮತ್ತು ಹುದ್ದೆ/ಪಾತ್ರ ಆಯ್ಕೆ.
  3. ಸ್ಪರ್ಧೆ ವಿಭಾಗ (Category): Role Play ಅಥವಾ Folk Dance — ಸರಿಯಾದ category ಆಯ್ಕೆ (ತಪ್ಪು ವಿಭಾಗದಲ್ಲಿ entry disqualify ಆಗಬಹುದು).
  4. ಫೈಲ್ ಅಪ್‌ಲೋಡ್: ಅಗತ್ಯ ದಾಖಲೆ/ಕೃತಿ ಸೂಚಿತ ಫಾರ್ಮ್ಯಾಟ್‌ನಲ್ಲಿ (ಸಾಮಾನ್ಯವಾಗಿ PDF/JPEG) — ಫೈಲ್‌ನ ಗಾತ್ರ ನಿಗದಿ ಮಿತಿಗಿಂತ ಕಡಿಮೆ ಇರಲಿ (ಉದಾ. 2MB ಗಿಂತ ಕಡಿಮೆ).
  5. Review & Submit: ಎಲ್ಲಾ ವಿವರ ಸರಿಯಿದೆಯೇ ಪರಿಶೀಲಿಸಿ → Final Submit.
  6. Submit ಆದ ನಂತರ ಬರುವ Acknowledgement Number / Reference ID ಪ್ರಿಂಟ್/ಸೇವ್ ಮಾಡಿಟ್ಟುಕೊಳ್ಳಿ — ಭವಿಷ್ಯದ ಹಂತಗಳಲ್ಲಿ ಈ ದಾಖಲೆ ಬೇಕಾಗುತ್ತದೆ.

⛓️ ಕ್ರಮ ಕಡ್ಡಾಯ (Linear workflow): ಶಾಲಾ ಮಟ್ಟದ ವರದಿ ಸಲ್ಲಿಸಿ ಪರಿಶೀಲನೆಯಾದ ನಂತರವೇ ವಿಜೇತ ತಂಡವನ್ನು ಮುಂದಿನ (ಬ್ಲಾಕ್/ಜಿಲ್ಲಾ) ಹಂತಕ್ಕೆ ನಾಮನಿರ್ದೇಶನ ಮಾಡಲು ಪೋರ್ಟಲ್ ಅನುಮತಿಸುತ್ತದೆ. ಪ್ರತಿ ಹಂತದ ಮೌಲ್ಯಮಾಪನ/ವರದಿ ಬಾಕಿ ಇದ್ದರೆ ಮೇಲಿನ ಹಂತದ entries ಲಾಕ್ ಆಗಿರುತ್ತವೆ.

4. ಪಾಸ್‌ವರ್ಡ್ ಮರೆತರೆ (Forgot Password)

  • Login ಪುಟದಲ್ಲಿ Forgot Password? ಲಿಂಕ್ ಕ್ಲಿಕ್ ಮಾಡಿ → ನೋಂದಣಿ ಮಾಡಿದ user type (School Nodal Officer) ಆಯ್ಕೆ → ನೋಂದಾಯಿತ mobile/email ಗೆ recovery link/OTP.
  • ಸಿಗದಿದ್ದರೆ — ಪೋರ್ಟಲ್‌ನ help desk / contact ಅಥವಾ ಕೆಳಗಿನ ಸಂಯೋಜಕರನ್ನು (WhatsApp) ಸಂಪರ್ಕಿಸಿ. (ಸಂಪರ್ಕ ವಿವರ ಬದಲಾಗಬಹುದು — ಪೋರ್ಟಲ್ ಪರಿಶೀಲಿಸಿ.)

7. FAQ

NPEP login URL ಯಾವುದು?

ನೇರ ಪೋರ್ಟಲ್: npepncert.in/competition → ಮೇಲೆ Login. (Login/Register ಗುಂಡಿಗಳು ಆ ಪುಟದಲ್ಲೇ ಇರುತ್ತವೆ.)

ಫಾರಂನ UDISE Code Search ಏನು?

ನೋಂದಣಿ ಫಾರಂನಲ್ಲಿ 11 ಅಂಕಿಯ ಶಾಲಾ UDISE+ ಕೋಡ್ ನಮೂದಿಸಿ Search ಒತ್ತಿದರೆ ಶಾಲೆಯ ಹೆಸರು/ವಿಳಾಸ ತಾನಾಗಿ ಬರುತ್ತದೆ — ತಪ್ಪು ಶಾಲೆ ಆಯ್ಕೆಯಾಗದಂತೆ auto-fill ಆದ ವಿವರ ಹೋಲಿಸಿ ನೋಡಿ.

Acknowledgement Number ಏಕೆ ಮುಖ್ಯ?

Submit ಆದ ಪ್ರತಿ entry ಗೆ Reference ID ಬರುತ್ತದೆ — ಉಳಿದುಕೊಳ್ಳಿ. ಮುಂದಿನ ಹಂತದಲ್ಲಿ ನಿದರ್ಶನ/ಸಾಕ್ಷ್ಯ, ಹೆಸರು ತಿದ್ದುಪಡಿ (ವಿಶೇಷ ಸಂದರ್ಭದಲ್ಲಿ) ಮತ್ತು ವರದಿಗಳಲ್ಲಿ ಇದು ಬೇಕಾಗುತ್ತದೆ.

ತಂಡದ ಪಟ್ಟಿ ಬದಲಾಯಿಸಬಹುದೇ?

ಶಾಲಾ ಮಟ್ಟದ ವರದಿ ಸಲ್ಲಿಕೆಯ ನಂತರ ಪೋರ್ಟಲ್ ತಂಡ ಪಟ್ಟಿಯನ್ನು ಲಾಕ್ ಮಾಡುತ್ತದೆ — ಹೆಸರು/ಆಟಗಾರ ಬದಲಾವಣೆ ವಿಶೇಷ ಮತ್ತು ಪರಿಶೀಲಿತ ಸಂದರ್ಭದಲ್ಲಿ ಮಾತ್ರ. ಹೆಸರುಗಳು ಮೊದಲ ಹಂತದಿಂದಲೇ ನಿಖರವಾಗಿಡಿ.

ಶಾಲೆ ನೋಂದಾಯಿಸದೇ ವಿದ್ಯಾರ್ಥಿ entry ಮಾಡಬಹುದೇ?

ಸಾಮಾನ್ಯವಾಗಿ ಸಾಧ್ಯವಿಲ್ಲ — ಮೊದಲು School Nodal Officer ನೋಂದಣಿ, ಆನಂತರ login → ವಿದ್ಯಾರ್ಥಿ/ತಂಡ entry.

Role Play ಯಾವ ತರಗತಿಗೆ?

Role Play = 9ನೇ ತರಗತಿ; Folk Dance = 8–9ನೇ ತರಗತಿ (2026-27 ಸ್ಕೀಮ್ ಪ್ರಕಾರ).

ಶುಲ್ಕವಿದೆಯೇ?

ಸ್ಪರ್ಧೆಗೆ ಸಾಮಾನ್ಯವಾಗಿ ಶುಲ್ಕವಿಲ್ಲ. ಯಾವುದೇ ಫೀಸ್ ಕೇಳಿದರೆ ಅದು ಅನಧಿಕೃತ — ಪೋರ್ಟಲ್/ದೂರು ಮಾರ್ಗ ಬಳಸಿ.

ಈ ಪುಟ ಅಧಿಕೃತವೇ?

ಇಲ್ಲ — ಇದು ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ. ಅಧಿಕೃತ: npepncert.in · ncert.nic.in.
