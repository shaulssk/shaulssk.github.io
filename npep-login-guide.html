1. NPEP Login — ನೇರ ಲಿಂಕ್

NPEP = National Population Education Project (NCERT). ಸ್ಪರ್ಧಾ ನೋಂದಣಿ/ನಿರ್ವಹಣೆಗೆ ಶಾಲೆಗಳು ಈ ಪೋರ್ಟಲ್‌ನಲ್ಲಿ login ಆಗುತ್ತವೆ:

🌐 Login ಪುಟ: npepncert.in/competition → ಮೇಲಿನ ಬಲ ಮೂಲೆಯ Login ಗುಂಡಿ.
📝 ಹೊಸ ಶಾಲೆ: ಅದೇ ಪುಟದಲ್ಲಿ Register / School Registration → Go to Registration Page.

Login ಮೋಡ್‌ಗಳು (User Type): School Nodal Officer · Jury · District Officer · State Officer · Final Admin — ಶಾಲೆಗಳಿಗೆ ಮುಖ್ಯವಾಗಿ "School Nodal Officer".

2. NPEP — ಏನು, ಯಾರಿಗೆ?

  • 🎭 Role Play — 9ನೇ ತರಗತಿ, 4–5 ವಿದ್ಯಾರ್ಥಿಗಳು, 5–6 ನಿಮಿಷ.
  • 💃 Folk Dance — 8–9ನೇ ತರಗತಿ, 4–6 ವಿದ್ಯಾರ್ಥಿಗಳು, 5–6 ನಿಮಿಷ.
  • 🎯 ಉದ್ದೇಶ: Life skills (ಸಮಸ್ಯೆ ಪರಿಹಾರ, ಸಂವಹನ, ತಂಡ ಕಾರ್ಯ) ಅಭಿವೃದ್ಧಿ — Adolescent Education, Mental Health, Population Education.

3. ಹಂತ-ಹಂತ: School Registration → Login

  1. ಪೋರ್ಟಲ್ ತೆರೆಯಿರಿ: npepncert.in/competition. (ಇಂಟರ್ನೆಟ್ ಸ್ಥಿರವಾಗಿ — mobile/desktop ಎರಡರಲ್ಲೂ work ಆಗುತ್ತದೆ.)
  2. Register / School Registration: "School Nodal Officer Registration is Open Now" → Register Now / menu ನಲ್ಲಿ Register, ಅಥವಾ School Registration Form → Go to Registration Page ಎಂದು ಕ್ಲಿಕ್ ಮಾಡಿ.
  3. ಶಾಲಾ ವಿವರ ಭರ್ತಿ: ಶಾಲೆಯ ಹೆಸರು, UDISE/DISE code, ತರಗತಿ (8/9), ಸಂಪರ್ಕ, Nodal Officer (ಸಂಯೋಜಕ) ಹೆಸರು/ಮೊಬೈಲ್ — ನಿಖರ ದಾಖಲಿಸಿ.
  4. Submit → Credentials: ನೋಂದಣಿ ಮುಗಿದ ನಂತರ ಸಿಗುವ User ID/Password (ಯಾ QR/email/portal) ಉಳಿಸಿಕೊಳ್ಳಿ.
  5. Login: Portal → Login → User Type = School Nodal Officer → User ID + Password → Login.
  6. ವಿದ್ಯಾರ್ಥಿ/ತಂಡ entry: login ಆದ ನಂತರ Role Play / Folk Dance ತಂಡದ ವಿದ್ಯಾರ್ಥಿ ವಿವರ + ದಾಖಲೆ (entry) ಭರ್ತಿ ಹಾಗೂ submit.

⚠️ Important: ಶಾಲಾ ನೋಂದಣಿ (School Registration) ಮೊದಲು ಆಗುವುದು ಕಡ್ಡಾಯ — ಹಿಂದೆ ಶಾಲೆ ನೋಂದಾಯಿಸದ ಹೊರತು ವಿದ್ಯಾರ್ಥಿ entry ಸಾಧ್ಯವಿಲ್ಲ. ಮೊದಲ ಹಂತವನ್ನೇ ಮುಗಿಸಿ.

4. ಪಾಸ್‌ವರ್ಡ್ ಮರೆತರೆ (Forgot Password)

  • Login ಪುಟದಲ್ಲಿ Forgot Password? ಲಿಂಕ್ ಕ್ಲಿಕ್ ಮಾಡಿ → ನೋಂದಣಿ ಮಾಡಿದ user type (School Nodal Officer) ಆಯ್ಕೆ → ನೋಂದಾಯಿತ mobile/email ಗೆ recovery link/OTP.
  • ಸಿಗದಿದ್ದರೆ — ಪೋರ್ಟಲ್‌ನ help desk / contact ಅಥವಾ ಕೆಳಗಿನ ಸಂಯೋಜಕರನ್ನು (WhatsApp) ಸಂಪರ್ಕಿಸಿ. (ಸಂಪರ್ಕ ವಿವರ ಬದಲಾಗಬಹುದು — ಪೋರ್ಟಲ್ ಪರಿಶೀಲಿಸಿ.)

7. FAQ

NPEP login URL ಯಾವುದು?

ನೇರ ಪೋರ್ಟಲ್: npepncert.in/competition → ಮೇಲೆ Login. (Login/Register ಗುಂಡಿಗಳು ಆ ಪುಟದಲ್ಲೇ ಇರುತ್ತವೆ.)

ಶಾಲೆ ನೋಂದಾಯಿಸದೇ ವಿದ್ಯಾರ್ಥಿ entry ಮಾಡಬಹುದೇ?

ಸಾಮಾನ್ಯವಾಗಿ ಸಾಧ್ಯವಿಲ್ಲ — ಮೊದಲು School Nodal Officer ನೋಂದಣಿ, ಆನಂತರ login → ವಿದ್ಯಾರ್ಥಿ/ತಂಡ entry.

Role Play ಯಾವ ತರಗತಿಗೆ?

Role Play = 9ನೇ ತರಗತಿ; Folk Dance = 8–9ನೇ ತರಗತಿ (2026-27 ಸ್ಕೀಮ್ ಪ್ರಕಾರ).

ಶುಲ್ಕವಿದೆಯೇ?

ಸ್ಪರ್ಧೆಗೆ ಸಾಮಾನ್ಯವಾಗಿ ಶುಲ್ಕವಿಲ್ಲ. ಯಾವುದೇ ಫೀಸ್ ಕೇಳಿದರೆ ಅದು ಅನಧಿಕೃತ — ಪೋರ್ಟಲ್/ದೂರು ಮಾರ್ಗ ಬಳಸಿ.
