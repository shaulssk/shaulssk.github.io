🏫 UDISE+ Teacher Module — Head of School (HoS) & Assistant HoS Mapping

UDISE+ Teacher Module · HoS / Assistant HoS · Staff Summary Report · AHOS Details · PRASHASTA ಸ್ಕ್ರೀನಿಂಗ್ ಸಂಬಂಧ

✅ Last verified: 25 Sep 2026 · 📌 Official Portal: udiseplus.gov.in (Karnataka)

⚠️ ಪ್ರಮುಖ: ಈ ಪುಟ ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ — UDISE+ / NIEPA / ಸರ್ಕಾರದ ಅಧಿಕೃತ ಪುಟ ಅಲ್ಲ. UDISE+ ಇಂಟರ್ಫೇಸ್, buttons ಮತ್ತು menu ಹೆಸರುಗಳು ಬದಲಾಗಬಹುದು — ಅಧಿಕೃತ udiseplus.gov.in Portal ಪರಿಶೀಲಿಸಿ.

1. ಈ ಕೆಲಸ ಏನು?

Head of School (HoS) ಮತ್ತು Assistant Head of School (Asst. HoS) ಗಳನ್ನು UDISE+ Teacher Module ನಲ್ಲಿ mapping ಮಾಡುವುದು — ಶಾಲೆಯ ಶಿಕ್ಷಕರ ಪಟ್ಟಿಯಿಂದ ಸರಿಯಾದ ವ್ಯಕ್ತಿಯನ್ನು ಆ ಪಾತ್ರಕ್ಕೆ ನೇಮಿಸುವಂತೆ ಗುರುತಿಸುವ ಕೆಲಸ. ಇದು Staff Summary Report ನ AHOS Details ವಿಭಾಗದ ಮೂಲಕ ಮಾಡಲಾಗುತ್ತದೆ.

💡 ಉದ್ದೇಶ: PRASHASTA ಸ್ಕ್ರೀನಿಂಗ್/ಬೇರೆ ಇಲಾಖಾ ಸಂದರ್ಭಗಳಲ್ಲಿ HOS ಯಾರು, Asst. HoS ಯಾರು ಎಂದು ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಸರಿಯಾಗಿ ದಾಖಲಾಗಿರಲು ಈ mapping ಮಾಡುತ್ತಾರೆ.

2. HOS & Asst. HoS Mapping — 7 ಹಂತಗಳು

1

Login: UDISE+ Karnataka Portal ತೆರೆದು, Teacher Module ಪಕ್ಕದ orange "Login" button ಕ್ಲಿಕ್ ಮಾಡಿ.

2

Dashboard: Main dashboard ನಲ್ಲಿ Quick Actions → Dashboard option ಕ್ಲಿಕ್ ಮಾಡಿ — ಶಾಲೆಯ staff data entry ವಿಭಾಗವನ್ನು ಪ್ರವೇಶಿಸಲು.

3

Staff Summary Report: Staff Summary Report ಪುಟದಲ್ಲಿ ಬಲ ಕೆಳಗಡೆ (bottom right) ಸ್ಕ್ರಾಲ್ ಮಾಡಿ — AHOS Details ವಿಭಾಗದ ಕೆಳಗಿರುವ ನೀಲಿ Mapping button ಕ್ಲಿಕ್ ಮಾಡಿ.

4

Role ಆಯ್ಕೆ: Select Details to be Mapped drop-down ನಲ್ಲಿ Head of School (HoS) ಅಥವಾ Assistant HoS ಆಯ್ಕೆಮಾಡಿ.

5

Region ಆಯ್ಕೆ: Select Region ನಲ್ಲಿ ಸೂಕ್ತ option ಆಯ್ಕೆಮಾಡಿ (ಉದಾ: Within the School).

6

Staff ಆಯ್ಕೆ: Select Staff To Be Mapped drop-down open ಮಾಡಿ, ಆ ಪಾತ್ರಕ್ಕೆ assign ಮಾಡಬೇಕಾದ ಶಿಕ್ಷಕರ ಹೆಸರು ಆಯ್ಕೆಮಾಡಿ.

7

Update: ಬಲಭಾಗದ ನೀಲಿ Update button ಕ್ಲಿಕ್ ಮಾಡಿ — ಬದಲಾವಣೆ ಉಳಿಸಿ.

3. ಪರಿಶೀಲನೆ (Verify)

  • Save ಆದ ನಂತರ Staff Summary Report ಹಿಂತಿರುಗಿ — HoS / Asst. HoS ಹೆಸರು ಸರಿಯಾಗಿ ಕಾಣಿಸುತ್ತದೆಯೇ ನೋಡಿ.
  • HoS ಮತ್ತು Asst. HoS — ಎರಡೂ roles ನಲ್ಲಿ ಸರಿಯಾದ ವ್ಯಕ್ತಿಗಳು ಇದ್ದರೆ ಮುಂದಿನ ಹಂತ.
  • ತಪ್ಪು ಹೆಸರು ಕಾಣಿಸಿದರೆ mapping reset/re-ಸರಿಪಡಿಸಿ.

🎯 ಸರಿ: Login (Teacher Module) → Dashboard → Staff Summary Report → AHOS Details → Mapping → HoS/Asst. HoS → Region → Staff → Update. ಶಾಲಾ records ನಲ್ಲಿ HoS ಯಾರು ಎಂಬುದಕ್ಕೆ ಅನುಗುಣವಾಗಿ mapping ಮಾಡಿ.

4. ಬಹಳ ಮುಖ್ಯವಾದ ಸೂಚನೆಗಳು

ನಿಯಮವಿವರ
🔴 ಸರಿಯಾದ roleHoS ಮತ್ತು Asst. HoS — ಯಾರಿಗೆ ಯಾವ role ಎಂಬುದನ್ನು ಶಾಲಾ ವ್ಯವಸ್ಥೆಗೆ ತಕ್ಕಂತೆ ಆಯ್ಕೆಮಾಡಿ.
🔴 ಸರಿಯಾದ staffSelect Staff To Be Mapped ನಲ್ಲಿ ತಪ್ಪು ಹೆಸರು ಆಯ್ಕೆಯಾದರೆ, ತಪ್ಪು ವ್ಯಕ್ತಿಗೆ role ಸಿಗುತ್ತದೆ — ಎಚ್ಚರ.
🔴 RegionWithin the School / ಇತರೆ region option ನ ಅರ್ಥ ಸ್ಪಷ್ಟಪಡಿಸಿಕೊಳ್ಳಿ.
🔴 Update ಖಚಿತUpdate button ಕ್ಲಿಕ್ ಮಾಡಿದ ನಂತರವೇ ಬದಲಾವಣೆ ಉಳಿಯುತ್ತದೆ.
🔴 Save ಆಗಿದೆಯೇಪುಟ refresh ಮಾಡಿ ಹೆಸರು ದಾಖಲಾಗಿದೆಯೇ ಪರಿಶೀಲಿಸಿ.

5. FAQ

HoS full form ಏನು?

HoS = Head of School — ಶಾಲೆಯ ಮುಖ್ಯೋಪಾಧ್ಯಾಯ/ಮುಖ್ಯಸ್ಥ.

Asst. HoS ಎಂದರೆ?

Assistant Head of School — ಉಪ ಮುಖ್ಯೋಪಾಧ್ಯಾಯ/ಸಹಾಯಕ ಮುಖ್ಯಸ್ಥ.

Mapping button ಎಲ್ಲಿ ಸಿಗುತ್ತದೆ?

Staff Summary Report ಪುಟದ ಬಲ ಕೆಳಗಡೆ — AHOS Details ವಿಭಾಗದ ಕೆಳಗೆ ನೀಲಿ Mapping button.

ಈ ಪುಟ ಅಧಿಕೃತವೇ?

ಇಲ್ಲ — ಇದು ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ. ಅಧಿಕೃತ: udiseplus.gov.in.
