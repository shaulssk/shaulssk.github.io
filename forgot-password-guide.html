SATS · UDISE+ · ನಿರಂತರ — ಪಾಸ್ವರ್ಡ್ ಮರೆತರೆ ಹೇಗೆ?

Login Password Reset ಮಾರ್ಗದರ್ಶಿ · ಕರ್ನಾಟಕ ಶಿಕ್ಷಕರಿಗೆ · ಕೊನೆಯ ನವೀಕರಣ: 06-09-2026

ಪ್ರಶ್ನೆ ಒಂದೇ: login ಪಾಸ್ವರ್ಡ್ ಮರೆತಿದ್ದೇನೆ — ಏನು ಮಾಡಲಿ? ಶಾಲಾ ದೈನಂದಿನ ಕೆಲಸದಲ್ಲಿ SATS, UDISE+, ನಿರಂತರ ಆ್ಯಪ್‌ನಲ್ಲಿ ಇದು ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆ. ಪ್ರತಿ ವ್ಯವಸ್ಥೆಗೂ ಬೇರೆ ಬೇರೆ ಪರಿಹಾರ ವಿಧಾನ ಇದೆ — ಮೊದಲು ಯಾವ ಸಿಸ್ಟಂ, ಅದರ ವಿಧಾನ follow ಮಾಡಿ.

⚠️ ಮುಖ್ಯ ಸೂಚನೆ: ಪೋರ್ಟಲ್/ಆ್ಯಪ್‌ನಲ್ಲಿ ಮೆನು ಹೆಸರು, OTP/email ವಿಧಾನ ಬದಲಾಗಬಹುದು. ನಿಮ್ಮ DDPI / BEO (block) office ಸೂಚನೆಗಳೇ ಅಂತಿಮ. ಪಾಸ್ವರ್ಡ್, OTP, PIN ಅನ್ನು ಯಾರಲ್ಲೂ share ಮಾಡಬೇಡಿ — ಅಧಿಕಾರಿಯೆಂದು ಹೇಳಿ ಕೇಳುವವರಿಗೂ ಕೊಡಬೇಡಿ.

1. SATS — ಪಾಸ್ವರ್ಡ್ ಮರೆತರೆ

1

sts.karnataka.gov.in/SATS/main.htm?actionCode=showLoginPage open ಮಾಡಿ — login ಪುಟ ತೆರೆಯುತ್ತದೆ.

2

Password field ನ ಕೆಳಗೆ "Forgot Password? Click here" ಲಿಂಕ್ ಇರುತ್ತದೆ — ಅದನ್ನು click ಮಾಡಿ.

3

ನಿಮ್ಮ Username / registered mobile number ನಮೂದಿಸಿ — ಸಿಸ್ಟಂ ನೋಂದಾಯಿತ ಮೊಬೈಲ್‌ಗೆ OTP / reset ಲಿಂಕ್ ಕಳುಹಿಸುತ್ತದೆ.

4

OTP ನಮೂದಿಸಿ ಹೊಸ ಬಲವಾದ ಪಾಸ್ವರ್ಡ್ ಸೆಟ್ ಮಾಡಿ (ಅಕ್ಷರ+ಸಂಖ್ಯೆ+ಚಿಹ್ನೆ, ಕನಿಷ್ಠ 8).

5

Mobile OTP login ಆಯ್ಕೆಯೂ ಇದೆ ("Login with Mobile OTP") — ಅದರಿಂದ account ಒಳ ಸೇರಬಹುದು.

Office / DDPI user login: ಈ ಲಾಗಿನ್‌ನ ಪಾಸ್ವರ್ಡ್ reset ಆಗದಿದ್ದರೆ — DDPI / ಜಿಲ್ಲಾ ಸಹ ದಾಖಲೆ ಸಹಾಯಕ (SD) ಕಚೇರಿ ಸಂಪರ್ಕಿಸಿ; ಅವರು admin ಮಟ್ಟದಲ್ಲಿ reset ಮಾಡಬಹುದು.

2. ನಿರಂತರ (ನಿರಂತರ AI ಅಟೆಂಡೆನ್ಸ್ ಆ್ಯಪ್) — ಪಾಸ್ವರ್ಡ್ ಮರೆತರೆ

ನಿರಂತರ ಆ್ಯಪ್‌ನಲ್ಲಿ ಲಾಗಿನ್ ಮುಖ್ಯವಾಗಿ KGID + OTP ಮೂಲಕ. ಪಾಸ್ವರ್ಡ್/ಲಾಗಿನ್ ಸಮಸ್ಯೆ ಇದ್ದಾಗ:

  • OTP ಆಪ್ಷನ್: ಲಾಗಿನ್ ಪುಟದಲ್ಲಿ ನೋಂದಾಯಿತ ಮೊಬೈಲ್‌ಗೆ OTP ತರಿಸಿ login ಆಗಿ — ಪಾಸ್ವರ್ಡ್ ಅಗತ್ಯವಿಲ್ಲ.
  • ಆ್ಯಪ್‌ನೊಳಗಿನ Grievance: ಸಮಸ್ಯೆ ಹೋಗದಿದ್ದರೆ ಆ್ಯಪ್‌ನ Grievance/ಸಹಾಯ ಆಯ್ಕೆಯಿಂದ ದೂರು ನೀಡಿ — registration/data ಸಮಸ್ಯೆಗಳಿಗೆ ಈ ಮಾರ್ಗ ಅಧಿಕೃತ.
  • ಸರ್ಕಾರಿ ಸಹಾಯ: ಆ್ಯಪ್ helpdesk / ಜಿಲ್ಲಾ ನೋಡಲ್ ಅಧಿಕಾರಿ ಸಂಪರ್ಕಿಸಿ.

3. UDISE+ — ಪಾಸ್ವರ್ಡ್ ಮರೆತರೆ

UDISE+ ಲಾಗಿನ್ ಕ್ರೆಡೆನ್ಷಿಯಲ್ಸ್ ಶಾಲೆಗೆ ಇಲಾಖೆಯಿಂದ ನೀಡಲಾಗುತ್ತದೆ. ಮರೆತರೆ:

  • ಲಾಗಿನ್ ಪುಟದಲ್ಲಿ "Forgot Password" ಲಿಂಕ್ ಇದ್ದರೆ ಅದರ ಮೂಲಕ reset ಪ್ರಯತ್ನಿಸಿ (ನೋಂದಾಯಿತ ಮೊಬೈಲ್/email).
  • Reset ಆಗದಿದ್ದರೆ DDPI / BEO office ಸಂಪರ್ಕಿಸಿ — UDISE+ ನೋಡಲ್ ಅಧಿಕಾರಿ ಹೊಸ ಕ್ರೆಡೆನ್ಷಿಯಲ್ ನೀಡುತ್ತಾರೆ.
  • ಹೊಸ ಕ್ರೆಡೆನ್ಷಿಯಲ್ ಬಂದ ನಂತರ ಮೊದಲ ಲಾಗಿನ್‌ನಲ್ಲೇ ಪಾಸ್ವರ್ಡ್ ಬದಲಾಯಿಸಿ.

4. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು & ಪರಿಹಾರ

ಸಮಸ್ಯೆಏನು ಮಾಡಬೇಕು?
"Forgot Password" ಲಿಂಕ್ ಕಾಣುತ್ತಿಲ್ಲಅಧಿಕೃತ ಪೋರ್ಟಲ್ ಮೇಲ್ಭಾಗ/ಸೆಟ್ಟಿಂಗ್ಸ್ ನೋಡಿ; ಇಲ್ಲದಿದ್ದರೆ BEO/DDPI office ಮಾತ್ರ reset.
OTP ಬರ್ತಿಲ್ಲನೋಂದಾಯಿತ ಸಂಖ್ಯೆಯೇ ಎಂದು ಖಚಿತ ಮಾಡಿ; spam/junk check ಮಾಡಿ; ಸ್ವಲ್ಪ ಕಾಯ್ದು ಪುನಃ try ಮಾಡಿ.
ಹೊಸ ಪಾಸ್ವರ್ಡ್ ಸೆಟ್ ಆಗುವುದೇ ಇಲ್ಲಬಲವಾದ ಪಾಸ್ವರ್ಡ್ ನಿಯಮ check ಮಾಡಿ; ಬ್ರೌಸರ್ cache ಮುಚ್ಚಿ (Incognito) try ಮಾಡಿ.
ಸಿಸ್ಟಂ "ಕ್ರೆಡೆನ್ಷಿಯಲ್ ತಪ್ಪು" ಎನ್ನುತ್ತಿದೆಖಾತೆ ಸರಿಯಾಗಿ login ಆಗುತ್ತಿದೆಯೇ? Caps Lock off? ಸಮಸ್ಯೆ ಇದ್ದರೆ admin reset — ಅದೇ ಅಂತಿಮ ಪರಿಹಾರ.

5. ಪ್ರಮುಖ ಅಂಶಗಳು ⭐

  • ಪಾಸ್ವರ್ಡ್ share ಮಾಡಬೇಡಿ: ಸಹೋದ್ಯೋಗಿಗೆ ಸಹ ಸಿಸ್ಟಂಲ್ಲೇ ಹಂಚಿಕೊಳ್ಳದೆ, ಅಗತ್ಯವಿದ್ದರೆ adminನಿಂದ reset ತರಿಸಿ.
  • ಅಧಿಕೃತ ವೆಬ್‌ಸೈಟ್ ಮಾತ್ರ: URL sts.karnataka.gov.in ಆಗಿರಲಿ — ಬೇರೆ ದಾರಿ ಲಾಗಿನ್ try ಮಾಡಬೇಡಿ.
  • OTP/PIN ಯಾರಿಗೂ ಕೊಡಬೇಡಿ: ಅಧಿಕಾರಿಯೆಂದು ಹೇಳುವವರಿಗೂ — ಸರ್ಕಾರಿ ಸಿಸ್ಟಂ OTP ಕೇಳುವುದಿಲ್ಲ.
  • ದಾಖಲೆ ಇರಿಸಿ: reset ಮಾಡಿದ ದಿನಾಂಕ, ಹೊಸ ಪಾಸ್ವರ್ಡ್ (ಸುರಕ್ಷಿತ ಜಾಗದಲ್ಲಿ) note ಮಾಡಿ.
  • ಹೊಸ ಶೈಕ್ಷಣಿಕ ವರ್ಷ: ವರ್ಷ ಆರಂಭದಲ್ಲಿ ಸಿಸ್ಟಂ ಪ್ರವೇಶಗಳು ಬದಲಾಗಬಹುದು — ಸಮಯ ದೊರಕಿದಾಗಲೇ "Forgot" try ಮಾಡಿ.

6. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. ಪಾಸ್ವರ್ಡ್ reset ಮಾಡಲು ಶುಲ್ಕ ಇದೆಯೇ?

ಇಲ್ಲ — ಸರ್ಕಾರಿ ವ್ಯವಸ್ಥೆಗಳಲ್ಲಿ ಪಾಸ್ವರ್ಡ್ reset ಉಚಿತ. ಯಾರೇ ಹಣ ಕೇಳಿದರೂ ಅದು ಸರಿಯಲ್ಲ — ಆ ಅಂಶವನ್ನು ಇಲಾಖೆಗೆ ತಿಳಿಸಿ.

2. OTP ಬರಲು ಎಷ್ಟು ಸಮಯ?

ಸಾಮಾನ್ಯವಾಗಿ ಕೆಲವೇ ನಿಮಿಷಗಳು. ಬರದಿದ್ದರೆ SMS vs OTP ಬೇರೆ — registered mobile ಸಂಖ್ಯೆ ಸರಿಯಿದೆಯೇ check ಮಾಡಿ ಹಾಗೂ ನೆಟ್‌ವರ್ಕ್‌ನಲ್ಲಿ delay ಆಗಬಹುದು.

3. ಹಳೆಯ ಶಿಕ್ಷಕ ನಿವೃತ್ತಿ ಆಗಿದ್ರೆ, ಅವರ ಹೆಸರಿನ login ಏನಾಗುತ್ತೆ?

Login ಮಾಲೀಕತ್ವ ಇಲಾಖೆ ನಿಯಮಾನುಸಾರ — BEO/DDPI office ಮೂಲಕ password reset/admin ನೋಡಿಕೊಳ್ಳಿ. ಹೊಸ ಸಿಬ್ಬಂದಿಗೆ ಸರ್ಕಾರಿ ಕ್ರೆಡೆನ್ಷಿಯಲ್ ಬೇಕು.

4. SATS ನಲ್ಲಿ ಎರಡು ಮೊಬೈಲ್ ನಂಬರ್ reset?

ನೋಂದಾಯಿತ ಸಂಖ್ಯೆಯೇ ಪ್ರಧಾನ. ಬೇರೆ ಸಂಖ್ಯೆ tied ಆಗಿದ್ದರೆ admin (DDPI/SD ಸಹಾಯಕ) ಮೂಲಕ ಹೊಸ ವಿಧಾನ ತಿಳಿಯಿರಿ — ಹಳೆಯ ಸಂಖ್ಯೆ ಇಲ್ಲದಿದ್ದರೆ office ಭೇಟಿ ಅಗತ್ಯ.

5. ಬೆಳಿಗ್ಗೆ ಲಾಗಿನ್ ಆಗುತ್ತಿದೆ, ಮಧ್ಯಾಹ್ನ ಆಗ್ತಿಲ್ಲ — ಏಕೆ?

ಸರ್ವರ್ ಹೊರೆ (peak hours) ಇರಬಹುದು; ಬ್ರೌಸರ್ refresh, timeout, ಬೇರೆ browser/Chrome try ಮಾಡಿ. ಇದು ಪಾಸ್ವರ್ಡ್ ಸಮಸ್ಯೆಯಲ್ಲ — ಸಹಾಯ ಸಿಗದಿದ್ದರೆ later try.
