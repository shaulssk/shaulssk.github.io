ℹ️ ನಿರಂತರ (Nirantara — ಕೆಲವರು "Niranthara" ಎಂದೂ ಬರೆಯುತ್ತಾರೆ) is a government education app. This article is an independent guide and is not an official government page.

✅ Last verified: 09 September 2026

ℹ️ Note: Portal/app process may change according to departmental instructions. ಇಲ್ಲಿನ ಮಾಹಿತಿ ಸಾಮಾನ್ಯ ಮಾರ್ಗದರ್ಶಿ ಮಾತ್ರ — ಪ್ರಸ್ತುತ ಅಧಿಕೃತ ನಿಯಮಗಳಿಗೆ ಇಲಾಖಾ ಪರಿಚಲನೆ ಮತ್ತು ಅಧಿಕೃತ ಸೈಟ್‌ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ. ಅಧಿಕೃತ circular/portal instructions ಬದಲಾದರೆ ಅವುಗಳೇ ಅಂತಿಮ.

ನಿರಂತರ ನೋಂದಣಿ (Nirantara registration) ಎಂದರೆ ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆಯ AI ಮುಖ ಗುರುತಿಸುವಿಕೆ ಹಾಜರಾತಿ ವ್ಯವಸ್ಥೆಯಲ್ಲಿ ವಿದ್ಯಾರ್ಥಿಯನ್ನು ಸೇರಿಸುವ ಪ್ರಕ್ರಿಯೆ. 2026-27ನೇ ಶೈಕ್ಷಣಿಕ ವರ್ಷದ ಸೂಚನೆಗಳ ಪ್ರಕಾರ ಸರ್ಕಾರಿ/ಅನುದಾನಿತ ಶಾಲೆಗಳಲ್ಲಿ ಪ್ರತಿ ಹೊಸ ವಿದ್ಯಾರ್ಥಿಯನ್ನು ಮುಖದ ಫೋಟೋಗಳು ಸಹಿತ ನೋಂದಾಯಿಸಬೇಕಾಗುತ್ತದೆ (ಸಾಮಾನ್ಯವಾಗಿ ಮೂರು — ಮುಂಭಾಗ, ಎಡ, ಬಲ). ನೋಂದಣಿಯಾದರೆ ಮಾತ್ರ ಆಪ್‌ನಲ್ಲಿ AI ಹಾಜರಾತಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

🗑️ ನಿರಂತರದಲ್ಲಿ Delete ಮಾಡಬೇಕಾದ 5 ಸಂದರ್ಭ (App v1.4.2)
  1. Wrong Student Registered: ಬೇರೆ ಮಗುವಿನ ದಾಖಲೆ ತಪ್ಪಾಗಿ register ಆದರೆ.
  2. Duplicate Registration: ಒಂದೇ ಮಗುವಿಗೆ ಎರಡು ಬಾರಿ register ಆಗಿದ್ದರೆ.
  3. Incorrect Face Registration: ತಪ್ಪು/ಮಸುಕು/mismatch ಮುಖದ ಫೋಟೋ register ಆಗಿದ್ದರೆ.
  4. Ghost Registration: ಮಗು ಶಾಲೆಯಲ್ಲೇ ಇಲ್ಲದೆ/fake ID ಸಹಿತ register ಆಗಿದ್ದರೆ.
  5. TC Issued: ಮಗು ಬೇರೆ ಶಾಲೆಗೆ ವರ್ಗಾವಣೆ/TC ಪಡೆದ ನಂತರ ಈ ಶಾಲೆಯ ನೋಂದಣಿ delete.

⚠️ Delete ಆಯ್ಕೆಯ ನಿಖರ ಸ್ಥಳ/ಅನುಮತಿ ಆ್ಯಪ್ version ಮತ್ತು ಇಲಾಖಾ ಸೂಚನೆಯಂತೆ ಬದಲಾಗಬಹುದು — ಇಲಾಖಾ ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ.

1. ನಿರಂತರ ಆ್ಯಪ್ Login ವಿಧಾನ

  1. Play Store ನಲ್ಲಿ Nirantara (ನಿರಂತರ) ಆ್ಯಪ್ ಹುಡುಕಿ — ಅಧಿಕೃತ ಡೆವಲಪರ್/ಲೋಗೋ ಪರಿಶೀಲಿಸಿ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ. (ಕೇವಲ ಇಂಡೆಕ್ಸ್: Play Store ನಲ್ಲಿ ಹುಡುಕಿ)
  2. ಮೊದಲ ಬಾರಿ ತೆರೆದಾಗ ಕೇಳುವ permissions (camera/OTP) Allow ಮಾಡಿ.
  3. ಪ್ರಸ್ತುತ ವಿಧಾನದಲ್ಲಿ ಶಿಕ್ಷಕರ KGID ಸಂಖ್ಯೆ ನಮೂದಿಸಿ → ನೋಂದಾಯಿತ ಮೊಬೈಲ್‌ಗೆ ಬರುವ OTP ನಮೂದಿಸಿ → Login.
  4. Login ಆಗದಿದ್ದರೆ ಆ್ಯಪ್‌ನ Grievance ಅಥವಾ ಬ್ಲಾಕ್/ಜಿಲ್ಲಾ ಇಲಾಖೆಯನ್ನು ಸಂಪರ್ಕಿಸಿ.

📌 ಅಧಿಕೃತ ಮೂಲ: login ವಿಧಾನ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ 2026-27 ಸೂಚನೆಯಲ್ಲಿ ನಿಗದಿಪಡಿಸಲಾಗಿದೆ — ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆ ಅಧಿಕೃತ ಸೈಟ್‌ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ.

2. ಹೊಸ ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ ಮಾಡುವ ವಿಧಾನ (Student Registration)

  1. ಆ್ಯಪ್‌ನಲ್ಲಿ Register Student ಆಯ್ಕೆ ಮಾಡಿ.
  2. ತರಗತಿ (Class) ಮತ್ತು ವಿಭಾಗ (Section) ಆಯ್ಕೆ ಮಾಡಿ — SATS ಲಿಂಕ್ ಆದ ವಿದ್ಯಾರ್ಥಿಗಳ ಪಟ್ಟಿ ಬರುತ್ತದೆ.
  3. ಮಗುವಿನ ಹೆಸರಿನ ಮುಂದೆ ಇರುವ Not Registered ಆಯ್ಕೆ ಕ್ಲಿಕ್ ಮಾಡಿ.
  4. ಮಗುವಿನ ಮುಖಕ್ಕೆ ಬೆಳಕು ಸರಿಯಾಗಿ ಬೀಳುವಂತೆ ನಿಲ್ಲಿಸಿ — ಮುಂಭಾಗ (Straight), ಎಡ (Left), ಬಲ (Right) ಮೂರು ಮುಖದ ಫೋಟೋ ತೆಗೆಯಿರಿ (ಪ್ರಸ್ತುತ ಇಲಾಖಾ ಸೂಚನೆಗಳ ಪ್ರಕಾರ — ಬದಲಾವಣೆಗೆ ಪೋರ್ಟಲ್/ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ).
  5. ಮಾಹಿತಿ ಪರಿಶೀಲಿಸಿ Submit ಒತ್ತಿ — ಬಂದ ನೋಂದಣಿ ಸಂಖ್ಯೆ ದಾಖಲಿಸಿ/ಉಳಿಸಿಕೊಳ್ಳಿ.

3. ನೋಂದಣಿಗೆ ಬೇಕಾದ Details (Required Details)

Detailಏಕೆ ಬೇಕು?
KGID (ಶಿಕ್ಷಕರ ಸಂಖ್ಯೆ)Login ಗಾಗಿ — ನೋಂದಾಯಿತ ಮೊಬೈಲ್ ಜೊತೆ OTP ಬರುತ್ತದೆ.
SATS ದಾಖಲೆ/STS IDವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿ SATS ನಿಂದಲೇ ಬರುತ್ತದೆ — SATS ನಲ್ಲಿ ಹೆಸರು/ತಪ್ಪು ಇದ್ದರೆ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣಿಸುವುದಿಲ್ಲ.
ತರಗತಿ + ವಿಭಾಗಯಾವ class/section ಗೆ ಸೇರಿಸಬೇಕು ಎಂಬುದು.
3 ಮುಖದ ಫೋಟೋAI face recognition ಗಾಗಿ — Straight, Left, Right.
ನೋಂದಾಯಿತ ಮೊಬೈಲ್OTP/login ಆಗುವ phone — ಶಾಲೆಯ ಅಧಿಕೃತ ಸಂಖ್ಯೆ ಇರಲಿ.

ಪ್ರೊ ಟಿಪ್: ಪ್ರವೇಶದ ಸಮಯದಲ್ಲಿ ಮಗುವಿನ ಜನ್ಮ ದಿನಾಂಕ, ಪೋಷಕರ ಮೊಬೈಲ್ ನಂಬರ್ ಮೊದಲೇ ಸಂಗ್ರಹಿಸಿಟ್ಟರೆ ನೋಂದಣಿ ವೇಗವಾಗಿ ಆಗುತ್ತದೆ.

4. ನಿರಂತರ ಹಾಜರಾತಿ ದಾಖಲಾತಿ (Attendance)

  1. ಆ್ಯಪ್ ತೆರೆದು Attendance ವಿಭಾಗ ಆಯ್ಕೆ ಮಾಡಿ.
  2. ತರಗತಿ (1–10) + ವಿಭಾಗ ಆಯ್ಕೆ ಮಾಡಿ.
  3. AI Face Recognition ಮೂಲಕ ಹಾಜರಾತಿ ದಾಖಲಾಗುತ್ತದೆ — ಮುಖ ಸ್ಪಷ್ಟ ಕಾಣುವಂತೆ ಫೋನ್ ಹಿಡಿದುಕೊಳ್ಳಿ.
  4. ಕೈಮೇಲ್‌ ಆಗಿದ್ದರೆ Present/Absent ಆಯ್ಕೆ ಮಾಡಿ; ದಿನದ ಕೊನೆಯಲ್ಲಿ Submit/Save — ಪ್ರತಿದಿನ ಕಡ್ಡಾಯ.
  5. ರಜೆ ಇರುವ ದಿನದಲ್ಲಿ ಹಾಜರಾತಿ ನಮೂದಿಸಬೇಡಿ.

📌 ಗಮನಿಸಿ: ನೋಂದಣಿ ಆಗದ ವಿದ್ಯಾರ್ಥಿ AI ಹಾಜರಾತಿಗೆ ಸಿಗುವುದಿಲ್ಲ — ಹೊಸ ಮಗು ಶಾಲೆಗೆ ಸೇರಿದ ತಕ್ಷಣ ಮೊದಲು ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ ಮಾಡಿ. ಇದರ ಪೂರ್ಣ ಚಿತ್ರಣ: ನಿರಂತರ ಆ್ಯಪ್ ಮಾರ್ಗದರ್ಶಿ.

5. Registration Status Check

  • ಆ್ಯಪ್‌ನ Student list ನಲ್ಲಿ ಪ್ರತಿ ಮಗುವಿನ ಮುಂದೆ Registered / Not Registered ಸ್ಥಿತಿ ಕಾಣುತ್ತದೆ.
  • Registered ಎಂದು ಕಾಣಿಸಿದರೆ ನೋಂದಣಿ ಯಶಸ್ವಿ — AI ಹಾಜರಾತಿಗೆ ಸಿದ್ಧ.
  • Not Registered / Pending ಆಗಿದ್ದರೆ ಮೇಲಿನ ವಿಧಾನದಂತೆ ಪುನಃ ನೋಂದಣಿ ಪ್ರಯತ್ನಿಸಿ.
  • ನೋಂದಣಿ number ಇಟ್ಟುಕೊಳ್ಳಿ — ತಿಂಗಳಾಂತ್ಯದಲ್ಲಿ SATS ಸಂಖ್ಯೆಗಳೊಂದಿಗೆ ಹೋಲಿಕೆ ಮಾಡಿ.

6. ಸಾಮಾನ್ಯ ದೋಷಗಳು ಮತ್ತು ಪರಿಹಾರ (Common Errors)

ದೋಷಪರಿಹಾರ
"Registration is not enabled"ಆ್ಯಪ್‌ನ Grievance → Registration Issue → ವಿವರ + ಸ್ಕ್ರೀನ್‌ಶಾಟ್ Submit ಮಾಡಿ.
ವಿದ್ಯಾರ್ಥಿ ಪಟ್ಟಿ ಕಾಣುತ್ತಿಲ್ಲSATS ದತ್ತಾಂಶ ಲಿಂಕ್ ಸಮಸ್ಯೆ — Grievance → Data Issue ಜೊತೆ ಶಾಲಾ ವಿವರ ಕಳುಹಿಸಿ.
ಫೋಟೋ ಬೇರೆ ಮಗುವಿನದ್ದುGrievance → Registration Issue → ಹೆಸರು + STS ID ನೀಡಿ ಸರಿಪಡಿಸಿ.
OTP ಬರುತ್ತಿಲ್ಲKGID ಸರಿಯೆ? ನೆಟ್ವರ್ಕ್ ಪರಿಶೀಲಿಸಿ; ಕೆಲ ನಿಮಿಷ ನಂತರ ಪ್ರಯತ್ನಿಸಿ.
ಹಳೆಯ ವರ್ಷದ ಪಟ್ಟಿGrievance → Data Issue → "2026-27 ಪಟ್ಟಿ ಬೇಕು" ಎಂದು ವಿವರಿಸಿ, ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ.

ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಪದ್ಧತಿ: ಪ್ರತಿ ಸಮಸ್ಯೆಯ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ತೆಗೆದಿಡಿ — Grievance ದೂರಿಗೆ ಇದು ನಿರ್ಣಾಯಕ ಪುರಾವೆ.

7. ವಿದ್ಯಾರ್ಥಿ ವಿವರ Delete — 5 ಕಾರಣಗಳ ಅರ್ಥ (App v1.4.2)

ಆ್ಯಪ್‌ನಲ್ಲಿ ವಿದ್ಯಾರ್ಥಿ ವಿವರ delete ಮಾಡುವಾಗ ಕಾಣಿಸುವ Delete Reason ಆಯ್ಕೆಗಳ ಅರ್ಥ. v1.4.2 ಅಪ್‌ಡೇಟ್‌ನಿಂದ ಈ 5 ಕಾರಣಗಳಿಗೆ ಮಾತ್ರ ವಿದ್ಯಾರ್ಥಿಗಳನ್ನು Delete ಮಾಡಲು ಸಾಧ್ಯ (ಮುಂದಿನ ಅಪ್‌ಡೇಟ್‌ನಲ್ಲಿ ಆಯ್ಕೆಗಳು ಬದಲಾಗಬಹುದು):

Delete Reasonಯಾವಾಗ ಆರಿಸಬೇಕು?
1. Wrong student registered (ತಪ್ಪಾದ ವಿದ್ಯಾರ್ಥಿಯ ನೋಂದಣಿ)ಸರಿಯಾದ ವಿದ್ಯಾರ್ಥಿಯ ಬದಲಿಗೆ ಬೇರೆ ವಿದ್ಯಾರ್ಥಿ/ಬೇರೆ ತರಗತಿಯ ವಿದ್ಯಾರ್ಥಿಯನ್ನು ಆಕಸ್ಮಿಕವಾಗಿ ನೋಂದಾಯಿಸಿದ್ದಾಗ.
2. Duplicate registration (ಪುನರಾವರ್ತಿತ ನೋಂದಣಿ)ಒಂದೇ ವಿದ್ಯಾರ್ಥಿಯನ್ನು ಒಂದಕ್ಕಿಂತ ಹೆಚ್ಚು ಬಾರಿ ನೋಂದಾಯಿಸಿದ್ದಾಗ — ಹೆಚ್ಚುವರಿ ದಾಖಲೆ ತೆಗೆಯಲು.
3. Incorrect face registration (ತಪ್ಪಾದ ಮುಖ/ಫೋಟೋ)ಒಬ್ಬ ವಿದ್ಯಾರ್ಥಿಯ ಪ್ರೊಫೈಲ್‌ಗೆ ಮತ್ತೊಬ್ಬ ವಿದ್ಯಾರ್ಥಿಯ ಮುಖದ ಫೋಟೋ ನೋಂದಣಿಯಾಗಿದ್ದಾಗ / ಫೋಟೋ ತಪ್ಪಾಗಿ ಹೊಂದಾಣಿಕೆಯಾದಾಗ.
4. Ghost Registration (ಅಸ್ತಿತ್ವದಲ್ಲಿಲ್ಲದ/ನಕಲಿ ನೋಂದಣಿ)ಶಾಲೆಯಲ್ಲಿ ಪ್ರಸ್ತುತ ವ್ಯಾಸಂಗ ಮಾಡದಿರುವ, ಶಾಲೆ ತೊರೆದಿರುವ ಅಥವಾ ವಾಸ್ತವವಾಗಿ ಇಲ್ಲದ (ನಕಲಿ) ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರು ವ್ಯವಸ್ಥೆಯಲ್ಲಿದ್ದರೆ.
5. TC Issued (TC ನೀಡಿರುವ ವಿದ್ಯಾರ್ಥಿ)ವಿದ್ಯಾರ್ಥಿಗೆ ವರ್ಗಾವಣೆ ಪ್ರಮಾಣಪತ್ರ (Transfer Certificate) ನೀಡಿದ್ದರೆ — ಶಾಲೆ ತೊರೆದ/ಬದಲಾಯಿಸಿದ ವಿದ್ಯಾರ್ಥಿ.

📌 ಗಮನಿಸಿ: Delete ದಾಖಲೆ ನಿರ್ಣಾಯಕ ಬದಲಾವಣೆ — ಹೆಸರು/SATS ID ಪರಿಶೀಲಿಸಿ, ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಇಟ್ಟುಕೊಳ್ಳಿ; ಅನುಮಾನವಿದ್ದರೆ ಇಲಾಖಾ ನೋಡಲ್ ಅಧಿಕಾರಿ ಸಲಹೆ ಪಡೆಯಿರಿ.

8. Registration Quick Checklist

  • ☑️ School Login / KGID+OTP ಸಿದ್ಧವಿದೆಯೇ?
  • ☑️ SATS ನಲ್ಲಿ ವಿದ್ಯಾರ್ಥಿ details ಸರಿಯಾಗಿವೆಯೇ?
  • ☑️ Existing student record ಪರಿಶೀಲಿಸಿದ್ದೀರಾ? (Duplicate ಆಗಬೇಡಿ)
  • ☑️ ಹೆಸರು, ಜನ್ಮ ದಿನಾಂಕ, ತರಗತಿ, ವಿಭಾಗ ಸರಿಯಾಗಿದೆಯೇ?
  • ☑️ ಮಾಹಿತಿ ಪರಿಶೀಲಿಸಿದ್ದೀರಾ?
  • ☑️ ಅಗತ್ಯವಿರುವ ಎಲ್ಲಾ fields + 3 ಫೋಟೋ ತುಂಬಿದ್ದೀರಾ?
  • ☑️ Registration status ಪರಿಶೀಲಿಸಿದ್ದೀರಾ?

9. FAQ — ಪದೇ ಪದೇ ಕೇಳುವ ಪ್ರಶ್ನೆಗಳು

1. ನಿರಂತರ ನೋಂದಣಿ ಎಂದರೇನು?

ನಿರಂತರ (Nirantara) ಆ್ಯಪ್‌ನಲ್ಲಿ ವಿದ್ಯಾರ್ಥಿಯ ಮುಖದ ಫೋಟೋ + SATS ದಾಖಲೆ ಲಿಂಕ್ ಮಾಡಿ AI ಹಾಜರಾತಿಗೆ ಸೇರಿಸುವ ಪ್ರಕ್ರಿಯೆ. ನೋಂದಣಿ ಆದ ಮೇಲೆಯೇ ಪ್ರತಿದಿನದ AI/hand attendance ಸಾಧ್ಯ.

2. ನೋಂದಣಿ ಮಾಡಲು ಎಷ್ಟು ಫೋಟೋ ಬೇಕು?

ಸೂಚನೆಯಂತೆ ಸಾಮಾನ್ಯವಾಗಿ ಮೂರು — ಮುಂಭಾಗ, ಎಡ, ಬಲ (Straight, Left, Right). ಪ್ರತಿ ಫೋಟೋದಲ್ಲೂ ಮುಖ ಸ್ಪಷ್ಟವಾಗಿ, ಬೆಳಕು ಸರಿಯಾಗಿರಲಿ. ನಿಖರ ಅಗತ್ಯಕ್ಕೆ ಇಲಾಖಾ ಸೂಚನೆ ಪರಿಶೀಲಿಸಿ.

3. SATS ನಲ್ಲಿ ಇಲ್ಲದ ಮಗುವನ್ನು ನೋಂದಾಯಿಸಬಹುದೇ?

ಮೊದಲು SATS ನಲ್ಲಿ ವಿದ್ಯಾರ್ಥಿಯ ದಾಖಲೆ ಸರಿಯಿರಬೇಕು — ನಿರಂತರ ಪಟ್ಟಿ SATS ನಿಂದಲೇ ಬರುತ್ತದೆ. SATS ಸಮಸ್ಯೆಗೆ SATS ಮಾರ್ಗದರ್ಶಿ →.

4. Registration ಸಂಖ್ಯೆ ಎಲ್ಲಿ ಸಿಗುತ್ತದೆ?

Submit ಆದ ನಂತರ ಆ್ಯಪ್‌ನಲ್ಲೇ ಸಾಮಾನ್ಯವಾಗಿ ತೋರಿಸುತ್ತದೆ — ಉಳಿಸಿಕೊಳ್ಳಿ. ತಿಂಗಳಾಂತ್ಯ SATS vs ನಿರಂತರ ಹೋಲಿಕೆಗೆ ಈ ಸಂಖ್ಯೆ ಉಪಯುಕ್ತ.

5. ಫೋಟೋ ತೆಗೆದ ನಂತರ ಮಗು ಶಾಲೆ ಬದಲಾಯಿಸಿದರೆ?

ಹೊಸ ಶಾಲೆಯಲ್ಲಿ ಮಗು ಪುನಃ ನೋಂದಣಿ ಆಗಬೇಕು; ಹಳೆಯ ಶಾಲೆಯ HM/ಶಿಕ್ಷಕರು ಇಲಾಖಾ ವಿಧಾನದಂತೆ ಸ್ಥಳಾಂತರವನ್ನು ದಾಖಲಿಸಬೇಕು.

6. ತಪ್ಪಾಗಿ add ಆದ ವಿದ್ಯಾರ್ಥಿಯನ್ನು remove/edit ಮಾಡುವುದು ಹೇಗೆ?

Submit ಆಗುವ ಮುನ್ನ ನೋಂದಣಿ ಪುಟದಲ್ಲೇ fields edit ಮಾಡಬಹುದು. Submit ಆದ ನಂತರ remove/delete ಆಯ್ಕೆ ಸಾಮಾನ್ಯವಾಗಿ ನೇರವಾಗಿಲ್ಲ — ತಪ್ಪು/ಪುನರಾವರ್ತಿತ (duplicate) ನೋಂದಣಿಗೆ ಆ್ಯಪ್‌ನ Grievance → Registration Issue ಮೂಲಕ ಶಾಲಾ ವಿವರ + ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಜೊತೆ ದೂರು ಸಲ್ಲಿಸಿ. ಅಂತಿಮ ನಿರ್ಧಾರ ಇಲಾಖಾ ನಿಯಮಾನುಸಾರ — ಪೋರ್ಟಲ್/ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ.

7. ತಪ್ಪಾದ/ಅನಗತ್ಯ ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ Delete ಮಾಡುವುದು ಹೇಗೆ?

ತಪ್ಪಾದ ವಿದ್ಯಾರ್ಥಿ, duplicate, ತಪ್ಪಾದ ಫೋಟೋ, Ghost ಅಥವಾ TC ಇದ್ದ ವಿದ್ಯಾರ್ಥಿಯ ದಾಖಲೆಯನ್ನು Delete ಮಾಡಲು ಆ್ಯಪ್‌ನಲ್ಲೇ Delete Reason ಆಯ್ಕೆ ಇದೆ — ಮೇಲಿನ Section 7 (ವಿದ್ಯಾರ್ಥಿ ವಿವರ Delete) ನಲ್ಲಿ 5 ಕಾರಣಗಳ ಪಟ್ಟಿ ನೀಡಲಾಗಿದೆ. Delete ದಾಖಲೆ ನಿರ್ಣಾಯಕ — ಹೆಸರು/SATS ID ಪರಿಶೀಲಿಸಿ, ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಇಟ್ಟುಕೊಳ್ಳಿ; ಅನುಮಾನವಿದ್ದರೆ Grievance → Registration Issue ಮೂಲಕ ದೂರು ಸಲ್ಲಿಸಿ.
