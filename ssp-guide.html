ℹ️ Note: Deadlines, ಯೋಜನೆ ಷರತ್ತುಗಳು ಮತ್ತು portal process ಬದಲಾಗಬಹುದು — ಅರ್ಜಿಗೆ ಮುನ್ನ current ಇಲಾಖಾ ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ.

SSP (State Scholarship Portal) — ಕರ್ನಾಟಕ ಸರ್ಕಾರದ ಅಧಿಕೃತ single-window ವಿದ್ಯಾರ್ಥಿವೇತನ ಪೋರ್ಟಲ್. 13 ಇಲಾಖೆಗಳ (ಸಮಾಜ ಕಲ್ಯಾಣ, ಹಿಂದುಳಿದ ವರ್ಗ, ಬುಡಕಟ್ಟು, ಅಲ್ಪಸಂಖ್ಯಾತ, ಅಂಗವಿಕಲರ ಕಲ್ಯಾಣ ಮುಂತಾದವು) pre-matric, post-matric ಮತ್ತು fee-reimbursement ಯೋಜನೆಗಳು — ಎಲ್ಲವೂ ಒಂದೇ ಪೋರ್ಟಲ್‌ನಲ್ಲಿ. ಅನುದಾನ ನೇರವಾಗಿ Aadhaar-linked ಬ್ಯಾಂಕ್ ಖಾತೆಗೆ (DBT) ಜಮೆಯಾಗುತ್ತದೆ.

✅ ಅರ್ಜಿಗೆ ಮೊದಲು 6 ಸಿದ್ಧತೆಗಳು (Requirements): ಈ ಕೆಳಗಿನವು ಸಿದ್ಧವಾದಾಗ ಮಾತ್ರ ಅರ್ಜಿ ಪ್ರಾರಂಭಿಸಿ — ಮಧ್ಯೆ ತಡೆ ಬರುವುದಿಲ್ಲ.

  • Aadhaar-linked active ಮೊಬೈಲ್: OTP ಇದರಿಂದಲೇ ಬರುತ್ತದೆ.
  • ಬ್ಯಾಂಕ್ passbook: ಹೆಸರು + IFSC + account ಸರಿ ಹೊಂದಾಣಿಕೆ — ಅನುದಾನ (DBT) ಇಲ್ಲಿಗೇ ಬರುತ್ತದೆ.
  • Caste/income certificate: RD Number ಇರುವ ಹೊಸ ಎಲೆಕ್ಟ್ರಾನಿಕ್ ಪ್ರಮಾಣಪತ್ರ — ಹಳೆಯದು/ಆಫ್‌ಲೈನ್ ಬೇಡ.
  • NSP OTR: OBC/SC/ST ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ ಕಡ್ಡಾಯ — NSP ID ಮೊದಲೇ ತಂದಿಡಿ.
  • Pre-matric: SATS ID (ಶಾಲೆಯಿಂದ); post-matric: ಕಾಲೇಜು ದತ್ತಾಂಶ UUCMS/UNIDATA ನಲ್ಲಿ.
  • Documents ಸ್ಕ್ಯಾನ್ (PDF/JPEG, ~500KB ಒಳಗೆ): ಒಂದೇ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ready.

⚠️ ಮುಖ್ಯ ಸೂಚನೆ: ಕೆಳಗಿನ deadlineಗಳು ಜುಲೈ 2026 ಇಲಾಖೆ ಸೂಚನೆಗಳ ಆಧಾರದಲ್ಲಿವೆ; ಇಲಾಖೆಗಳು ವಿಸ್ತರಿಸಬಹುದು. ಅರ್ಜಿ ಹಾಕುವ ಮೊದಲು ssp.karnataka.gov.in ನಲ್ಲಿ current deadline ಪರಿಶೀಲಿಸಿ.

🌐 SSP Portal (Pre-Matric) 🌐 SSP Portal (Post-Matric)
👨‍🏫 SSP ಅರ್ಜಿಯಲ್ಲಿ 5 ತಪ್ಪುಗಳು
  1. Pre vs Post-matric portal: SSP pre-matric (high school) ಮತ್ತು post-matric (PUC/degree) ಬೇರೆ ಬೇರೆ — ಸರಿಯಾದ portal ಆರಿಸಿ.
  2. Bank details ತಪ್ಪು: IFSC + account number mismatch ಆದರೆ installment ತಡವಾಗುತ್ತದೆ. Passbook ಜೊತೆ ಹೋಲಿಸಿ.
  3. Income category ತಪ್ಪು: ಹೊಸ income certificate (ಸುಮಾರು ₹2.5 ಲಕ್ಷ) ಪ್ರಕಾರ category ಆರಿಸಿ — ಹಳೆಯ certificate ಬೇಡ.
  4. Doc upload size/format: Photo/signature specific KB & format ಬೇಕು — ಅರ್ಧ upload ಆದರೆ application incomplete.
  5. ಕೊನೆಯ ದಿನ submit: Server load/school closure ಆದರೆ deadline ಮಿಸ್ — 2–3 ದಿನ ಮುಂಚಿತವಾಗಿ submit ಮಾಡಿ.

1. ಯಾರಿಗೆ ಅರ್ಜಿ ಹಾಕಬಹುದು?

  • ಕರ್ನಾಟಕದ ಶಾಶ್ವತ ನಿವಾಸಿ ವಿದ್ಯಾರ್ಥಿಗಳು (recognised ಶಾಲೆ/ಕಾಲೇಜಿನಲ್ಲಿ ದಾಖಲಾತಿ)
  • SC / ST / OBC / EWS / ಅಲ್ಪಸಂಖ್ಯಾತ / BC ಮತ್ತು ಇತರ ನಿರ್ದಿಷ್ಟ ವರ್ಗದವರು
  • ಕುಟುಂಬ ವಾರ್ಷಿಕ ಆದಾಯ ಮಿತಿ — ಇಲಾಖೆ ಮತ್ತು ಯೋಜನೆಗನುಸಾರ (ಅನೇಕ post-matric SC/ST ಯೋಜನೆಗಳಿಗೆ ಸುಮಾರು ₹2.5 ಲಕ್ಷ — ಪ್ರಸ್ತುತ ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ)
  • Pre-matric ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ SATS ID ಬೇಕು; post-matric ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ ಕಾಲೇಜು ದತ್ತಾಂಶ UUCMS/UNIDATA ನಲ್ಲಿ ಇರಬೇಕು

2. 2026-27 ಅರ್ಜಿ deadlineಗಳು (ಸ್ಥೂಲ — ಪರಿಶೀಲಿಸಿ)

ಯೋಜನೆಸೂಚಿತ ಕೊನೆಯ ದಿನ

Post-Matric — ಹಿಂದುಳಿದ ವರ್ಗ / ಬುಡಕಟ್ಟು ಕಲ್ಯಾಣ31 ಆಗಸ್ಟ್ 2026 (extension ಇದೆಯೇ ಪರಿಶೀಲಿಸಿ)
Post-Matric — ಅಲ್ಪಸಂಖ್ಯಾತ ಕಲ್ಯಾಣ (Merit-cum-Means)30 ಸೆಪ್ಟೆಂಬರ್ 2026
Post-Matric — ಸಮಾಜ ಕಲ್ಯಾಣ (SC/ST)31 ಜನವರಿ 2027

3. ಮೊದಲ ಹಂತ: NSP OTR (OBC/SC/ST ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ ಕಡ್ಡಾಯ)

OBC, SC, ST ವಿದ್ಯಾರ್ಥಿಗಳು SSP ಅರ್ಜಿಗೆ ಮೊದಲು NSP (National Scholarship Portal) ನಲ್ಲಿ One-Time Registration (OTR) ಮಾಡಬೇಕು — ಅಲ್ಲಿಂದ ಬರುವ NSP ID ನಂತರ SSP ಅರ್ಜಿಯಲ್ಲಿ ಕೇಳುತ್ತಾರೆ. ಈಗಾಗಲೇ NSP ID ಇದ್ದರೆ "Know NSP ID" ಆಯ್ಕೆಯಿಂದ ತರಿಸಿ; ಮತ್ತೆ register ಬೇಡ.

4. SSP ಖಾತೆ ತೆರೆಯುವುದು (Create Account)

1

Official portal open — ssp.karnataka.gov.in (pre) ಅಥವಾ ssp.postmatric.karnataka.gov.in (post). URL ಸರಿಯಾಗಿದೆಯೇ ಖಚಿತಪಡಿಸಿ.

2

Create Account click — ಹೆಸರು, ಜನ್ಮದಿನ, ಲಿಂಗ, ಮೊಬೈಲ್, ಇಮೇಲ್ fill ಮಾಡಿ.

3

Aadhaar ನಮೂದಿಸಿ — ಹೆಸರು Aadhaar.card ನಲ್ಲೇ ಇರುವಂತೆ (school/college records ಗೆ match ಆಗಬೇಕು).

4

Aadhaar-linked ಮೊಬೈಲ್‌ಗೆ ಬರುವ OTP ನಮೂದಿಸಿ; ಬ್ಯಾಂಕ್ ಖಾತೆ link ಮಾಡಿ.

5

ಬಲವಾದ ಪಾಸ್ವರ್ಡ್ ಸೆಟ್ (8–15 ಅಕ್ಷರ: uppercase + lowercase + ಅಂಕ + ಚಿಹ್ನೆ). User ID/SSP ID SMS ನಲ್ಲಿ ಬರುತ್ತದೆ — ಉಳಿಸಿಕೊಳ್ಳಿ.

6

Pre-matric if school ವಿದ್ಯಾರ್ಥಿ — SATS ID ಸೇರಿಸಿ; ನಂತರ account activated.

5. ಅರ್ಜಿ ಸಲ್ಲಿಸುವುದು

1

SSP dashboard → Student Login (user ID + password + captcha).

2

e-KYC ಪೂರ್ಣಗೊಳಿಸಿ — Aadhaar + OTP (ಇದು ಅರ್ಜಿಗೆ ಮೊದಲ ಕಡ್ಡಾಯ ಹಂತ).

3

Apply for Scholarship → ನಿಮ್ಮ ವರ್ಗ/ವಿಷಯಕ್ಕೆ ಸರಿಯಾದ department scheme ಆಯ್ಕೆ (ಸಮೀಪದ್ದಲ್ಲ, ನಿಖರವಾದ್ದು).

4

Personal, academic, bank, income ವಿವರ fill; 10ನೇ ತರಗತಿ ವಿವರ, caste/income certificate ಯ RD Number, domicile fill.

5

Post-matric: e-Attestation — bonafide, marks card, fee receipt upload; ಕಾಲೇಜು verify ಮಾಡಿ e-attestation ID ಕೊಡುತ್ತದೆ — ಇದಕ್ಕೆ ಬೇಕಾಗುವ ಸಮಯ ಕಾಲೇಜಿನ ಪ್ರಕ್ರಿಯೆಗನುಸಾರ ಬದಲಾಗುತ್ತದೆ.

6

Documents upload (PDF/JPEG, ~500KB ಮಿತಿ) — ಅಳವಡಿಸಿ Preview ನೋಡಿ.

7

Submit — acknowledgement slip download ಮಾಡಿ. ನಂತರ ಕಾಲೇಜು/ಶಾಲಾ ಮುಖ್ಯಸ್ಥರಿಗೆ approve ಮಾಡಲು ನೆನಪಿಸಿ.

6. ಸ್ಥಿತಿ ಪರಿಶೀಲನೆ (Status)

  • Pre-Matric: status ಪೋರ್ಟಲ್ → "Know Pre-Matric Scholarship Status" → SATS ID + ಹಣಕಾಸು ವರ್ಷ → Search.
  • Post-Matric: SSP dashboard → Track Scholarship Status / Year Wise Student Status — institution verification → department approval → payment.

7. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು & ಪರಿಹಾರ

ಸಮಸ್ಯೆಪರಿಹಾರ
ಹೆಸರು mismatch (Aadhaar vs school records)ಜೋಡಿಸಿಕೊಳ್ಳಿ — ಹೆಸರು ನಿಖರವಾಗಿ ಹೊಂದಿಕೊಳ್ಳದಿದ್ದರೆ reject ಆಗುತ್ತದೆ. School records apply ಸಮಯದಲ್ಲೇ correct ಇರಲಿ.
Income/caste certificate ನಲ್ಲಿ RD Number ಇಲ್ಲಸರಿಯಾದ ಕಚೇರಿಯಿಂದ RD Number ಇರುವ ಹೊಸ ಪ್ರಮಾಣಪತ್ರ ತರಿಸಿ.
OTP ಬರ್ತಿಲ್ಲAadhaar-linked ಮೊಬೈಲ್ active ಇದೆಯೇ; network ಇದೆಯೇ; ಕೆಲವು ನಿಮಿಷ ಕಾಯ್ದು retry.
ಫೈಲ್ upload ಆಗ್ತಿಲ್ಲPDF/JPEG, ~500KB ಒಳಗೆ ಇರಲಿ — size ಕಡಿಮೆ ಮಾಡಿ (ಸ್ಕ್ಯಾನ್ quality reduce).
Login ಆಗ್ತಿಲ್ಲ / ID ಮರೆತೆ"Know Your Student ID / Forgot Password" — Aadhaar ಮೂಲಕ; duplicate ಖಾತೆ create ಮಾಡಬೇಡಿ (ಮತ್ತಷ್ಟು delay).
ಕಾಲೇಜು approve ಮಾಡುತ್ತಿಲ್ಲಅರ್ಜಿ software submit ಆಗಿರಬೇಕು; principal/ಕಾಲೇಜು admin login ನಲ್ಲಿ approve/pending ಇದೆ — ನೆನಪಿಸಿ.

8. ಕಾರ್ಯ ಉದಾಹರಣೆ — ಹಂತ ಹಂತ (Worked Example)

ಉದಾಹರಣೆ 1 — 9ನೇ ತರಗತಿ, Pre-Matric (SC ಹುಡುಗಿ):

  1. ರಮ್ಯಾ (9ನೇ ತರಗತಿ, SC) ಶಾಲೆಯಿಂದ SATS ID ಪಡೆಯುತ್ತಾಳೆ.
  2. NSP ನಲ್ಲಿ OTR — NSP ID ತಂದು ಇಡುತ್ತಾಳೆ (ಈಗಾಗಲೇ ಇದ್ದರೆ "Know NSP ID").
  3. ssp.karnataka.gov.in ನಲ್ಲಿ Create Account → OTP → bank link → activate.
  4. e-KYC complete → "Pre-Matric (SC)" scheme ಆಯ್ಕೆ.
  5. ಅರ್ಜಿ fill: SATS ID, caste RD Number, income certificate, domicile, bank.
  6. Documents upload → Preview → Submit → acknowledgement slip save.
  7. ಶಾಲಾ ಮುಖ್ಯಸ್ಥರಿಗೆ approve ಮಾಡಲು ನೆನಪಿಸುತ್ತಾಳೆ — ಅರ್ಜಿ ಶಾಲಾ ಪರಿಶೀಲನೆಗೆ ಹೋಗುತ್ತದೆ.

ಫಲಿತಾಂಶ: ಇಲಾಖಾ ನಿರ್ಣಯದಂತೆ pre-matric stipend DBT ಮೂಲಕ ಬ್ಯಾಂಕ್‌ಗೆ. (ಮೊತ್ತ ಇಲಾಖಾ ಯೋಜನೆ ನಿಗದಿಯಂತೆ ಬದಲಾಗುತ್ತದೆ.)

ಉದಾಹರಣೆ 2 — PUC/degree, Post-Matric:

  1. ಅರ್ಜಿ submit → e-Attestation: bonafide + marks card + fee receipt upload.
  2. ಕಾಲೇಜು e-attestation verify → e-Attestation ID ಸಿಗುತ್ತದೆ.
  3. ಇಲಾಖೆ ಅನುಮೋದನೆ → status "Approved" → DBT ಬ್ಯಾಂಕ್‌ಗೆ.

ಸಲಹೆ: status ನಲ್ಲಿ "Institution Not Verified" ಕಂಡರೆ — ಕಾಲೇಜು ವಿದ್ಯಾರ್ಥಿ ವಿಭಾಗದಲ್ಲಿ attestation portion ಸ್ಥಿತಿ ಪ್ರಶ್ನಿಸಿ; ಅದು ಮುಗಿಯುವವರೆಗೂ ಮುಂದಿನ ಹಂತ ನಡೆಯುವುದಿಲ್ಲ.

10. ಪ್ರಮುಖ ಅಂಶಗಳು ⭐

  • ಎಡೆಮಾಡದೆ ಒತ್ತಡ: deadline ಮುಗಿಯಲು ಒಂದು ವಾರ ಮೊದಲೇ submit — portal traffic spike ಆಗುತ್ತದೆ.
  • ನಕಲಿ site back off: ssp.karnataka.gov.in / ssp.postmatric.karnataka.gov.in ಮಾತ್ರ official — lookalike sites ಜಾಗ್ರತೆ.
  • DBT: ಹಣ Aadhaar-linked active ಬ್ಯಾಂಕ್ ಖಾತೆಗೆ ಮಾತ್ರ — account inactive ಆಗಿದ್ದರೆ payment fail.
  • KUTUMBA: ಕೆಲವು ಇಲಾಖೆ ಯೋಜನೆಗಳಿಗೆ KUTUMBA portal registration / ID ಬೇಕಾಗಬಹುದು — scheme ವಿವರ ನೋಡಿ.
  • ಎಲ್ಲೂ ಹಣ ಕೊಡಬೇಡಿ: ವಿದ್ಯಾರ್ಥಿವೇತನ ಅರ್ಜಿ free — ಯಾರೂ commission ಕೇಳಿದರೆ ತಗುಲಿಸಬೇಡಿ.

11. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. SSP ಅರ್ಜಿಗೆ ಶುಲ್ಕವಿದೆಯೇ?

ಇಲ್ಲ. ಅರ್ಜಿ, e-KYC, submit — ಎಲ್ಲಾ ಉಚಿತ. ಏಜೆಂಟ್/ಕಮಿಷನ್ ಕೇಳಿದರೆ ಅದು ಸುಳ್ಳು.

2. ಹಿಂದಿನ ವರ್ಷ apply ಮಾಡಿದ್ದರೆ — SSP ID ಇದೆ, ಏನು ಮಾಡಬೇಕು?

ಹೊಸ account ಬೇಡ — ಅದೇ SSP ID/password ನಿಂದ login ಆಗಿ renewal/ಹೊಸ year application submit ಮಾಡಿ. NSP ID ಇದ್ದರೆ "Know NSP ID" ಬಳಸಿ.

3. SATS ID ಇಲ್ಲದೆ apply ಆಗುತ್ತದೆಯೇ?

Pre-matric (1–10) ಅರ್ಜಿಗೆ SATS ID ಸಾಮಾನ್ಯವಾಗಿ ಕಡ್ಡಾಯ — ಶಾಲೆಯಿಂದ SATS ID ಪಡೆದುಕೊಳ್ಳಿ. Post-matric ಕಾಲೇಜು ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ SATS ID ಅಗತ್ಯವಿಲ್ಲದ್ದು ಸಾಮಾನ್ಯ.

4. ಡಾಕ್ಯುಮೆಂಟ್ rejection ಆಯ್ತು — ಮತ್ತೆ apply ಮಾಡಬೇಕಾ?

ಸಾಮಾನ್ಯವಾಗಿ correction/resubmission ಆಯ್ಕೆ ಇರುತ್ತದೆ. ಏನು ಕೊರತೆ ಎಂದು status ನಲ್ಲಿ ನೋಡಿ, ಸರಿಪಡಿಸಿ resubmit — ಹೊಸದಾಗಿ ಮತ್ತೆ ಅರ್ಜಿ ಬೇಡ.

5. ಹಣ ಸಿಗಲು ಎಷ್ಟು ದಿನ?

e-Attestation, ಇಲಾಖೆ approval, DBT process — ಸಾಮಾನ್ಯವಾಗಿ ವಾರಗಳಿಂದ ತಿಂಗಳುಗಳು; ಇಲಾಖೆ/ವಿತ್ತೀಯ ಪ್ರಕ್ರಿಯೆಯನ್ನು ಅವಲಂಬಿಸಿದೆ. Status dashboard ನಲ್ಲಿ track ಮಾಡಿ; ತಡವಾದರೆ ಕಾಲೇಜು/ಇಲಾಖೆ ಸಂಪರ್ಕಿಸಿ.

6. RD Number ಎಂದರೇನು — ಅದು ಇಲ್ಲದಿದ್ದರೆ?

RD Number ಹೊಸ ಎಲೆಕ್ಟ್ರಾನಿಕ್ caste/income certificate ನಲ್ಲಿರುವ ದಾಖಲೆ ಸಂಖ್ಯೆ. ಹಳೆಯ/ಆಫ್‌ಲೈನ್ ಪ್ರಮಾಣಪತ್ರ ಅಥವಾ RD ಇಲ್ಲದ ಪತ್ರವನ್ನು SSP ಅರ್ಜಿಗೆ ಸ್ವೀಕರಿಸಲಾಗದ ಸಾಧ್ಯತೆ ಇದೆ — ಸಂಬಂಧಿತ ಕಚೇರಿ/ಜನಸೇವಾ ಕೇಂದ್ರದಿಂದ RD ಇರುವ ಹೊಸ ಪ್ರಮಾಣಪತ್ರ ತರಿಸಿ.

7. e-Attestation ಮಾಡದಿದ್ದರೆ ಏನಾಗುತ್ತದೆ?

Post-matric ಅರ್ಜಿಯಲ್ಲಿ e-Attestation (ಕಾಲೇಜು verify + ID) ಪೂರ್ಣವಾಗುವವರೆಗೆ ಮುಂದಿನ ಇಲಾಖಾ ಹಂತಕ್ಕೆ ಹೋಗುವುದಿಲ್ಲ. ಕಾಲೇಜು ಮುಂದೂಡಬಹುದು ಆದರೆ ಅದು ಇಲ್ಲದೆ ಅನುಮೋದನೆ/ಪಾವತಿ ಆಗುವ ನಿರೀಕ್ಷೆ ಬೇಡ — ಬೇಗ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ, ಕಾಲೇಜಿಗೆ verify ಮಾಡಲು ನೆನಪಿಸಿ.

8. ಸರಿಯಾದ scheme ಯಾವುದು ಎಂದು ಗೊತ್ತಾಗುತ್ತಿಲ್ಲ — ಹೇಗೆ ಆಯ್ಕೆ?

ನಿಮ್ಮ ವರ್ಗ (SC/ST/OBC/EWS/ಅಲ್ಪಸಂಖ್ಯಾತ), ಕೋರ್ಸ್ (pre/post-matric) ಮತ್ತು ಇಲಾಖೆಯ ಆಧಾರದಲ್ಲಿ scheme ಆಯ್ಕೆಯಾಗುತ್ತದೆ. SSP dashboard ನಲ್ಲಿ ನಿಮ್ಮ ವಿವರಕ್ಕೆ ತಕ್ಕ scheme ಗಳ ಪಟ್ಟಿ ತೋರಿಸಲಾಗುತ್ತದೆ. ಯಾವುದು ಅನ್ವಯವಾಗುತ್ತದೆ ಎಂಬ ಖಚಿತ ಮಾಹಿತಿಗೆ ಕಾಲೇಜು/ಶಾಲಾ ವಿದ್ಯಾರ್ಥಿ ವಿಭಾಗ ಅಥವಾ ಇಲಾಖೆ ಕಚೇರಿ ಕೇಳಿ — "ಸಮೀಪದ್ದು" ಅಲ್ಲ, ನಿಖರವಾದ್ದು ಆಯ್ಕೆ ಮಾಡಿ.
