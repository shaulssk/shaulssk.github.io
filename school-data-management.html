ಶಾಲಾ ದತ್ತಾಂಶ ನಿರ್ವಹಣೆ (School Data Management)

ಕರ್ನಾಟಕ ಶಾಲಾ ಸಿಬ್ಬಂದಿಗೆ · SATS + UDISE+ + ನಿರಂತರ ಸಮನ್ವಯ · ಕೊನೆಯ ನವೀಕರಣ: 06-09-2026

ಕೊನೆಯ ನವೀಕರಣ / Last updated: 06-09-2026

ಶಾಲಾ ದತ್ತಾಂಶ ನಿರ್ವಹಣೆ ಎಂದರೆ ವಿದ್ಯಾರ್ಥಿಗಳ ಬಗ್ಗೆ ಇರುವ ಪ್ರತಿ ಮಾಹಿತಿ — ಪ್ರವೇಶ, ಹಾಜರಾತಿ, ಗ್ರೇಡ್, ಫೋಟೋ, TC, ಪೋಷಕರ ವಿವರ — ಅದನ್ನು ನಿಖರವಾಗಿ, ಒಂದೇ ಸ್ಥಳದಲ್ಲಿ, ನಿಯಮಿತವಾಗಿ ನವೀಕರಿಸಿಡುವುದು. ಕರ್ನಾಟಕದಲ್ಲಿ ಇದು SATS, UDISE+, ನಿರಂತರ ಎಂಬ ಮೂರು ವ್ಯವಸ್ಥೆಗಳಲ್ಲಿ ಸಾಗುತ್ತದೆ. ಈ ಮೂರೂ ಒಂದೇ ರೀತಿ, ಒಂದೇ ಸಮಯಕ್ಕೆ ಸರಿಯಾಗಿ ಇದ್ದರೆ ಮಾತ್ರ ಶಾಲೆಗೆ ಬರುವ ಅನುದಾನ, ಸ್ಕಾಲರ್ಶಿಪ್, ಪಠ್ಯಪುಸ್ತಕ, ಮಿಡ್-ಡೇ ಮೀಲ್ ಎಲ್ಲಾ ಸರಾಗ.

⚠️ ಗಮನಿಸಿ: ಈ ಮಾರ್ಗದರ್ಶಿ ಸಾಮಾನ್ಯ ಉತ್ತಮ ಅಭ್ಯಾಸ (best practice) ಮತ್ತು ನಮ್ಮ ಕನ್ನಡ ವಿವರಣೆ — ಇದು ಸರ್ಕಾರಿ ನಿಯಮಾವಳಿ ಅಲ್ಲ. ಪ್ರತಿ ವ್ಯವಸ್ಥೆಯ ಅಧಿಕೃತ ಮೆನು/ಕೊನೆ ದಿನಾಂಕ ನಿಮ್ಮ BEO/DDPI ಪರಿಚಲನೆಗೆ ಅನುಸರಿಸಿ ಬದಲಾಗಬಹುದು.

🗄️ UDISE+ ಪೂರ್ಣ ಮಾರ್ಗದರ್ಶಿ 🌐 SATS ಮಾರ್ಗದರ್ಶಿ 📱 ನಿರಂತರ ಆ್ಯಪ್

1. ಮೂರು ವ್ಯವಸ್ಥೆಗಳು — ಯಾವುದು ಏನು?

ವ್ಯವಸ್ಥೆಯಾವುದಕ್ಕೆಯಾರು ನಮೂದಿಸುವುದು
SATS (sts.karnataka.gov.in)ವಿದ್ಯಾರ್ಥಿ ದಾಖಲಾತಿ, TC, CCE ಗ್ರೇಡ್, ಪ್ರಮಾಣಪತ್ರ, ಶಾಲಾ ವರದಿಶಾಲೆ / DDPI ಅನುಮೋದನೆ ಇರುವ ಮುಖ್ಯ ಶಿಕ್ಷಕ
UDISE+ (udiseplus.gov.in / SDMS)ರಾಷ್ಟ್ರೀಯ ಶಾಲಾ ದತ್ತಾಂಶ, ಅನುದಾನ ಲೆಕ್ಕಡೇಟಾ ಆಪರೇಟರ್ / ಶಾಲೆ, ನಂತರ BEO certify+freeze
ನಿರಂತರ (ಮೊಬೈಲ್ ಆ್ಯಪ್)ದೈನಂದಿನ AI ಹಾಜರಾತಿ, ತ್ವರಿತ ನೋಂದಣಿಶಿಕ್ಷಕ / HM

2. ಪ್ರವೇಶ ದಾಖಲೆ (Admission Record) — ಮೊದಲ ಹೆಜ್ಜೆ

1

ಮಗು ಶಾಲೆಗೆ ಬಂದ ದಿನವೇ ಪ್ರವೇಶ ದಾಖಲೆ ಮಾಡಿ — ಜನ್ಮ ದಾಖಲೆ/ಆಧಾರ/ಪೋಷಕರ ವಿವರ ಕೇಳಿ.

2

ಹೆಸರಿನ ಕಾಗುಣಿತ (spelling) ಒಂದೇ ರೀತಿ ಇರಲಿ — ಜನ್ಮ ದಾಖಲೆಯಂತೆಯೇ ಬರೆಯಿರಿ. ವ್ಯತ್ಯಾಸವೇ ದೊಡ್ಡ ತಲೆನೋವಿನ ಮೂಲ.

3

ಪ್ರವೇಶವನ್ನು SATS ನಲ್ಲಿ ದಾಖಲಿಸಿ → SATS ID generate ಆಗುತ್ತದೆ.

4

ಅದೇ ವಿದ್ಯಾರ್ಥಿಯನ್ನು ನಿರಂತರ ಆ್ಯಪ್‌ನಲ್ಲಿ ನೋಂದಾಯಿಸಿ (ಫೋಟೋ + ವಿವರ) — SATS ID ಮತ್ತು ನಿರಂತರ ನೋಂದಣಿ ಸಂಖ್ಯೆ ಒಂದಕ್ಕೊಂದು ಹೊಂದಿಕೆಯಾಗಬೇಕು.

5

ಹೊಸ ವರ್ಷ ಪ್ರಾರಂಭದಲ್ಲಿ UDISE+ SDMS ನಲ್ಲಿ ಹೊಸ ಪ್ರವೇಶ + progression ಸರಣಿ ನಮೂದಿಸಿ.

3. ಕಾಗುಣಿತ ಮತ್ತು ಫೋಟೋ — ಯಾಕೆ ಮುಖ್ಯ?

  • ಒಂದೇ ಮಗು ಎರಡು ಸ್ಪೆಲ್ಲಿಂಗ್‌ನಲ್ಲಿ ಇದ್ದರೆ: SATS ನಲ್ಲಿ "Kiran", UDISE+ ನಲ್ಲಿ "Kiran Kumar" ಇದ್ದರೆ — ಅನುದಾನ/ಸ್ಕಾಲರ್ಶಿಪ್ ಲೆಕ್ಕದಲ್ಲಿ ಮಗು ನಷ್ಟವಾಗಬಹುದು.
  • ಫೋಟೋ ತಪ್ಪಾಗಿ ಅಪ್‌ಲೋಡ್ ಆದರೆ: ದೈನಂದಿನ AI ಹಾಜರಾತಿ ತಪ್ಪಾಗಿ ಗುರುತಿಸುತ್ತದೆ. ಫೋಟೋ ಬೇರೆ ಮಗುವಿನದ್ದಾದರೆ ನೋಂದಣಿ ತಡೆ ಹಿಡಿಯಲಾಗುತ್ತದೆ.
  • ಪರಿಹಾರ: ವರ್ಷಕ್ಕೆ ಒಮ್ಮೆಯಾದರೂ ಮಗುವಿನ ಪಟ್ಟಿಯನ್ನೇ ಇಳಿಸಿ (export) ಎಲ್ಲಾ ಕಾಗುಣಿತ + ಫೋಟೋ ಹೋಲಿಸಿ.

4. SATS vs UDISE+ ಸಮನ್ವಯ (ಏನು ಹೊಂದಿಕೆಯಾಗಬೇಕು?)

SATS ರಾಜ್ಯ ಮಟ್ಟ, UDISE+ ರಾಷ್ಟ್ರ ಮಟ್ಟ — ಸ್ವತಂತ್ರ ವ್ಯವಸ್ಥೆಗಳು. ಆದರೆ ಇವು ಒಂದೇ ಶಾಲೆಯನ್ನು ಉಲ್ಲೇಖಿಸುತ್ತವೆ:

ಅಂಶSATSUDISE+ (SDMS)
ವಿದ್ಯಾರ್ಥಿ ಸಂಖ್ಯೆSATS ID (9 ಅಂಕಿ ಟ್ರ್ಯಾಕಿಂಗ್ ಕೋಡ್)PEN / UDISE+ code (11 ಅಂಕಿ)
ವ್ಯಾಪ್ತಿಕರ್ನಾಟಕ ಮಾತ್ರಇಡೀ ದೇಶ
ದಾಖಲಾತಿ ಲೆಕ್ಕಶಾಲಾ ವರದಿಅನುದಾನ / Samagra / RTE ಲೆಕ್ಕ

ಎರಡರಲ್ಲೂ ಒಟ್ಟು ಮಕ್ಕಳ ಸಂಖ್ಯೆ ಹೊಂದಿಕೆಯಾಗಬೇಕು — ತಿಂಗಳ ಅಂತ್ಯದಲ್ಲಿ SATS ಮತ್ತು UDISE+ ಲೆಕ್ಕ ಹೋಲಿಸಿ. ವ್ಯತ್ಯಾಸ ಇದ್ದರೆ ಕಾರಣ ಪಟ್ಟಿ ಮಾಡಿ (vistara: SATS vs ನಿರಂತರ ವ್ಯತ್ಯಾಸ).

5. UDISE+ ಕಾಲಮ್ಗಳನ್ನು ಪೂರ್ತಿ ಮಾಡಿ

ಖಾಲಿ ಬಿಟ್ಟ ಕಾಲಮ್ (column) ಅರ್ಥ — ಆ ಭಾಗಕ್ಕೆ ಅನುದಾನ ತಡೆ. ಈ ಕ್ರಮ ವಿಶೇಷವಾಗಿ ಗಮನಿಸಿ:

  • Progression (ಹಿಂದಿನ ವರ್ಷದ ಮಕ್ಕಳನ್ನು ಮುಂದಿನ ತರಗತಿಗೆ ಸರಿಸಿ)
  • New Admission (ಹೊಸದಾಗಿ ಸೇರಿದ ಮಕ್ಕಳು)
  • APAAR ID (2026-27 ರಿಂದ ಕಡ್ಡಾಯ — ಒಂದೇ ವಿದ್ಯಾರ್ಥಿಗೆ ಒಂದೇ APAAR)
  • CWSN (ವಿಶೇಷ ಅಗತ್ಯದ ಮಕ್ಕಳು — ಶೇಕಡಾ ಲೆಕ್ಕ)
  • Validate → Certify → Freeze (ಕೊನೆಯ ಹಂತ — freeze ಆದ ಮೇಲೆ ಬದಲಾಯಿಸಲು ಆಗುವುದಿಲ್ಲ)

✅ ನೆನಪಿಡಿ: Reference Date — 30 ಸೆಪ್ಟೆಂಬರ್ 2026 ಆಗಿದ್ದರೆ, freeze ಮಿಸ್ ಮಾಡಿದರೆ ಶಾಲೆಗೆ ಅನುದಾನ ಶೂನ್ಯವಾಗಬಹುದು. ಪೂರ್ಣ ವಿವರ: UDISE+ ಪೂರ್ಣ ಮಾರ್ಗದರ್ಶಿ.

6. ದತ್ತಾಂಶ ಆಪರೇಟರ್ — ರೋಲ್ ಮತ್ತು ಜವಾಬ್ದಾರಿ

1

ಯಾರು data entry ಮಾಡುತ್ತಾರೋ ಅವರೇ ಅಂತಿಮ ಜವಾಬ್ದಾರಿ — ಲಾಗಿನ್ ಹಂಚಿಕೊಳ್ಳಬೇಡಿ.

2

ಎಲ್ಲಾ ದಾಖಲೆಗಳನ್ನು ನಮೂದಿಸಿದ ಮೇಲೆ ಎರಡನೇ ವ್ಯಕ್ತಿ (HM) ಪರಿಶೀಲಿಸಿ — "ಆಮೇಲೆ ಸರಿಪಡಿಸುತ್ತೇನೆ" ಬೇಡ.

3

ಸ್ಕ್ರೀನ್‌ಶಾಟ್ + ದಿನಾಂಕ ದಾಖಲೆ (evidence) ಇಡಿ — ವಿವಾದ ಬಂದರೆ ಸಾಕ್ಷ್ಯ.

4

ಪ್ರಮುಖ ಕೆಲಸವನ್ನು ಬ್ಯಾಕಪ್ ಮಾಡಿ — ಹೊರಗೆ export, ತಿಂಗಳಿಗೆ ಒಮ್ಮೆ.

7. deadline ಕ್ಯಾಲೆಂಡರ್

ಕೆಲಸಅಂದಾಜು ಕೊನೆ (ನಿಮ್ಮ BEO ಸೂಚನೆಗೆ ಹೊಂದಿಸಿ)
ನಿರಂತರ / SATS ಹೊಸ ನೋಂದಣಿಹೊಸ ವರ್ಷ ಆರಂಭದಲ್ಲಿ (ಸಾಮಾನ್ಯವಾಗಿ ಜೂನ್–ಜುಲೈ)
UDISE+ SDMS data entry + certify30 ಸೆಪ್ಟೆಂಬರ್ 2026 (Reference Date)
ಮಾಸಿಕ ಹಾಜರಾತಿ / ಶಾಲಾ ವರದಿಪ್ರತಿ ತಿಂಗಳ ಕೊನೆ

8. ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು & ಪರಿಹಾರ

ತಪ್ಪುಪರಿಣಾಮಪರಿಹಾರ
ಹೆಸರಿನ ಸ್ಪೆಲ್ಲಿಂಗ್ ವ್ಯತ್ಯಾಸಮಗು ಲೆಕ್ಕದಿಂದ ಬಿಟ್ಟುಹೋಗುತ್ತದೆಜನ್ಮ ದಾಖಲೆ ಆಧಾರ editor ಅಂದೇ ಸರಿಪಡಿಸಿ
ಡಬಲ್ ನೋಂದಣಿ (ಒಂದೇ ಮಗು ಎರಡು)ಅನುದಾನ ಲೆಕ್ಕ ತಪ್ಪುಹೆಸರು+ಜನ್ಮ ದಾಖಲೆ ಹೋಲಿಸಿ ಒಂದು ತೆಗೆಯಿರಿ
ಫೋಟೋ ಬೇರೆ ಮಗುವಿನದ್ದುAI ಹಾಜರಾತಿ ತಪ್ಪುGrievance ಎ ಮೂಲಕ ಸರಿಪಡಿಸಿ
ಖಾಲಿ ಕಾಲಮ್ ಬಿಟ್ಟಿದ್ದುಆ ಭಾಗ ಅನುದಾನ ಕಡಿತಎಲ್ಲಾ ಕಾಲಮ್; fill before freeze
Freeze ಮಿಸ್ಅನುದಾನ ಶೂನ್ಯdeadlineಗೆ ಮುಂಚೆ prepare + submit

9. ಪ್ರಮುಖ ಅಂಶಗಳು ⭐

  • ಒಂದು ಮಗು = ಒಂದೇ ID ಎಲ್ಲಾ ವ್ಯವಸ್ಥೆಯಲ್ಲಿ.
  • ಸ್ಪೆಲ್ಲಿಂಗ್ + ಫೋಟೋ ಎರಡೂ ಒಂದೇ — ಅನುದಾನ ಮತ್ತು AI ಹಾಜರಾತಿ ಇದನ್ನೇ ಅವಲಂಬಿಸಿವೆ.
  • ತಿಂಗಳಿಗೆ ಒಮ್ಮೆ export + ಹೋಲಿಕೆ SATS vs UDISE+.
  • Freeze ಮಿಸ್ ಬೇಡ — 30 ಸೆಪ್ಟೆಂಬರ್ ನಿಯಮಿತವಾಗಿ ನೆನಪಿಸಿ.
  • ದಾಖಲೆ/ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಇಡಿರಿ — ಸಾಕ್ಷ್ಯ ಯಾವಾಗಲೂ ಬೇಕಾಗುತ್ತದೆ.

10. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. SATS, UDISE+ ಎರಡರಲ್ಲೂ ಒಂದೇ ಮಗು ಬೇರೆ ಬೇರೆ ಸಂಖ್ಯೆಯಲ್ಲಿ — ಸರಿಯೇ?

ಇದು ಸಾಮಾನ್ಯ — SATS ID (ಕರ್ನಾಟಕ) ಮತ್ತು UDISE+/PEN code (ರಾಷ್ಟ್ರ) ಬೇರೆ ವ್ಯವಸ್ಥೆ. ಮುಖ್ಯವಾಗಿ ಒಟ್ಟು ಮಕ್ಕಳ ಸಂಖ್ಯೆ ಎರಡರಲ್ಲೂ ಹೊಂದಿಕೆಯಾಗಬೇಕು. ಒಂದೇ ವ್ಯವಸ್ಥೆಯೊಳಗೆ ASPA ವಿದ್ಯಾರ್ಥಿಗೆ ಎರಡು ID ಇದ್ದರೆ ಮಾತ್ರ ಸಮಸ್ಯೆ.

2. ಮಗು ಶಾಲೆ ಬಿಟ್ಟು ಹೋದರೆ ಏನು ಮಾಡಬೇಕು?

TC ನೀಡಿ SATS ನಲ್ಲಿ ವಿದ್ಯಾರ್ಥಿಯನ್ನು abolish/transfer ಮಾಡಿ; UDISE+ ನಲ್ಲಿ ಎಷ್ಟು ಬಿಟ್ಟುಹೋಯಿತು ಎಂದು ದಾಖಲಿಸಿ. ಬೇರೆ ಶಾಲೆಗೆ ಹೋದರೆ ಹೊಸ ಶಾಲೆ SATS ID ಪುನಃ ಬಳಸುತ್ತದೆ.

3. ಡೇಟಾ ತಪ್ಪಿದರೆ freeze ನಂತರ ಸರಿಪಡಿಸಬಹುದೇ?

Freeze ಆದ ನಂತರ ಸಾಮಾನ್ಯವಾಗಿ ಹೊಸ ಸುತ್ತಿನವರೆಗೆ ಬದಲಾವಣೆ ಆಗುವುದಿಲ್ಲ — ಆದರೆ ದೊಡ್ಡ ತಪ್ಪಿದ್ದರೆ DDPI/BEO ಮೂಲಕ ಸಂಪರ್ಕಿಸಿ. ಹೀಗಾಗಿ freeze ಮೊದಲೇ ಎಚ್ಚರಿಕೆಯಿಂದ fill ಮಾಡಿ.

4. ಲಾಗಿನ್ ಮರೆತರೆ?

SATS: password reset/ forgot ಆಯ್ಕೆ ಅಥವಾ BEO office reset. UDISE+: Block MIS coordinator/helpdesk. ನಿರಂತರ: ಆ್ಯಪ್‌ನ Grievance. ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಇಡಿ.

5. ಒಬ್ಬಕ್ಕೇ data entry ಸಾಧ್ಯವಿಲ್ಲ — ಯಾರು ಬೇರೆ?

ಇಲಾಖೆ ನೀಡುವ data operator role ಇದ್ದರೆ ಆ ವ್ಯಕ್ತಿ; ಇಲ್ಲದಿದ್ದರೆ HM ಅನುಮತಿ ಇರುವ ನೋಡಲ್ ಶಿಕ್ಷಕ. ಲಾಗಿನ್ ಹಂಚಿಕೊಳ್ಳಬೇಡಿ — ನೀವೇ operator ನೋಂದಾಯಿಸಿದರೆ.
