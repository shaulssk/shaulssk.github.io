SATS Report Card — ಡೌನ್‌ಲೋಡ್, ಪ್ರಿಂಟ್ & ಸಮಸ್ಯೆಗಳು

School Report Card & Student Report ಮಾರ್ಗದರ್ಶಿ · ಕರ್ನಾಟಕ · ಕೊನೆಯ ನವೀಕರಣ: 06-09-2026

ಕೊನೆಯ ನವೀಕರಣ / Last updated: 06-09-2026

SATS (Student Achievement Tracking System) ನಲ್ಲಿ ಎರಡು ರೀತಿಯ ರಿಪೋರ್ಟ್ ಇದೆ: School Report Card (ಶಾಲಾ ಸಮಗ್ರ ದತ್ತಾಂಶ) ಮತ್ತು Student Report (ಒಬ್ಬೊಬ್ಬ ವಿದ್ಯಾರ್ಥಿಯ ವಿವರ). ಇವು ಪ್ರಮಾಣಪತ್ರ, TC, CCE ಅಂಕ, ಯೋಜನೆ ಪರಿಶೀಲನೆ — ಎಲ್ಲಾ ಸಂದರ್ಭದಲ್ಲಿ ಬೇಕಾಗುತ್ತದೆ.

⚠️ ಮುಖ್ಯ ಸೂಚನೆ: ಮೆನು ಹೆಸರು ಮತ್ತು ಹಂತಗಳು ಪೋರ್ಟಲ್ ನವೀಕರಣದಿಂದ ಭಿನ್ನವಾಗಿರಬಹುದು. ಡೌನ್‌ಲೋಡ್ ಮಾಡುವ ಮೊದಲು ಪೋರ್ಟಲ್‌ನ User Manual ಮತ್ತು BEO/DDPI ಸೂಚನೆಗಳು ಪರಿಶೀಲಿಸಿ.

🌐 SATS Portal — LOGIN 📚 General Manual (PDF)

1. School Report Card — ಡೌನ್‌ಲೋಡ್ ಮಾಡುವುದು

1

SATS portal ನಲ್ಲಿ School login ಮೂಲಕ ಲಾಗಿನ್ ಮಾಡಿ.

2

ಮುಖ್ಯ ಮೆನುವಿನಲ್ಲಿ School Report Card ಆಯ್ಕೆ click ಮಾಡಿ (ಪೋರ್ಟಲ್ ಮುಖಪುಟದಿಂದಲೂ ಲಭ್ಯ).

3

ಜಿಲ್ಲೆ → ಬ್ಲಾಕ್ → ಶಾಲೆ ಆಯ್ಕೆ ಮಾಡಿ — ಶಾಲಾ ಕೋಡ್ ಆಟೋ ಆಗುತ್ತದೆ.

4

Academic year ಆಯ್ಕೆ ಮಾಡಿ Generate / Download click — PDF ಇಳಿಯುತ್ತದೆ.

2. Student Report — ವಿದ್ಯಾರ್ಥಿಯ ರಿಪೋರ್ಟ್ ನೋಡುವುದು

1

ಎಲ್ಲರಿಗೂ ಲಭ್ಯ: SATS ಮುಖಪುಟದಲ್ಲಿ Student Report ಆಯ್ಕೆ open ಮಾಡಿ.

2

Academic year → District → Block → Cluster ಡ್ರಾಪ್‌ಡೌನ್‌ಗಳನ್ನು fill ಮಾಡಿ.

3

School name / school code ಆಯ್ಕೆ ಮಾಡಿ.

4

With Aadhaar / Without Aadhaar ಆಯ್ಕೆ ಮಾಡಿ — ಹುಡುಕಲು ಸಹಾಯವಾಗುತ್ತದೆ.

5

Search click — ವಿದ್ಯಾರ್ಥಿಯ ರಿಪೋರ್ಟ್ ಕಾಣಿಸುತ್ತದೆ; ನಂತರ print/download.

3. ರಿಪೋರ್ಟ್‌ನಲ್ಲಿ ಏನಿರುತ್ತದೆ?

  • ವಿದ್ಯಾರ್ಥಿ ಹೆಸರು, SATS ID, ಜನ್ಮದಿನಾಂಕ, ತರಗತಿ
  • ಹಾಜರಾತಿ ಸಾರಾಂಶ (Present/Absent ದಾಖಲೆ)
  • CCE ಅಂಕಗಳು / ಏಕೀಕೃತ ಫಲಿತಾಂಶ (school login ಮೂಲಕ)
  • ಶಾಲಾ ವರ್ಗಾವಣೆ, TC ಆಧಾರ ದತ್ತಾಂಶ

4. ಪ್ರಿಂಟ್/ಸೇವ್ ಮಾಡುವ ಸಲಹೆಗಳು

  • A4 Paper: ಪ್ರಿಂಟ್ ಮಾಡುವಾಗ ಲೇಔಟ್ → Portrait select ಮಾಡಿ.
  • PDF ಆಗಿ save: Browser print → "Save as PDF" ಆಯ್ಕೆ — ದಾಖಲೆಗೆ ಸುಲಭ.
  • Background: ಹೆಚ್ಚಿನ browser "Background graphics" ಸೆಟ್ ಮಾಡಿದರೆ header/footer ಸಿಗುತ್ತದೆ.
  • ನೆಟ್ವರ್ಕ್: ಡೌನ್‌ಲೋಡ್ ಮುಗಿಯುವವರೆಗೆ page refresh ಮಾಡಬೇಡಿ.

5. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು & ಪರಿಹಾರ

ಸಮಸ್ಯೆಪರಿಹಾರ
Report blank / empty ಬರುತ್ತಿದೆದತ್ತಾಂಶ ದಾಖಲಾಗಿರಬಹುದೇ check — ದತ್ತಾಂಶ ನಮೂದಿಸಿದ ಮೇಲೆ ಮತ್ತೆ generate; browser cache clear/incognito try.
ಹಳೆಯ ವರ್ಷ ಕಾಣಿಸುತ್ತಿಲ್ಲAcademic year ಡ್ರಾಪ್‌ಡೌನ್‌ನಲ್ಲಿ ಬೇರೆ year ಆಯ್ಕೆ ಮಾಡಿ; ಸಿಗದಿದ್ದರೆ BEO/DDPI ಆಫೀಸ್ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ತೋರಿಸಿ.
School dropdown ಖಾಲಿಮೊದಲು district→block ಚುನಾಯಿಸಿ; ಆಗ school ಪಟ್ಟಿ ಬರುತ್ತದೆ.
PDF open ಆಗುತ್ತಿಲ್ಲAdobe/PDF viewer ಇದೆಯೇ check; ಬೇರೆ browser ಪ್ರಯತ್ನಿಸಿ.
ಮಾಹಿತಿ ತಪ್ಪಾಗಿದೆಯಾವ ದತ್ತಾಂಶ ದೋಷ ಎಂದು ಗುರುತಿಸಿ — SATS ನಲ್ಲಿ ಹಾಜರಾತಿ/CCE ಮಾತ್ರ school login ಮೂಲಕ update; basic details correction ಅಧಿಕಾರಿಯಿಂದ.

6. ಪ್ರಮುಖ ಅಂಶಗಳು ⭐

  • ಪ್ರತಿ ಹಣಕಾಸು/ಜನಗಣತಿ ಲೆಕ್ಕ — ರಿಪೋರ್ಟ್ ನಿಖರವಾಗಿದ್ದರೆ ಶಾಲಾ ಯೋಜನೆ/ಅನುದಾನ ಸುಗಮ.
  • ಹಳೆಯ ದತ್ತಾಂಶ newer: ಹಿಂದಿನ ವರ್ಷದ ಹಾಜರಾತಿ update ಆಯ್ಕೆಯೂ school login ನಲ್ಲಿ ಇದೆ.
  • TC/CCE: ವರ್ಷಾರಂಭದಲ್ಲಿ CCE result, TC issue, Promote student — school login ನಲ್ಲೇ ಆಯ್ಕೆಗಳು.
  • Screen-ಷಾಟ್ ಇರಿಸಿ: ರಿಪೋರ್ಟ್ ತೆಗೆದ ದಿನಾಂಕದೊಂದಿಗೆ save ಮಾಡಿಕೊಳ್ಳಿ.
  • ನಿಯಮ ಬದಲಾಗಬಹುದು: ಮೆನು ನವೀಕರಣವಾದಾಗ User Manual ನೋಡಿ.

7. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. School Report Card ಮತ್ತು Student Report ಗೆ ವ್ಯತ್ಯಾಸ?

School Report Card = ಶಾಲೆಯ ಒಟ್ಟು ದತ್ತಾಂಶ ಸಾರಾಂಶ (ಎಲ್ಲಾ ಮಕ್ಕಳು, attendance, results). Student Report = ಒಬ್ಬ ವಿದ್ಯಾರ್ಥಿಯ ವಿವರ — TC/ಪ್ರಮಾಣಪತ್ರ, ಪೋಷಕರಿಗೆ ಬೇಕಾಗುತ್ತದೆ.

2. Login ಇಲ್ಲದೆ Student Report ನೋಡಬಹುದೇ?

ಹೌದು — SATS ಮುಖಪುಟದ Student Report option ಸಾರ್ವಜನಿಕ; school/block dropdown ಮೂಲಕ ಹುಡುಕಬಹುದು. School Report Card ಡೌನ್‌ಲೋಡ್ ಸಾಮಾನ್ಯವಾಗಿ login ಇಲ್ಲದೆಯೂ ಪೋರ್ಟಲ್ menu ನಿಂದ ಲಭ್ಯ (district+school select ಮೂಲಕ).

3. ರಿಪೋರ್ಟ್‌ನಲ್ಲಿ wrong ಗ್ರೇಡ್ ಆದರೆ?

CCE grade school login ಮೂಲಕ correction; ಪ್ರತಿ ಬಾರಿ ಸರಿಪಡಿಸಿ regenerate — ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ದಾಖಲೆ ಇರಿಸಿ.

4. Download ಆದ PDF ಇಂಗ್ಲಿಷ್ ನಲ್ಲಿ ಮಾತ್ರ ಇದೆ — ಕನ್ನಡಕ್ಕೆ?

ಸಾಮಾನ್ಯವಾಗಿ ಪೋರ್ಟಲ್ Kannada/English selection ಇರುತ್ತದೆ (login ಪುಟದಲ್ಲಿ). ಲಭ್ಯವಿದ್ದರೆ ಭಾಷೆ ಬದಲಿಸಬಹುದು — ಇರದಿದ್ದರೆ PDF ಹಾಗೆ ಉಳಿಸಿ, ಪ್ರಮುಖ ಭಾಗಗಳನ್ನು ಕನ್ನಡದಲ್ಲಿ ವಿವರಿಸಿ.

5. ಶಾಲೆಯ data entry ಆಗಿದೆಯೇ — ಗೊತ್ತಾಗುವುದು ಹೇಗೆ?

School Report Card ಒಮ್ಮೆ generate ಮಾಡಿ — ಖಾಲಿ/faulty ಕಂಡರೆ data ಭರ್ತಿಯಾಗಿಲ್ಲ ಎಂದರ್ಥ; attendance/CCE ಮೊದಲು ನಮೂದಿಸಿ.
