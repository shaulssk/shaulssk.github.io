📡 ವಿದ್ಯಾವಾಹಿನಿ | Vidyavahini — Portal Login Guide

ಸಮಗ್ರ ಶಿಕ್ಷಣ ಕರ್ನಾಟಕ (ಇಲಾಖಾ Portal) access — ಹಂತ-ಹಂತ ಕನ್ನಡ ಮಾರ್ಗದರ್ಶಿ

✅ Last verified: 19 Sep 2026 · 📌 ಅಧಿಕೃತ source: schooleducation.karnataka.gov.in · Vidyavahini

⚠️ ಪ್ರಮುಖ: ವಿದ್ಯಾವಾಹಿನಿ (Vidyavahini) ಇದು ಸಮಗ್ರ ಶಿಕ್ಷಣ ಕರ್ನಾಟಕ (SSK) ಇಲಾಖೆಯ portal/app ಆಗಿದೆ. ಈ ಪುಟವು ಕೇವಲ ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿ — ಇದು ಸರ್ಕಾರದ ಅಧಿಕೃತ ಪುಟವಲ್ಲ, ಇಲಾಖೆಯ ಪರವಾಗಿ ಅಲ್ಲ. Protected: ಯಾವುದೇ OTP/password ಅನ್ನು ಯಾರೊಂದಿಗೂ ಹಂಚಿಕೊಳ್ಳಬೇಡಿ.

ಇಲಾಖೆಯ ವಿವಿಧ online ಸೇವೆಗಳಿಗೆ (ವಿದ್ಯಾರ್ಥಿ ದತ್ತಾಂಶ, ಹಾಜರಾತಿ, ಶಾಲಾ ಮಾಹಿತಿ) ಸಂಪರ್ಕ ಕಲ್ಪಿಸುವ portal ಇದು. Login ಮಾಡಲು ಈ ಕೆಳಗಿನ ಹಂತಗಳನ್ನು ಅನುಸರಿಸಿ:

1. ಲಾಗಿನ್ ಹಂತಗಳು | Login Steps

  1. ಇಲಾಖಾ ವೆಬ್‌ಸೈಟ್ ತೆರೆಯಿರಿ: schooleducation.karnataka.gov.in — ಪುಟದಲ್ಲಿ Department Software Links ವಿಭಾಗ ಕಾಣುತ್ತದೆ.
  2. Vidyavahini ಆಯ್ಕೆ: ಅಲ್ಲಿ ವಿದ್ಯಾವಾಹಿನಿ / Vidyavahini ಆಯ್ಕೆ ಕ್ಲಿಕ್ ಮಾಡಿ — login ಪುಟ ತೆರೆಯುತ್ತದೆ.
  3. ಇಲಾಖೆಯ ಬಳಕೆದಾರ ವಿಭಾಗ: login ಪುಟದಲ್ಲಿ "ಇಲಾಖೆಯ ಬಳಕೆದಾರರು" ಆಯ್ಕೆ ಮಾಡಿ.
  4. ಬಳಕೆದಾರ ಐಡಿ (User ID): HM + ನಿಮ್ಮ ಶಾಲೆಯ UDISE ಕೋಡ್ — ಉದಾ. HM29xxxxxxxx (HM = Head Master/ಮುಖ್ಯೋಪಾಧ್ಯಾಯ · 29 = ಕರ್ನಾಟಕ state code · xxxxxxxx = ನಿಮ್ಮ ಶಾಲೆಯ UDISE code).
  5. ಪಾಸ್‌ವರ್ಡ್ (Password): ಇಲಾಖೆ ನೀಡಿದ/ಸ್ಥಾಪಿಸಿದ ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿ.
  6. ಭದ್ರತಾ ಕೋಡ್ (Security Code): ತೋರಿಸುವ ಕೋಡ್ ಅನ್ನು ಟೈಪ್ ಮಾಡಿ.
  7. ಲಾಗಿನ್ ಕ್ಲಿಕ್: Login ಒತ್ತಿ — ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ತೆರೆಯುತ್ತದೆ.

💡 password reset / ಹೊಸದಾಗಿ login: ನಿಮ್ಮ ಶಾಲೆಗೆ ಇಲಾಖೆ ಒದಗಿಸಿದ circular/user manual ಪ್ರಕಾರ default password ಪರಿಶೀಲಿಸಿ; ಮರೆತಲ್ಲಿ ಇಲಾಖಾ ಕಚೇರಿ (BEO/DDPI) ಅಥವಾ official tech help ಮೂಲಕ reset ಮಾಡಿಸಿ.

2. Vidyavahini ನಲ್ಲಿ ಏನೆಲ್ಲಾ ಸಿಗುತ್ತದೆ?

  • 📋 ಶಾಲಾ ಮಾಹಿತಿ & ವಿದ್ಯಾರ್ಥಿ ದತ್ತಾಂಶ (department services).
  • 📊 ದಾಖಲೆ ನಮೂದು, ವರದಿಗಳು ಮತ್ತು portal ನಿರ್ವಹಣೆ.
  • 🔗 ಇತರ ಇಲಾಖಾ portal ಗಳಿಗೆ links/shortcuts.
  • 🗂️ ನೋಂದಣಿ, ಹಾಜರಾತಿ ಮತ್ತು school-data ಕಾರ್ಯಗಳು.

3. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು | Troubleshooting

ಸಮಸ್ಯೆಏನು ಪರಿಶೀಲಿಸಬೇಕು
Login ಆಗುತ್ತಿಲ್ಲಇಂಟರ್ನೆಟ್, browser cache, ಮತ್ತು UDISE code/HM ಫಾರ್ಮ್ಯಾಟ್ ಸರಿಯಿದೆಯೇ ನೋಡಿ.
"ಇಲಾಖೆಯ ಬಳಕೆದಾರರು" ಕಾಣಿಸುತ್ತಿಲ್ಲಸರಿಯಾದ Vidyavahini login ಪುಟ ತೆರೆದಿದ್ದೀರಾ ಪರಿಶೀಲಿಸಿ.
Password ಮರೆತಿದ್ದೇನೆಇಲಾಖಾ circular/user manual ಮೂಲಕ reset; ಅಥವಾ BEO/DDPI ಕಚೇರಿ ಸಂಪರ್ಕಿಸಿ.
ಸಮಸ್ಯೆ ಸರಿಯಾಗುತ್ತಿಲ್ಲಮತ್ತೊಂದು browser ಪ್ರಯತ್ನಿಸಿ; official portal ನ ಹೊಸ ನವೀಕರಣ/notification ಪರಿಶೀಲಿಸಿ.

4. FAQ — ಆಗಾಗ ಬರುವ ಪ್ರಶ್ನೆಗಳು

Vidyavahini login ಕ್ಕೆ ಬೇರೆ ID ಬೇಕೇ?

ಇಲ್ಲ — ಸಾಮಾನ್ಯವಾಗಿ ಶಾಲೆಯ UDISE code + HM ಜೊತೆಗೆ ಇಲಾಖೆ ನೀಡಿದ login ಬಳಸಲಾಗುತ್ತದೆ. ನಿಖರವಾದ ಫಾರ್ಮ್ಯಾಟ್ಗೆ ಇಲಾಖಾ circular ಪರಿಶೀಲಿಸಿ.

ಇದು ಅಧಿಕೃತ portal ನೇ?

ಹೌದು — Vidyavahini ಸಮಗ್ರ ಶಿಕ್ಷಣ ಕರ್ನಾಟಕ ಇಲಾಖೆಯ portal. ಈ guide ಮಾತ್ರ ಸ್ವತಂತ್ರವಾದುದು.

Password ಯಾರಿಗೂ ಕೊಡಬಹುದೇ?

ಇಲ್ಲ. ಯಾವುದೇ password/OTP ಹಂಚಿಕೊಳ್ಳಬೇಡಿ — ಇದು trust + safety issue.
