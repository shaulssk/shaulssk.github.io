🏫 ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ daily ನೋಡುವ (practical workflow)
  • ಬೆಳಿಗ್ಗೆ: ನಿರಂತರ — ಇಂದಿನ attendance status, present/absent count ನೋಡಿ.
  • SATS: ಹೊಸ enrollment/promotion pending ಆಗಿ ಇದೆಯೇ — dashboard red flags ಗಮನಿಸಿ.
  • UDISE+: deadline ಸಮೀಪ ಇದ್ದರೆ data entry % ಎಷ್ಟು — freeze ದಿನಾಂಕ ಗಮನದಲ್ಲಿ.
  • GIS: ಜಿಯೋ-ಟ್ಯಾಗಿಂಗ್ pending schools ಇದ್ದರೆ ಕಾರ್ಯ ನಿಗದಿ.
  • SSP: scholarships application status/track — pending application ತೀರಿಸಿ.

ಪ್ರತಿ ವ್ಯವಸ್ಥೆ — ಸಂಪೂರ್ಣ ಪರಿಚಯ (Complete System Guide)

A. SATS — Student Achievement Tracking System

ಏನು: ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆಯ ವಿದ್ಯಾರ್ಥಿ/ಶಿಕ್ಷಕ ದಾಖಲೆ ಮತ್ತು ಹಾಜರಾತಿ ವ್ಯವಸ್ಥೆ. ವಿದ್ಯಾರ್ಥಿಯ ಹೆಸರು, ಜನ್ಮದಿನ, ಜಾತಿ, ವಿಳಾಸ, ಫೋಟೋ, ಅಂಕಗಳು, ಹಾಜರಾತಿ — ಎಲ್ಲವೂ SATS ನಲ್ಲಿ.

ಯಾರಿಗೆ: ಎಲ್ಲಾ ಸರ್ಕಾರಿ/ಅನುದಾನಿತ ಶಾಲೆಗಳ ಶಿಕ್ಷಕರು ಮತ್ತು ಮುಖ್ಯ ಶಿಕ್ಷಕರು.

Login: sts.karnataka.gov.in/SATS — ಶಾಲಾ username + password (ಸಮಸ್ಯೆ ಇದ್ದರೆ BEO/ವೇದಿಕೆ ಸಾಮಗ್ರಿ ಮೂಲಕ).

ಮುಖ್ಯ ಕೆಲಸಗಳು:

  • ದೈನಂದಿನ ಹಾಜರಾತಿ ನಮೂದು (ಆಂತರಿಕ + SSA ಪರೀಕ್ಷೆ ಅಂಕ ಸಹ)
  • ಹೊಸ ಪ್ರವೇಶ / ತರಗತಿ promotion — SDMS ವಿದ್ಯಾರ್ಥಿ ದಾಖಲೆ
  • ಅಂಕ ಪಟ್ಟಿ / ವರದಿ ಕಾರ್ಡ್ ಪ್ರಿಂಟ್
  • ವಿದ್ಯಾರ್ಥಿ ವರ್ಗಾವಣೆ, ಹಿಂದಿರುಗಿಸುವಿಕೆ (TC)

ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆ → ಪರಿಹಾರ: "Error Occurred" ಪುಟ → ಸರ್ವರ್ ತಾತ್ಕಾಲಿಕ — ನಂತರ ಪ್ರಯತ್ನಿಸಿ; ಪಾಸ್‌ವರ್ಡ್ ಮರೆತರೆ → ಪಾಸ್‌ವರ್ಡ್ ಮಾರ್ಗದರ್ಶಿ; ವಿದ್ಯಾರ್ಥಿ ದಾಖಲೆ ಸಿಗದಿದ್ದರೆ → ಹೆಸರು/UDISE code ಹೊಂದಾಣಿಕೆ ಪರಿಶೀಲಿಸಿ. ವಿವರ: SATS ಸಂಪೂರ್ಣ ಮಾರ್ಗದರ್ಶಿ.

ಸಣ್ಣ FAQ:

  • Q. ಹಾಜರಾತಿಯನ್ನು SATS ನಲ್ಲಿ ಮಾತ್ರ ಹಾಕಬೇಕೇ?  A. ದೈನಂದಿನ ಅಧಿಕೃತ ದಾಖಲೆ SATS; ನಿರಂತರ ಆ್ಯಪ್ ಇರುವ ಶಾಲೆಗಳಲ್ಲಿ ಫೇಸ್-ಆಧಾರಿತ ಹಾಜರಾತಿ ಜೊತೆ SATS ಸಿಂಕ್ ಆಗುತ್ತದೆ.
  • Q. ವಿದ್ಯಾರ್ಥಿ ಅಂಕಗಳು ತಪ್ಪಾಗಿ ನಮೂದಾಗಿದೆಯೇ?  A. Admin/ಶಾಲಾ login ನಲ್ಲಿ rectify/ಸರಿ ಮಾಡಿ — ಇಲಾಖಾ ಸೂಚನೆ ಪ್ರಕಾರ.

B. ನಿರಂತರ (Nirantara) — AI ಮುಖ ಗುರುತಿಸುವಿಕೆ ಹಾಜರಾತಿ

ಏನು: ಕರ್ನಾಟಕ ಶಾಲಾ ಶಿಕ್ಷಣ ಇಲಾಖೆಯ AI ಆಧಾರಿತ ಫೇಸ್-ರೆಕಗ್ನಿಷನ್ ಹಾಜರಾತಿ ವ್ಯವಸ್ಥೆ — 2026-27ನೇ ಸಾಲಿನಿಂದ ಸರ್ಕಾರಿ/ಅನುದಾನಿತ ಶಾಲೆಗಳಲ್ಲಿ ಉಪಯೋಗವಾಗುತ್ತಿದೆ ಎಂದು ಇಲಾಖಾ ಸೂಚನೆಗಳು ತಿಳಿಸುತ್ತವೆ.

ಯಾರಿಗೆ: ಶಿಕ್ಷಕರು (ಪ್ರತಿದಿನ ಹಾಜರಾತಿ), ಶಾಲಾ ನಿರ್ವಾಹಕರು (ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ), ವಿದ್ಯಾರ್ಥಿಗಳು (ಮುಖ ಸೆರೆಹಿಡಿಯುವಿಕೆ).

Login: nirantara.karnataka.gov.in — KGID + OTP ಮೂಲಕ. (ಹಳೆಯ satschool ವಿಳಾಸ ಈಗ ಬಳಕೆಯಲ್ಲಿಲ್ಲ — ಹೊಸ ಲಿಂಕ್ ಉಪಯೋಗಿಸಿ.)

ಮುಖ್ಯ ಕೆಲಸಗಳು:

  • ದೈನಂದಿನ ವಿದ್ಯಾರ್ಥಿ ಹಾಜರಾತಿ capture
  • ಹೊಸ ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ — ಸಾಮಾನ್ಯವಾಗಿ 3 ಫೋಟೋ (ಮುಂಭಾಗ, ಎಡ, ಬಲ)
  • ತಪ್ಪು/ನಕಲಿ/ಗೈರು/TC ಕಾರಣಗಳಿಗೆ ವಿದ್ಯಾರ್ಥಿ delete
  • ಶಿಕ್ಷಕ/ಸಿಬ್ಬಂದಿ ದಾಖಲೆ ನಿರ್ವಹಣೆ

ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆ → ಪರಿಹಾರ: OTP ಬಾರದಿದ್ದರೆ → KGID/ಮೊಬೈಲ್ ಸಂಖ್ಯೆ ಸರಿಯಾಗಿದೆಯೇ ನೋಡಿ; ಮಗು ನೋಂದಣಿ ಆಗದಿದ್ದರೆ → SATS ನಲ್ಲಿ ಮೊದಲು ದಾಖಲಾಗಿದೆಯೇ ಗಮನಿಸಿ; delete ಮಾಡಿದ್ದು ತಪ್ಪಾದರೆ → ಮರು-ನೋಂದಣಿ (ಗ್ರೀವೆನ್ಸ್ ಆಯ್ಕೆ). ವಿವರ: ವಿದ್ಯಾರ್ಥಿ ನೋಂದಣಿ ಮಾರ್ಗದರ್ಶಿ · ನಿರಂತರ ಸಂಪೂರ್ಣ ಮಾರ್ಗದರ್ಶಿ.

ಸಣ್ಣ FAQ:

  • Q. SATS ಮತ್ತು ನಿರಂತರ ಅಂದರೆ ಒಂದೇ?  A. ಇಲ್ಲ — SATS ದಾಖಲೆ ಮತ್ತು ಹಾಜರಾತಿ ವ್ಯವಸ್ಥೆ; ನಿರಂತರ AI ಮುಖ-ಹಾಜರಾತಿ ಆ್ಯಪ್. ವ್ಯತ್ಯಾಸ: SATS vs ನಿರಂತರ.
  • Q. ವಿದ್ಯಾರ್ಥಿಯನ್ನು ಯಾವಾಗ delete ಮಾಡಬೇಕು?  A. ಸೂಚನೆ ಪ್ರಕಾರ ತಪ್ಪು ನೋಂದಣಿ / ನಕಲಿ / ಗೈರು ವಿದ್ಯಾರ್ಥಿಗೆ — ಕಾರಣ ಆಯ್ಕೆ ಮಾಡಿ.

C. UDISE+ — ರಾಷ್ಟ್ರೀಯ ಶಾಲಾ ದತ್ತಾಂಶ

ಏನು: ಭಾರತದ ಮಾನ್ಯತೆ ಪಡೆದ ಎಲ್ಲಾ ಶಾಲೆಗಳ ಸಮಗ್ರ ದತ್ತಾಂಶ (Ministry of Education / NIEPA). ಪ್ರತಿ ಶಾಲೆಗೆ 11-ಅಂಕಿಯ UDISE+ ಕೋಡ್. PM POSHAN, Samagra Shiksha, RTE ಮುಂತಾದ ಅನುದಾನ ಲೆಕ್ಕದಲ್ಲಿ ಈ ದತ್ತಾಂಶವನ್ನು ಬಳಸುವ ಸಾಧ್ಯತೆ ಇದೆ — ಸಂಬಂಧಪಟ್ಟ ಇಲಾಖಾ ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ.

ಯಾರಿಗೆ: ಶಾಲೆಯ ಡೇಟಾ ಆಪರೇಟರ್/ಶಿಕ್ಷಕ → ದತ್ತಾಂಶ; ಶಾಲೆ certify → BEO ಅನುಮೋದನೆ.

Login: udiseplus.gov.in — ರಾಜ್ಯ(ಕರ್ನಾಟಕ) → ಜಿಲ್ಲೆ → ಶಾಲೆ → UDISE+ ಕೋಡ್.

ಮುಖ್ಯ ಕೆಲಸಗಳು:

  • ಶಾಲಾ profile, ವಿದ್ಯಾರ್ಥಿ (SDMS module), ಶಿಕ್ಷಕ module, ಸೌಲಭ್ಯ/ಹಣಕಾಸು
  • Reference Date (30 ಸೆಪ್ಟೆಂಬರ್ 2026) ಪ್ರಕಾರ ದತ್ತಾಂಶ
  • Freeze → certify → submit; ಬದಲಾವಣೆಗೆ block/district MIS ನಿಂದ unlock

ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆ → ಪರಿಹಾರ: module lock ಆದರೆ → ಮುಂಚಿತವಾಗಿ freeze/ಅಥವಾ MIS unlock ವಿನಂತಿ; ವಿದ್ಯಾರ್ಥಿ ಸಂಖ್ಯೆ SATS ಜೊತೆ ಹೊಂದಿಕೆಯಾಗದಿದ್ದರೆ → ತಿಂಗಳ ಕೊನೆಯಲ್ಲಿ ಹೋಲಿಸಿ ಕಾರಣ ಪಟ್ಟಿ ಮಾಡಿ. ವಿವರ: UDISE+ ಪೂರ್ಣ ಮಾರ್ಗದರ್ಶಿ.

ಸಣ್ಣ FAQ:

  • Q. Reference Date ಎಂದರೇನು?  A. ಯಾವ ದಿನಾಂಕದ ಸ್ಥಿತಿಯ ಪ್ರಕಾರ ದತ್ತಾಂಶ ದಾಖಲಿಸಬೇಕು ಎಂಬ ಅಧಿಕೃತ ಉಲ್ಲೇಖ ದಿನ — ಈ ಸಾಲು 30 ಸೆಪ್ಟೆಂಬರ್ 2026.
  • Q. UDISE+ ದತ್ತಾಂಶ ಏಕೆ ಮುಖ್ಯ?  A. ಬಹುತೇಕ ಶಾಲಾ ಅನುದಾನ ಮತ್ತು ಇಲಾಖಾ ಅಂಕಿಅಂಶಗಳಿಗೆ UDISE+ ದತ್ತಾಂಶವನ್ನು ಆಧಾರವಾಗಿ ಬಳಸುವ ಸಾಧ್ಯತೆ ಇದೆ — ಇಲಾಖಾ ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ.

D. UDISE+ GIS Capture — ಶಾಲಾ ಜಿಯೋ-ಟ್ಯಾಗಿಂಗ್

ಏನು: ಶಾಲೆಯ ನಿಖರ GPS ಸ್ಥಳ + ಕಡ್ಡಾಯ ಫೋಟೋಗಳನ್ನು ಸೆರೆಹಿಡಿಯುವ ಆ್ಯಪ್ (UDISE+ ನ ಭಾಗ).

ಯಾರಿಗೆ: ಶಾಲೆ/ನಿಯೋಜಿತ ಸಿಬ್ಬಂದಿ → ಜಿಲ್ಲಾ ಅನುಮೋದನೆ.

Login: Android ಆ್ಯಪ್ UDISE+ GIS Capture (Play Store) — ಶಾಲಾ/ಅಧಿಕಾರಿ login.

ಮುಖ್ಯ ಕೆಲಸಗಳು: ಶಾಲೆಯ ಸ್ಥಳ GPS capture, 4 ಅಗತ್ಯ ಫೋಟೋ (ಮುಖ್ಯ ಕಟ್ಟಡ ಮುಂತಾದವು), submit → ಜಿಲ್ಲಾ/ಬ್ಲಾಕ್ ಪರಿಶೀಲನೆ.

ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆ → ಪರಿಹಾರ: GPS ದೂರ/ತಪ್ಪು → ಶಾಲಾ ಮುಖದ್ವಾರದ ಹೊರಗೆ ಆಕಾಶ ಸ್ಪಷ್ಟವಾದ ಕಡೆ capture; capture ಆಗದಿದ್ದರೆ → ಆ್ಯಪ್ ಸ್ಥಳ (location) ಅನುಮತಿ on ಮಾಡಿ; reject ಆದರೆ → ಮರು-ಸೆರೆಹಿಡಿದು submit. ವಿವರ: GIS ಜಿಯೋ-ಟ್ಯಾಗಿಂಗ್ ಮಾರ್ಗದರ್ಶಿ.

ಸಣ್ಣ FAQ:

  • Q. ಕಡ್ಡಾಯ ಫೋಟೋಗಳು ಎಷ್ಟು?  A. ಆ್ಯಪ್/ಇಲಾಖಾ ಸೂಚನೆ ಪ್ರಕಾರ ಸಾಮಾನ್ಯವಾಗಿ 4 — ನಿರ್ದಿಷ್ಟ ಸಂಖ್ಯೆಗೆ ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ.
  • Q. ಫೋಟೋ reject ಏಕೆ ಆಗುತ್ತದೆ?  A. ಮಸುಕು/ತಪ್ಪು ಕೋನ/GPS ಹೊಂದಾಣಿಕೆ — ಸ್ಪಷ್ಟ ಲೈಟ್ ನಲ್ಲಿ ಮತ್ತೆ ತೆಗೆಯಿರಿ.

E. SSP — State Scholarship Portal

ಏನು: ಕರ್ನಾಟಕ ವಿದ್ಯಾರ್ಥಿವೇತನ ಅರ್ಜಿ ಮತ್ತು ಮೇಲ್ವಿಚಾರಣೆ ಪೋರ್ಟಲ್.

ಯಾರಿಗೆ: ವಿದ್ಯಾರ್ಥಿ/ಪೋಷಕ (ಅರ್ಜಿ), ಶಾಲಾ ಪೋಸ್ಟಿಂಗ್ ಅಧಿಕಾರಿ/ಸಿಬ್ಬಂದಿ (forward).

Login: ssp.karnataka.gov.in — ವಿದ್ಯಾರ್ಥಿ/ಶಾಲಾ login ಪ್ರಕಾರ.

ಮುಖ್ಯ ಕೆಲಸಗಳು: ಅರ್ಜಿ ಭರ್ತಿ, ದಾಖಲೆ upload, ಶಾಲಾ forward, status/track ಪರಿಶೀಲನೆ, ನವೀಕರಣ (renewal).

ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆ → ಪರಿಹಾರ: reject ಆದರೆ → ದಾಖಲೆಗಳಲ್ಲಿ ಹೆಸರು/ದಿನಾಂಕ ಹೊಂದಾಣಿಕೆ (ಅಧಿಕೃತ ದಾಖಲೆ proಕಾರ); status ಹಳೆಯದಾಗಿದ್ದರೆ → shift/correction ಪ್ರಕ್ರಿಯೆ. ವಿವರ: SSP ಮಾರ್ಗದರ್ಶಿ.

ಸಣ್ಣ FAQ:

  • Q. ಅರ್ಜಿ ಮತ್ತು ಶಾಲಾ forward ಮಧ್ಯೆ ಸಮಯ ಯಾಕೆ?  A. ಶಾಲೆ ಪರಿಶೀಲಿಸಿ ದಾಖಲೆ ಸರಿ ಎಂದು ದೃಢಪಡಿಸಿದಾಗ only forward — ದೋಷ ಇದ್ದರೆ ಹಿಂತಿರುಗುತ್ತದೆ.
  • Q. renewal ಬಿಟ್ಟರೆ?  A. ಮುಂದಿನ ಸಾಲಿಗೆ ಮರು-ಅರ್ಜಿ ಮಾಡಬೇಕಾಗುತ್ತದೆ — deadline ಗಮನದಲ್ಲಿಡಿ.

1. ಯಾವ ವ್ಯವಸ್ಥೆ — ಯಾವುದಕ್ಕೆ?

ವ್ಯವಸ್ಥೆಏನಕ್ಕೆಯಾರು ಬಳಸುತ್ತಾರೆ
SATS (sts.karnataka.gov.in/SATS)ವಿದ್ಯಾರ್ಥಿ/ಶಿಕ್ಷಕ ದಾಖಲೆ, ಹಾಜರಾತಿ, ಅಂಕ ಪಟ್ಟಿ (ಆಂತರಿಕ + SSA ಪರೀಕ್ಷೆ)ಶಾಲೆ (ಎಲ್ಲಾ)
ನಿರಂತರ (Nirantara — AI attendance ಆ್ಯಪ್)ವಿದ್ಯಾರ್ಥಿ ಹಾಜರಾತಿ (ಫೇಸ್ ರೆಕಗ್ನಿಷನ್), ವಿದ್ಯಾರ್ಥಿ/ಶಿಕ್ಷಕ ನೋಂದಣಿ — ದೈನಂದಿನ ಚಟುವಟಿಕೆಶಾಲೆ (ಎಲ್ಲಾ)
UDISE+ (udiseplus.gov.in)ರಾಷ್ಟ್ರೀಯ ಶಾಲಾ ದತ್ತಾಂಶ — ವಿದ್ಯಾರ್ಥಿ ಸಂಖ್ಯೆ, ಶಿಕ್ಷಕ, ಸೌಲಭ್ಯ; Reference Date 30 ಸೆಪ್ಟೆಂಬರ್ಡೇಟಾ ಆಪರೇಟರ್ / ಶಾಲೆ → BEO certify
UDISE+ GIS Capture (ಆ್ಯಪ್)ಶಾಲಾ GPS ಸ್ಥಳ + 4 ಕಡ್ಡಾಯ ಫೋಟೋ (ಜಿಯೋ-ಟ್ಯಾಗಿಂಗ್)ಶಾಲೆ → ಜಿಲ್ಲಾ ಅನುಮೋದನೆ
SSP (ssp.karnataka.gov.in)ವಿದ್ಯಾರ್ಥಿವೇತನ ಅರ್ಜಿ/ಮೇಲ್ವಿಚಾರಣೆವಿದ್ಯಾರ್ಥಿ/ಶಾಲಾ ಪೋಸ್ಟಿಂಗ್

2. ಅತಿ ಮುಖ್ಯವಾದ ಡೇಟಾ — ಎಲ್ಲಿ ದಾಖಲಿಸಬೇಕು?

ದತ್ತಾಂಶಪೋರ್ಟಲ್
ವಿದ್ಯಾರ್ಥಿ ಹೆಸರು/ಜನನ/ಜಾತಿ/ವಿಳಾಸ (ಪ್ರವೇಶ)SATS + UDISE+ (SDMS ವಿದ್ಯಾರ್ಥಿ module)
ಹಾಜರಾತಿ (ದೈನಂದಿನ)SATS (ಶಿಕ್ಷಕ login)
ಅಂಕಗಳು / ಒಳ ಮೌಲ್ಯಮಾಪನSATS (ಅಂಕ ನಮೂದು) · ನಿರಂತರ (ಕಲಿಕಾ ದಾಖಲೆ)
ಶಾಲಾ ಸೌಲಭ್ಯ / ಶಿಕ್ಷಕ ಸಂಖ್ಯೆ / ವಿದ್ಯಾರ್ಥಿ ಸಂಖ್ಯೆ (ವಾರ್ಷಿಕ)UDISE+ (Reference Date 30 ಸೆಪ್ಟೆಂಬರ್ 2026)
ಶಾಲಾ ಫೋಟೋ + GPS ಸ್ಥಳUDISE+ GIS Capture ಆ್ಯಪ್
ವಿದ್ಯಾರ್ಥಿವೇತನSSP / ಸಂಬಂಧಿತ ಇಲಾಖಾ ಪೋರ್ಟಲ್

4. ಸಾಮಾನ್ಯ ದೋಷ-ಸ್ಥಿತಿ → ಮುಂದಿನ ಹೆಜ್ಜೆ

ಕಂಡ ಸ್ಥಿತಿಹೇಗೆ ಸರಿಪಡಿಸುವುದು
SATS ನಲ್ಲಿ "Error Occurred" ಪುಟಸರ್ವರ್ ತಾತ್ಕಾಲಿಕ ಸಮಸ್ಯೆ — ನಂತರ ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ; ಮುಂದುವರಿದರೆ ಯೂಸರ್‌ನೇಮ್/ಪಾಸ್‌ವರ್ಡ್ ಪರಿಶೀಲಿಸಿ (ವಿವರ: SATS ಮಾರ್ಗದರ್ಶಿ)
ಪಾಸ್‌ವರ್ಡ್ ಮರೆತಿದ್ದೇನೆಪೋರ್ಟಲ್ ನ "Forgot Password" ಬಳಸಿ (SATS ಆಪರೇಟರ್ ಸ್ತರದ ಮೂಲಕ reset) — ಕನ್ನಡ ಮಾರ್ಗದರ್ಶಿ
UDISE+ entry lock ಆಗಿದೆಸರಿಯಾದ ಸಮಯದಲ್ಲಿ freeze — block/district MIS ನಿಂದ unlock request
GIS GPS ದೂರ ಇದೆಶಾಲೆಯ ಮುಖದ್ವಾರದ ಹೊರಗೆ ಸ್ಪಷ್ಟ ಆಕಾಶದಲ್ಲಿ capture; ಜಿಲ್ಲಾ reject ಆದರೆ ಮರು-ಸೆರೆಹಿಡಿಯಿರಿ
ವಿದ್ಯಾರ್ಥಿವೇತನ ಅರ್ಜಿ rejectದಾಖಲೆ ಹೆಸರು/h2 ನಮೂದು ಹೊಂದಾಣಿಕೆ (ಅಧಿಕೃತ ದಾಖಲೆ ಪರಿಶೀಲಿಸಿ)

5. ಹಂತ-ಹಂತ: ಇಂದಿನ ಚೆಕ್‌ಲಿಸ್ಟ್

  1. SATS login → ಹಾಜರಾತಿ ದಾಖಲಿಸಿ (ಪ್ರತಿದಿನ).
  2. ಇತ್ತೀಚಿನ ಅಂಕ/ಪರೀಕ್ಷೆ ಫಲಿತಾಂಶ SATS ನಲ್ಲಿ ದಾಖಲಾಗಿದೆಯೇ ಪರಿಶೀಲಿಸಿ.
  3. UDISE+ Reference Date (30 Sep) ಸಮೀಪ — ವಿದ್ಯಾರ್ಥಿ/ಶಿಕ್ಷಕ/ಸೌಲಭ್ಯ ದತ್ತಾಂಶ ಸರಿಯಾಗಿದೆಯೇ ನೋಡಿ.
  4. GIS ಫೋಟೋ/GPS pending ಇದ್ದರೆ — ಜಿಯೋ-ಟ್ಯಾಗ್ complete ಮಾಡಿ.
  5. ನೋಟೀಸ್ ಬೋರ್ಡ್ ಇಲಾಖಾ ಪತ್ರ ಪರಿಶೀಲಿಸಿ — ಹೊಸ deadline ಇದ್ದರೆ ನಮೂದಿಸಿ.
