ℹ️ Note: ಚಟುವಟಿಕೆ ಅಪ್‌ಲೋಡ್‌ನ ನಿಖರ deadline, default password ಮತ್ತು ಕಡ್ಡಾಯ ವಿವರ ಒಂದು ರಾಜ್ಯದಿಂದ ಇನ್ನೊಂದಕ್ಕೆ ಬದಲಾಗಬಹುದು — ಪ್ರತಿ ಬಾರಿ ಅಧಿಕೃತ ಪೋರ್ಟಲ್ + ನಿಮ್ಮ ರಾಜ್ಯ ಇಲಾಖಾ ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ.

🌿 Eco Clubs for Mission LiFE — ಭಾರತ ಸರ್ಕಾರದ ಶಿಕ್ಷಣ ಸಚಿವಾಲಯವು ಪ್ರತಿ ಶಾಲೆಯಲ್ಲಿ ಎನ್ವಿರಾನ್‌ಮೆಂಟ್ ಸ್ನೇಹಿ (ಪರಿಸರ ಸ್ನೇಹಿ) ಚಟುವಟಿಕೆಗಳಿಗೆ ರಚಿಸಿರುವ ವಿದ್ಯಾರ್ಥಿ ಕ್ಲಬ್. NEP-2020 ರ ಪ್ರಕಾರ ವಿದ್ಯಾರ್ಥಿಗಳಲ್ಲಿ ಪರಿಸರ ಜಾಗೃತಿ ಮೂಡಿಸಿ, Mission LiFE (Lifestyle for Environment) — ಪ್ರಧಾನಮಂತ್ರಿಗಳ ಜಾಗತಿಕ ಉಪಕ್ರಮ — ಅಡಿಯಲ್ಲಿನ 7 ಥೀಮ್ ಗಳನ್ನು ಪಾಲಿಸಲು ಶಾಲೆಗಳು ಈ ಕ್ಲಬ್ ಮೂಲಕ ಚಟುವಟಿಕೆ ನಡೆಸುತ್ತವೆ. ಈ ಎಲ್ಲಾ ಚಟುವಟಿಕೆಗಳ ದಾಖಲೆ (ಗಣನ, ಈವೆಂಟ್, ಫೋಟೋ, quiz) ಅಧಿಕೃತ ಪೋರ್ಟಲ್ ecoclubs.education.gov.in ನಲ್ಲಿ ನಮೂದಿಸುವುದು ಕಡ್ಡಾಯ.

🌍 ದೇಶದ ಒಟ್ಟಾರೆ ಭಾಗವಹಿಸುವಿಕೆ (ಪೋರ್ಟಲ್ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್): 36 States/UTs · 836 ಜಿಲ್ಲೆಗಳು · 3,87,251 ಶಾಲೆಗಳು · 9,09,94,374ಕ್ಕೂ ಹೆಚ್ಚು ಭಾಗವಹಿಸಿದವರು · 17,65,975 ಈವೆಂಟ್‌ಗಳು · 8,62,31,309 ಪ್ರತಿಜ್ಞೆ (pledges).

⚠️ ಮುಖ್ಯ ಸೂಚನೆ: ಇಲ್ಲಿನ ಮಾಹಿತಿ ಸಾಮಾನ್ಯ ಮಾರ್ಗದರ್ಶಿ ಮಾತ್ರ. ಪ್ರಸ್ತುತ ಅಧಿಕೃತ ನಿಯಮಗಳು, password ಫಾರ್ಮ್ಯಾಟ್ ಮತ್ತು upload deadline ಗಳಿಗಾಗಿ ಅಧಿಕೃತ ಪೋರ್ಟಲ್ ಮತ್ತು ಸಂಬಂಧಿತ ಇಲಾಖೆ ಪರಿಚಲನೆಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.

1. Mission LiFE — 7 ಥೀಮ್‌ಗಳು (ಈ ಚಟುವಟಿಕೆಗಳು ಯಾವುದಕ್ಕೆ?)

#ಥೀಮ್ಶಾಲಾ ಚಟುವಟಿಕೆ ಉದಾಹರಣೆ
1Save Energy (ಶಕ್ತಿ ಉಳಿಸಿ)ವಿದ್ಯುತ್ ಆಫ್ ಅಭಿಯಾನ, LED ಬಳಕೆ, ಸೌರಶಕ್ತಿ ಜಾಗೃತಿ
2Save Water (ನೀರು ಉಳಿಸಿ)ನೀರು ಸೋರಿಕೆ ತಡೆ, ಮಳೆನೀರು ಕೊಯ್ಲು, ನೀರು ಬಳಕೆ ಅಡಿತ್
3Say No To Single-Use PlasticsSUP ನಿಷೇಧ ಅಭಿಯಾನ, ಬಟ್ಟೆ ಚೀಲ/ಜೂಟ್ ಚೀಲ ಬಳಕೆ
4Reduce E-WasteE-waste collection bin, recycler handover
5Reduce Waste, Segregate Wasteತ್ಯಾಜ್ಯ ವಿಂಗಡಣೆ, compost ಪಿಟ್
6Reduce Food WastageMDM/bಿಸಿಯೂಟ ವ್ಯರ್ಥ ರಹಿತ ಅಭಿಯಾನ
7Adopt Healthy Lifestylesನಡಿಗೆ/ಸೈಕಲ್, ಅಂಗನವಾಡಿ ಜೊತೆ ಆರೋಗ್ಯ ಜಾಗೃತಿ

📌 Portal ನಲ್ಲಿ "Learning Material" modules (Class 1–12 ಹಂತಕ್ಕೆ), video, ನಂತರ 10 ಪ್ರಶ್ನೆಗಳ quiz → Certificate ಇರುತ್ತದೆ. ವಿದ್ಯಾರ್ಥಿ/ಶಿಕ್ಷಕ ಇಬ್ಬರಿಗೂ ಪ್ರಯೋಜನಕಾರಿ.

2. ಶಾಲೆಯಲ್ಲಿ Eco Club — ಗಣನ structure (ಯಾರೆಲ್ಲಾ ಸೇರಿಸಬೇಕು)

ಪದನಾಮಯಾರು
Head / Patronಶಾಲಾ ಮುಖ್ಯಸ್ಥ (HM/Principal)
Teacher In-Charge1 ನೋಡಲ್ ಶಿಕ್ಷಕ (ಚಕ್ರ ಕ್ರಮದಲ್ಲಿ)
Eco Club Presidentಅತ್ಯುನ್ನತ ತರಗತಿಯ 1 ಸಕ್ರಿಯ ವಿದ್ಯಾರ್ಥಿ
Membersಪ್ರತಿ ತರಗತಿಯಿಂದ 4–5 ವಿದ್ಯಾರ್ಥಿಗಳು

ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಈ ಮಾಹಿತಿ (ನೋಂದಣಿ notification) ನಮೂದಾಗುವಾಗ: ಶಾಲಾ ಹೆಸರು, ಶಾಲಾ ಪ್ರಕಾರ (ಪ್ರಾಥಮಿಕ/ಉಚ್ಚ ಪ್ರಾಥಮಿಕ/ಮಾಧ್ಯಮಿಕ), HM/Principal ಹೆಸರು, Teacher In-Charge ಹೆಸರು + ಪದವಿ, ವಿದ್ಯಾರ್ಥಿ ಸದಸ್ಯರು ಬೇಕಾಗುತ್ತದೆ.

3. ಪೋರ್ಟಲ್ Login — ಹಂತ ಹಂತವಾಗಿ (ecoclubs.education.gov.in)

  1. ಬ್ರೌಸರ್‌ನಲ್ಲಿ ತೆರೆಯಿರಿ: ecoclubs.education.gov.in → ಮೇಲೆ Login ಬಟನ್.
  2. User ID: ನಿಮ್ಮ ಶಾಲೆಯ UDISE code (ಅಥವಾ ಪೋರ್ಟಲ್‌ನ ನೀಡಿದ User ID) ದಾಖಲಿಸಿ.
  3. OTP Login (ಸಾಮಾನ್ಯ): ನೋಂದಾಯಿತ mobile/email ಗೆ ಬರುವ OTP ಭರ್ತಿ → Login.
  4. ಪಾಸ್‌ವರ್ಡ್ ಬದಲಾವಣೆ: ಮೊದಲ ಬಾರಿಗೆ ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ (8–15 ಅಕ್ಷರ, ವಿಶೇಷ ಚಿಹ್ನೆ ಸಹಿತ) ಸೆಟ್ ಮಾಡುವಂತೆ ಕೇಳುತ್ತದೆ → Save/Submit.
  5. Eco Club Formation: "Click here to go to Eco Club Formation for Mission LiFE landing page" ಒತ್ತಿ → ಮೇಲಿನ structure ಅನುಸಾರ ಗಣನ ಪ್ರಮಾಣಪತ್ರ/notification PDF ನಲ್ಲಿ upload ಮಾಡಿ.
  6. ಭಾಗವಹಿಸುವಿಕೆ ನಮೂದು: ಚಟುವಟಿಕೆಗಳ data, ಫೋಟೋ/ವೀಡಿಯೋ day-wise ಅಪ್‌ಲೋಡ್, E-waste items ಪಟ್ಟಿ — ನಿಗದಿತ ಟ್ಯಾಬ್‌ಗಳಲ್ಲಿ.

🔑 Password ಸಿಗದಿದ್ದರೆ: ಕೆಲ ರಾಜ್ಯಗಳಲ್ಲಿ default password UDISE code ಅಥವಾ 'admin' ಆಗಿರಬಹುದು. ಮೊದಲಿಗೆ Official login ನಲ್ಲಿ Forgot Password ಪ್ರಯತ್ನಿಸಿ; ಸಾಧ್ಯವಾಗದಿದ್ದರೆ ರಾಜ್ಯ/ಜಿಲ್ಲಾ ನೋಡಲ್ ಅಧಿಕಾರಿ ಅಥವಾ ಹೆಲ್ಪ್‌ಲೈನ್ (ಕೆಳಗೆ) contact ಮಾಡಿ.

4. ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಏನೇನು ಮಾಡಬಹುದು (Portal Features)

  • Learning Material: Class 1–12 ರ ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ Lesson Modules.
  • Video + Quiz + Certificate: ಮಾಡ್ಯೂಲ್ ಮುಗಿಸಿ 10 ಪ್ರಶ್ನೆಗಳ quiz ಗೆ ಉತ್ತರಿಸಿ certificate ಪಡೆಯುವುದು.
  • SWM (Solid Waste Management) Events: ಶಾಲೆಯ ಚಟುವಟಿಕೆಗಳು + ಫೋಟೋ ಅಪ್‌ಲೋಡ್.
  • E-Waste Collection in Schools: ಸಂಗ್ರಹಿಸಿದ items ವಿವರ + ಫೋಟೋ ಅಪ್‌ಲೋಡ್.
  • ಪ್ರತಿಜ್ಞೆ (Pledge): ವಿದ್ಯಾರ್ಥಿ/ಶಿಕ್ಷಕರ e-pledge ದಾಖಲೆ.
  • ಹೆಲ್ಪ್/ಟ್ರೈನಿಂಗ್: ವರ್ಗ ಅವಧಿಗಳಲ್ಲಿ online handholding ಸತ್ರಗಳ ಲಿಂಕ್ ಪೋರ್ಟಲ್ ಮುಖಪುಟದಲ್ಲಿ ಕಾಣಿಸುತ್ತದೆ.

5. ಶಾಲಾ ಚಟುವಟಿಕೆ ಸಲಹೆಗಳು (ವರ್ಷ ಪೂರ್ತಿ)

  • ವೃಕ್ಷಾರೋಪಣ, ಶಾಲಾ ತೋಟ/ಗಿಡ ನರ್ಸರಿ.
  • ಪ್ಲಾಸ್ಟಿಕ್ ಮುಕ್ತ ಶಾಲಾ ಆಂದೋಲನ (SUP ಹೊರತೆಗೆಯುವಿಕೆ).
  • ನೀರು ಸಂರಕ್ಷಣೆ — ಸೋರುವ ಬಿಳಿ ಸರಿಪಡಿಸಿ, ಮಳೆನೀರು ಕೊಯ್ಲು ಯೋಜನೆ.
  • E-waste collection bin ನಿರ್ವಹಣೆ → CPCB/SPCB ಪ್ರಮಾಣೀಕೃತ recycler ಗೆ handover (E-waste Rules 2022).
  • ತ್ಯಾಜ್ಯ ವಿಂಗಡಣೆ, compost ಒಡೆತನ, MDM ನಲ್ಲಿ ಆಹಾರ ವ್ಯರ್ಥ ಕಡಿತ.
  • ನುಕ್ಕಡ್ ನಾಟಕ, ವಿಚಾರಗೋಷ್ಠಿ, ಚಿತ್ರಕಲೆ/ಸ್ಲೋಗನ್ ಸ್ಪರ್ಧೆ.
  • ಸ್ಥಳೀಯ ಸಂಸ್ಥೆ/ಪಂಚಾಯತ್ ಜೊತೆ ಜಾಗೃತಿ ಕಾರ್ಯಕ್ರಮ.
  • #SpecialCampaign6 / #EcoClubsForMissionLiFE hashtag ನೊಂದಿಗೆ social media ನಲ್ಲಿ ಪ್ರಕಟಣೆ.

6. ಫೋಟೋ / Data Upload — ಸಲಹೆಗಳು 📸

📌 ಪ್ರತಿದಿನದ ಚಟುವಟಿಕೆಯ ನಂತರ: (1) portal ನಲ್ಲಿ ಚಟುವಟಿಕೆ ವಿವರ + ಫೋಟೋ/ವೀಡಿಯೋ, (2) ಭಾಗವಹಿಸಿದ ವಿದ್ಯಾರ್ಥಿಗಳ ಸಂಖ್ಯೆ, (3) E-waste ಇದ್ದರೆ item ಪಟ್ಟಿ + kg — ಒಟ್ಟಿಗೆ ದಾಖಲಿಸಿ. ಫೋಟೋ ಫೈಲ್ ಹೆಸರಿಗೆ ಶಾಲಾ ಹೆಸರು/UDISE code ಸೇರಿಸಿ. ಅಪ್‌ಲೋಡ್ ಯಶಸ್ಸಿನ ನಂತರ screen-shot ಇಟ್ಟುಕೊಳ್ಳಿ — ತಪಾಸಣೆ/ವರದಿ ಸಮಯದಲ್ಲಿ ಸುಲಭ.

🛰️ Portalನಲ್ಲಿ "Geo-Tagged Photo" ಬೇಕಾದರೆ: ಫೋಟೋಗೆ GPS (Latitude/Longitude) ಸೇರಿಸಲು ನಮ್ಮ ಉಚಿತ tool ಬಳಸಿ — ಫೋಟೋ Geo-Tag Tool → (ಫೋಟೋ selected ತೊಗೊಂಡು, ಸ್ಥಳ ಹಾಕಿ, GPS ಸೇರಿದ JPG download ಮಾಡಿ, ನಂತರ portal ಗೆ upload ಮಾಡಿ.)

7. ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು & ಪರಿಹಾರ

ಸಮಸ್ಯೆಪರಿಹಾರ
Login ಆಗುತ್ತಿಲ್ಲ / OTP ಬರುವುದಿಲ್ಲUDISE code ಸರಿ ನೋಡಿ; OTP ಡಿಸಲ್‌ಬಲ್ ಆಗಿದ್ದರೆ email/spam check; ಇಲ್ಲದಿದ್ದರೆ Forgot Password ಅಥವಾ ಹೆಲ್ಪ್‌ಲೈನ್.
ಪಾಸ್‌ವರ್ಡ್ ಯಾವುದು?ಕೆಲ ರಾಜ್ಯಗಳಲ್ಲಿ default = UDISE code/admin; ಇಲ್ಲದಿದ್ದರೆ mobile/email ನೋಂದಾಯಿತ OTP ಮೂಲಕ ಹೊಸ ಪಾಸ್‌ವರ್ಡ್ ಸೆಟ್ ಮಾಡಿ.
Upload deadline ಮುಗಿದಿದ್ದರೆ?ಪೋರ್ಟಲ್ ತೆರೆದು ನಿಜವಾದ deadline ಪರಿಶೀಲಿಸಿ; ಮುಗಿದಿದ್ದರೆ ರಾಜ್ಯ ಇಲಾಖಾ ಪರಿಚಲನೆ ಪ್ರಕಾರ ನಡೆಯಿರಿ — ಕೆಲವೊಮ್ಮೆ extension ಬರಬಹುದು.
ಗಣನ ಪ್ರಮಾಣಪತ್ರ ಫಾರ್ಮ್ಯಾಟ್?ಪೋರ್ಟಲ್/ರಾಜ್ಯ ಸೂಚನೆಯಲ್ಲಿ ಕೊಟ್ಟ ಪ್ರಾರೂಪದಲ್ಲಿ ಶಾಲಾ ಹೆಸರು, HM, Teacher In-Charge, ಸದಸ್ಯರು — PDF ಆಗಿ upload.
E-waste ಸಂಗ್ರಹ ಸುರಕ್ಷತೆ?ಬ್ಯಾಟರಿ, ಮುರಿದ ಸಂಕೀರ್ಣ device ಮಕ್ಕಳು ಮುಟ್ಟಬಾರದು; ಆಧಿಕೃತ recycler ಮೂಲಕವೇ handover (zero dismantling).

8. FAQ — ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

1. Eco Club ಗಣನ ಕಡ್ಡಾಯವೇ?

ಅನೇಕ ರಾಜ್ಯಗಳಲ್ಲಿ ಎಲ್ಲಾ ಸರ್ಕಾರಿ/ಸಹಾಯ ಪಡೆದ ಶಾಲೆಗಳಿಗೆ ಕಡ್ಡಾಯ. ನಿಮ್ಮ ರಾಜ್ಯದ ಪರಿಚಲನೆ ಪರಿಶೀಲಿಸಿ.

2. Portal ನಲ್ಲಿ ಏನೆಲ್ಲಾ upload ಮಾಡಬೇಕು?

Eco Club ಗಣನ notification/ಪ್ರಮಾಣಪತ್ರ, ಚಟುವಟಿಕೆ ವಿವರ, ಫೋಟೋ/ವೀಡಿಯೋ, E-waste item ಪಟ್ಟಿ, quiz/pledge ದಾಖಲೆ — ಪೋರ್ಟಲ್ ಟ್ಯಾಬ್ ಪ್ರಕಾರ.

3. ವಿದ್ಯಾರ್ಥಿ quiz certificate ನಿಜವಾಗಿಯೇ ಸಿಗುತ್ತದೆಯೇ?

ಹೌದು — Learning material ಓದಿ, video ನೋಡಿ, 10 ಪ್ರಶ್ನೆಗಳ quiz ಪೂರ್ಣಗೊಳಿಸಿದವರಿಗೆ certificate ನೀಡಲಾಗುತ್ತದೆ ಎಂದು ಅಧಿಕೃತ ಪೋರ್ಟಲ್ ಪ್ರಕಟಿಸಿದೆ.

4. 1–5 ತರಗತಿ ವಿದ್ಯಾರ್ಥಿಗಳು ಸೆರೆಯಾಗಬಹುದೇ?

ಕೆಲ ಶಾಲೆಗಳಲ್ಲಿ ಅಂಗವಿಧಿ ನಡೆಸಲು ಸಾಮಾನ್ಯ ಚಟುವಟಿಕೆಗಳಲ್ಲಿ ಭಾಗವಹಿಸಬಹುದು; ಅಧಿಕೃತ ಸದಸ್ಯರನ್ನು ಸಾಮಾನ್ಯವಾಗಿ 6+ ತರಗತಿಯಿಂದ. ರಾಜ್ಯ ಸೂಚನೆ ನೋಡಿ.

5. ಚಟುವಟಿಕೆಗೆ ಹಣ ಬೇಕೇ?

ಬೇಕಾದ ಚಟುವಟಿಕೆ ನಡೆಸಲು ಸಮಗ್ರ ಶಿಕ್ಷಣ ಬಜೆಟ್‌ನಲ್ಲಿ Eco Club ಗೆ ಪ್ರತಿ ಶಾಲೆಗೆ ನಿಗದಿತ ಮೊತ್ತ ಮಂಜೂರಾಗುತ್ತದೆ (ಉದಾ. ಕೆಲ ರಾಜ್ಯದಲ್ಲಿ ವರ್ಷಕ್ಕೆ ₹5000) — ರಾಜ್ಯ ಪರಿಚಲನೆ ನೋಡಿ.
